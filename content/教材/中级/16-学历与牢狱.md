# 学历与牢狱

本章合讲两个专题：**学历**（读书的高低、文理方向）与**牢狱**（犯罪特征、入狱、出狱）。两者都靠「做功」判断：学历看印、官杀、食神是否做功；牢狱看是否出现「反局」与阴阳失衡。

## 一、学历：判断的神

### 1. 各神的含义

| 神 | 对学历的意义 | 要点 |
|---|---|---|
| 官杀 | 身份的象征；七杀还有聪明与勤奋 | 官配印；杀要么配印，要么被制服；杀无制化反凶顽 |
| 印 | 学业、本事 | 必须**做功**才表示学历；不做功＝懒惰不好学、笨、不开化 |
| 食神 | 思想、思考，主学习好 | |
| 财 | 欲望之星，一般学习最忌（心乱、贪恋女色金钱） | 只有印太旺需财克印时，反有上进之意 |
| 伤官 | 不守规矩、不爱学教科书；但聪明多能 | 伤官配印做功，或配官杀做功，都学有所成；伤官配财、配比劫不学习 |
| 比劫 | 好动，争斗，结伙成群 | 一般主不思学习，劫财尤甚 |

**学历之神**：官杀、印、食神。**破坏学历之神**：财、伤官（无制）、比劫。

### 2. 文理区别

| 方向 | 象 |
|---|---|
| 金水主理，木火主文 | 基本原则 |
| 数学 | 庚、申、戌、亥（戌主数学，亥为数字） |
| 化学 | 申子辰结合 |
| 法律 | 申酉金加丑 |
| 中文 | 寅卯配火；食神为中文或外语 |
| 理科 | 官杀 |

### 3. 学历判断的步骤

先看**印与官杀、食神**哪个做功（制化是否干净）；再看**破坏之神**（财、比劫、伤官）有没有坏印；最后看**大运**是否配合（少年行印运、官杀运则好，行比劫财运则差）。从格局到象到事：先定格局高低，再看象（文理方向），再落到具体学历。

> - 伤官配印做功，应学文；杀印伤都有功，木火主文，庚金没被制尽，也可学文类。

## 三、牢狱之灾的看法

### 1. 五类基本信号

1. **阴制阳**：亥水、丑土、辰土是十二支中阴的地支，有牢狱象；八字中有阳性的有用的东西被这些坏了，可能牢狱。阳制阴不为牢狱。
2. **水多金沉**为牢狱。
3. **枭神夺食**为牢狱：食伤是重要做功之神，被枭神克夺＝失去自由。
4. **劫财、伤官组合**：主结伙违法，再与官杀对抗必牢狱。
5. **反局**：凡出现反局，局中有辰、丑等字，多数应牢狱。

### 2. 犯罪的特征

- **伤官与官杀不和**为牢狱之征：日主的想法与做法与法律相冲。食伤得旺，自以为是，失去自我约束，但必须是**官出现之年**才产生牢狱之灾——官星不出现时不会意识到官的厉害。
- **比劫伤官组合**：口诀「比劫本是无知物，一遇伤官势必归」——比劫见伤官去生伤官，有伤官心性，都听伤官的。
- **伤食与官杀对抗**（注意是**对抗**而不是制；制去了就不是）。
- **七杀无制、夹制日主**：也是犯罪结构。
- **比劫抗杀**，或比劫成林抗杀：对抗法律。
- **劫财为手，官为盗贼，劫财与官在主位组合**＝小偷。
- **黑道的两种组合**：①劫伤组合（拉帮结派）；②伤食与官杀对抗。
- 「婚不顺者女命多，牢狱之灾者男命多。」

### 3. 反局：入狱的核心机制

原局本是「制」的结构（冲、制），大运或流年把它变成**合**（冲制不喜合，合则反）；或功神被坏；或「主位逢冲，宾位合」的**冲合反局**。大部分反局结构都主牢狱，且丑土、辰土本身也为牢狱。**流年局部反局**（搅局）也可坐牢，但时间短。

### 4. 出狱的看法

- **日主得禄之年**，或日主**合出、冲出**日主之年出狱；
- 牢狱为库者，**冲、穿坏了库**为出狱（冲穿）；
- 辰运入狱，辰酉合**闭辰库**，亦为出狱。

## 四、牢狱命例

### 1. 比劫伤官怕见官

**乾造**：甲丁乙庚／寅卯丑辰

大运：辰 巳 午 未 申 酉

己巳运壬申年因抢劫判五年。日主合时上庚官（官要用），但木火成势制庚金，原局本身反局；比劫与寅中伤官成势、拉帮结派，伤官藏在寅中，表示主谋不是他。壬申年庚官见禄，官旺；申为法律、公家。**无劫甲透出，则无事。**

**乾造**：甲丁丙己／辰丑寅亥

大运：寅 卯 辰 巳

杀人犯，判死刑。寅印被辰丑土晦制（晦寅中丙火），寅亥合灭寅中丙火；辛巳运的巳运，巳火禄出现，被辰丑晦、被亥冲，又穿寅印。癸酉年被捕（癸杀为忌，坐印透干不可见七杀），甲戌年枪决。丙寅为阳，辰丑亥为阴，以阴灭阳，本质坏。

**乾造**：戊壬己戊／申戌巳辰

大运：亥 子 丑 寅 卯 辰 巳

杀人犯。巳火印被辰土晦制，戌冲辰制不净，被湿土坏掉；巳申合，戌辰冲，八字反局；巳到被辰晦又入戌墓。己戊申是比劫伤官拉帮结派。

### 2. 冲合反局

**乾造**：己壬己乙／巳申未丑

大运：未 午 巳 辰 卯 寅 丑

未冲丑本意制财，但巳申合变成制印之义，成了冲合反局：主位逢冲宾位合的结构。湿土金与燥土火交叉出现，年月合，日时冲；申为法律；癸未年三刑戌丑未为牢狱，应期在见丑之年。

**坤造**：辛乙辛庚／丑未酉子

辛酉见丑入墓＝结党黑社会，黑财；金水有势冲制未财库，乙未＝烟草，做假烟（也可想象为假药）；庚子运金见水沉，有牢狱。

### 3. 因财、贪污入狱

**乾造**：戊丙壬戊／戌辰申申

大运：巳 午 未 申 酉 戌 亥

申辰拱水，金水成气，丙火财星虚透为才华；年上戊戌七杀太重无制，杀无制就是犯罪结构，又坐财库。月令辰为劫财库，冲财库是通过劫财方式取财而犯罪。温岭市政府办公室主任受贿42万元，癸未年入狱判9年。辛酉运与月柱丙辰天地合，财合印，印合杀，闭了劫财库，酉戌穿倒戌墓为入狱信息；癸未年戊癸合，杀合劫为应期。

**乾造**：丙辛丙癸／申丑申巳

大运：壬 癸 甲 乙 丙（寅卯辰巳午）

禄头官，当官命。日丙见巳为禄，巳中戊克合癸官，得官；月上辛财，丙合之，巳申合。乙巳运升副县长，贪财百万；丙午运午穿丑，反局，甲申年判刑。理由：①以阴制阳；②午运反局，见丑。

**乾造**：壬己癸辛／申酉巳酉

大运：戌 亥 子 丑 寅 卯

金融诈骗犯。巳为财在坐下，癸巳自合，巳申合、巳酉合把印换象看成财。丑运众金入墓，巳酉丑三合，钱入口袋；甲运合去己官，没人管，非法集资；寅运寅冲申、穿巳，做功状态改变，反局，坐牢，财产没收。

**乾造**：戊己癸己／申未巳未

大运：申 酉 戌 亥 子

上海庄家，数十亿资产。双杀夹克身，有官灾之象；癸亥运乙酉年牢灾（癸为自己到，乙年为杀到）。

**乾造**：乙己壬辛／巳丑辰丑

大运：子 亥 戌 酉 申 未

辰丑有牢象，阳被阴晦；戌运冲辰发财四亿，乙酉运之乙运第一年被捕，判十年（乙表辰到，辛克乙，资产全没）。

### 4. 杀人、重罪

**乾造**：乙乙庚丙／酉酉寅戌

大运：申 未 午 巳 辰 卯 寅

羊刃酉金穿戌土杀库，戌为火库、枪库；己卯运己卯年因杀人被枪毙（共杀 20 多人）。羊刃众与官杀对抗，戌穿酉为杀人；卯合戌引动。

**乾造**：丁丙丙丁／酉午戌酉

戴笠造。酉金萧杀之象，秋风扫落叶，表死人；自坐杀库穿了酉，表杀人无数。

**乾造**：丙丙丙丁／申申辰酉

名中医：丙火名气，丁火为名也为玄学；辰为食伤＝中药；酉＝病人。

**乾造**：戊丙甲丙／申辰寅寅

大运：丁 戊 己 庚 辛 壬 癸（巳午未申酉戌亥），75年7岁起运

太原黑社会老大。丙火文化在天干（记忆力超常，能记住 1000 多个电话）；寅木禄冲制年上申金七杀，七杀有原神，禄与七杀对抗＝犯罪结构。己未运未穿申，合财得财；庚申运七杀到，被抓，乙酉年亥月枪毙。甲为死木，怕长生。

**乾造**：甲癸甲壬／寅酉子申

大运：戌 亥 子 丑 寅 卯

2004年甲申年杀人后枪决。比肩抗杀＝犯罪象；癸水生年上甲，甲通根寅，寅可看作日主之根，申冲寅，根被坏；冲禄；七杀羊刃为枪，金也为枪，年上为公家的枪；亥月死（冲怕合）。

**乾造**：乙己甲辛／酉卯戌未

一岁运：戊 丁 丙 乙（寅丑子亥）

丁丑大运癸卯流年，19岁，强奸罪坐牢十七年。戌为伤官库，穿年支酉官星：劫财伤官穿官；甲己合财（女人），伤官代表放纵。酉官原局弱形不成对抗，丑运助起酉官形成对抗。

**坤造**：辛己己戊／卯亥巳辰

大运：庚 辛 壬 癸 甲（子丑寅卯辰），四岁起运

甲辰运买彩票为名骗朋友 300 万，癸未年拘留，甲申年判刑 20 年。亥辰牢狱星，巳火阳被阴晦；卯能生巳，怕辰运穿倒卯；癸到辰到。

**乾造**：壬癸辛庚／寅丑未寅

大运：寅 卯 辰 巳 午 未 申 酉

「比劫本是无知物，一遇伤官势必归」。丙辰运癸亥年入狱：丙官合身，伤官食神入辰墓；辰丑一党牢象，坏了八字中阳性。丑未冲开财库本发财，但辰运来食伤入墓＝失去自由，不能与外界联系。食伤虚透为胡说八道，杂现为骗子结构。入狱 10 年，癸酉年辰酉合，闭辰库，出狱。32–42岁丁巳运伤食怕杀又走杀运，寅巳穿穿财，牢狱官司不断。入狱三条理由：①比劫伤官同见又行官杀运；②走辰运坏了八字中的阳性；③食神入墓。

**乾造**：甲戊戊癸／寅辰子丑

大运：巳 午 未 申 酉 戌 亥

少年犯。一辈子穷命：年上七杀无制，比劫一片抗杀，对抗法律。己巳运犯罪（巳禄穿寅杀）；戊辰年犯罪（辰晦巳禄）；庚午年坐牢（午印受辰丑晦，子冲午），判 20 年，辛运出来。三条理由：①比劫成林抗杀；②印巳穿了寅杀；③以阴灭阳。

### 5. 大运反局、流年搅局

**乾造**：戊甲辛癸／申寅卯巳

大运：卯 辰 巳 午 未

原局效率高，制去申金。丙辰运辰合申、穿卯，大运反局，坐牢五年。

**乾造**：丙辛己辛／午丑卯未

大运：寅 卯 辰 巳 午 未

杀库制食神库，当大官的命；但甲辰大运十年牢灾：甲合身，本去制别人的反了；辰收丑土藏起来，也反了。

**乾造**：丙辛戊戊／午丑戌午

癸未年坐牢一年。戌刑丑制得好，未来搅局，反局；控制上百亿的老总，辛丑一柱在月令，天干地支都治，大财（公家的）。

**乾造**：庚己丙壬／戌丑辰辰

大运：庚 辛 壬 癸 甲 乙（寅卯辰巳午未），72年起运

二十亿资产的电厂矿山老板。壬辰运大电厂厂长；癸运癸未年戌丑未三刑搅局，流年反局，坐牢半年。

**乾造**：丁癸乙甲／未丑酉申

金水成势制未库，小官；酉运丙戌年丑未戌三刑搅局，流年局部反局，媒体曝光违法乱纪。

### 6. 小偷与盗贼

**乾造**：辛丙己甲／亥申丑戌

大运：未 午 巳 辰 卯 寅 丑

小偷。甲己合，甲下戌为比劫为体（主位的体要用），但金水成势反把戌刑坏，八字反局，见丑有牢狱；比劫在时为手，用官坏官＝跟官对着干。天干想求官，地支想求财，有反局之意；时上比劫主手，用手偷。

**乾造**：乙己庚己／酉卯子卯

专偷自行车和摩托车（酉在年上主腿脚）。乙庚合作功，用酉劫财，反局；卯酉冲对抗，金见水沉，子卯破不做功：牢狱命。

## 本章小结

**学历**

1. 学历之神：官杀、印、食神；破坏之神：财、伤官、比劫。印必须做功；官配印，杀要配印或被制；伤官必须配印或官杀。
2. 金水主理，木火主文；庚申戌亥为数学，申子辰为化学，申酉加丑为法律，寅卯配火为中文。
3. 食神（印）被制干净、杀印俱有功，学历高；比劫无制、印被财坏，学历低。

**牢狱**

1. 阴制阳（亥、丑、辰）、水多金沉、枭夺食、劫伤组合对抗官杀、反局。
2. 犯罪特征：伤官与官杀对抗（不是制）；食伤得旺自以为是；官出现之年才出事。
3. 出狱：日主得禄、合出冲出日主；冲穿坏库；辰库被酉合闭。

**自测**

1. 判断学历高低看哪几个神？印不做功意味着什么？

<details><summary>答案</summary>看官杀、印、食神；破坏者为财、伤官、比劫。印不做功＝懒惰、不好学、笨、不开化。</details>

2. 牢狱的五类基本信号是什么？

<details><summary>答案</summary>阴（亥丑辰）制阳；水多金沉；枭神夺食；劫财伤官组合与官杀对抗；反局且局中有辰丑等字。</details>

3. 黑道的两种组合？

<details><summary>答案</summary>①劫财伤官组合（拉帮结派）；②伤食与官杀对抗（注意是对抗不是制）。</details>

4. 出狱的应期有哪些？

<details><summary>答案</summary>日主得禄之年；合出或冲出日主之年；冲穿坏牢狱库之年；辰库被酉合闭之年。</details>

5. 乙乙庚丙／酉酉寅戌为何被枪毙，应期在哪？

<details><summary>答案</summary>羊刃酉金穿戌杀库（枪库），羊刃众与官杀对抗，为杀人命；己卯运己卯年卯合戌引动。</details>
