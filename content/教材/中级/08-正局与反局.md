# 正局与反局

> 本章要解决的问题：一个盘里“日柱做的功”与“整个盘的意思”是否一致？一致是正局，相反是反局。反局落在哪里，哪里就凶。

## 一、基本概念

- **正局**：日柱做功，所表达的意思与原局整体的意思一致。八字无势、只有日主自己能做功，也算正局。
- **反局**：日柱做功所表达的意思与原局整体的意思相反，主凶。
- 反局按出现位置分三类：**原局反局**（原局本身凶）、**大运反局**（该步大运凶，过运则吉）、**流年反局**（该年凶）。
- 大运、流年又各有一种特殊形式——**冲合反局**（见第四节）。

> 口诀：日柱之意随大势为正，逆大势为反；反在哪一类，凶在哪一类。

## 二、如何判定原局的正反

### 1. 判定顺序

1. **先看日主**。日主不合、不生（不做功），就不看日主，转看日支。
2. **日支做功有方向**：日支所**追求**的东西，若与八字整体的“势”对抗，就是反局。注意不是“日支这个字与势对抗”，而是“日支表达的意图”与势对抗。
3. **日主与日支同时做功**：比较两者的意思，一致为正局，不一致为反局，**以日主之功为主**，不以日支为主。日主合到哪里就要看到哪里（官为统领，带着自己的坐支），再看这个坐支有没有做功，做的功就是日主自己做的功。
4. **年月与日时有冲合对立**：见第四节。

**例（日支合顺势）**：己己辛甲／卯巳亥午。日支亥与午合，合去伤官，日支的意向正是整局“制伤官”的方向，所以是**正局**。

### 2. 日合官：合年月官与合时官，意思不同

| 日主合到 | 含义 | 要点 |
|---|---|---|
| 年、月上的官 | 我去**管理、控制**别人 | 主动，一般不构成问题 |
| 时上的官 | 我被**管理、控制**，头脑受制于人 | 被动；官即代表我的意向 |

时柱是主位，主一个人的头脑。时干坐官，等于官星控制了我的头脑，官的意向就是我的意向。一柱之内**干是统帅、支是兵卒**，统帅打仗必须用兵卒，所以此时**时支必须用、不可坏**。

特别要记住：只有**己日主配甲戌时、辛日主配丙申时**，必须用时支且不可坏——因为这两个时支（戌对己、申对辛）是劫财，是“体”；**体不可坏，用才可坏**。

**例一（反局：用的时支被日支刑坏）**

**乾造**：辛丙己甲／亥申丑戌

己日合时上甲官，即被甲戌一柱控制，必须用甲坐下的戌。但日支丑借年月金水之势刑戌，坏了戌，反局。时为门户，戌是劫财（手），丑中癸水为暗财，丑又主阴暗、小偷，申与丑的组合主犯罪牢狱，此人常坐牢。丑本是钱库，被一刑就空了，发不了大财（自己制财才得财，这里是自己被财制，所以不得财）。

对照：同一组合如果甲戌官在**月**上（辛亥 甲戌 己丑），日主合月上官是“管理控制别人”，不要求用戌，不构成反局。

**例二（反局：时支被局中官合坏）**

**乾造**：乙庚辛丙／巳辰卯申

辛日合丙官，要用坐下的申（劫财）。但申不能制官，反被局中巳火官（巳申合）拴住，反局。主牢狱之灾：学生时因偷几本书被关一年，恰逢严打，是丙寅年应事。因原局金水有势，所以只是短暂的牢狱。他本人没有官，是个教师。

**例三（换一个时柱，意思就变）**

**乾造**：乙庚辛壬／巳辰卯辰

时柱换成壬辰，巳火泄于辰土，伤官制官，不再是“合时官”结构，丙子运升正处级。（此造父亲早亡，应期见第九章。）

### 3. 日合年月官的正局例

**乾造**：甲戊癸己／辰辰卯未

日支意向：食神卯与未拱旺、穿制辰官；因是用财的原神去制官，所以是与钱有关的官。日主戊合月令癸，是“管理、控制”之意，所以不算反局。此人是银行某支行行长：官不大但权很大，属企业之官。

**乾造**：戊壬丁丁／辰戌丑未

朱元璋造。日主丁合月令壬官，是管理控制之意；戌冲辰、刑丑，丑未冲，把官库财库全部制住——制了就要得到，所以是皇帝命。日主与日支意向一致，**正局**。（学员批注的理解：火与燥土势大，去湿土库，故为正局。）

## 三、连体不可坏

两个字“连成一体”（如戊生申、戊申一柱；金水连体），这个体就是“用”，**不可被坏**，坏则反局，严重者伤寿。

**乾造**：壬戊辛戊／寅申巳戌

原局火土成势制金，巳申合本是去金，但戊申一柱中，戊生申、辛与申因戊相连成连体金，此金是“用”，不可坏。巳申合坏了它，反局。此人为电工，壬申年被电打死。（原稿同列另一造丁戊辛丁／未申未巳，同属此类，庚辰年死于车祸；该盘干支不合历法，待校，此处只取断法。）

**乾造**：甲癸辛己／午酉卯亥

辛酉月辛日连体。原局金水成势去木火，连体的酉金是用。己卯运丙戌年戌穿酉（穿了禄），流年反局，五一前后车祸而亡。该造甲午带象（午=己），为官带财帽，曾任财政局副局长，丁丑运最好。

**乾造**：庚庚庚戊／子辰辰寅

金水连体，伤官子水是用。后来走未运，未穿子，用被穿坏，中毒、大病多次。

**对比（不连体则可制）**

**乾造**：辛丙辛癸／卯申未巳

李宗仁造。辛金日主不受生，日主合月令丙官，坐下申是劫财（军队，在月令，主大的军队集团）；巳申合制劫财，是主位的官做功，管理军队的大官。申与日主不连体，可以制，**正局**。

> 判断连体的要点：看被制的字与日主（或用神位）之间有无生、通根相连。连体则制之为反，不连体则制之为正。

## 四、冲合反局

“合”与“冲”是两种相反的做功方式。若整个盘里一边合、一边冲，就把自己弄乱了，称冲合反局。冲合反局比较少见。

### 1. 原局冲合反局

- 不是日元日支的问题，而是**年月与日时两党**表达相反：年月合而日时冲，或年月冲而日时合，都要细查。
- 必须是**地支与地支**的冲合才算；干合支冲不算反局。
- 关键看两党排列：把盘分成两党（A 党、B 党），

| 排列 | 名称 | 是否反局 |
|---|---|---|
| A B A B（两党交叉间隔） | 交叉 | **反局** |
| A B B A（一党在内、一党在外） | 内外 | 不反 |
| A A B B（一党在左、一党在右） | 左右 | 不反 |

内外、左右结构表示“里制外”“主制宾”，一冲一合只是对外手段不同，意向一致，所以不反。

**例一（交叉：反局，一生坐牢）**

**乾造**：己壬己乙／巳申未丑

火土一党（巳、未、己己），金水一党（申、丑、壬、乙），交叉排列：年月巳申合，日时未丑冲，两种势力对抗。比肩与七杀对抗，官反局；前面合住、后面冲，对抗就要被逮。丑中含财，头上顶官，是公家的财；未冲丑，是用比劫取丑中之财；巳申一合又把己抓住，申金伤官有公安之象，申丑组合主边犯罪边坐牢。一辈子坐牢，癸未年归案。

对照：把位置改成“申巳未丑”（内外）或“丑申未巳”（左右），都不是反局。

**例二（交叉：财反局，穷）**

**乾造**：戊丁戊戊／申巳子午

初看火土有势、去财与财的原神申，似乎大富。但日时子午冲，年月巳申合，火土与金水两党交叉，一冲一合，主宾做功方式相反，财星反局，**哪方面反局哪方面凶**：此人极穷，一年收入不足五千，养活三四口，干苦力。

**例三（内外或左右：不反）**

**乾造**：乙癸己壬／巳未丑申

火土一党在左（巳未），金水一党在右（丑申），左右结构：主位一党、宾位一党，主位用、宾位体，要制宾，表述一致，不反。亿万富豪。丙戌年戌与未丑三刑，坏了冲，轻则官司。

**坤造**：丁癸丙辛／未丑申卯

年月未丑冲、日时申卯合，但金水（丑、申）在内、木火（未、卯）在外，内外结构：用里面的制外面的，意思清楚，不反。学历高、在大学任官。第一任丈夫癸是短暂的，申（中含壬水）夫星得正位是长久的第二任丈夫，申卯合做功，第二次婚姻好且长久。（得正位的星是长久的夫或妻。）

### 2. 岁运冲合反局

原局有**明确的制**（冲或合）时，最怕大运流年用相反的方式来破：原局冲做功，怕岁运来合；原局合做功，怕岁运来冲。原局没有明确的制，则不怕。

**例一（运合坏冲）**

**乾造**：庚己丙乙／申丑申未

大运：庚寅 辛卯 壬辰 癸巳（原稿只记地支 寅卯辰巳，干按月柱顺排）

原局两申入丑墓、冲未（去印库），冲做功。辛卯运卯申合：合了申，申从丑中来、卯从未中引出，本来冲做功变成合，反局。庚为父，卯为父之财，卯运父亲破财（父欠债自杀，父债子还）。若是寅运则不反。注意：原局乙庚合（天干合）与丑未冲（地支冲）不构成反局，只有卯运地支上又冲又合才反。

**例二（流年与大运天地合，反冲）**

**坤造**：癸乙辛己／卯丑未丑

大运：丙寅 丁卯 戊辰 己巳 庚午（原稿只记地支 寅卯辰巳午）

原局丑未冲制财库，发大财，做汽车销售。己巳运甲申年，大运己与流年甲合、巳与申合，天地合绊，原局冲被合住，反局。巳是未的党，申是丑的党，原局相冲为吉，岁运逢合则凶。甲为头、申为脊柱，一合绊，身体不能动、大脑不能思考，严重车祸成植物人。

**例三（流年申合卯，破穿制）**

**乾造**：癸丙戊丙／卯辰子辰

大运：乙卯 甲寅 癸丑 壬子 辛亥 庚戌（原稿只记地支 卯寅丑子亥戌，干按月柱逆排）

原局靠两辰穿制卯做功（官带财），两辰能把卯穿住（只有一个辰反被卯穿坏）。子水财被两辰夹住不做功，所以是管理国企的官，不是自己的企业。壬子运甲申年，申入辰子水党，又与卯暗合，冲合反局，且申带甲木官杀，官灾：审查三个月后证明被陷害，释放，辞职转私企。甲木虚透，所以最终无事。壬申年（丑运）无事，因申入丑墓，不起作用。

> 第二年乙酉，卯酉冲，不再反，所以平反。

**例四（同类企业家）**

**乾造**：癸丙戊甲／卯辰申子

内食神格，乡镇企业集团。申与卯合是主位做功（好）。不喜甲木透干克身。癸未年被纪检带走三个月，是政治斗争的替罪羊。官星高透克身，当官就有官灾，他当了县政协领导，有官则有官灾。

**例五（辛巳运反局）**

**乾造**：庚戊丁庚／申寅未子

月日一党、年时一党（内外两党），一致对外：食神穿杀为功，寅申冲也为功，靠冲穿做功。庚辰运会水局、敌人多，穿得更厉害，一生最光辉；癸未运无敌人，不好；辛巳运巳合申，坏了穿，反局，受迫害。未与水异党，所以不入辰墓。

**例六（周恩来）**

**乾造**：戊甲丁甲／戌寅卯辰

大运：乙卯 丙辰 丁巳 戊午 己未 庚申 辛酉 壬戌

卯穿辰为功，最怕亥（亥从辰出，合寅卯），主出叛徒。一生未走亥运，但亥年也凶：乙亥年（长征）重病、权力被他人代替（乙为肝，肝中有水）。丁巳运庚申年，水党与火党合，反局，坐牢六个月（巳申合、申辰拱的意思很弱，不是主要原因）。己未运延安整风，权力被削弱。壬戌运乙卯年去世（原稿所记年份，存疑），穿了子女宫，膀胱、直肠有问题。

**例七（不怕反的盘）**

**乾造**：癸甲己戊／卯寅卯辰

甲己合，穿的意思是附带的，可穿可不穿，不明确，不专心，所以不怕反，反运也无事。由于功太多，每五年换一种行业。

**例八（干为钥匙、支为锁）**

**乾造**：戊甲己辛／申寅未未

己未喜刑冲，寅是未中生出，冲了，所以婚姻没事（二婚）。辛亥运丈夫发财：亥寅合，寅还冲。

**乾造**：丁癸己乙／酉丑丑丑

丁癸冲（丁=未，癸=丑，即丑未冲），兄弟三人都是公检法的官，本人是中级法院院长。

## 五、大运反局

原局很好、做功明确，最怕行**反局大运**：运的意思与原局相反，或运的势力与原局对抗而无法被制。这一步大运凶，过了则吉。

**大运体用**（与前章“体用”含义不同）：用＝作用、运动；体＝静态、固定。**走天干运，支为体、干为用；走地支运，天干为体、地支为用**。实际是干支一起看，由体来指挥用，用处在运动之中，体是静止的。详例见第九章。

**例一（薄一波，丙辰运）**

**乾造**：戊甲辛癸／申寅卯巳

大运：乙卯 丙辰 丁巳 戊午 己未 庚申 辛酉 壬戌

木火一气制金水：寅申冲制申，戊癸合、巳申合把申拉回来，正局，大官。丙辰运之辰运：辰生申金、穿卯木、晦巳火，反局，坐牢五年（辰为伤官库，伤官入库无自由，辰又主牢狱）。丙为官，丙辛合本不好，但丙虚透，所以丙运尚能跑掉；辰到则巳火“跑了”（丙=巳虚透），辰穿功神卯、晦巳火，又使癸见实（虚被制、见实不好）。丁运放出；巳运功神到位，任政治局委员；庚申运庚透干无制（庚=申透干），十年蹲牛棚；辛酉运辛到自己到，酉冲卯，任中顾委委员；壬戌运壬虚透吉。

**例二（天津市长，甲辰运）**

**乾造**：丙辛己辛／午丑卯未

大运：（原稿只记地支 寅卯辰巳午未申酉；干按月柱顺排）壬寅 癸卯 甲辰 乙巳 丙午 丁未 戊申 己酉

火与燥土之势要制金水，己丑、己未日主必须逢刑冲，这里丑未冲，结党制食神局，大官。甲辰运被抓去坐牢十年：辰与丑一党，穿卯晦火，制食神局不成，反局。为何本造甲运就坐牢，而上一造只是辰运？因上造丙运丙虚，而本造甲与己合，甲坐辰是实，旺官合身，且辰为牢狱；若是甲子运反而好（未穿子）。戊申运辛有生、制不了，赶上文革，坐牛棚。（口诀：大人物多有反局的经历。）

**例三（袁世凯，辰运、丙辰年）**

**乾造**：己癸丁丁／未酉巳未

大运：（原稿大运地支 申未午巳辰卯寅；干按月柱逆排）壬申 辛未 庚午 己巳 戊辰 丁卯 丙寅

火与燥土成势：年上食神制杀，日上劫财制财，杀与杀的原神被制，大官。戊辰运：戊癸合制癸，但辰运辰酉相生合，晦巳火，反局，被贬，在青岛闲居五年（相当于软禁）。丁卯运丁到即日主到，卯酉冲制酉，升总统（壬子年）。**丙辰年死**：流年反局，原局要用巳，丙火一虚透，辰再晦，巳火倒戈变成金，内部矛盾、手下反他。

**例四（和珅，庚寅运）**

**乾造**：庚乙庚壬／午酉子午

大运：（原稿大运地支 戌亥子丑寅；干按月柱顺排）丙戌 丁亥 戊子 己丑 庚寅

金水有势制火，伤官食神制官，大官。年上午制不净，官杀制不净当财看，故财特别多；时上午制净了，当官看。乙庚合，人吝啬。时上壬水食神虚透合制午，才华出众。行亥子丑北方水地三十年好运，升大学士、军机大臣；庚寅运，庚坐寅绝地，官制不住，寅午拱火，时上午也制不了，反局，革职后赐死。

**例五（上海富翁，癸亥运）**

## 七、本章小结

### 判定表

| 问题 | 规则 |
|---|---|
| 先看谁 | 日主；日主不做功看日支 |
| 日支做功的方向 | 日支的**意向**与八字势对抗为反 |
| 日主日支同做功 | 一致正局、不一致反局，以日主为主 |
| 日合年月官 | 我管人，一般不反 |
| 日合时官 | 我被管，时支必须用、不可坏（己日甲戌时、辛日丙申时尤其，体不可坏） |
| 连体 | 不可坏，坏则反局、伤寿 |
| 冲合反局 | 地支冲合、两党交叉（ABAB）才反；内外、左右不反；干合支冲不算 |
| 岁运冲合 | 原局冲做功怕运合，原局合做功怕运冲；无明确制则不怕 |
| 大运体用 | 走干运干为用支为体，走支运支为用干为体 |
| 应期顺序 | 先地支后天干；地支先本气再墓气再余气 |

### 自测

1. 己日甲戌时，日支丑刑戌，为何是反局？如果甲戌在月上又怎样？
<details><summary>答案</summary>己日合时上甲官，是被官控制，必须用甲坐下的戌（劫财，是体，体不可坏）；日支丑刑戌坏了它，所以反局（辛亥 丙申 己丑 甲戌，常坐牢）。甲戌在月上，则日主合月官是我管理控制别人，不要求用戌，不构成反局。</details>

2. 年月巳申合、日时未丑冲，一定是反局吗？
<details><summary>答案</summary>不一定。要看两党排列：火土与金水交叉间隔（ABAB，如己壬己乙／巳申未丑）才反局；若是内外（申巳未丑）或左右（丑申未巳）则不反。干合支冲也不算。</details>

3. 戊申一柱、辛金与申连体，巳申合为何反？
<details><summary>答案</summary>连体金是“用”，不可坏；巳申合去金，坏了连体，所以反局，坏则伤寿（壬寅 戊申 辛巳 戊戌，电工壬申年被电死）。李宗仁造辛金不受生，申不连体，可制，所以是正局。</details>

4. 乙酉年“乙到”，原局有乙、卯、辰、未，先应谁？
<details><summary>答案</summary>先应地支再应天干；地支中先本气卯，再墓气未，最后余气辰。</details>

5. 原局庚己丙乙／申丑申未靠冲做功，为何辛卯运反局而寅运不反？
<details><summary>答案</summary>原局是申入丑墓冲未（冲做功），辛卯运卯与申合，把冲变成合，冲合反局，且父亲之财破；寅运寅申冲，仍是冲，不反。</details>
