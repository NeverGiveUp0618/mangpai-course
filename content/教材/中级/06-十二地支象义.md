# 十二地支象义

> 每个地支按「天地物象、月时、阴阳属性 → 类象（含职业、人体）→ 与其他地支相见 → 属相与命例」讲。原稿没有完整四柱盘，命例取原稿提到的人物与单柱（如孔子庚子日、邵子甲子日、马云与马化腾的辰戌冲、慈禧等属羊者）；这些都是原稿的断语，不另编干支。

## 通用

- 十二支阴阳（位）：子寅辰午申戌为阳位，丑卯巳未酉亥为阴位。地支藏干再分阴阳，三层（五行属性、位、藏干）合看。
- 四长生（寅申巳亥）气散，四帝旺（子午卯酉）气专，四墓库（辰戌丑未）气聚（见前章）。
- 相见关系每支都按：合、冲、穿、破、刑、拱（半合）、入墓、劫财比肩等逐一说明。

## 一、子

### 象
| 项目 | 内容 |
|---|---|
| 天地物 | 在天雨露，在地为泉，在物为水晶 |
| 月时 | 冬至之月（冬至一阳生，太阳直射南回归线极点）；子时23点至1点，是日之分界 |
| 性 | 清澈透亮，干净清洁，晶莹剔透；占阳位而藏阴，表现阳水特点，周流不息；气专而圆润饱满，灵动活泼；智慧与理性思想的象征 |
| 属相 | 鼠：子时老鼠出没；前爪四趾后爪五趾，前阴后阳，是阴阳分界与交结 |

### 四层类象
1. **起始与根本**：古代圣贤称子（老子、孔子、庄子），子代表本原、哲学、初始。
2. **根与传承**：儿子、孙子、老子；种子＝植物的遗传；承载遗传下一代、生生不息。
3. **数字**：水火两端表气，火表感性，水表理性，理性最初的本原就是发明数。**亥子都表数，子之数是小的、细分的数**。带子的人对数字敏感且仔细，适合计算运算；喜干净、整洁、利索，不喜拖泥带水、脏乱差。
4. **小的、圆的、可转动之物**：流转不息之水，表江河；车的轮子、车子；围棋子、算盘珠、药物、硬币、雨滴。十二属相中老鼠体量最小，与子主小一致。

### 子与其他地支
| 见 | 关系 | 象义 |
|---|---|---|
| 丑 | 合 | 水被吸走；丑为下水道，水流入下水道，水变脏，也被固化不能流动 |
| 卯 | 破 | 严重伤害子。子为轮胎，卯破＝胎走气或爆胎，圆而饱满之性不存；水不流畅或断流 |
| 辰 | 拱合 | **提纯**：辰是泥巴，水与泥混合，子清澈，辰化子就是提纯；水性化工产品、制药 |
| 午 | 冲 | 交换，水火既济。**子午又是皇门**：皇宫坐正子午线，民宅一般定丁癸线；占两极之冲，阴阳气化，阴阳中和 |
| 未 | 穿 | 取象**算盘运算**：子为珠，穿上下拨动；也可能是车祸（子为车，未穿为翻车）。**坏的是子不是未**，所以要未占体穿用之子才好，反了就坏 |
| 申 | 合（生拱） | 加强子之势，子水得源，有冲奔之势 |
| 亥 | 相比 | 都是水，子动亥静；子水不太生卯，见卯反坏；亥水容易生木，本含木之根 |

> 天一生水为子，是天地之始。子灵动又专一，集灵活与专注为一体，是万物始。**得子贵者能统一方之治，得子而富者必才智双全**。天得一以宁，地得一以清。**命例：孔子生于庚子日，邵子生于甲子日**（原稿为证）。

## 二、丑

### 象
| 项目 | 内容 |
|---|---|
| 天地物 | 在天霾，在地为冻土，在物为金石 |
| 月时 | 腊月（最寒冷时节）；凌晨1至2点 |
| 字形 | 土字上加边像房子：丑是土，又是库 |
| 阴阳 | 十二支中酉为阴中之阴（金水一边、阴位、藏阴干）；**丑是阴中之至阴**，比酉更寒，占一年之末位，极阴 |

### 类象
1. **黑暗、隐蔽**：牢狱、黑社会、地下室、下水道、厕所、矿井、阴谋、坟墓。**与黑社会对立的是警察：占阳位而制阴丑＝警察**。
2. **金之库**：银行（钱库）、军营（武库）；按所临十神取象。
3. **脏、污点、见不得人的地方**：清洁工、洗衣工；丑与己相关性强，象意相近。**人体代表生殖器**（隐蔽、阴中之阴，特指女性），某类特殊职业女性可能与丑有关。丑字不同于「丑陋」，繁体的难看之丑是酒鬼的意思。
4. **玄学**：阴中之至阴如黑洞，人对未知玄奥学问有好奇；玄学、易学可以用丑表示。

### 丑与其他地支
| 见 | 关系 | 象义 |
|---|---|---|
| 子 | 被合 | 丑被子合而闭其库，阴寒加强；丑本寒湿，加子水气加重，固化难消；命中出现对身体不利 |
| 寅 | 阴阳之合（暗合） | 一阴之极、一阳之极，显中和之性，**见寅丑合者多吉**；有些公安组合，搞易学成就高 |
| 辰 | 入辰墓 | 放大：废物再利用，由小变大，**得龙而化，脱变重生** |
| 巳 | 拱合 | 巳火消解变性，丑得巩固其性；丑之坚冰不能消溶，反消尽其火，做了无用功 |
| 午 | 穿 | 丑无损，只是被午穿动，午反受辱 |
| 未 | 冲 | 丑库得未而开，丑尽其用为喜；丑之阴湿被未破，立见消融 |
| 申 | 申入丑墓 | 申能代表丑，丑能代表申，可以为一家 |
| 酉 | 拱局 | 见一酉，丑生而拱之；见多酉，则丑墓之；可互相代表，为一家 |
| 戌 | 相刑 | 戌刑丑，墓中之物有用，但同时有刑坏之伤 |

- 丑牛象：牛肉并无寒性反补脾；推测牛无上齿，以肉代之以嚼，丑为肉，金墓无齿之象（原稿推测）。

## 三、寅

### 象
| 项目 | 内容 |
|---|---|
| 天地物 | 在天为风，在地为树木，在物为门楼 |
| 月时 | 正月（一年之开始）；凌晨3至5点 |
| 阴阳 | **阳中之阳，十二支中最阳**（占三阳：木火为阳、占阳位、所藏全阳）。丑占三阴，寅占三阳。气实体固，气象宏大，如万物初生阳气十足 |

### 类象
1. **学堂**：寅为火之长生，象文明文化之源；有些老师职业与寅有关，可判学历高低，但**并非所有老师都看寅，也不是所有高学历都看寅**。
2. **国家机关**：寅有**暴力**之意也有**生助**之意（国家既显示暴力与控制，也有社会救助）；寅还有**组织**之意，木能自发生长，是稳定的自组织系统。
3. **高堂**：富丽堂皇。寅加三点水为演，演戏需要漂亮舞台；高楼、门楼、高档会所、酒店。东方青龙有高贵之象，寅藏火主漂亮。**坐下有寅，家里装修必定考究**。
4. **枪弹、暴力**：寅要穿巳显其暴力；车祸多是开快车，可能是寅巳穿。寅带火，主快且有力。
5. 人体：头、眼；心与肝胆；五邪中**风邪为寅**，肝主风气，中风引发心梗脑梗＝头；肝开窍于目。

### 寅与其他地支
| 见 | 关系 | 象义 |
|---|---|---|
| 卯 | 劫财 | 争夺之意，寅卯是两种不同的木；寅见卯大运，寅走旺地 |
| 巳 | 穿 | 寅强巳坏，巳强寅坏；两阳相穿，互不服气，暴力争斗，你死我活；**寅巳穿不可为体，穿体则身体要坏** |
| 午 | 拱火局 | 焚烧：木见火燃之更旺，寅木化火成灰＝**脱气，一种转化**；寅形质化火为气＝**形化气** |
| 未 | 入墓 | 寅归未成一家；入墓也易变坏、失去自由；寅能代表未，未也能代表寅 |
| 申 | 冲 | **收放之冲：寅主放，申主收**。可能是银行或大型贸易；寅被申冲则受伤，**寅不可为体** |
| 戌 | 拱火局 | 寅不能克戌土，有相照应的关系，粘接性很差，只是有一点相关 |
| 亥 | 合 | **寅亥合亥水灭寅中之阳，风湿病就是这么得的**（寅主风亥主湿，湿性粘腻侵于人体要害）；寅如为体，有脑出血之象 |
| 丑 | 暗合 | 阳得阴；丑得阳而喜（卑贱合了高贵），寅阳性制而用之反显其能；**寅制丑用** |

- 寅为虎：虎虎生风；虎骨入骨去风，是同气相求；虎为山中之王，寅在艮位主山：丑为山之石，寅为山之势。**得寅之命气势必足**。寅为青龙为贵，主头首，为诸阳之汇；阳气聚于一身，司公权之命，恩威并用；岁之首，生机勃发，开拓有力。

## 四、卯

### 象
| 项目 | 内容 |
|---|---|
| 天地物 | 在天为雷，在地为禾，在物为藤 |
| 月时 | 二月；早晨5至7点 |
| 状态 | 寅是种子生长的膨胀状态，卯是发芽、破土而出的状态 |
| 性 | **专、柔两相反**：卯木活则柳（柔美），死则铆（专强） |

### 三类象
1. **弯曲之柔象**：草木、花木、绳索、纺织物、丝线。
2. **刚而专象**：武器、钢筋、铆钉、钻研、专注力。
3. **第一类的衍生象**：现代传播与波；互联网。

- 卯木女孩身材好，曲线美。**专与散相对：寅申巳亥主散，子午卯酉主专，四帝旺中尤以卯为甚**（卯占形，比子午之气专；在形中又占阳，比酉更专）。人的发明创造力在四长生，四帝旺表示工匠精神。
- 人体：肝胆、四肢；所有弯曲部位（四肢关节、脊柱、手指、手腕、足腕）；筋（肝主筋，同象）；筋骨可取卯申之合（申为骨）。

| 巳 | — | **书本文章**：卯笔，巳为文章或书画 |

| 酉 | 冲 | 互换往来，卯放酉收，可取银行；**必是卯受伤**；卯为禄逢酉冲或申合，如无生助容易肢体筋骨之病 |

- 兔象：推测兔缺唇，取卯穿辰故无唇（原稿推测）。

## 五、辰

### 象
| 项目 | 内容 |
|---|---|
| 天地物 | 在天为龙，在地为泥，在物为堤坝 |
| 月时 | 三月；早晨7至9点 |
| 阴阳 | **阳中之阴**（水墓属阴，却占上半年阳气上升之时）；对应的戌为阴中之阳，如太极图两个鱼眼。辰有阴阳两性，能沟通阴阳 |
| 生灭两性 | 生：温暖之土，北方播种，草木复苏；灭：阳中之阴又占墓。长生主散，帝旺主专，墓库主收聚。**辰是四墓中最大的墓**（既水墓又土墓），称地户，收聚能量最大 |

### 类象
- **堤坝**：航运、港口（沿海）；内地则为土地、地产。
- **化工**：水土混合物，水性化工提纯；辰配子，也有辰配亥。
- **中药**：辰含土水木，中药有矿物与草木，煎汤成水；辰为木之余气，主草根树皮；辰在东方合东方医学。
- **机器**：辰中有子水，子转动，许多转动的东西组合＝机器；引申**辰车**：**甲辰与庚辰可取车象**，取印，承载之意。
- **牢狱**：取阳中之阴象——白天大家热闹乱动时只有辰安静，占墓主收，即牢狱。
- **互联网**：交互市场与社交圈；辰是地上最大，戌是天上最大，两者相冲表示互联网。**马云与马化腾都有辰戌之冲。**
- 人体：膀胱、内分泌系统、胰腺，与水液代谢相关。

| 见 | 关系 | 象义 |
|---|---|---|
| 未 | 未入辰墓 | 但**见子丑，未不入辰**；辰收未，辰做功 |
| 申 | 拱 | 辰土性本不足，见申泄气，有化水倾向 |
| 酉 | 合 | 一般合墓为闭，但**大运辰被酉合，为合动**；酉伤辰中之木，辰不被酉金泄气 |
| 戌 | 冲 | 两库之冲力量都大，能做大市场的有些有辰戌之冲；**辰当水库用、当体用，不敢被戌冲，一冲堤坝崩塌** |
| 亥 | 入辰墓 | 辰有功之意；辰能代表亥，亥也代表辰 |
| 子 | 拱水局 | **辰十二支中最怕两个字：戌（冲坏）、子（化掉，消解，如坚冰融化）** |
| 丑 | 丑入辰墓 | 辰丑俱阴土，为一家；阴上加阴；辰墓丑也为功 |
| 卯 | 穿 | 一般情况辰喜卯穿，辰为堤坝，卯穿之更坚 |

- 辰有包容性，收藏阴阳水与阴土，取龙象，能上天入地翻云吐雾。**负阴而抱阳，冲气以和**：一方面阴阳和谐，一方面如潜伏敌人随时可反阳。清明祭祖，寄托哀思又蒙动生机，显示中国人对生死的理解：死并不消亡，而是另一种永生。

## 六、巳

### 象
| 项目 | 内容 |
|---|---|
| 天地物 | 在天为彩虹，在地为繁花，在物为影像 |
| 月时 | 四月；上午9至11点 |
| 阴阳 | **沟通阴阳**：本占阳却能化阴，本火却是金之长生，能与酉丑合成金局而化金；善变，如无间道。遇金与湿土强则失火性，遇木火强则显火性。比喻：酒会按心情放大，遇喜助兴、遇忧更伤心 |

### 类象
1. **思想**：思想属火且善变化，一根筋不叫思想；凡思想都照应阴阳两面，伟大思想家思考的是深刻问题。
2. **文字、文化、文明**：与丁有点象；巳本象如两本厚书放在一起（同己）。文化既静态也动态（可传播）。
3. **电脑与互联网、移动互联网**：巳主显示屏，承载文字与影像。
- 带巳者适合文化、思想类行业；因阴阳两性，巳与其他地支关联性强，几乎都有关联。
- 人体：蛇之形弯延曲折；少阳三焦，相火气化；面、齿、目、喉、小肠。

## 七、午

### 象
| 项目 | 内容 |
|---|---|
| 天地物 | 在天为暖阳，在地为烈炎，在物为火器 |
| 月时 | 五月；中午11至13点 |
| 阴阳 | **阳中之阳，占阳之极**；阳极阴生，所藏之支为阴，体现阴阳转化。与巳不同：午只有阳性，见阴则对抗，不妥协不沟通，性直无变通；**唯与亥子之水能交融（水火既济）** |

### 类象
- 象意不如巳丰富；性烈似丙。物象：武器、动力、快速之物；现代：电子、色彩、装潢、广告。
- 四正神中**唯一藏两种五行**（火土旺地，藏己土，已燥热，无生金之能）。寅午戌三合同党，午的象意可借寅戌：公门之意。**子午皇门**：午为中轴线，取公门、公正严明；入公门易为正职高官。
- 性格：光明磊落，或多言外向，或是非公道，或激扬奋发。
- 人体：心脏；午火太旺多阳性体质，再有木生易阳亢病，表现三高。

## 自测

1. 子丑合、子辰合、子未穿各取什么象？
<details><summary>答案</summary>子丑合：水流入下水道，变脏、被固化；子辰拱合：提纯（水性化工、制药）；子未穿：算盘运算，也可能车祸翻车，坏的是子，要未占体穿用之子才好。</details>

2. 为什么说「寅巳穿不可为体」，申亥穿为何最弱？
<details><summary>答案</summary>寅巳两阳相穿，你死我活，穿体则身体要坏，力量最大；申亥是阴穿阴，只是冷暴力，没有特别的伤害。</details>

3. 辰为什么喜卯穿而怕戌冲、怕子？
<details><summary>答案</summary>辰为堤坝，卯如木桩穿入使坝更坚；戌冲则堤坝崩塌；子能化掉辰，如坚冰被融化，小能克大。</details>

4. 戌为何表示打官司而不是牢狱？
<details><summary>答案</summary>申酉管法律之收，先关起来不讲道理；戌是申酉戌中阳性，是唯一能讲道理、争讼的地方。</details>

5. 亥、子、戌三者都表数，区别是什么？
<details><summary>答案</summary>戌是平台、大数据运算；亥是普通数学、数理能力，借头脑算；子是小数、精微之数，精打细算。</details>
