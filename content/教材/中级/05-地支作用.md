# 地支作用

> 本章讲地支之间的作用：藏干与刃、墓库入出、六合与暗合、六冲、六穿、三合局与党、三刑与破、墓库开用。原稿没有给完整四柱盘，命例取原稿提到的单柱组合、人物（如特朗普、马云、马化腾、刘翔）与日时配置，不编造干支。

## 一、地支遁藏与刃

### 1. 藏干的规律（不必死记）
天干是轻清之气，地支是重浊之气，所以地支藏有天干。藏气有规律：

| 类别 | 地支 | 藏气规律 |
|---|---|---|
| 四长生 | 寅申巳亥 | **所藏天干俱阳**。长生是生生之气，只有阳气才能推动生长。基本藏两气：**本气＋长生之气**。寅：本气木藏甲，长生火藏丙；寅申又是土的长生，藏阳土，但太弱忽略不计。巳：火土旺地，所藏火土俱旺；又是金的长生，藏阳金，但受本气火克，旺度相对弱。亥：只藏两气，没有土 |
| 四帝旺 | 子午卯酉 | **所藏天干俱阴**。事物发展到极旺点已阳极生阴，不能再有力量推动，故藏气俱阴。只藏本气、旺气；因火土同生同旺，午也是土的旺气点，**只有午藏两气**，其余四支一气 |
| 四墓库 | 辰戌丑未 | 本气俱为土，**所藏之气俱阴**（死而归墓，没有生机）；但墓库本身分阴阳：**丑未阴土，辰戌阳土**。藏三气：**本气、墓气、余气（退气）**；墓气比余气足得多，余气很弱 |

- 按原稿文字还原的藏干（原稿的藏干表 OCR 散乱，此处是对照文字叙述整理，余气项存疑）：子癸；丑己癸辛；寅甲丙(戊弱)；卯乙；辰戊乙癸；巳丙戊庚；午丁己；未己丁乙；申庚壬(戊弱)；酉辛；戌戊辛丁；亥壬甲。另有说明可与文字互证：丑中含金水(辛癸)，未中含木火(乙丁)，辰中含水木，戌中含火金，寅中甲丙，丑中己辛，午中丁巳（疑为丁己）。

### 2. 旺气与刃
- 天干五行在地支的**旺气有二**，如木旺于寅、卯：**寅气散而卯气专**。所以**阳日干以寅为禄、以卯为刃**。刃是气太专凝成刃，杀伐之力的象征。
- **只有阳日干有刃，阴日干无刃**。水火阴阳错配，**壬子、丙午为自坐刃**；金木阴阳正配，只能见旁支刃。**戊土之刃特别，戊刃在未**。
- 阳日干除地支刃外，**见天干也称刃**：甲见乙、庚见辛、戊见己之类。

## 二、墓库的入与出

### 1. 入墓与出墓
| 情形 | 判断 |
|---|---|
| 原局有墓，大运来墓中所藏之支 | 出墓 |
| 原局有支，大运来墓 | 入墓 |
| 年月有墓，日时有墓中所藏之支 | 出墓（引出） |
| 年月有支，日时有墓墓其支 | 入墓 |
| 距离太近 | 月上有墓，日上见所墓之神，因太近也论入墓，不称出墓 |
| 大运之外 | 流年也能引出 |

- **多而墓之**：多现才入墓。例：辰见丙子（原稿）双子入辰墓；辰见一子，辰被消解，子辰相合化；见双子，双子入辰墓。
- 多而墓之也表现在天干：**天干多而相连，通于地支墓，多而墓之**。如天干多辛，连于辛丑，辛会墓于丑；单个辛丑，辛不会墓于丑。
- **本坐库不为入墓**：辛丑、壬辰为坐墓，不为入墓。辛酉见丑才入墓（辛酉入丑，也是因为多）。
- 比喻：见一群学生，知道他们在学校，学校收之；见一个学生，可能在家，家里父母宠着，在学校学校管着。

### 2. 阴干的墓
- 阴天干**通地**（得地支）入其本墓，如辛酉墓于丑；**阴天干不通地，入墓不在本墓**。
- 阴干之墓：**癸墓在未，丁墓在丑，辛墓在辰，乙墓在戌**（阴长生逆行之墓地）。
- 阴日干逆长生的用法，**仅仅用墓，其他没什么用处**。

> 万物生于土而归于土，成于土又败于土。得库而富，亿万家业；归墓而穷，身无片瓦。

## 三、地支之合

### 1. 六合
六合在手指上以中线对称：**子丑、寅亥、卯戌、辰酉、巳申、午未**。只讲合，不讲化（合化说不成立）。

| 类型 | 组合 |
|---|---|
| 生合 | 寅亥、辰酉、午未 |
| 克合 | 卯戌、巳申、子丑（克的力量较小） |

### 2. 六合的五层含义
1. **结合、连接、附着**：锁与钥匙，耳机插入插孔。
2. **得到**：合到什么代表得到什么，好坏都有，由不得人（粘接性太强）。
3. **控制与支配**：局限于克合。卯戌合，卯能支配戌；巳申合看哪个「党」强，强者支配对方。**克合可做功**。
4. **停留或方向**：合到哪，留到哪；冲到哪，离开哪。可用合找变动方位，相遇的人可能从远方来；合到年时一般主变动。
5. **缠绊，散失自主性**（最重要）：地支六合是所有合中粘接性最强的，相合两支原则上都失去一定自主性，**贴近之合尤甚，远合影响不大**。所以八字中有合多数是合坏，只有少数合好。

### 3. 六合逐个讲
| 合 | 要点 |
|---|---|
| 子丑 | 子水本是流动之水，一合就不动。丑本阴土，固定子水作用不强；子水多见，丑没有能力控制。反过来，丑因合子，其金库得闭。**两阴相合，阴结沉闷，阳气不足易生病** |
| 寅亥 | 粘接**损阳**：寅是阳中之阳，生生之气很强，一遇亥合，湿气侵入，阻遏生发之机。寅也主暴力、弹药、动力，一合就熄火；亥水被寅吸去（寅如海绵），水性也丧失 |
| 卯戌 | **卯控制戌**。十二地支最大的两支，一是辰（怕子消），二是戌（怕卯合）。戌能量足如弹药夹，卯来如缠胶带牢牢控制。**多数能做功** |
| 辰酉 | 相生之合，类似焊接、粘接。酉精致金属被辰合会生锈；但辰得酉，强固了水库的力量。**辰酉合并不闭库，水一样进辰**；可取象钢筋水泥结构（建筑），如三峡大坝 |
| 巳申 | 相克之合：巳中火克申金，但申得旺（申中有足够的水），巳反被申克，可合坏巳。两者各失自主性。**能做功** |
| 午未 | 六合中最无聊：阳性都足，没有互补性；相互得到没意义，反而牵绊不能做事，如同性家庭。午得到的是一个墓库，库里的东西也被关闭。**除非一起完成冲丑或坏子的工作才有意义** |

### 4. 暗合
暗合三：**午亥、卯申、寅丑**。粘接程度比六合差、比拱合紧。

| 暗合 | 要点 |
|---|---|
| 午亥 | 午中丁己与亥中壬甲相合；紧密性不强，不丧失自我，能在合中互补、互通有无，如做生意双方双赢。**这三个暗合实际比六合更有价值** |
| 寅丑 | 寅中甲丙与丑中己辛相合；阴阳之合：寅是阳中之阳，丑是阴中之极阴，互补互通，阳使阴动、阴能附阳，阴阳平衡之象。有寅丑合的命多懂阴阳变通之理，适合学阴阳之学，**有功则事业也有不错发展** |
| 卯申 | 卯中乙合申中庚，称**合绝**（卯绝于申，合中必带绝）。如夫妻在一起相互伤害、不在一起又相爱得不行。做功可以（申来制卯）；若代表人事、婚姻则容易有克 |

> 六合则颓废牵绊，六冲则激扬奋发。合则贪恋懒惰，冲则谋为图强。合多的人随和无争，却容易碌碌无为，多顾虑；冲刑穿害无所惧。**多数合能合坏，多数冲能冲好。冲为开、为动，合为闭、为闲。**

## 四、地支六冲

### 1. 冲的本意
六冲：**子午、丑未、寅申、卯酉、巳亥、辰戌**。本意是**往来互换**：交易（互换），婚姻（往来），出差、远行、常去亲戚家都是往来。

**冲与合的交易区别**：**冲是简单交易**（一供一需，自古就有，冲不散失独立性）；**合是复杂交易**（加包装、加品牌、入股分红，有利益共同体，散失一部分独立性）。

### 2. 三组冲
| 组 | 性质 | 要点 |
|---|---|---|
| 子午、巳亥 | **水火相冲，水火既济** | 气之相冲，水需要火，火需要水（心肾相交）。**金水伤官喜见官、木火伤官喜见印**就是水火喜相冲相见。水强能克火，火强也能克水，**一方强另一方败**。双方可处成朋友，情分上可交友。丑午穿则犯心脏病 |
| 寅申、卯酉 | **金木交战**，形争，无情之争 | **一旦相冲，一定金胜木**，没见过一块木头坏一块金。做生意一辈子成不了朋友：金融行业用这两冲（木放金收，银行柜员与储户、行长与贷款方难成朋友）；证券股票期货不知赚谁的亏哪里；金木夫妻不和谐，争吵必定 |
| 丑未、辰戌 | **土墓相冲，开库** | 库不开则为墓（知道里边有宝，开不了）；库随时可开，里边东西可享用。**见墓要开，开了就成库** |

- 丑未：冲而**互开其库**。丑中含金水，未中含木火，一冲俱得用。库冲功用大，一旦有用，财富也多。**丑未阴库，辰戌阳库**；辰中含水木，戌中含火金，辰戌为天门地户，级别比丑未更高。**命例：马云、马化腾的命局都有辰戌之冲为用**，不是一般财富。

### 3. 冲主动
- **所冲之支必是动支**（不会安闲，总要做事，跑来跑去），古人将冲看作**马星**。原局中字安静，遇大运来冲，这个字会动起来。
- **木来冲金只看动；金来冲木，冲中带克**，被克之字弱，有可能冲克掉。**体不可克，用冲克无妨**。
- 流年冲八字中的字也是冲动：凡动则变，变在哪里，就应本年哪里发生事情。多数流年犯冲不以凶论；也有激旺凶神为凶的，那是原局有凶，流年为应期。
- **体不喜多动，动则劳碌辛苦；用喜动，动则功成名就。**

## 五、地支六穿（六害）

### 1. 六穿
**子未、丑午、寅巳、卯辰、申亥、酉戌**（每根手指上的两个字）。地支六穿也称六害，在本派命理中十分重要。

### 2. 穿的五层含义
| 层 | 含义 |
|---|---|
| 一 | **排斥、敌视、破坏、伤害、仇人**。人际上专门伤害你、相见如仇人的人；应在身体上则出大麻烦：小则刀伤手术，大则要命。**自己身体与身体相穿，叫命局反局，是天亡之命** |
| 二 | **穿倒、穿偏**：力量大的一方穿倒或穿偏另一方。穿倒＝穿反，出现与十神本意相反的意思：食神逢穿称穿倒食神（食神代表女儿，穿倒不生女儿反生男儿），正印逢穿称穿倒正印。**正星不喜穿倒，偏星穿倒反为正** |
| 三 | **穿能做功**：能做功的穿不多，有相克之意带穿可以做功。**子未（未克子）、卯辰（卯克辰）、酉戌（戌克酉）可做功；相生之穿寅巳、申亥不做功；丑午虽相生，但一阴一阳，有做功的可能** |
| 四 | **穿能穿动**：与冲一样，穿可使安静的字变动。多指流年来穿八字中字，如丙申年穿亥，亥有动意 |
| 五 | 穿主**速度**，特别是穿中带火主速度；穿衣服（穿印＝爱穿好看衣服，印主衣服） |

### 3. 力量大小
**阳穿阳力大（如两男人打斗），阴穿阴力小**。寅巳穿力量最大，申亥穿力量最小。

### 4. 六穿逐个讲
| 穿 | 性质 | 要点与象 |
|---|---|---|
| 寅巳 | 相生而穿，本没有功，却是**力量最大的穿** | 两字都阳，如两只公牛角斗，拼出你死我活；寅有暴力之意，可表示**车祸、枪弹射杀、刑事犯罪、手术、权斗不妥协**；表示速度很快，日时出现寅巳穿爱开快车 |
| 卯辰 | 相克而穿 | 穿一般主不好，**唯一喜欢穿的是辰喜卯穿**：辰是水坝，建坝时木桩一根根穿进去，坝坚不可坏；相反辰一般不喜戌冲，一冲就垮。辰被卯穿多数穿好，穿到有功；**是辰好了，卯是被穿坏的** |
| 子未 | 相克而穿 | 子被未穿，是子坏；子再多也只能将未穿走、穿倒，不可坏未；未对子的克害一定。未主力量、坚忍之力，未穿子反显未之力。**子为珠、算盘，穿＝打算盘，子未穿有些命当会计** |
| 酉戌 | 戌为燥土，对酉克害 | 戌与寅相似有暴力之意，戌穿酉有酉被暴力伤害之意，**也容易发生车祸** |
| 丑午 | 阴阳之穿 | 丑湿土坏午之阳，午受伤严重（午代表心脏则发心脏病）；**丑午穿在日时上也容易引发车祸** |
| 申亥 | 六穿中最弱 | 除申亥关系不和外没有特别伤害，是**冷暴力**，不理不睬 |

### 5. 穿的原则
- **墓库逢穿不能开墓**：墓坚固不坏，不怕别的东西穿，反而能穿坏别的东西。
- **命例：刘翔**——八字带穿，而且穿在**年上**（年主足），穿主速度。
- **用的东西可以穿，体的不可以穿**（穿体就是手术与伤灾）；唯一可以体穿的是**墓当体**（墓主穿别人，穿不了自己）。
- 命中见穿有穿好、有穿坏；**六亲不可见穿，穿则六亲无缘**。带穿之人必有个性：固执、执着、坚韧、无情、专注、决断、杀伐。**合者办事拖泥带水，穿则干净利落**，穿能用好事业前程有望。

## 六、地支三合局与党

### 1. 三合局的意义
**申子辰合水局，亥卯未合木局，巳酉丑合金局，寅午戌合火局**。由**长生、帝旺（中神）、墓库**三者相聚而成，象征社会关系中的**结党**（党团、团队、结社）；六合象征结亲（夫妻，粘合性极强）。

- 三个部分：**中神是组织核心（纲领、目标、头目），长生是新生力量，墓库是老一代退休力量**。
- 三合局粘合度差，如党团只有开会时聚在一起（美国总统大选两大党只在选举时拱合核心，选完就散）。粘合性过强，甚至强过夫妻六合，是不正常的党。
- **半合**：长生与中神、中神与墓库；**拱局**：长生与墓库相拱，中神不在场（党主席不在场，党员各自心存对中神的崇敬）。

### 2. 四局逐个
| 局 | 要点 |
|---|---|
| 申子辰（水） | 力量很大，水一党独大；同时**申金被泄，辰土被消**。申子、子辰半合，申辰拱 |
| 亥卯未（木） | 卯木力量很大；亥被泄，未的土性被消。亥卯、卯未半合，亥未拱 |
| 巳酉丑（金） | 酉金力量很强；**巳见酉被化，丑见酉助酉（不泄，结成强同盟）** |
| 寅午戌（火） | **三合局中唯一不以中神为核心的局**：火局后生助了戌，戌反成中心，如党内老人干政；午火之火性从于戌 |

### 3. 巳：沟通阴阳
**十二支中唯有巳可沟通阴阳**：巳本性火属阳，却能与阴金合成金局而变阴，占阴阳两象；遇木火为火，遇酉丑变金，变化性类似人的思维。带巳的人学易学与中医都比较快。

### 4. 党的更一般划分
- 三合局只是社会组织的一种形式。本派把十二地支分两党：**木火为阳党，金水为阴党，土分阴阳（阴土归阴党，阳土归阳党）**。形成一势，就表示形成一个组织。
- 原稿举例：申子辰与丑、酉、申（重）、亥可组成一党（阴党）；寅午戌与卯、巳、未、戌可组成一党（阳党）。**（存疑：未为阴土，列入阳党与「阴土归阴党」自相矛盾，原稿或有误，仅记原文。）**
- **有党成势，再有功，命局不会差到哪里**。党＝团队，自己有团队，有目标，又做事，就是做功。**只有党而没有功，如养一群废物成天闲着，八字就废了。**
- 学命理要把干支关系对应到生活，不对应只以干支论干支，是没学到位。

## 七、地支刑与破

### 1. 三刑
**三刑有二：寅巳申三刑、丑戌未三刑。**

| 刑 | 构成与要点 |
|---|---|
| 寅巳申 | 三者**同时出现**才构成刑。巳申见为合，寅申见为冲，寅巳见穿。原局两个，**大运来第三个也构成三刑；流年来第三个只是引动，不构成三刑** |
| 丑戌未 | 三者相见三刑。丑来见（未）为冲，丑戌见为刑，未戌见也刑。**丑戌刑一阴一阳，能做功**（丑力大坏戌，戌力大能坏丑）；**未戌刑不能做功，只是开库** |

- 三刑**不代表刑罚**；会伤及六亲；**中间被两头刑的字会出问题**；婚姻宫构成三刑，婚姻多数出问题。墓相刑（丑戌、未戌）有开库之意。
- **体不可被刑，六亲不可被刑**（刑有破坏、受难、不完整、损伤）。刑到哪个字，哪个字有问题，可由问题程度判断吉凶。
- 书中「辰午酉亥自刑」之说，本派不讲（不应）。

### 2. 地支之破
**破有三：子卯破、卯午破、子酉破**（另：午酉本相克，再加破力，伤害更大）。

- 原理：**本是相生而不生，反而要破**。子午卯酉气太专，只顾自己，相见不生反破；集专制与自私于一身（父母爱孩子却成仇人：太自私或太专制）。
- 破的开脑洞：破口大骂（两口子带破）、破案（公安刑警）、破货破身（女人私生活不检点，或男人找的女人不正经）、破产破财、读书破万卷（读书多学历高）、当权者破别人财使人家破人亡（纪检、执纪官员）。
- **不可破自己，可以破别人**：体被破就是破自己，主自己受伤或手术；破别人要分析职业与破坏性有关，如手术大夫。
- **力量**：**卯午破最厉害，子卯破其次，子酉破几乎不破。** 卯午俱阳，阳见阳破得最凶；子酉阴见阴，称**相隔**，意同申亥穿，互不理会冷暴力。

| 破 | 象 |
|---|---|
| 卯午 | 破身体：午为心、卯为血管，血管破裂，心脑血管突发病变，常有生命危险。卯当书＝读书破万卷；有些律师、法律工作者有卯午破（破条文）；卯当布＝裁缝 |
| 子卯 | 子水怕死于卯，卯破子在身体上很凶，会得肾病；出现在日时，轻一点会尿频或前列腺疾病 |

## 八、地支之墓：入、出与开库

### 1. 墓的含义
**辰为水墓、戌为火墓、丑为金墓、未为木墓**。墓是收藏、获取、控制、聚集、得到之意，也含死亡之意。**不开者称墓，能开者称库**。

### 2. 入墓出墓
- 年月有墓，日时见所墓之神，为引出；太近也论入墓。年月见所墓之神，日时见墓，为入墓。原局有墓而大运出所墓之神，引出墓神；原局有所墓之神而大运见墓，入墓。流年也能引出。
- 寅申巳亥四长生点，见其对应墓神入墓；**子午卯酉四帝旺点，见所对应的墓神为拱局**（不入墓）；只有中神**双现或多现**，多而墓之必入其墓。
- 多而墓之除地支多入墓外，**天干加地支相连见墓也为入墓**：辛酉见丑，乙卯见未，两辛相连见辛丑。

### 3. 阳墓与阴墓
**辰戌阳墓为气墓，丑未阴墓为形墓**。阳墓如阳宅，阴墓如坟墓；阳主动、阴主静。**入阳墓凶小，入阴墓凶大**：入阳墓之凶类似住院或进看守所；入阴墓可能人就没了。**阳墓不开也可用，阴墓一定要开。**

### 4. 开库的三种方法
| 方法 | 内容 | 例 |
|---|---|---|
| 一、直开 | 刑冲开墓：冲能开，刑也可开（未戌刑、丑戌刑都可开墓） | **命例：特朗普**——己未日见戌年，未之墓被戌刑开了，里边的杀星可用到 |
| 二、旁开 | 不直接冲墓，冲旁边所墓之神 | 地支见丑申寅组合，寅申冲而旁边开墓 |
| 三、开天库 | 地支没有冲，透到天干的、能代表墓的神相冲 | 地支丑无冲，天干透癸代表丑，见丁冲，为开天库；透辛冲乙也可开丑 |

- **天引法**：地支引墓除日时与大运引出外，还有天引：通过天干的**虚透**引出墓中之神（必须是虚透），如原局有丑，天干别处透辛，引出丑墓之金。
- 效率：**冲者开库最全，引出其次；直开最全，旁开其次；地支较全，天引其次**。地引如从库中接管子、从水库引渠；天引如毛衣引出线头（可把全毛衣变线，但效率不高），如卖东西只能拿出一小部分在外边卖，来得慢而已；直开如一个不剩全卖。**天引取象多是卖东西的命局组合**。

### 5. 丑未亥子入辰墓的分辨
- **丑未同见辰：辰只收丑，不收未**（辰丑一党）。如两小孩子打架，来一个大人是丑的家长，直接领回家，**丑未之冲不成立**。
- **未子同见辰：辰不收未，却能拱子，子未相穿更加激烈。**
- **亥未同见辰：亥未相合，一起入墓。**
- **亥子丑见辰：亥子丑一起入墓。**
- 亥子见辰，算子辰拱还是子入辰墓？巳午见戌，算午戌拱还是巳午入戌？其理一样：**只要多见，就一起入墓**。

### 6. 墓库与做功
- 墓冲开就有用，不必非要做功，能做功者更强。
- **丑来、辰戌冲、丑戌刑可做功，未戌刑不以做功论，只是开库。**
- 被墓之神收入墓库本身就是功，意为能量聚集。**丑入辰墓与未入辰墓是放大，也是功。**
- 墓库做功能量巨大（墓是五行所归，能做功就是无保留得到全部）。阳墓得气，阴墓得形。有墓者多，能用墓者少，得到全墓者少之又少。

## 自测

1. 六穿中哪些可以做功？哪个穿力量最大、哪个最小？
<details><summary>答案</summary>子未（未克子）、卯辰（卯克辰）、酉戌（戌克酉）可做功，丑午阴阳之穿有可能；寅巳、申亥相生之穿不做功。寅巳穿阳穿阳力量最大，申亥阴穿阴最小（冷暴力）。</details>

2. 金木相冲与水火相冲有何本质区别？
<details><summary>答案</summary>水火相冲是气的相冲，水火既济，强者胜；金木相冲是形争、无情之争，一旦相冲一定金胜木，双方难以处成朋友（如银行与客户）。</details>

3. 辰为何喜卯穿而不喜戌冲？
<details><summary>答案</summary>辰如水坝，建坝要把木桩一根根穿进去，坝才坚固；戌冲辰则一冲就垮。卯辰穿是辰被穿好，卯被穿坏。</details>

4. 丑未同见辰、未子同见辰、亥子丑见辰，各怎么论？
<details><summary>答案</summary>丑未同见：辰只收丑不收未，丑未之冲不成立；未子同见：辰不收未，拱子，子未相穿更激烈；亥子丑一起入墓。</details>

5. 开库有哪三种方法？效率如何排序？
<details><summary>答案</summary>直开（冲刑）、旁开（冲旁边所墓之神）、开天库（天干透神相冲），另有天引（虚透引出）。冲者最全，引出其次；直开最全，旁开其次；地支较全，天引其次。</details>
