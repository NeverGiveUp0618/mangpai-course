# 十神与宫位

> 取象有三条线：**干支（是什么）、十神（与我什么关系）、宫位（落在哪里）**，如同坐标系三轴，三者合看才能精确定位一个字的象。本章讲十干的位次与性情、天干五合、十神释义、十神的社会学含义、十神与六亲、四柱宫位。原稿未给四柱盘，本章用断例与规则示例说明。

## 一、十干之位：阴阳尊卑与阶层流动

### 1. 十干的本义
- 十干起于甲骨文时代，随干支纪日而生，是**五行再分阴阳**：甲乙阴阳木，丙丁阴阳火，戊己阴阳土，庚辛阴阳金，壬癸阴阳水。前者阳，后者阴；顺序木、火、土、金、水即相生之序。方位：甲乙东，丙丁南，戊己中，庚辛西，壬癸北。
- 地支对应十二个月、十二时辰；天上没有「十」这个周期，所以十干本意就是阴阳五行。

### 2. 以植物生长描述十干之序
| 干 | 象 |
|---|---|
| 甲 | 种子破壳，先出的芽向下入土 |
| 乙 | 初生嫩芽，弯曲（豆芽） |
| 丙 | 破土而出，受阳光快速成长 |
| 丁 | 开出小花朵，一点点 |
| 戊 | 盛大，茂盛长成（戊＝成） |
| 己 | 结出果实，是肉，入脾胃成食物 |
| 庚 | 果实成熟变硬（庚通更，变更） |
| 辛 | 收割（辛古为刀） |
| 壬 | 孕育，选饱满者作种，承担繁殖 |
| 癸 | 归，收藏种子，来年再种 |

### 3. 十干之序：由阳到阴，有尊卑贵贱
> 「卑高以陈，贵贱位矣。」

以社会阶层比拟（不固化，流动才是动力）：

| 干 | 阶层 |
|---|---|
| 甲乙 | 权贵阶层（最高位） |
| 丙丁 | 知识精英阶层，掌握话语权 |
| 戊己 | 资本财富阶层 |
| 庚辛 | 工薪奋斗阶层（庚辛＝「更新」，想靠努力改变命运），社会中绝大多数 |
| 壬癸 | 学生阶层，高智商但尚在启蒙 |

- 经济发展靠资本与社会分工，差异性是动力；财富绝对平等经济就不发展。
- **流动的方式**：①**相生**：甲乙生丙丁、丙丁生戊己、戊己生庚辛、庚辛生壬癸、壬癸生甲乙，向下生也同时是向上流动（丙丁以甲乙为印，即依靠）；②**相合**：天干五合是跳跃式改变等级。甲己合＝最高等级向下合卑贱；戊癸合＝最低等级的癸向上，「贫困少女嫁有钱老头」。
- 老子「知其白而守其黑」：永远处低位而心向高位，低位者才有高位可合；高位者反要合低处，实现财富阶层的流动。
- **十为体，只用其九**：日干代表「我」，是体，不用。所以**取日干衰旺没有意义**（日主旺衰既不表示能力、身体、力量；把「体」放到「用」的位置是没有理解命理本质）。

- 性固定，变化常在：命局没有变化，就没有转轨成功的可能。

## 三、天干五合

### 1. 合的几个问题
- 五合：甲己、乙庚、丙辛、丁壬、戊癸。合于河图之数：1-6、2-7、3-8、4-9、5-10 各为一家。
- 合能改变天干之性，只是改变有大有小。命理**讲合而不讲化**：合化在命理中没有实际意义（五运六气才用），但不等于不存在化。
- 阴阳属性：合是相对于冲而言，**合属阴，冲属阳**。

### 2. 「合」的六层含义
| 含义 | 例 |
|---|---|
| 结合 | 男女结为夫妇 |
| 粘合、附着 | 小人去合君子才显其为小人；化妆品附着在脸上 |
| 连接 | 玉佩用线连玉；文字连成句、成文；纽扣是一对阴阳连接 |
| 获得与加码 | 「互联网＋」：原有的没有根本改变，只加了不同的东西 |
| 定义关系 | 丙为眼睛，丙辛合，辛主清彻水润，合又主动＝明眸善睐的大眼睛；辛为珠宝，丙定义它：灯光照射下的珠宝 |
| 发用 | 体用相合，体发用于用。如伤官合印＝我的想法（伤官）加文化（印），即学习文化知识 |

## 四、十神释义

### 1. 十神的定义
以日干为我，其他干与我产生五种生克关系，加阴阳，成十神。日主为体，其他干支为用，十神围绕「我」定义。

| 与日主关系 | 异性（阴阳不同） | 同性（阴阳相同） | 以甲日为例 |
|---|---|---|---|
| 生我 | 正印 | 偏印（枭） | 癸正印，壬偏印 |
| 克我 | 正官 | 七杀（杀） | 辛正官，庚七杀 |
| 我生 | **伤官** | **食神** | 丁伤官，丙食神 |
| 我克 | 正财 | 偏财 | 己正财，戊偏财 |
| 同类 | 劫财 | 比肩（也称禄） | 乙劫财，甲比肩 |

- **阳日主，正财必合身**（甲见己）；**阴日主，正官必合身**（乙见庚，必乙庚相合）。
- 十神之间的生克：印克伤食、印生比劫；官杀生印、官杀克比劫；财克印、财生官杀（原稿另有「财生比劫」一句，存疑）；伤食生财、伤食克官杀；比劫克财、比劫生伤食。比劫与日主同，与其他星发生同样关系。「六亲生克关系必须非常熟，张口便来」。
- 标注法：天干标十神；地支先取**本气**（寅阳木、卯阴木、辰阳土、巳阳火、午阴火、未阴土、申阳金、酉阴金、戌阳土、亥阳水、子阴水、丑阴土）。简写：正财「财」，偏财「才」，正印「印」，偏印「枭」，比「比」，劫「劫」，食「食」，伤「伤」，官「官」，杀「杀」。

| 日主甲见 | 寅 | 卯 | 辰 | 巳 | 午 | 未 | 申 | 酉 | 戌 | 亥 | 子 | 丑 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 标注 | 比 | 劫 | 才 | 食 | 伤 | 财 | 杀 | 官 | 才 | 枭 | 印 | 财 |

> 「六亲叫『子孙』，十神叫『伤、食』，意义也完全不同。」

- 附：十干之禄（比肩称禄）：甲禄寅，乙禄卯，丙戊禄巳，丁己禄午，庚禄申，辛禄酉，壬禄亥，癸禄子。（原稿此句为「丙戌禄在巳，丁巳禄在午」，OCR 疑为「丙戊禄在巳，丁己禄在午」，此处按后者；存疑。）

### 2. 人性与社会角度的十神
**马斯洛需求对十神**：生理需求→伤官食神（我生，发泄）；安全需求→印（保护我者）；爱与归属→印；尊重→官杀（荣誉）；自我实现→财星与官杀。

**五种能力**：印＝借助能力；伤食＝思考能力；财＝支配、沟通能力；官杀＝自我克制、荣誉感；比劫＝行动能力。生克使能力此消彼长：

| 现象 | 原因 |
|---|---|
| 思考强的人行动力不足 | 伤食泄比劫 |
| 行动力强的人不需保护、借助力不足 | 印星泄于比劫（原稿用语：印泄比劫） |
| 依赖心强的人不强调尊严 | 印泄官杀 |
| 有自我克制力，欲望减少 | 官杀泄财 |
| 沟通力强的人往往不爱思考 | 财泄伤食 |

### 3. 十神是体用关系，做功即做事
- 人生有目的：获取财富、权力、知识、尊重，这些是「用」；达到它要靠本体努力、借助工具或组团队，这是「体」。体用之间的作用关系就是**做功**。
- 一般以日主、印、食神为体，以财、官杀、伤官为用；但**体用不固定**，财官杀也可以为体，印比劫也可以为用。

### 4. 先天与后天
| 十神 | 属性 | 含义 |
|---|---|---|
| 食神、伤官 | 本能（先天） | 自己的主张、想法、欲念，个性化的东西 |
| 财 | 本能 | 我要支配的，欲望（小孩一生出就哭着要吃，玩具不许人拿） |
| 比肩（禄） | 先天 | 自我感、自足感、自我意识，自己享用享受 |
| 印 | 社会性 | 庇护我者＝文化、教育；有文化归宿感才安全（去外国没有归属感）。印克伤食：对有些人是保护，对另一些人是束缚（反传统的变革者、叛逆者） |
| 官杀 | 社会性 | 荣誉感；压力、打击、磨难，也是成长的必要经历 |
| 劫财 | 社会性 | 行动力、竞争力，在社会交际中体现 |

儒家「修身」就是约束先天欲望与任性，获得文化认同与荣誉感。

### 5. 十神衍生含义
| 十神 | 引申 |
|---|---|
| 印 | 庇护我者：衣服、车子、房子、文凭、身份、地位、单位、机构 |
| 伤食 | 我生出来的，意志的延伸：精神、思想、智力、自由、感受、任性、学生、情趣、爱好、欣赏、艺术、快乐、享受、吃喝、服务 |
| 财 | 我克者，支配享用：金钱、下属、沟通能力（财的另一半是「才」，人能支配的只有自己的语言） |
| 官杀 | 官方、领导、权力、压力、小人、官司、暴力、疾病；属心性则为克制、荣誉、尊严、心机、多疑 |
| 比劫 | 比肩＝禄：自我、享受、劳累；劫财：争夺、朋友、哥们、对手、乙方、破财者 |

### 6. 五点校正
1. 十神没有好坏，在组合与配置。杀伤刃虽被当作凶神，但**凶神得用比吉神厉害**，成就特别高的命许多用了凶神，是能对付凶人凶事的厉害人。
2. 正印偏印、正财偏财含义差别不大。**正印不一定是正当职业，偏财不一定非分收入。**
3. **官与杀区别很大**：阴日主正官合身，阳日主正官克身，同是正官含义差别极大；七杀的区别看日主阴阳。
4. 伤官与食神区别巨大。
5. **财星若合日主，是我要追求的，优先看**；财星除沟通能力还有欲望之意。

## 五、十神的社会学内涵

命理的本质是**表述自我的东西与社会交换的方式**。

### 1. 自我与社会
- 自我的除日主外是伤官、食神：**伤官偏激，主蔑视社会规则；食神平和，不走极端，随遇而安**。伤官偏重独创、个性化；食神显得平淡。
- 伤官合印、食神合印＝我的思想创造被社会接受认可（所以利名声）。思想不被社会认可就没有名声。
- **官杀是社会组织的突出点、制高点；印是社会的普遍化、扁平化，大众化的主流社会观，特别容易平庸。** 所以官杀特别是七杀很难为人所用，一旦用起来就了不起。
- 官杀分阴阳：**阳官合身（主约束，有自我约束或被约束，也有管理与被管理），阴官克身（有害无益）；阴杀克害，阳杀不克害。** 杀是偏星，个性鲜明、有张力、走极端，主杀伐，名声不好，办事干脆；正官容易虚伪，杀星不计后果，「后果我担当」。

### 2. 十神心性对照
| 十神 | 心性 |
|---|---|
| 财 | 浮华，爱显摆；世俗世故圆滑 |
| 印 | 厚重，有深度；刻板无趣 |
| 伤食 | 创造，有新意；不守规则但活泼有趣 |
| 比劫 | 着急，没耐心；能作，不安分；冲动，没脑子（愣头青） |
| 官杀 | 担当，守规矩；官规矩，杀莽撞 |

- **比劫与伤官合谋，容易干坏事**（比劫义气用事，伤官不守规则，如狗头军师）。

### 3. 伤官合杀与合印
- **阳日主伤官合印，阴日主伤官合杀**；合杀更厉害，因七杀更突出（如网红必须突出）。
- 新事物的发展链：**伤食（创造）→伤食生财（融资）→财生官杀（企业社会化，财富放大，成社会突出点）→官杀生印（规模化、普及，扁平化）→印生比劫→最终破产**。印＝产能巨大化、效率低下、平庸。
- **财富 ≠ 财星**：财星只是养命之源（维持日常），是自己支配之物，够不上财富。能构成财富的要有资本级别，**官杀得用才可能是财富；规模看印**。养命的财是自己享用，资本的官杀可能成负担。
- **印**：不能太重（重则平庸），要虚才好，虚的印可以匹配其他东西，一切都要社会化才能有用。**财合印**＝财的放大、加码，上市融资、打包讲故事。印是包装。
- 命中既无官杀也无印星，社会化程度很低，要么活在自己世界，要么社会边缘人。
- **伤官偏性太重，一定要社会化才有用**：合印或被印制，合杀，或去生财（生财是效率最低的方式）。

> 人生是「我」与社会的交换：我有什么，能与社会哪方面交换。有而不能交换，终是无用之人。

## 六、配与十神的六亲

### 1. 「配」
配同「佩」，虚配的意思；有因合而配，也有干支上下一体为配（地支配天干）。

| 配 | 含义 |
|---|---|
| 配杀 | 张力化，突显引人注目 |
| 配财 | 实用化、更现实；财主沟通，也主生动趣味化 |
| 配伤食 | 增加艺术性与个性，趣味化 |
| 配比劫 | 不一定好；一般是指这东西是别人的（财配比劫＝别人的钱） |
| 配印 | 放大、包装 |

- **伤官合杀、伤官合印、食神合印、财星合印，一般主吉。唯食神合官多数不喜**：阳日干代表体的旺食神合官为凶，是引鬼上身，官代表麻烦、疾病、官司、官灾。因为食神是体（自己合到麻烦）。**伤官合杀吉，因伤官不是体，是用、是工具**：用工具制服敌人，工具虽被毁，人完好。

### 2. 十神与六亲（命理称十神不称六亲）
| 六亲 | 取法 |
|---|---|
| 母亲 | **食神**（有养育、给予养育之意）。星代表人时，用神与原神同看，故生食神的**比肩、禄**也为母 |
| 父亲 | **财星**（财的本意是养命之源，父亲辛苦养育我们）；同时取财所生的官杀同看父（父亲有管理责任）；无官星之命，父子关系和蔼 |
| 妻子 | 成家后养育责任转移到妻，**财星**也代表妻（操持养育整个家）；亦看伤官食神。**并非正财是正妻、偏财是妾，正妻要看夫妻宫**；财星落在比肩劫财下，再怎么讲都是别人的老婆 |
| 丈夫（女命） | **官杀星**（古称官人，以夫为贵）；无官杀则以财星当丈夫（财养命，合丈夫养家） |
| 子女 | **女命以伤官食神为子女；男命以官杀为子女**（官杀代表荣耀，七杀心性生猛，代表儿子）。不论男女，**财星也可以代表孩子**（无官杀有财时，财为养命之源） |

- 印不称父母：印的本意是保护，父母的意义不在保护（保护时间很短）。
- **禄**：有干禄有支禄。衣禄、享用之意：有禄或有食神的人才可能享受生活、悠然自得；但禄同时有忙碌之意，要看**有没有印配**。禄矫情要呵护；女人有禄因矫情而可爱（爱自己、爱打扮、自恋）；男人之禄要么懒，要么累死没钱赚。福禄寿，禄也有寿之意。**有禄要有印护才幸福**。

### 3. 幸福的人生
官杀与印是社会性，财与食伤是本性。成功者社会化程度高（用官杀与印），但成功未必幸福，往往身不由己被社会责任裹胁。**财星与伤食让人获得幸福，尤其是财**：财务自由，免除基本匮乏；财能克住印，保护伤官食神之自由。没有财星自由支配、没有食神享受伤官自由，谈不上幸福。

## 七、四柱宫位

### 1. 宾主与里外
- 年月一家、日时一家（月从年起，时从日起）：**年月为宾（外人、外边的事物、别人的财物），日时为主（我自己、我的财物）**。
- **里外**：月日为里，年时为外。例：开门店要把里边的东西往外卖。里外结构还用于**包局**：一般是外边包里边，外边围着里边打转（领导被一堆人围着调度；进牢房是外边凶煞包住里边，跑不出去）。结构有里外结构、左右结构，也有无结构的，但心中要有结构概念。

### 2. 时间与空间
| 宫 | 时间 | 空间 |
|---|---|---|
| 年 | 童年、少年 | 远方（古今远方概念不同）。问孩子适不适合出国，**先看年柱** |
| 月 | 青年 | 家乡（父母所在地，或小时候生活的地方）；离开与否看月与日的关系 |
| 日 | 中年 | 日支＝当下生活的地方，居住所（最重要，无法离开） |
| 时 | 老年 | 门户（比年近许多；人能不能走动，要看门户开不开） |

> 时间顺序只是大致早晚。如多次婚姻：先后顺序从年往时看，年月在先，日时在后。

### 3. 六亲与宫位
- 年月宾：祖上、外戚、父母、兄弟。**年**＝祖上、岳父母、公公婆婆；**月**＝父母、兄弟本位；**日支**＝配偶宫（坐支特别重要，此宫坏了会离婚）；**时**＝子女宫（含子孙）。
- 为什么配偶宫坏必离婚，其他宫坏不一定克：配偶不回家就不算婚姻；孩子不回家很正常、可以到处跑。所以由**子女宫与自己的关系可判断孩子将来是否远离**；只有**子女宫、星俱坏，才可能克子女**。

### 4. 宫位与身体
| 宫 | 部位 |
|---|---|
| 年 | 离日主最远，腿足。残障者常见年宫加比劫被坏 |
| 月 | 身躯，脊柱。若连体坏了可能瘫，甚至死亡 |
| 日支 | 生命最核心：胸、五脏、六腑、心、脑（具体要综合其他信息） |
| 时 | 门户，与外界联系沟通的器官：五官（眼、嘴、耳、舌）、手、生殖器官；显示沟通交流能力 |

### 5. 人物与物件
| 宫 | 人物 | 物件 |
|---|---|---|
| 年 | 长辈；有时同乡 | 鞋子、拐杖，也代表别人的东西 |
| 月 | 同学、同事、老乡、领导（结婚找同学者，其配偶星与月柱有关） | 祖产、家业、单位（富二代要注意月柱） |
| 日支 | 配偶（宫里只有配偶能在，**比劫落配偶宫不表示争配偶**，是其他意思） | 住宅、卧室，也代表自己的钱财 |
| 时 | 学生、晚辈、下属、比自己小的人 | 车子（旧时自行车，今小车）、衣服（爱打扮看时）、眼镜、化妆品、饰品 |

## 本章小结

1. 十干五行分阴阳，序由阳至阴有尊卑；甲乙权贵、丙丁精英、戊己资本、庚辛奋斗、壬癸学生；靠相生与五合流动；**日干为体不论衰旺**。
2. 五合：甲己尊卑、乙庚刚柔、丙辛日月、丁壬小大、戊癸燥润；**阴喜合阳**，合有结合、粘合、连接、加码、定义、发用六义。
3. 十神：生我印、克我官杀、我生伤食、我克财、同类比劫；**阳日财合身，阴日官合身**；伤官异性、食神同性；食伤财为本能，官杀印为社会性。
4. 做功即体用互动；伤官合杀/印、食合印、财合印为吉，食神（体）合官为凶；财富看官杀与印，财星只是养命。
5. 六亲：母＝食神（含比肩），父＝财（含财所生官杀），女命夫＝官杀（无则财），男命子＝官杀，女命子＝伤食，财亦可代表子。
6. 宫位：年月宾、日时主，月日里、年时外；日支配偶宫，时柱子女宫；年足、月脊、日心腹、时门户五官。

## 自测

1. 为什么取日主旺衰没有意义？
<details><summary>答案</summary>十为体、只用其九；日干代表「我」，是体不用。把体放到用的位置，是没有理解命理本质；日主旺衰既不表示能力强，也不表示身体好、力量大。</details>

2. 乙庚合与丁壬合，哪边沾光？依据是什么？
<details><summary>答案</summary>乙与丁沾光。一切合都是阴喜合阳：乙为阴、庚为阳，丁为阴、壬为阳；位次虽乙、丁高于庚、壬，但阴合阳是上升。</details>

3. 「伤官合杀吉，食神合官凶」的区别在哪？
<details><summary>答案</summary>食神（阳日干旺者）是体，合官等于自己合到麻烦、引鬼上身；伤官不是体，是用、是工具，用它制服敌人，工具虽被毁，自己无损。</details>

4. 财星为什么既代表父又代表妻？财富与财星有何区别？
<details><summary>答案</summary>财的本意是养命之源：幼时父亲养育，成家后养育责任转到妻子。财星只是支配与日常养命之物；财富要有资本级别，需官杀得用、印主规模。</details>

5. 为什么配偶宫坏必离婚，子女宫坏不一定克子女？
<details><summary>答案</summary>配偶不回家就不成婚姻；孩子不回家很正常。所以子女宫坏多看孩子是否远离，只有宫与星俱坏才克子女。</details>
