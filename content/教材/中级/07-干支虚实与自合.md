# 干支虚实与自合

> 本章是干支象义的收束：先把六十甲子按「干支配置」分类，讲清虚与实、实化虚的三种情形；再讲六个干支自合柱；最后用一个命例演示「反局」与取象。

## 一、干支的五类配置

天干与地支的配置不同，象义就不同——这是本派不用传统衰旺的原因。把六十甲子分成五类：

| 类别 | 含义 | 柱子 |
|---|---|---|
| 1. 干支通禄 | 天干通于地支，连体 | 甲寅、乙卯、庚申、辛酉、壬子、癸亥、丁巳、丙午（共八柱）。水火阴阳错配，壬子中子含的是癸水，仍称通禄。**戊辰、戊戌、己丑、己未之土不称通禄** |
| 2. 干支托根 | 干依支而生存，支坏则干也坏 | 甲辰、乙未、乙亥、丙寅、丁未、戊午、己巳、辛丑、壬辰、壬申（共十柱） |
| 3. 干支带象 | 天干生地支，如同一个整体的人：天干代表头，地支代表身子 | 一般天干能代表地支象。放在日主上看，就是坐下伤官或食神，地支之字可不可以被坏要看情况：**日主如果有依托的印星，地支可以被坏** |
| 4. 干支假生 | 看似生，实则非真生 | 丁卯、癸酉、甲子、庚辰、庚戌、辛未（六柱）。**这六柱地支是可以坏的，有些组合是地支被坏才好，不坏反而不好，如癸酉** |
| 5. 干支相克 | 天干克地支，或地支克天干（甲辰、乙未除外） | 甲申、甲戌、乙酉、乙丑、丙子、丙申、丁亥、丁酉、戊子、戊寅、己亥、己卯、庚午、庚寅、辛巳、辛卯、壬戌、壬午、癸巳、癸未（共二十柱），称**天干虚透**；其中一部分属于干支自合 |

- **天干虚透共二十二柱**：上面二十柱，加假生的庚戌、辛未。
- 剩下四柱：**戊辰、戊戌、己丑、己未**。戊辰、戊戌不喜刑冲；己丑、己未须刑冲反吉（因戊辰戊戌为阳库、己丑己未为阴库，见前章）。
- 说明：原稿对「带象」未列出具体柱子，仅给出定义；按原稿分类，托根与带象在柱数上有交叠之处，此处不另行推算。

## 二、虚实的应用

### 1. 虚是什么
**虚是弱化、轻化、气化，通俗地说，是地支跑天上去了**。虚实讲变化，在命理中特别重要。

| 虚透的十神 | 含义 |
|---|---|
| 财星虚透 | **才气** |
| 官杀虚透 | **名气** |
| 印星虚透 | **放大、包装、身份、荣誉**（单纯的虚） |

- **子水在天干虚，是癸代表子，不是壬**（壬不能代表子）。
- 若子表示妻子，柱中见**癸未**，那代表妻子一定跑了，离开了自己。

### 2. 实化虚的含义与三种情形
**含义**：①人（妻）离开；②做生意的一种类型——产品从多的一方移到少的一方卖出去，一边实，到另一边虚。

| 情形 | 内容 | 例 |
|---|---|---|
| 一、本气的实化虚 | 本气之支，在别处以天干形式出现 | 年上地支有寅，时上见**甲申**：寅虚在时上 |
| 二、所藏旺气的虚 | 地支中藏的旺气，以天干出现 | 寅字可以虚成**丙申**，也代表寅虚了、跑了 |
| 三、墓气的虚 | 墓中之气以天干出现，不用冲就能出墓 | 未字见**乙酉**：未中乙木可以从墓中出来，虚而出墓 |

- **大运同看**：原局没有虚实变化，大运逢之也同看。原局卯为妻，大运行**乙酉**运，代表妻在此运中跑了；原局婚姻本身不稳就会离婚，婚姻稳定则夫妻可能因工作而分离。
- **流年发生实变虚的情况，不会有大事发生。**
- 另一种变化：**庚辰变庚子**，虽不是虚实之变，也是一种变化。庚代表财，庚辰变庚子，也是一种生意——从不值钱的地方，通过加工转化变得值钱了。

## 三、干支自合

### 1. 六个自合柱
**丁亥、戊子、己亥、辛巳、壬午、癸巳**（原稿「巳亥」据上下文校为「己亥」）。干支自合属于干支相克一组，因其特殊单独讲。

| 柱 | 合 | 谁克谁 |
|---|---|---|
| 丁亥 | 亥中壬合丁 | **地支克天干** |
| 辛巳 | 巳中丙合辛 | **地支克天干** |
| 戊子 | 子（癸）合戊 | 天干克地支 |
| 壬午 | 午（丁）合壬 | 天干克地支 |
| 己亥 | 亥中甲合己 | 天干克地支（亥中虽有甲，仍是本气受克） |
| 癸巳 | 巳中戊合癸 | 天干克地支（同理） |

- 天干为君、地支为臣，天干克地支、地支不能克天干（甲申、乙酉，申酉克不到甲乙，因天干位高）。**但六十甲子中，唯有丁亥与辛巳两柱，地支克到天干**：丁亥的亥本气是壬，能合丁而克之；辛巳的巳本气是丙，能合辛而克之。比喻：皇帝权力最高，但历史上少数皇帝因后宫专权而丧失权力。
- 戊子、壬午很明显是天干克地支；己亥、癸巳看似亥中有甲、巳中有戊，但仍是天干克地支，因**地支之本气受天干所克**。

### 2. 自合的婚姻与取象
- 干支自合是**正星得正位、上下相合**（如女命正官得正位自合），按理夫妻应很好，**事实上婚姻不幸的很多，只有少数和美**。原因：
  1. 自合者心中存有一个**完美的理想结婚目标**，现实往往不能实现，理想与现实的差距造成不幸；
  2. 干支自合之支**不可被坏，不能合、不能冲刑破**，一有风吹草动就会离婚，因过于理想而变得脆弱；对婚姻要求高，造成离婚率高或单身者多。
- **多喜配在时上**：自合是阴阳相交，配合得当，表示自己的能力能充分发挥。
- 取象：

| 柱 | 象 |
|---|---|
| 戊子、己亥 | 如**井盖**，将水盖在里边 |
| 壬午、癸巳 | 阴阳气交，**水火既济**之象 |
| 丁亥、辛巳 | **天地反晦，投海、投火自毁**之象 |

## 四、命例：反局与取象

### 命例
**乾造**：己丙戊丁／巳寅午巳

大运：乙丑

- （原稿此盘为扫描件 OCR，第三个天干误作「戌」，据正文「戊土日」及日时推演〔戊日巳时为丁巳〕校为「戊」；年月〔己巳年丙寅月〕与五虎遁相符，故可信。）
- 此即上一章「隐性因果」所举的小孩：夏老师断「活不过13岁，死于戊寅年亥月，死于车祸，死时一只眼带不走」，应验。时年虚岁11。

### 断法：反局
**反局**＝命理表达的意思出现前后相反的矛盾，如论文观点前后矛盾，反应在人命上就是反局。

1. 日主戊土，戊土托于午；寅午一家，**寅的意象如人的头**：这是日与月相连的表达。
2. 同时另一个表达存在：**戊通禄于巳**（主位落丁巳，与戊连体），年上巳与时上巳也都表示他的身体。
3. 问题：**寅与巳相穿**——身体与身体相穿，相排斥、不相容，是**身首分离**之象。故必死无疑。

### 车祸之象
- 寅巳穿是**速度、动力**，两个巳相当于车的两个轮子，穿＝车轮辗在头上。
- 寅上见丙，如头上的一只眼；这个丙禄在巳，寅巳穿，**一只眼在车祸中飞走**。「如同亲眼所见车祸现场」。
- 时间：戊寅年亥月（流年应期，见前章）；大运乙丑。

### 同一盘的另一种取象（古代）
若生在古代，不是车祸（古代车无此速度），夏老师断**必死于火灾**：丁巳是印，印代表房子；丁巳、己巳两印包住命主，就是他们家住的房子，己土是瓦；寅巳穿一定是引爆什么火苗而起火，房子着火，自己包在里边出不去。

> 同一个八字可以取两种象，每个都能得到合理解释：**象既要合于理，又要合于现实生活。**

### 命理的象理
- 命理通过**干支关系、十神关系、宫位关系**呈象；每一个字在关系中得到定义与确定，离开关系无从理解命理。
- 例：戏曲舞台上武将骑马，手拿马鞭就代表马——取其象。西方谚语「长得像鸭子、叫声像鸭子、走路像鸭子，那就是鸭子」，东方人只听鸭子一声叫或走态就明白它是——象的思维。

## 本章小结

1. 六十甲子五类配置：**通禄八、托根十、带象（干生支）、假生六、相克二十**，天干虚透共二十二柱；余四柱戊辰、戊戌、己丑、己未。
2. **虚＝地支跑天上**：财虚才气，官杀虚名气，印虚放大包装；子虚为癸。
3. 实化虚三种：本气虚（寅→甲申）、所藏旺气虚（寅→丙申）、墓气虚（未→乙酉，虚而出墓）；大运同看，流年实变虚无大事。
4. **干支自合六柱**：丁亥、戊子、己亥、辛巳、壬午、癸巳；**丁亥、辛巳是唯二地支克天干的柱**；婚姻多不幸（理想过高、支不可坏）；喜配时；戊子己亥如井盖，壬午癸巳水火既济，丁亥辛巳反晦自毁。
5. 反局：命理表达前后矛盾；象要合理、合生活，同盘可取古今两种象。

## 自测

1. 通禄八柱是哪些？戊辰、戊戌、己丑、己未为何不称通禄？

2. 实化虚有哪三种？举例。
<details><summary>答案</summary>本气虚（年上寅，时上甲申）；所藏旺气虚（寅虚成丙申）；墓气虚（未见乙酉，未中乙木虚而出墓，不用冲）。</details>

3. 六十甲子中唯有哪两柱地支能克天干？
<details><summary>答案</summary>丁亥（亥中壬合丁而克之）与辛巳（巳中丙合辛而克之）。</details>

4. 干支自合为什么婚姻多不幸？
<details><summary>答案</summary>自合者心中存有完美的理想目标，现实往往不能实现；且自合之支不能被合冲刑破，一有风吹草动就离婚，过于理想而脆弱，要求高，离婚率高或单身者多。</details>

5. 命例「己丙戊丁／巳寅午巳」，为什么是反局？
<details><summary>答案</summary>戊通禄于巳，年时两巳表示身体；寅又象头；寅巳相穿，即身体与身体相穿，身首分离之象，是前后相反的矛盾。寅巳穿为速度动力，故应车祸。</details>
