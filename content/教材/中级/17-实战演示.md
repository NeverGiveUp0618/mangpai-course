# 实战演示

前面各章讲的是「套路」，本章讲怎样把套路用到实战里。套路相当于阴，修为相当于阳；只有套路而无修为，论命会死板。本章提炼出一套**实战步骤**，并用示范命例逐步演示，最后收录轶闻类命例里的分析思路。

## 一、修为的两个来源

1. **来自圣人**：推荐《系辞》和《鱼樵问答》。《系辞》讲象，《鱼樵问答》讲体用。
2. **来自生活**：多观察生活、观察自然，从中悟出命理。

**两条提纲**：

- 「在天成象，在地成形」；「易者，象也」。盲派命理的核心就是**抓象**。四个天干为「在天成象」，地支为「在地成形」；地支是形，是实的，要按天来解释；但天地需要辩证地理解，不可死套，天地之理可能互相交错。
- 「体无定用，唯变是用；用无定体，唯化出体」。**理为体，象为用**；化，是改变形态。

**示范**：

**乾造**：癸甲丁甲／巳子酉辰

天干四字为象，地支四字为形：看天干定性质，再用地支落实。

**乾造**：丁壬丁辛／未子巳亥

全是无形之气，唯一的形是辛，还虚透而为忌：手拙而头脑好。其以子为第一位（北方，万物之源），未穿子，思想在琢磨万物之源，故搞玄学。

**乾造**：癸戊己甲／卯午酉戌

此人手很巧：原局是要制有形的酉，故手巧。

## 二、实战步骤（提炼）

| 步骤 | 做什么 | 要点 |
|---|---|---|
| 1. 看格局 | 确定包围、内外、阴阳结构 | 分析方法：**格局→象→事** |
| 2. 定核心功神 | 找出被制或被用的那个字，以及用什么制 | 要制的是形还是气；功神是否连体（连体之字不能坏） |
| 3. 辨虚实 | 透干的字是虚还是实 | 实则合了就固定＝制；虚则合走＝坏功。袁世凯造与朱镕基造的差别全在虚实 |
| 4. 看阴阳形气 | 阴＝形、金水；阳＝气、木火 | 阴实阳虚；阴制阳（亥丑辰）为牢狱象，阳制阴为枪象 |
| 5. 定象 | 定职业、事业层次、性格 | 抓住功神的象（如酉＝法律，丑酉＝黑道，卯申＝带枪） |
| 6. 看大运 | 大运＝路，原局＝车 | 原局不好大运好，也能在此运中好，但运过即完 |
| 7. 断流年 | 流年先论原局应期，再论大运应期 | 原局应期优于大运应期 |
| 8. 验六亲、婚姻 | 用宫位和连体字判断 | 见上章婚姻与本章轶闻例 |

## 三、阴阳与形气

- 木为形之始，辰为形之初，金为形之终，戌为气始收，丑为气之形。辰戌称天门地户。
- 从水开始，依次是气→形→气→形→气，是形气转换的过程；八字多考虑形，故辰戌用得多。（记录者自注：对形气转换尚未深入理解，此处只录明确结论。）
- 阴阳本是一家，**一体两用**。天道为阳（阳可见，阴不可见）；地道为阴（阴可见，阳不可见）；人道：体为地道（人由父母所生），用为天道（人生的追求和做事要符合天道，命由天注定）。邵子曰：天常以用为基，以体为末。
- 易经反映时空观：寅卯是萌芽状态，看不见，故为凌晨。

**示范**：

**乾造**：丙戊辛壬／戌戌酉辰

执行死刑的公安干部。酉禄合辰＝正，不为邪；丙辛合＝干部；酉合成正＝公安。辰戌结构有屠宰场之义，戌辰为生死起灭（形气转化）：酉合辰，要制戌，戌为气灭，辰为气始，戌为要杀的人。

**乾造**：壬壬壬甲／午子子辰

传统看法只能说是富贵；盲派看：壬坐子入辰为刃带库，把财去净，官也去了，为帝王之造。天干食神吐秀，文质彬彬；地支羊刃制财，羊刃带库，杀气腾腾。（理：《滴天髓》《穷通宝鉴》；技：《渊海子平》。）

## 四、十干日主的用法特点

| 日主 | 特点 |
|---|---|
| 甲 | 最难伺候，怕金，怕外来力量侵害；甲为阳，指气；乙为阴，指形，故乙木相对好伺候 |
| 乙 | 相对好伺候；喜金克，克才能成器，喜金火组合 |
| 丙 | 阳火，怕焚、怕过旺 |
| 丁 | 阴火，喜旺；搞玄学，天干中丁越多越好，地支有子、丑；丁是神秘之字，天文＝老天做的文章 |
| 庚辛 | 金为形之成，不必考虑旺衰，关键是如何去用；「体阴用阳，体阳用阴」，这就是金水伤官喜见官 |
| 辛 | 乐水之盈，庚金是钢坯，辛金是首饰；天干虚了也不怕（如辛巳、癸巳，一点癸已足够） |
| 戊 | 偏重于形，要找气，故要开戌、辰库 |
| 己 | 气胜于形，要找形，故要开丑、未库 |
| 壬癸 | 水喜落到实处生木；壬寅容易成大格；气一定要找形 |

补充：木生火——木是形的形成，不代表体的形成，火是外在条件；水、金、火喜「从」，木很少喜从（除甲午、甲戌）；形的只能自己坐自己（如甲寅、庚寅），气的则要坐别的（如丙午）。（记录者自注：此条存疑。）

**癸乙、甲丙、戊申、丁己**：癸见乙＝食神最厉害，功大，喜；戊见申＝厉害，功大，喜；甲见丙＝搞文的，泄了；丁见己＝不好，泄了（丁不喜泄）。

## 六、流年应期的三条规则与长篇示范

**规则**：

1. 原局是车，大运是路。
2. 原局不好、大运好，也能在此大运中好，但**运过即完**（不多见，特殊）。大运就是原局的应期。
3. 流年有两种应期：原局应期与大运应期；**流年的原局应期优于大运应期**，若发生了作用，则以大运为主。

**乾造**：辛戊庚己／丑戌寅卯

## 八、命术轶闻中的分析思路

### 1. 父母应期与大限

**坤造**：乙乙丙己／未酉戌丑

乙为母，未与乙连了也是母；酉为父，戌穿酉，死父。母：丑未戌三刑母有问题，16 岁庚戌年死母（大限定在 18 岁前，未戌刑了，16 岁为标准应期，戌到）。父在月柱，大限为 18 岁之后，19 岁癸丑年死父（原局戌穿酉刑未；大运丁亥，丁到为戌到，丁透干无制，戌旺要应事；酉太弱，不是拱而是入墓，癸丑是墓到）。同年同月同日生、庚寅时者，父甲寅年去世（金绝于寅，原局有寅应寅年；此造原局有丑应丑年）。
 
- 婚姻：夫宫犯三刑，无官以财为夫，穿了，故不好；无官无财则印也可为夫。19 岁癸丑年结婚（丑刑戌，解酉戌穿，要刑入夫宫）；运走官杀地则一定能结，走比劫地不一定。戊子运甲戌年离（应穿）。
- 诀：**女命年上伤官空亡，公婆不喜，子女不孝。** 肾病在己丑运丁丑年：子女宫坏，伤主肾；丙的根有两个（未和戌）则不敢坏，若一个根则敢坏。
- 命犯桃花：丑中癸水不为夫而是桃花——**余气的含义**：①很弱了、最后一个、量很小；②剩下的、中途的、别人的、别人退下的。诀：丙见丑中癸水为淫荡（阴阳关系）；丙子年丙到，丁丑年离，一刑就走。

### 2. 黑道与违法组合

**坤造**：壬癸辛丙／寅丑酉申

丈夫是黑道人物：寅丑合过来，寅丑酉申入丑中；一星三宫应三次婚姻。己巳年巳酉拱第一次婚（巳代表丙）；庚午年离（丑午穿，寅午一党，寅丑合表婚，丑午穿表离）。壬伤官为儿，生寅（带帽），孩子给了男方。

**乾造**：壬甲癸乙／辰辰巳卯

（夫的盘）辰主阴，穿卯（阳），阴制阳＝比劫伤官组合；乙卯力量大于甲，甲统领辰，是老二；戊申运反局，癸酉年穿倒食神，凶死。

**黑道的两种组合**：①劫伤组合（比劫本是无知物，一见伤官势必归）；②伤食与官杀**对抗**（不是制）。

**坤造**：己甲甲乙／酉戌申丑

16 岁开始从男人手里赚钱（做小姐）。甲己合，申酉入丑，丑主阴阳、背着人；戌中暗伤官（内伤官），酉戌穿与官杀穿，对抗法律。丁丑运丁运己巳年投案，减刑后住三年，壬申年出，丁壬合，第二年又进去一年；过了丁运就没牢狱。原局金水有势要制戌，对抗不起来，丁运火旺才能对抗。甲戌年妇科病：丑戌刑到子女宫，宫外孕，大手术。

### 3. 虚实、汉奸与多妻

**乾造**：戊壬辛甲／戌戌亥午

（改编的故事）丙寅运当县长，合火局，去伤得官；丁卯运之丁运乙酉年丢官逃跑；七个老婆（一个妻宫，很多妻星，木火都是妻星）；戊辰运丁酉年被枪毙，冲合反局。哪个酉年都没事，唯独戊辰运酉年有事（酉辰合）。

**乾造**：戊壬乙己／辰戌未卯

原局制净了水，丁卯大运之丁运劳动改造，反局。

**虚实对比**（朱镕基造戊壬乙己／辰戌未卯与袁世凯造己癸丁丁／未酉巳未）：朱的壬水为虚，原局有戊克，丁运一合，因虚被合走，原局要制水，合走了就制不成；袁的水为实，实的一合就固定了，固定住了就是制了，制了就得到了。

**多妻组合**：

**乾造**：辛庚甲庚／巳寅午午

妻宫多现，五个老婆。

**乾造**：壬癸辛辛／寅丑亥卯

七个老婆。五个星宫，合了两次，共七次；顺序从上而下，从年到时。

### 4. 命克子女

**坤造**：丙戊丁丁／子戌丑未

三刑，子丑一合，反局；若无子丑合，至少老公很有钱，一合就穷命。子女星犯三刑，子女残疾：

- 长子 **乾造**：甲丁甲丁／辰丑戌卯 — 甲生了丁，丁为思想，左右相战（丑入辰与卯相穿），思想有问题，神经病；23 岁卯运卯年谈恋爱被拒而疯。
- 次子 **乾造**：壬丙丁甲／子午丑辰 — 午火比肩主手足，子在年上为腿，一冲腿残了。
- 三子 **乾造**：甲丁辛庚／寅丑酉寅 — 年时两头坐绝，不能出门户，瘫痪（禄逢墓绝，禄为身体）。辛日主两头墓，亦盲人且不能动；巳酉丑，阳气不足，阴土无阳气，脾湿，土主脾主力，要治脾。

### 5. 骗子、小偷、其他

**乾造**：壬癸辛乙／子丑酉未

大运：甲寅（3 岁）乙卯 丙辰

门户坐财，做房地产、大酒店，局大；伤官食神透干主语言，是骗子。26 岁丙运丁丑年发财，28 岁己卯年结婚，庚辰年坐牢：原局只一个未是阳，辰运一来全是阴地，终生坐牢；丑酉组合表黑道；骗上亿资产（制库）。

**盗贼与小偷**：乙己庚己／酉卯子卯（偷自行车摩托车，用脚）；辛丙己甲／亥申丑戌（用时上比劫，用手偷）。

**坤造**：壬辛己丙／寅亥未寅

寅入未库，寅亥合，壬寅带象。一生卖身赚男人的钱，右腿有毛病，官统财又顶着财入坐下，库不开，故不发大财；亥未拱一点，能拱出一点乙木。寅亥合，肾病，死于辛巳年（寅亥合又入未库，丙辛合，水气全无，血枯精闭）；无子女。相似例壬辛己丙／戌亥未寅，有钱，婚姻几次，拱一个、墓一个，估计无孩子；刑开了，所以无事。

### 6. 将门虎女、父亲的悲哀

**坤造**：壬癸丙戊／辰卯辰子

婚姻好：卯辰穿，癸不是夫（如只是官杀穿则可能是夫）；辰为夫宫，年上壬为夫；辰拱合子，子是一家（中神），不当第二个夫，算副宫；丙戊一家，丙辰→戊子表搬家。戊癸合，食神制官，能说会道。无孩子：卯辰穿了子女星，晚得子，**润月年生孩子**（中国为三统历：阴、阳、甲子历；润由阴不足阳有余，阴不足则形不足，润来补，故润月年补足形，易生子）。

**乾造**：甲丁丙戊／辰卯辰子

子星入墓被穿，无子，癸酉年润月年生一女（无财，官杀都当女儿看）。

**乾造**：乙己壬壬／卯卯子寅

丁丑运甲戌年春洗澡时煤气中毒死。时上寅食主寿，入空亡，寿不长；伤官破子，坏了子水，阴不足；最坏在丑运，天地合绊不能生寅木；甲戌年甲木虚透合走。丁丑：湿土上生的火，燃烧不充分，煤气之象。

**乾造**：己丙戊丁／巳寅午巳

3 岁时断活不过 13 岁，实际乙丑运戊寅年亥月车祸，丢一只眼。寅为头，丙为目，长在头上，一穿，左眼飞了。穿禄、反局结构：若不透丙火也没事，穿了顶多腿受点伤，透了丙，丙为戊，丙为头，一穿身体分开。禄占两头，没有生存机会，必须在丑运之内死，大限卡了。

## 本章小结

1. 实战步骤：格局→象→事；定功神→辨虚实→看阴阳形气→定象→看大运（路）→断流年（原局应期优先）。
2. 修为来源：圣人（《系辞》《鱼樵问答》）和生活。
3. 十干特性：甲难伺候，乙喜金克，丙怕焚，丁喜旺，庚辛不论旺衰重用，戊找气开辰戌，己找形开丑未。
4. 虚实：实的一合固定＝制；虚的一合走就坏功。
5. 流年应期：原局车、大运路；运过即完；原局应期优先。
6. 轶闻思路：大限定应期（18 岁分界）、余气为桃花、阴制阳为牢、劫伤组合与对抗为黑道、穿是推倒、冲刑是开库。

**自测**

1. 虚与实对合绊的结果有什么不同？举例说明。

<details><summary>答案</summary>实的一合就固定住，等于制了；虚的一合就被合走，功神被破坏。朱镕基造的壬水是虚（合走即坏功），袁世凯造的癸水是实（合绊即固定，等于制）。</details>

2. 「流年的原局应期优于大运应期」是什么意思？

<details><summary>答案</summary>流年有原局应期（原局作功部位、关键点）与大运应期两种，原局应期优先；若发生了作用，则以大运为主，如徐向前造中戊午年为原局应期。</details>

3. 余气（如丑中癸）的两层含义？为什么不能当夫？

<details><summary>答案</summary>①很弱、最后一个、量小；②剩下的、中途的、别人的、退下的。因此不足以构成丈夫，只作桃花。</details>

4. 十干日主戊与己各要开什么库？

<details><summary>答案</summary>戊偏重形，要找气，开戌、辰库；己气胜形，要找形，开丑、未库。</details>

5. 甲坐戌、丙戊类「包围型」命局，如何区分「半个主子」与「皇帝」？

<details><summary>答案</summary>看日主与时柱坐支是否全是自己的禄：康熙造丁坐午全禄，是皇帝；林彪造未是丁半个禄，半个主子；癸水压年上反象则是伪政府。</details>
