# 官命看法

官为立身之本。盲派看「能不能当官、当什么官、官多大」，不看日主旺衰，只看官杀、印与其他神是否**做功**，以及这个功落在谁身上。

## 一、官命的核心与总则

**核心**：必须有官（杀）与印。官杀主职务，印主权柄。

**可成官命的六种组合**（有做功才成，官职大小看做功好坏）：

| 组合 | 做功方式 |
|---|---|
| 官杀配印 | 印化官杀（生用、化用） |
| 官杀配伤官 | 伤官制官杀，或官杀制伤官 |
| 官杀配劫刃 | 官杀制劫刃，或劫刃制官杀 |
| 印配财星 | 财制印，或印制财 |
| 印配食伤 | 印制食伤，或食伤制印 |
| 印配比禄 | 印生禄，禄在主位当权力（官禄格） |

**总则**：

1. 官杀与印不管怎么做功，**必须有根**；官杀虚透只当名气。官杀虚透，大运落实时，也易当官。
2. 印、官杀、伤食或财星做功，**必须有主位的字参与**；若功落在其他位置，容易走向发财；做功做不好，也容易转向取财。
3. 做功要「制干净」：制一定要真正制住对方，对抗而不分胜负不算。制不净者官小或转为取财。

**部门特征**（看做功的字）：

| 组合 | 部门 |
|---|---|
| 申、酉做功 | 检察、法院、法律 |
| 申、酉、丑、寅做功 | 公安 |
| 羊刃＋七杀 | 执法、实权、军队 |
| 伤官＋官杀 | 实权部门或纪检 |
| 食神合印（佩印） | 带思想文化性的行业 |
| 伤食旺 | 文化或文官（不一定执法） |

## 二、制用做功当官

制用当官最多。分四类。

### 1. 官杀配伤食

**乾造**：丙甲乙甲／申午卯申

乙木坐禄，合时上正官，原局无七杀混杂，故官高。甲换象到月上，坐午火伤官，透年上丙火围制年上申金，是伤官制官；时上申与卯是「合」，不叫制。卯只合时上申（近合先合），羊刃甲当自己看。最高人民法院副院长。

**乾造**：戊癸庚丁／子亥戌丑

大运：甲子 乙丑 丙寅 丁卯 戊辰 己巳

山西省公安厅长。金水有气去火土，子亥旺但与戌不起作用，不算做功；丙戊同出于戌，戊合癸，戌官库在坐下。辰运冲开官库、会水局，庚辰年升职，壬午年升厅长（引出戌中丁火）。时辰疑为丁丑（丑戌为法律之象，更能制戌）。

**乾造**：庚壬乙丙／寅午酉戌

寅午戌合火局去酉金（杀），乙庚合得官，是伤官去官格，山西省政法委书记。丁亥运丁壬合住印，寅亥合、午亥暗合，都是合印，印为权。

**乾造**：壬丁辛甲／午未巳午

杀制伤官，官杀重而伤官轻，捕多贼少，喜行贼运：辛亥、壬子二十年水运升至厅级，体委主任。

**乾造**：戊癸辛辛／戌亥卯卯

大运：子 丑 寅 卯 辰 巳

局中无官，官杀库（戌）当官看；卯财合戌是「拉」，制不净，木土结构搞房地产。曾是厅级国有建筑公司经理，后企业改制降级。

### 2. 官杀配劫刃

**乾造**：甲丁甲甲／申卯申子

甲日坐七杀，卯申合，杀合羊刃（卯）而做功；羊刃主枪，申为屁股，相合＝带枪，公安系统。申为妻，杀为子，都在公安系统。丙寅年（寅申冲冲动夫宫）妻想调动调不成，丁卯年卯申合得合回而调成。

**乾造**：戊乙甲丁／申卯申卯

申暗合卯，羊刃透干，时上丁火坐卯＝伤官泄秀在时上，门户为手：耍笔杆子的政法委处长。**诀：伤官泄了羊刃，主文笔、文官**；卯木空亡不带枪，庚申运才带枪。

**乾造**：丙辛甲丁／午卯申卯

不是执法部门：伤官（丁）太重泄羊刃，卯午破、火旺破刃，卯空亡；伤官主自由，不愿被约束。新加坡石油公司高级主管；甲申年公司给股份发财。

**乾造**：辛丙辛癸／卯申未巳

李宗仁造。未、巳旺，卯又生之，卯申合，未穿申，是制去申金（劫财）；巳申合，官合劫财。管军队的军官（火制金为军人，金水为伤官、七杀、劫财时更明显）。**不敢见戊**：戊申连体生身，使申辛密切，原局本为去申，反局；戊子运戊申年死。

**乾造**：戊壬癸壬／辰戌巳戌

李鹏造。火土气势，用财库制去比劫库，戊癸合为控制管理，是管经济的最大官；戊辰、己巳运当官。

**乾造**：壬丙壬丙／子午辰午

壬水自坐七杀，旺财生七杀，年上壬子入辰库（羊刃库），羊刃合杀、杀统财：法院经济庭庭长，是管财而不是贪财。（羊刃库、七杀、官统财三象。）

**乾造**：壬丙壬丁／子午辰未

此造与上造仅时辰不同，即不为官也不发财。年月支冲、日时干合，且未入辰墓，原局就反局；庚戌运戌冲辰坏自己的根，判断因贪财入狱。**对照**：壬丙壬己／子午辰酉（阴包制阳，内外结构，不反，搞技术）、壬丙壬壬／子午辰寅（医生）。

**乾造**：癸丁丁戊／巳巳巳申

布莱尔造。癸杀坐巳被合制，戊伤官又合杀，制杀得权，制得好权大；巳申合制官之原神。伤官在门户主表达，官主法律，当过律师。壬子运甲子年当律师，癸亥入下议院，丁丑年任首相。

**乾造**：乙戊壬癸／巳子子卯

地区公安局纪检书记。刃透干合杀；乙巳带象，估计到顶。

### 3. 印配财星

**乾造**：丁己癸丁／未酉巳巳

刑警队长。火土成气势制酉金（印），酉上戴官帽，己酉一象；印为权力，未七杀制酉，制酉如抓犯人（酉为阴中之阴＝罪犯，阳制阴为枪象）。己酉运、辛巳年连升。

**乾造**：戊壬乙己／辰戌未卯

大运：亥 子 丑 寅 卯 辰 巳 午

朱镕基造。燥土气势制辰中水和天干水（辰戌冲，未戌刑，壬戌自合），制得好；时上卯禄合戌，合到主位，财库制印库，印为权力，制印得权，是管财的大官。戊辰、己巳运好。

**对照（反局）**：

**乾造**：己癸丁丁／未酉巳未

袁世凯造。戊运当官。癸水是**实**的（癸酉一柱），实的一合就固定住了，合绊后不能再坏事，相当于制去；朱造的壬水是**虚**的，原局靠戊土克它，丁运一合走壬，等于坏了功神，故不同。区别全在虚实。

**乾造**：戊壬辛甲／戌戌亥午

丁卯运丢官罢职，戊运酉年被枪毙，与朱造同样原因——反局。

### 4. 印配伤食

**规则**：一定要做功，一定要制了另一方。

**乾造**：乙丁甲丙／未亥午子

大运：戌 酉 申 未 午 巳 辰

木火有势制亥，丁亥自合，午亥暗合：伤官去印，去印得权，但制不干净，亥未拱是拱印分权。辛巳年巳冲亥印，从县委书记到市委书记（职级未变，正处）。甲木是活木，制水表示身体有问题，流年冲主动，无问题。

**乾造**：乙丙甲甲／未戌子戌

火与燥土成势，财制印；财是食神之库，与文化有关；未是羊刃库，也与执法有关：早年当教授校长，后任法院院长，司法局局长（厅级）。

**乾造**：辛己甲庚／丑亥子午

乙未运癸未年升副县长。印制食伤，甲为活木；制干净不怕合。

## 三、生用化用做功当官

### 1. 官杀配印，印化官杀

**乾造**：甲戊甲甲／申辰寅子

原是副省长，后任部长。戊辰月令财星，是政府的官；子水化申杀、合成水局生身，升国家计生委主任（正部级）。

**乾造**：戊戊戊甲／午午午寅

《滴天髓》例。火土一气，午火印化杀生身。**化用不如制用效率高，所以级别不大。**

**乾造**：戊戊戊甲／戌午午寅

入狱之造。无财以伤官为财，寅午戌因中神午双现不能成局；戌中辛是财，所有的午都来抢辛而入墓。本为几百元的发票开成三千报销，入狱三年。辛酉运穿戌，换了几次地方，一干饭店就倒：**财不能穿，穿了与财无缘**。

**乾造**：丙辛戊丁／午丑寅巳

大运：寅 卯 辰 巳 午 未 申

县委副书记主管政法。七杀（寅）做功，丑主阴暗，时上见禄，印制伤；丙在年上、丙辛合到年上，故外放；寅巳穿也主外。寅丑暗合：辛丑为靠山。乙巳运辛巳年外放，丙午运在外升职。（盘上寅为小人，戊寅年犯小人。）

**乾造**：丙辛戊丙／午丑寅辰

同样只差一个时辰，印丙太虚化不了，不为官：做公司，留学生输出（伤官库往外合）。

另有一例正处（原稿盘面有疑，略）：把戊土、申金（官和官之原神）全制了，大官。流年规律：禄冲官杀倒霉，冲财得财；合太岁＝亲合；冲印主调动；比劫合走自己的位，表位被人占。

### 2. 印生禄，禄在主位当权（官禄格）

**坤造**：乙丁乙己／未亥丑卯

大运：子 丑 寅 卯 辰 巳 午

慈禧造。三合成禄局，去官与官的原神，时上见禄；亥印主权、国家，卯为朝纲；女命禄为身体，禄会到时上＝乱怀不乱朝，克夫克子。午运破禄而死（戊申年）。

**坤造**：乙丁乙己／未亥未卯

满盘皆禄，丈夫很有钱，但另有小情人生子；乙卯身材好，性感；禄印相随，会享受。

### 3. 印带官帽子，与主位发生关联

**乾造**：壬己壬甲／寅酉申辰

大运：戌 亥 子 丑 寅 卯 辰 巳

银行副处级。印去制宾位寅木，印为权力在主位，辰酉合、申辰拱；伤食为财的原神，申为金融。**官帽子可摘**：甲己合去官帽，甲申年丢官。**印为用时，怕大运坏印，坏印则丢官**。

**乾造**：壬丁丁庚／寅未巳戌

壬寅为印带官帽，寅入未库，巳入戌库，寅巳穿。庚戌运巳入戌库不穿寅，做官；辛亥运亥冲巳解穿，仍做官；壬子运不当官而经商（穿了）。

**乾造**：甲甲戊癸／午戌午亥

木火成气，午火带劫财之印合亥财，戊癸合财，制官的原神；午伏吟到年上戴杀帽，化杀生身：军区司令部副部长（正厅）。

**乾造**：甲丙戊癸／午子午亥

方式同上，但丙午冲一子，夹冲不净，官的原神去不净：正科级。

**乾造**：庚己甲己／子卯辰巳

副县长。庚子带象，子辰合：辰生庚，中神过河；子印与主位辰拱，官位与己有关。壬午、癸未运穿冲年上印，升职（癸未年升常务副县长）；中神在宾位＝副职；甲己合，桃花多。

**乾造**：甲癸辛己／午酉卯亥

大运：戌 亥 子 丑 寅 卯 辰 巳

年上杀带财帽，在宾位，但己午相通到主位，被亥合制：财政局长。丑运穿午，升局长；寅运寅生午，升而无实权（明升暗降）；己卯运丙戌年车祸亡（连体之字不能坏，流年反局）。

**乾造**：辛庚丙癸／丑子戌巳

无印，官透到禄上，是企业经理人。乙未运丙戌年：戌刑丑，问升职、加薪、调动，实为调动（从内部管理调去市场开拓）。

## 五、管财的官与做企业的官

**规则**：**戴什么帽子就以什么为主。**

| 帽子 | 以什么为主 | 常见职业 |
|---|---|---|
| 官戴财帽子 | 以财为主，以财看象 | 国有企业经营者 |
| 财戴官帽子 | 以官为主，以官看象 | 行政官员（与财有关的官） |

**乾造**：乙己庚庚／巳丑午辰

官戴财帽，杀偏（在年上）；辰化杀生身，乙庚合；乙酉运巳酉丑合，辰酉合，副职：学校总务处副处长。丁丑年、辛巳年升官，与午无关，穿倒午，与巳有关。

**乾造**：壬辛壬辛／寅亥子亥

大运：壬 癸 甲 乙 丙 丁（子丑寅卯辰巳）

印刷厂厂长，管三十来人（亥木三，不超过两个因两亥）。去财结构，去不净，效率低；内食神不透干，搞企业；寅亥合月上辛亥为公家的厂，合时上辛亥为自己的厂，甲寅运合时上亥化公财为私财。**看子女：把子女出生年放到第五柱来结合看**：子丙寅年生，与时柱合绊，丙主语言，合绊＝不爱说话；羊刃比劫，儿子将来当将军。

**乾造**：乙庚辛壬／巳辰卯辰

官戴财帽，一辈子离不开管财管物；坐下财透年上，早婚；卯辰穿不生儿子，要借腹生子。乙亥年升副处，戊寅年正处，丁丑年扩权，庚辰年副厅。

**乾造**：丁己戊丙／未酉子辰

银行管财的官。丙戊为一家，子未穿官库；子辰虽会财局，但是替别人管钱。无官以印当官，乙巳运印生官，辛巳年升官，甲申年巳申合、申子辰会财局又升。母丁坐未，子未穿坏母根，壬午年丁壬合、午未合闭未库，母亡。

**乾造**：癸癸庚庚／卯亥午辰

钢铁集团副总。水生财入辰库（辰为印＝单位）；月令亥水合午官，月令为大，国有大企业。未运三合木局，自己只得余气，二把手；戊午运可能一把手。

**乾造**：己丙庚己／亥寅辰卯

大运：丑 子 亥 戌 酉 申 未 午

自己的私营企业。寅亥合制杀取财，制不好；亥入辰库＝控制，辰为印为企业。财戴官帽不用官去官＝私企。不敢财星合身（破大财）；乙亥年乙庚合，卯到，打大官司破财二百万美元。官司因财而起（民事纠纷）；若官被坏则是公检法来闹。

**乾造**：乙庚丁辛／巳辰未亥

大运：卯 寅 丑 子 亥 戌

## 六、根与虚的要求（总结）

- **有根**：官杀、印必须有根；虚的只能当名气，要靠大运落实。
- **有主位的字**：功必须落在主位或与主位相连。
- **有制有用**：制要制得干净，印要真正做功。
- **连体之字不能坏**：如辛庚、丙戌等，流年大运坏了即反局，丢官或出事。
- **官帽可摘**：印戴官帽，大运、流年合走即丢官。
- **差一个时辰**：官命与否常由虚实、能否合回主位而定，如丙辛戊丁／午丑寅巳与丙辛戊丙／午丑寅辰。

## 本章小结

1. 官命核心：有官杀与印，有根，有主位的字做功。
2. 六组合：官杀配印、配伤官、配劫刃；印配财、配食伤、配禄；制用效率高于生用、化用。
3. 部门：申酉＝检法，申酉丑寅＝公安，刃＋杀＝执法军队，伤官＋官杀＝纪检，食神佩印＝文化。
4. 印戴官帽：官帽可摘，印不能被大运坏。
5. 官戴财帽＝管企业，财戴官帽＝管财的官。
