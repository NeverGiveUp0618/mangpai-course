# 天道、阴阳、五行、体用

> 本章是干支象义的总纲：先弄清「天道—阴阳—五行—生克—形气—体用—象」这条逻辑链，后面所有取象、做功都从这里长出来。原稿本部分只在车祸断例处给出一个四柱盘（取自原稿后文），其余以断例故事与生活类比为主，不编造干支。

## 一、天道：干支为什么能推命

### 1. 天不是空间，是时间
- 古人说的「天」，不是头顶的太空，而是**日月运行、寒来暑往的周期时间**，即天道。
- 「天圆地方」的本意：**圆＝时间的循环（天道主时），方＝四方的方域（地道主位）**，并非说天穹是圆的、大地是方的。
- 研究范围限定在「太阳之下、地球之上」的万物；与此无干的东西存而不论。

### 2. 天人合一与可验证性
- 天道规范人道：人的行为、命运都受天道约束。天道既然**可知**（圣人用干支把它表出来），人的未来就可以预知，这是一切术数的根源。
- 命理重**实用、可检验**：只问「能不能预知」，不问纯推理。术数与数学的区别就在于术数只有一个目的——预知未来。
- 对天道有敬畏（畏天命），但中国传统里没有凌驾于天人之上的「神」：只有天与人，天道支配一切，人敬畏而不迷信。

### 3. 命理的起源与结构（时相学）
| 项目 | 要点 |
|---|---|
| 三统历 | 阳历（太阳周期）、阴历（月亮周期）、干支历（中国特有）。命理只用**太阳周期的二十四节气中的十二节**与干支历，不用月亮周期 |
| 纪日 | 干支纪日自甲骨文时代起连续不断，从未错过一天 |
| 纪年 | 干支纪年始于汉武帝时期；此前纪年名称各异（如「摄提」） |
| 命理的出现 | 须先有干支纪年、纪月，才可能有命理；秦汉前只有「天命」观念 |
| 沿革 | 唐代李虚中最早用干支推命，但以年为主、不用时，多用纳音；宋代徐子平完善，以日为主，故命理又称子平术 |
| 月柱 | 以太阳历十二节定月，月干由年干起，用**五虎遁** |
| 时柱 | 一天十二时辰定时支，时干用**五子遁**从日干起 |

- 核心思路：**出生时间 → 干支符号 → 四柱模型 → 象义模拟 → 时序展开（大运流年）→ 推演命运**。命理是「时相学」，这里的时间是地球上循环往复、寒热往来、影响万物生灭的时间，不是均匀流逝的物理时间。
- 四柱结构：年月一家、日时一家（月从年起，时从日起）。以日干为「我」，其余干支都按与日干的关系定亲疏吉凶，离日主越近越亲：日下坐支（配偶）最近→时柱（子女）→月令（父母）→年柱（祖上及岳家、公婆）。这就是**宾与主**的概念（详见本书宫位一章）。

## 二、阴阳：天地之道

### 1. 《内经》定义的五句话
> 口诀：阴阳者，天地之道也，万物之纲纪，变化之父母，生杀之本始，神明之府也。

| 句 | 含义 |
|---|---|
| 天地之道 | 阴阳来自**日地运行**：地球公转产生寒暖（一年），自转产生昼夜（一天）。夏至阳极、冬至阴极，是阴阳分界 |
| 万物之纲纪 | 地球上一切有形之物（人、动植物、山川）都在阴阳的规范之中。知道天地之道，就能知道万物的相关性 |
| 变化之父母 | 同性质的是「变」（禾苗长成庄稼），转为异性质的是「化」（蛹化成蝶）。阴阳是推动一切变化的力量 |
| 生杀之本始 | 阳推动生，阴推动杀；没有永远的生，生者终要死，留种再生 |
| 神明之府 | 神＝能沟通天地；神明也是人的思想意识，悟得阴阳，思想才能与天地相通 |

### 2. 阴阳的三个属性
1. **互根、互存、互用、互藏**：阳极处阴并未消失，是藏起来了（夏天地下凉＝阴藏于地，冬天泉水不冻＝阳藏于地）。
2. 相互**消长**。
3. 能相互**转化**：阳极反阴。冬至一阳生，夏至一阴生。

### 3. 阴阳是绝对概念
阴阳不是相对的矛盾统一，而是确定的属性：阳就是阳，阴就是阴。

| 类别 | 阳 | 阴 |
|---|---|---|
| 寒热 | 热 | 寒 |
| 升降 | 升 | 降 |
| 动静 | 动 | 静 |
| 左右 | 左（主肝升） | 右（主肺降），不可颠倒 |
| 性别 | 男 | 女 |
| 方向 | 横（动物横行、五官能动者横长） | 竖（植物竖长、耳鼻竖长不动） |
| 生物 | 动物 | 植物 |

- 积阳为天，积阴为地；人得天地之气最全：头圆象天、足方象地，直立而横行，有完整的声（地气）与音（天气），上下眼皮同动而合，五官俱全（耳眼鼻口眉）。
- 日常的阴阳互用：出拳先收（阴为阳用）；家庭中「阴在内，阳之守也；阳在外，阴之使也」。

### 4. 干支使阴阳可定性定量
圣人用干支符号化阴阳：**阳到极点就是「午」（夏至前后一个月的天候），阴到极点就是「子」（冬至）**。从此阴阳不再是观念，而成为可以演算的规则。子午是阴阳的符号，干支把「阴阳之理」转为「阴阳之象」，演算才成为可能。

## 三、五行：阴阳的五种力量

### 1. 五行不是五种物质
「行」是运行、行使，五行是**五种不同的力量（能量）**，由阴阳二气化生。金木水火土只是便于理解的形象名称。

### 2. 一天、一年中的五行
| 五行 | 一天 | 一年 | 阴阳状态 | 气的性质 |
|---|---|---|---|---|
| 木 | 早晨日升 | 春，三月 | 阳始 | 温，生物；升气 |
| 火 | 正午最热 | 夏，三月 | 阳极 | 热，长物；热气 |
| 金 | 下午日落 | 秋，三月 | 阴始 | 凉，收物；降气 |
| 水 | 夜晚 | 冬，三月 | 阴极 | 寒，藏物；寒气 |
| 土 | — | 寄于每季最后一个月（季月） | 中气 | 承载其他四行；不偏不倚 |

- 木火主阳（上半年），金水主阴（下半年）；土按所在季节分属阴阳。
- 土代表**地球本身**：人立足于土，才感受得到另外四种来自太阳的能量；土居中央，承载四行，无土则四行无立足之处。
- 土藏于四季月：每季最后一月（季月）为土月，秉四季木火金水之余气而成，故有「五季」：春、夏、长夏（季夏）、秋、冬，对应木火土金水。

### 3. 五行类象（象义的第一层）
| | 木 | 火 | 土 | 金 | 水 |
|---|---|---|---|---|---|
| 气 | 升 | 热 | 中气 | 降 | 寒 |
| 类象 | 升腾、向上、生长、给予、释放、膨胀、仁爱、慈爱、关爱、温情 | 阳气盛、成长、盛大、光亮、开放、艳丽、激烈、热情、文采、文艺、影视 | 承载、养育、运化、中和、包容、受纳；厚重、忠诚、笨拙、中庸、自足、圆满、和谐、平台、中介、过渡、纽带 | 下降、凋败、清冷、干净、清净；杀伐、收回、坍缩、律令、理性 | 寒冷、趋下、归隐、闭藏、没有生机、阴险、深藏不露；机巧、计算、谋略 |
| 色 | 青 | 赤 | 黄 | 白 | 黑 |
| 德 | 仁 | 礼 | 信 | 义 | 智 |
| 气（中医） | 风 | 热 | 湿 | 燥 | 寒 |
| 脏 | 肝 | 心 | 脾 | 肺 | 肾 |
| 方 | 东 | 南 | 中 | 西 | 北 |
| 味 | 酸 | 苦 | 甘 | 辛 | 咸 |

- 备注：水主黑，秦人尚黑取水德，并以立冬水月为岁首，违天道而国祚短（古人的评述）。五德以「信」为本，故帝王宫室服饰用黄（土色，居中取信）。肝气从左升、肺气从右降，指气的运行，不是解剖位置。味觉口苦＝胃中有火，是五味入医的例子。
- 由自然之象推及人事之象，万物经类象变成符号，纳入演算——这就是「象」的第一次出现。

## 四、五行生克

### 1. 生与克的来源
- **生**＝五季顺序运行：春木生夏火，火生季夏土，土生秋金，金生冬水，水生春木。若把五行当五种物质，就解释不了「金生水」「火生土」；只有当作五种气的时序接续才讲得通。
- **克**＝阴阳之克：春主升、主生，秋主降、主杀，故**金克木**；夏热冬寒，寒克热，**水克火**。这四极之克不能圆满，加土之后成隔位之克：金克木、木克土、土克水、水克火、火克金。
- 生主阳，克主阴，是一对阴阳；生克是五行运行的**运算法则**，如同算术的加减乘除。

### 2. 生克的现实意义
- 生＝生长、促进、推进、放大、滋养、助力；克＝抑制、消灭、破坏、打压、消耗。复杂系统必须有促进和抑制两个功能形成反馈才能稳定（如成骨细胞与破骨细胞）。
- **只生不克会成灾**，克是为了更好的生：

| 克的作用（无克之弊） | 只生不克（过生之弊） |
|---|---|
| 金克木，木无金克不能成栋梁 | 木生火，火更旺则灰飞烟灭 |
| 木克土，土无木克则飞沙走石 | 火生土，越生土越焦烈 |
| 土克水，水无土克则泛滥成灾 | 土生金，越生反被土埋没 |
| 水克火，火无水克不成既济 | 金生水，越生越无生机 |
| 火克金，金无火克不能成器 | 水生木，越生越野草丛生 |

- 做人也是如此：任何事物的偏爱不可过分，一味付出的感情久了会由爱生恨。

### 3. 生克化生六亲、十神
设一个「我」，生克产生五种关系：

| 关系 | 六亲（占卜用） | 十神（八字用，分阴阳） |
|---|---|---|
| 生我者 | 父母 | 正印、偏印（枭） |
| 我生者 | 子孙 | 伤官、食神 |
| 克我者 | 官鬼 | 正官、七杀 |
| 我克者 | 妻财 | 正财、偏财 |
| 同类者 | 兄弟 | 比肩、劫财 |

十神的具体内容见下章。

## 五、形与气

### 1. 形气的划分
- **形是实的，气是虚的。**
- 五行分类：**金木为形（有形可拿），水火为气（无形），土归形**。（「拿东西」不说「拿南北」。）
- 形气对比：

| | 形 | 气 |
|---|---|---|
| 五行 | 金、木、土 | 水、火 |
| 含义 | 人类享用的自然之物 | 人类精神活动的产物 |
| 发展方向 | — | 向火：语言→图腾→文字→艺术、表演、装饰，一切对「美」的追求（感性思维）；向水：数字→算术→数学→哲学→科学，一切对「真」的追求（理性思维） |
| 命格上 | 形旺主体格健盛，用形者喜物质享受 | 气旺主智慧超群，用气者追求精神生活 |

- 物件取象：形上加赋其气。手机是有形之物，有用在于它的显像内容（气）；**丙辰为手机之象**（原稿给出，推理依据：形＋气的合成，丙为光/显示，辰为形；存疑处不扩展）。
- 行业上：偏形者如钢材、水泥；偏气者如影视、信息、教育、软件、文化、传媒、互联网。人对「气」有共同偏好，越虚的东西越有想象空间。
- 围棋之气由棋形决定，股市之气由型态决定：看得见的是形，感受到的是气。

### 2. 形气转化（命局高低的关键）
> 口诀：形化气，以气用才有意义；气化形，形我用才可以。

| 转化 | 对应生法 | 例 |
|---|---|---|
| 形化气 | 金生水、木生火 | 庚子、辛亥（金之形化水之气）；石头雕成工艺品 |
| 气化形 | 水生木、火生土 | 投资生产出产品 |
| 形化形 | 土生金 | 没有气，不显贵重 |

- 「命局之高低在于干支之变化，所谓化，就是形气之转化」，只有形化气的组合才显其贵重。
- 中医的对应：**阳化气，阴成形**；先有气之病，不治发展为形之病。「病」字中的「丙」＝阳气。人出生时与天地交换的第一口气叫**禀气**，是命运的基础（王充：「人生性命当富贵者，初禀自然之气」）。气推动人生命运行→中医；气推动人命运运行→命理。
- 东西方差异：西方研究形与质，东方研究气与态；阴阳五行干支八卦都是讲气，「在天呈象，落地成形」。

## 六、体与用

### 1. 概念
- **体＝本体，用＝功用。** 中国哲学只问功能，不问结构（中药只问性味归经，不分析成分）。「体」的内涵通过「用」的表现得到。
- 邵雍：「体无定用，惟变是用。」

### 2. 体用三种关系
| 关系 | 含义 | 例 |
|---|---|---|
| 体无定用，体全而用缺 | 一体可多用；用不能穷尽体 | 菜刀可切菜也可作凶器；应聘只展示一部分技能；天有四季人用三（冬不农事），地有四方人用三（背后看不到），一周七天用五天，一天二十四小时用十六小时 |
| 体静用动 | 体静，用动才显 | 身体是体，拳是用；翼是体，飞是用；眼为体，视为用 |
| 体阴用阳 | 万物以阳用事，但用阳者多体阴 | 老子尊阴（上善若水），孔子尊阳；以老子之阴为体、孔子之阳为用，并不矛盾 |

- 体阴用阳在十干里的验证：十干以甲为贵、癸为贱，但**癸水日主贵者多，甲木日主贵者少**。癸至阴，可用之字多（可用甲、可用戊）；甲至阳，可用之字少，不喜之字多，难成贵格。「满招损，谦受益」；谦称自己为「己」（处中、居低位之阴，追求甲之阳，甲己合）。
- 关键在「知」：**知其白而守其黑**——体阴是为了追求阳，不是体阴而抱阴；不知白而守黑，只是穷困。

### 3. 体用与命理
- 命理里的干支「什么都不是，又什么都是」：**体没有用是无意义的，干支在命局里动了（与他支发生关系、有变化），才能从变化中知道它的用，象就是这样取出来的。**
- 《说卦》乾卦：为天、为圆、为君、为父、为玉、为金、为寒、为冰、为大赤、为良马、瘠马、驳马、木果——一体多用；取哪一个，要因时、因地、因情形，取象带一定主观性。
- 类比量子叠加：卦象、干支象的本体是多重可能的叠加，取象一旦确定，多重象就坍缩成确定的象——**体的多重内涵化为用的单一结果**。
- 所以命理不讲单一用神：一个「用神」表达不了复杂命运。以体用理解：**「体」＝我与我所用的工具，「用」＝我要实现的目的**（取财、做官、扬名、求知），体与用必须发生关联，这就是**做功**。
  - 比喻：喝水需要手（体）与杯水（用）两样东西相互作用。
- 体用最终落到「象」：中医发展为藏象学，术数离不开象，**象是本体转化为功用的一个模式**。

## 七、隐性因果与象

### 1. 两种因果
- **显性因果**：物质世界可观察的因果（物理、化学定律），每件事能找出许多理由，且不可预知。
- **隐性因果**：术数的逻辑——一件事背后只有**一个原因：命运的定数**，知与不知、采取什么手段都避不开。成功者讲出的许多条件（贵人、行情、投资），在命理看来也只是一个原因。结婚（多婚的女遇到将离婚的男，时间还刚好）也是隐性因果的体现。
- 术数能预知未来，证明事物发展有多层因果，而非唯一因果。

### 2. 命例：车祸之断
**乾造**：己丙戊丁／巳寅午巳

大运：乙丑

（盘取自原稿后文，OCR 将第三干误作「戌」，据「戊土日」校为「戊」；完整的反局断法见本部分第七章。）

> 邢老师的小外甥三岁，夏老师排八字后断：「短命，活不过13岁；1998戊寅年立冬之亥月，死于车祸。」家人想尽办法回避，仍死于1998年亥月，虚岁11。

- 断法要点：时间落在**戊寅年亥月**（流年流月），事象是车祸；**命局须有类象「车」的干支组合，再有发生车祸的特定结构**。
- 象的推理：原稿说该命「不火烧死就是车祸死，最后确定车祸」；若生在古代必死于火灾（古代建筑易着火）。结论：**象是在相似性基础上的合理推断，读象的功夫是研习命理最重要的能力**。
- 同一家另一个同岁（己巳年生）的孩子，断「狱鬼，二十岁后牢中常客」，后来果然十五岁辍学混社会，数次被拘。说明**禀赋（性）先天，后天的习改变不了命**。

### 3. 象的定义
- **象是建立隐性因果的、万物相互关联的模式。** 圣人将万物类象处理，**打破物与物、物与人的边界**，用关联性连起来；这种联系真实存在，可以检验（如中医的「肺」包含皮毛汗孔，发汗可开肺气）。
- 象的本质不是相似，而是**相关性**；消解边界靠的是**时间**（时相，有结构的干支符号）。
- 信息承载量极大：二十二个字（十干十二支）组成八个字，要表示六亲、才智、个性、财富、地位、灾祸、遇到的人；这一切错综相关（如离婚会牵出对公司管理权的争夺）。
- 干支应是对命运的**描述与模拟**（别的术数如卦数、邵子神数也能预知），而非命运的原因本身。

## 本章小结

1. **天道**＝周期时间；干支是天道的符号；命理是时相学，路径：出生时间→干支→四柱模型→象义→大运流年。
2. **阴阳**绝对、不相对：热升动左男横为阳，寒降静右女竖为阴；子（冬至）阴极、午（夏至）阳极。
3. **五行**是五种气：木升、火热、金降、水寒、土中；春木夏火秋金冬水，土寄四季之末。
4. **生克**：相生顺行、相克隔位；生主阳、克主阴；只生不克、只克不生都有害。以「我」为中心，五种关系分阴阳得十神。
5. **形气**：金木土为形，水火为气；**形化气（金生水、木生火）、气化形（水生木、火生土）**，形化气以气用、气化形形我用。
6. **体用**：体无定用、体静用动、体阴用阳；命理以「体与用做功」取代单一用神；干支动则见用，用定则成象。
7. **隐性因果**：事件背后唯一的因是命运定数；象＝相关性模式，读象是命理的基本功。

## 自测

1. 「天圆地方」的含义是什么？
<details><summary>答案</summary>圆＝时间的循环（天道主时），方＝四方方域（地道主位），不是说天穹圆、大地方。</details>

2. 为什么说五行不是五种物质？「生」「克」的来源分别是什么？
<details><summary>答案</summary>五行是阴阳化生的五种气（力量）。生来自春夏长夏秋冬的时序接续；克来自阴阳之克（金克木＝秋杀克春生，水克火＝寒克热），加土后成隔位相克。</details>

3. 金木水火土哪些为形、哪些为气？哪种转化才有意义？
<details><summary>答案</summary>金木土为形，水火为气。形化气（金生水、木生火）以气用才有意义；气化形（水生木、火生土）形我用才可以；土生金是形化形，没有气。</details>

4. 「体阴用阳」怎样解释癸水日主贵者多、甲木日主贵者少？
<details><summary>答案</summary>癸至阴，可用之字多（可用甲、戊），故容易成格；甲至阳，可用之字少，许多字是它不喜欢的，难成贵格。守阴是为了追求阳（知其白守其黑）。</details>

5. 显性因果与隐性因果有什么区别？「象」的本质是什么？
<details><summary>答案</summary>显性因果是物质世界可观察的多因；隐性因果是命运定数这一唯一原因，不可避免。象的本质是相关性：以时间（干支）消解万物边界，建立万物间的关联模式。</details>
