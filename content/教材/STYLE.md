# 教材改写规范（给改写者）

目标：把「逐字整理的讲义」改写成**教材**——消化、归纳、重组，**但知识点一个都不能丢**。

## 必须做到
1. **不照抄**：用自己的话重写，按「概念 → 规则 → 判断步骤 → 例外与禁忌 → 命例」的逻辑重新组织；口语、重复、闲聊、问答来回压缩掉。
2. **知识点不丢**：原稿里的每一条规则、口诀、判断条件、例外、数字、对应关系（象）、断语依据都要进教材。写完后自查：逐节对照原稿，列出覆盖清单（写到 `_coverage/` 里，不进站）。
3. **命例**：每个知识点至少配 1–2 个**代表性命例**（原稿里有的就用原稿的，**干支必须逐字照原稿，不许改、不许编**）；其余命例留在命例库，不必全搬。命例要写清「谁和谁做功、用什么作用方式、应在哪个运/年」。
4. **汇总**：每章结尾给「本章小结」：口诀/规则用表格或编号列表归纳；再给 3–5 道**自测题**（题目＋答案，答案折叠在 `<details>` 里）。
5. **口径**：只写盲派成熟体系（不论日主旺衰、不取用神忌神；用宾主、体用、做功、虚实、象）。原稿里出现用神/旺衰的早期说法，要么略去，要么明确标「（早期说法，本体系不采用）」。
6. **禁用**：不写六爻、奇门、梅花等其他术数；不出现「视频」二字；不写任课老师真名（统一称「老师」或「本派」）；命例里的历史人物可保留。

## Markdown 约定（站点解析器 mdlite 支持的）
- 文件首行 `# 章标题`；一级分节用 `## `（App 里每个 `##` 默认折叠成一节，所以 `##` 要有意义、不要太碎，一章 4–8 个）；细分用 `###`。
- **四柱盘**必须单独成行，格式：`**乾造**：甲乙丙丁／子丑寅卯`（八个字：四干／四支，年月日时顺序；坤造写 `**坤造**：…`）。盘下一行写大运（如有）：`大运：甲辰 乙巳 …`，再写断解。**盘前不要放长段落**（盘会吸顶，方便对着讲解读）。
- 表格用标准 markdown 表格；重点用 `**粗体**`；要点提示用 `> ` 引用块；口诀单独一行用 `> 口诀：…`。
- 折叠答案：`<details><summary>答案</summary>…</details>`。
- 不要用 emoji 当标题；不要写「老师说」「课上讲」之类的转述口气。

## 篇幅
每章约 3000–7000 字；宁可多分几章也不要一章塞太多。总量约为原稿的 40–60%，靠归纳压缩，不靠删知识点。

## 输出位置
`content/教材/<初级|中级|高级>/<两位序号>-<章标题>.md`；覆盖清单写到 `content/教材/_coverage/<你的任务名>.md`。
