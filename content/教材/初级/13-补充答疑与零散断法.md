# 补充答疑与零散断法

前十二章已把体系的主干讲完。本章收的是散见于答疑记录和案例补注里的零碎断法：单条都不长，但在实际断盘时常被问到。凡原稿两种说法并存的，一律并列照录，不替它取舍。

## 一、禄的处置：坐下不坏，时上可坏

日主之禄分两个位置，处理不同：

| 禄所在 | 能否被坏（刑冲破穿制） | 说明 |
|---|---|---|
| 日主坐下（日支） | **不可坏** | 这是日主的根，坏了伤身伤寿 |
| 时上 | 可以坏 | 坏了身体会差，但**不至于损寿** |

另有两条与时上之禄相关的补充：

- **时上有禄，不可再去生日主的东西**：禄在时上是孤单的东西，前面再有生身之物（印）、再见比劫，就不是“单禄”了；那样的禄不可坏。
- 年、月上的禄不代表日主自己，被制、被冲无妨；禄在日、时才是自己。

> 口诀：坐下之禄不可坏，时上之禄可坏但伤身。
> 说明：原稿这一段是答疑时的对话记录，“六亲不利”一语出自追问，答语不完整，此处只取上面可确认的几条。

**命例**：

**乾造**：癸壬辛庚／卯戌亥寅

大运：辛酉 庚申 己未 戊午 丁巳 丙辰 乙卯 甲寅（九岁起运）

此造由提问者给出，紧接着记录的就是上面关于禄的讨论，原稿没有给断解，只记了事实：命主二十九岁辛未年结婚，壬申年（1992）离婚。

## 二、日主合官：年月管人，时上被管

日主合官（合官即追求官，是日主之“意向”）时，合的官在哪一柱，含义不同：

| 所合之官 | 含义 | 官的坐支 |
|---|---|---|
| 合**年、月**上的官 | 日主**管理、控制**这个官所代表的东西 | 坐支可以被坏，看原局的意思，有的要用有的不用 |
| 合**时上**的官 | 日主**被人管理**（被别人管着） | 一定要用官坐下的支，**支不能被坏**；要用时支去制别的支 |

要点：合是日主所追求的，所以合到时上才“有用”，用的就是时支；合年月官是外来的单位、外面的人，日主只是去管。第九章已讲“合官必用时支”，这里补上“年月管人、时上被管”这对相反的象。

**同日不同时的对照**（两造年月日完全相同，只差时辰）：

**乾造**：辛丁癸戊／丑酉酉午

日主癸合时上戊官，要用戊坐下的午火：是财制印，印太旺，南方火运助起原局之火，把印制了。不是贵格，开出租车。

**乾造**：辛丁癸己／丑酉酉未

同天未时出生，官至公安分局局长。原稿的断语只有一句：原局把火制住了（制成了）。两造只差一个时辰，一个只开出租车，一个做到分局局长，差别在于火制不制得住。

## 三、破、穿、自合的几条答疑

1. **破只有坏处，没有好处**。破不叫做功，只表象；运中来的破，**解不了**命中的破。（暗合则不同，暗合也是做功。）
2. **合解不了穿，穿什么也解不了**。原局有穿，不能指望遇合来化解。
3. **日主与日支自合的地支，能制**。日支自合并不妨碍它去制别的字。
4. **夫妻宫生穿不要紧，克穿厉害**。申亥、寅巳之类生穿，对婚姻宫的伤害轻；子未、卯辰、酉戌、丑午这类相克又穿的才重。
5. **天地合制地支时**，遇到地支再冲、穿，也不好。

**命例**（制用结构里“主位之印去制财”）：

**坤造**：壬丙己己／子午巳巳

大运：癸卯 壬寅

壬被丙冲制，子被午冲制，是印去制财。印党大，财党（天透地藏）也不小，制财得财；做海外贸易，发财千万，癸卯、壬寅运发财。财全是自己的：她一个人的公司，因为午与己是一个象。这种结构不必计较制得净不净，要**换象**——印强财弱，印也表财。原稿注：这个不算制得干净，但不影响发财。（原稿标题称“印制劫的例子”，而断语讲的是制财，此处从断语。）

## 四、空亡、泄用与几条虚实补注

- **空亡可由运、岁填空**：原局食神、官星等落空亡，大运流年逢到所落之字，称填空。本派承认这一说。
- **食神落空亡短寿，有前提**：前提是水没有流绝。水有源头、流到时上归库（不流绝）的，食神落空亡也不短寿。
- **泄用**：土金、木火可以泄秀；用神泄秀的结构，一般是搞学问的。
- **官星虚透看学历**：看学历有无与高低，**先看官星，再看印星**。
- **看做功以地支为主**：虚透只是表象，真正做功的不会是虚的。
- **时上伤官虚透，不能生月干之财**：虚透之字生不了别的字。

## 五、两处存疑：照录

1. **日主坐库是否一定要刑冲？** 第六章据另一处讲法写“日主坐库者除四柱外皆喜刑冲开库”；而答疑中有人问女命壬辰日、辰库没有刑冲会不会影响婚姻，答曰“不需要刑冲也可以”。两说并存，未见调和，断盘时以原局实际做功情况（库是否为所用）为准。
2. **寅巳穿正印，是否一律论品性不好？** 口诀有“穿倒正印不走正路”。答疑中有人举自己的八字反问，回答是不可一概而论，**要看正官在不在主位**。即正印被穿论品性时，须结合官星的位置，不能只看穿。

## 六、几则只有问答的命例

以下几造原稿只留下提问与简短回答，没有展开断语。照录问答，作为判断的参照。

**乾造**：乙癸甲壬／丑未戌申

问：会是当官的吗？答：不会。追问：官库被制，壬又可化申杀，能否当官？答：**不能化杀**。

**乾造**：己癸己庚／酉酉丑午

问：这个时上的禄可以穿制吗？答：己丑日主（坐库）**一定要刑冲**。（参看第一节：时上禄可坏。）

**坤造**：癸己戊戊／丑未午午

问：这个能大富吗？答：能富。（原稿未给理由。）

## 本章小结

| 条目 | 要点 |
|---|---|
| 禄 | 坐下之禄不可坏；时上之禄可坏，伤身不损寿；时上有禄不可再生日主之物 |
| 合官 | 合年月官是管理控制，合时上官是被管理、必用时支 |
| 破 | 只有坏处；运中破解不了命中破；暗合才是做功 |
| 穿 | 合解不了穿；生穿轻、克穿重 |
| 空亡 | 运岁可填空；食神落空亡短寿以水流绝为前提 |
| 泄用 | 土金、木火泄秀，多为学问之人 |
| 学历 | 先看官星，再看印星 |
| 存疑 | 坐库要不要刑冲、穿正印如何论，两说并存 |

### 自测

1. 日主合时上的官和合年月的官，各是什么含义？坐支处理有何不同？
<details><summary>答案</summary>合年月官是日主管理控制；合时上官是被人管理。合时上官必须用官坐下的时支，支不能被坏；合年月官的坐支可坏，看原局意思。</details>

2. 日主坐下的禄与时上的禄，被坏的后果有何不同？
<details><summary>答案</summary>坐下之禄是日主的根，不可坏；时上之禄可以坏，坏了身体差但不至损寿。时上有禄还不可再生日主之物。</details>

3. 原局有破，大运来一个什么，能不能解破？
<details><summary>答案</summary>解不了。破只有坏处，运中来的破也解不了命中的破；同理合也解不了穿。</details>

4. 食神落空亡一定短寿吗？
<details><summary>答案</summary>不一定。前提是水流绝；水有源头、流到时上归库而不流绝的，不论落不落空亡都不短寿。</details>
