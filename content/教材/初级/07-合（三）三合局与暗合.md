# 合（三）三合局与暗合

## 一、三合局总论

**四个三合局**：申子辰合水局、亥卯未合木局、寅午戌合火局、巳酉丑合金局。

- 在所有合法中，**三合局是唯一能“合化”的**（如申子辰合化水局）。
- 三合局由五行的**长生、帝旺、墓库**三者聚而成局，类似社会关系中的结党，故称**党局**。其主要体现是**一个目标与核心**：中神（子、午、卯、酉）如党魁、纲领，其余两神是佐神。三合局的本意就是三方会聚、拱起中神。
- 紧密性：有一定亲密性，但比六合差，故有**六合能解三合**之说。会局讲“合成了什么”，六合不讲这一层。
- **三合局不为合绊**：局中每个神都有一定自由度，还可以去作用其他神，只是因为合局，一心向“党”，力量会起变化。
- 三合成局与否，**与同五行在天干透不透无关**；三合局必须三个字都现，其中中神最重要，要看落在哪个位置。
- 三合局、半合局、拱局常用于断**婚姻应期**；三合局大都应在婚姻上。

## 二、三合局中各神的力量变化

| 局 | 变化 |
|---|---|
| 申子辰（水） | 辰本身土力弱，合局更弱，局中如无原神来生，不仅失土性，还会被水荡；申金被水泄，力量减弱但不变性；子水大增力 |
| 亥卯未（木） | 未为木库，被三合局克而变弱（这种力量不是克，是弱化或自动放弃）；亥水生卯木，亥水减力（被泄） |
| 巳酉丑（金，原稿一处误作“火局”） | 巳是十二支中唯一的“变色龙”，五行性质随局中水火力量强弱变化，在此放弃自己的立场；丑土生酉金，本来土性就弱，合则更弱（被泄） |
| 寅午戌（火） | 寅木因生火而泄力，从了火势；戌被局中旺火所生，越生越旺，土性增强 |

> 要点：半合局成局力量小于三合局，故其中两字的力量变化不大。

## 三、半合局与拱局

三合局中有两个也能成局，称**半合局**，成局力量小于三合局。

| 类别 | 组合 |
|---|---|
| 生地半合局（长生+帝旺） | 亥卯半合木局、寅午半合火局、申子半合水局、巳酉半合金局 |
| 墓地半合局（帝旺+墓库） | 卯未半合木局、午戌半合火局、酉丑半合金局、子辰半合水局 |
| 拱局（长生+墓库，无中神） | 亥未拱木局、寅戌拱火局、巳丑拱金局、申辰拱水局 |

- **拱局**没有中神，其余两神是“虚拱”着中神，有特殊的象的用法：例如原局有辰为财库而不开，不能为日主所用，大运若见申，申辰相拱，就能拱出原局辰中之财，为我所用；其他库依此类推（详见中级）。
- 巳酉丑中，酉丑具有双重性：以**拱**为主，以墓金为辅，巳丑为拱局。

## 四、三合局的用法与注意事项

1. **用于断婚姻应期**：三合局、半合局、拱局常用于此。
2. **中神位置十分重要**：中神落在主位临吉神、他星拱之，主大吉；落在宾位被生拱，即使是吉神，也只是次吉。例如日主坐食神丑土，拱了月上的酉财，表示以自己的技术替别人创造财富。
3. **六合能解三合**：三合局中若中神与他支有六合关系，则三合局受损——六合紧密性强于三合，中神趋于六合，按合绊论。如三合局的长生支或墓支有六合，则先论六合，剩下的支论半三合。
4. **三合局最忌冲**，冲则破合，也怕被穿或刑坏。如亥卯未三合木局，杂有巳酉丑中一字，而该字与所冲木局之神紧贴，则木局被破：
   - 酉去破中神卯 → 三合木局完全不成；
   - 巳去破亥 → 三合不成，但卯未半合仍成；
   - 丑去冲未 → 亥卯半合仍成立。
   三合局的中神最重要，大运来冲三合局的中神，则此局被坏。
5. **中神双现或多现，不成三合局，以中神入墓论。**

> 要点：成局之后怕冲，冲中神则破合；三合局要三个字齐现，中神位置是关键。

### 中神的用法

**坤造**：甲辛乙癸／寅未亥未

大运：庚午 己巳 戊辰 丁卯 丙寅 乙丑 甲子

断解：局中寅亥合，又亥未拱。亥与寅合是夫宫被他合，属婚姻方面的问题。寅在宾位，是日主的劫财，且亥合寅在先、亥上坐乙是后来的，其实她找了一个离过婚的男人为夫，这里有象的运用。亥未拱的是禄（卯），禄在局中似无实有，财星两未向夫宫拱，意为夫有财，她本人间接有财。另一稿：夫妻宫印星合到年上，合绊，婚姻有问题；寅是劫财在宾位，是别的女人，她是类似第三者的角色，所找男人的老婆已出国，婚姻名存实亡；命局层次高，两未土往里拱，财主钱，有钱，且原局没有卯木存在，未土弱化程度低，两处财往里拱，财就大。长期与该男同居，断甲申年结婚，不对：甲申年寅申冲、申亥穿，亥是正夫，寅亥合被破，两人分手，自己买了套房（印主房子，寅亥合绊住的印被申冲开）；今年仍存在婚姻应期的可能。

**坤造**：甲辛乙己／寅未亥卯

大运：庚午 己巳 戊辰 丁卯 丙寅 乙丑 甲子

断解：亥卯未三合禄局，中神卯禄明现时支。未财拱到了时上宾位，她的夫便无大财。比上造，本造比劫重而财轻，己财又透到时上被年干甲劫合，格局比上造差得多。另一稿：丈夫以前有很多女人，结婚后管得很紧；亥卯未会局使财星弱化，不是被克弱，而是自己自动放弃，没太多钱；辰运亥有入墓之嫌，卯辰有穿，老公怕有坐牢或到医院等问题。

### 婚姻应期中的用法

**乾造**：辛丙丁乙／亥申丑巳

大运：乙未 甲午 癸巳 壬辰 辛卯 庚寅 己丑

断解：年上辛金偏财，月支申金正财。巳丑拱财，拱到妻宫；巳之原身丙透月干，合年上辛，辛在年上为先，故以年上辛为妻星，财在年上，结婚应早。午运**癸酉年**：巳酉丑三合财局，把流年妻星合到妻宫，结婚。（另一稿：巳丑拱财局拱到妻宫，癸酉年巳酉丑合金局成功，此年结婚；财合到位，一定结婚。）

**乾造**：己丁丁庚／酉卯未戌

大运：丙寅 乙丑 甲子 癸亥 壬戌 辛酉 庚申

断解：以财为妻。丑运**癸酉年**：丑酉半合财局，又逢大运丑冲入妻宫（丑未冲，库喜冲，老婆到位；酉金也到位），结婚。

**坤造**：辛乙乙戊／亥未卯寅

大运：丙申 丁酉 戊戌 己亥 庚子 辛丑 壬寅

断解：日主坐禄，三合局中神卯落在夫宫，卯能得亥生，乙木为活木。年柱辛亥为印带官帽，合局将年上唯一的辛金官星合入夫宫，辛当夫看。戌运**癸酉年**：戌合夫宫，流年酉冲夫宫（酉为辛之禄，酉到即辛到），夫宫在原局和大运中都被合，**合以冲为应期**，结婚。另一稿补充：以事实婚姻（同居）为主，领证为印；女命官杀是男人，冲禄身体，破身了，同居；癸为印，结婚证到了；断两个年份较保险。

**乾造**：丁壬丁辛／未子巳亥

大运：辛亥 庚戌 己酉 戊申 丁未

断解：以辛为财，夫妻宫为巳火。己酉运的己运**癸酉年**，巳酉合，结婚。丑年，巳酉丑又合一个，犯桃花，过路桃花；每到酉年丑年可能都要犯点桃花。（戊申运巳申合见《合（二）》。）

### 中神双现不成局

**乾造**：戊戊戊甲／戌午午寅

大运：己未 庚申 辛酉 壬戌 癸亥 甲子 乙丑

断解：地支全寅午戌，但午火中神双现，不成三合局，论中神入墓。寅木七杀被午火印化，两午入墓，墓在年支宾位又不开，不做功；戊日主生午月无贵气，穷命、无官。八字无财，伤食当财看，局中也无食伤。酉运（辛酉）酉当财看，酉穿戌，又逢癸酉年，坐牢：酉戌穿坏食神，食神主自由，坏则失去自由，入狱；食神也为财，因贪财而坐牢。此造天干戊本无墓库，但日主戊三现，坐午坐戌，戊土与午火一起入戌墓；戌为牢狱之象。此例戌墓穿酉“财”是犯财或与财不和，不是制财而发财。（另一稿：戊土喜见甲寅时，因戊长生在寅；食伤当财，戌代表戊，戌中有辛，是日主追求之物；不贵，因全都入墓，火带土一起入墓，而墓不开。）

提示：**相穿不能开墓，只有刑、冲才能开墓。**

**乾造**：丁癸辛丁／未卯卯酉

大运：壬寅 辛丑 庚子 己亥 戊戌 丁酉 丙申

断解：日主辛坐卯财，月上又见卯，年支未为木库，中神双现不为半合局，两卯都入了年上的财库，好像自己坐下的财都跑到别人那里去了。但年柱丁未为半禄关系，当一家看，丁又伏吟到时干坐在酉金上，酉为日主之禄，年上财库仍是自己的库（时支禄又坐丁、到年上丁，所以未是自己的库）。卯酉冲，意为本属自己的财被冲动而入了年上财库；库虽未开，整局之象仍是发财的。木土结合做功，是搞建筑的包工头。提示：**禄不怕冲，最怕被穿**；时上的禄有时可以冲，但不可以穿，穿了寿有问题。看职业一定要看财与财的原神之象。

**乾造**：甲甲戊壬／辰戌子子

大运：乙亥 丙子 丁丑 戊寅 己卯 庚辰 辛巳

断解：子水中神双现，因财墓辰居年支，两子水是从辰里出来的。局中水与湿土旺，戌冲辰开了财库，也为辰与子水结党制了戌，是财库制了戌土比劫（与财制比劫相似），财库有功。两库换象，戌（比劫库、印库，戌与戊可看成一个象）当财看。子水为财，源源不断从辰库流出，被日主自合得之，是发大财的命。若无辰去冲戌，绝不发财。（另一稿：主位的财入宾位财库，戌冲开财库，辰制戌是制印库；“谁强显谁性”。）

提示：水有流动特性，年支见辰墓，月、日、时见子水，则子是从年上墓中出来的，但辰能墓水的象仍存在；时上见辰墓，年、月、日见子水，则子水都入了时支的墓。其他如未见寅卯、戌见巳午，就没有这种特点。

## 五、暗合

**三组暗合**：寅丑暗合、午亥暗合、卯申暗合（只有这三组）。

- **含义**：两个地支的本气与遁藏的人元相合。寅丑：寅中戊、丙、甲分别合丑中癸、辛、己；午亥：午中丁、己分别合亥中壬、甲；卯申：卯中乙合申中庚。
- **性质**：近似六合，是做功的一种方式；紧密度不如六合、比三合强。有时表示暗中操作的事情，有时不一定。
- **互制**：相合双方一强一弱，谁得势谁制，如卯申暗合，卯旺可制去申，申旺也可制去卯。
- **与六合的区别**：原局中紧邻暗合和大运暗合命局，**都不论合绊**，只论相制如何做功；但**流年合原局和大运的旺支，则为合动**，表示要应事。
- 暗合也可换象：伤官合杀、合官等；暗合得暗财（寅丑暗合容易得暗财，统领）。

**乾造**：戊壬辛甲／戌戌亥午

大运：癸亥 甲子 乙丑 丙寅 丁卯 戊辰 己巳

断解：火与燥土有气势，午戌半合火局，两戌克亥水，午亥暗合，意在制伤官亥水，七杀午火为功神。杀合制伤官，杀与伤换象，伤官可代表官，制伤得官，当官之命。月透壬水，虽有年上戊克，无法制净，是隐患（亥水制不尽，有制的象；戊克壬的象较好）。丙寅运当县长：寅午戌合火局，中神午火制去亥水而提升；大运透丙合身亦吉。丁运丁壬合，壬即局中要制之亥，壬因丁合得保护，戊土无法克（这与壬水在原局的状态有关：原局戊克壬，丁运丁合壬是保护，不是合去），丢官罢职；卯运卯合戌、卯破午，功神被坏，下台。戊辰运：亥水入辰墓得保护而无法制，辰冲戌，与功神戌对抗，反局了；戌在原局多而旺，是官杀库、火库，象为枪、刀、炸药，结果在酉年被枪毙。死于酉年：辛日主见酉为禄，被原局旺戌穿倒，禄被穿，凶死（另一稿补：酉年合动了辰）。提示：原局在地支要制的字，不喜其原身或遁藏之物透干无制；戌土为官杀库时，象可代表枪支、弹药、刀剑。口诀：好好理解为何原局亥午合，而大运丁壬合反而相反。

**乾造**：癸丙戊甲／卯辰申子

大运：乙卯 甲寅 癸丑 壬子 辛亥 庚戌 己酉

断解：戊日坐申食神，申子辰三合财局。年柱癸卯为官带财帽，日主戊合癸财，申暗合卯，年柱带象合到主位；申卯合、卯辰穿，意在用食神与财库去制官，是管财的官；日主坐支食神申生子水财，三合财局，为内食神格，综合判断为企业里管财的官。原局有病：在制卯，意在得卯官，但卯被辰穿、子破；日主要合用的东西，在地支不能被坏，且是自己坏的；局中在制卯官，不喜时柱七杀甲木透天——做官不顺。实际是一家大企业老总，上任后常有不顺；（另一稿：癸未年入牢，当政协参政后）；见寅吉，见甲凶，因戊长生在寅；杀为忌时，杀为官非、小人、破财遭灾。注：**合用的东西一定不能穿。**

**乾造**：壬辛丁癸／寅亥丑卯

大运：壬子 癸丑 甲寅 乙卯 丙辰 丁巳 戊午

断解：年月时柱都是带象：年壬寅印带官帽，与主位有丁壬合、寅丑合；月辛亥官带财帽，亥之原身壬透年干合日主，亥与寅合，寅与日支丑合；时癸卯杀带财帽，亥卯半合局，亥即壬，丁壬合，寅亥合。三个带象与主位都有关系。日主坐财库丑，库不开，丑合寅，是财库合印，换象后印星寅木可当财看，年柱带象就不是当官，意在求财，丁壬合仅表示管理，手中有点权力；月、时带象通过寅亥合、亥卯合、寅丑合，官印与日支丑财库发生关系，合则换象，印和官杀可当财看，意在求财、并不当官。局中水旺金弱，官多财少，属**财统官**，把所有官当财看，有多少官就有多少财。寅、卯运与亥合，合官等于合财，故发财（原稿作“壬卯运”，见存疑）。丙辰运：丙合辛财，劫财合财，劫取之意；辰、丑皆阴暗之库，丑入辰墓，以不正当手段不劳而获。丁巳运：丁为日主，巳为劫财，与丑拱财，仍发财；但巳穿寅，日主天干合壬官为求财（官当财看），就不喜地支被穿；寅为正印，是局中功神，被穿表示不走正道，不是合法取财（口诀：**穿倒正印不走正路**）。寅丑合，木土做功，丑为财库，表示木土行业，是建筑包工头，在两步运里以阴暗方式取财数千万，干的都是“豆腐渣”工程（丑财库为阴财暗象，偷工减料，暗财；暗合有暗财；“统”的能量很大）。三柱带象，坐财库不开，可开可不开，也可当食神用；无辛亥和癸卯则当官。

**乾造**：己己辛甲／卯巳亥午

大运：戊辰 丁卯 丙寅 乙丑 甲子 癸亥 壬戌

断解：坐下亥水伤官暗合午杀。杀为权力，伤为智慧头脑，是伤官合杀。局中火气势旺，是官杀去伤官的格局，用换象原理，杀旺去伤官，伤官就代表权力；火特别旺，用贼捕原理，希望亥水出现。原是很小的官，子运为处级，癸亥运连升三级成省委常委组织部长，壬运到人大，现已退休。

**乾造**：甲丁丁辛／寅丑丑亥

断解：盲人小孩的盘。两个象：寅丑暗合、寅亥合。丁火代表两眼，本是甲木生丁火，但寅丑暗合把寅木合到丑地，眼睛有问题，光这点瞎不了；寅亥再合，灭去寅中之火，没法生，**用的东西怕坏**，所以是盲人。丑是财星库，无刑冲，财藏库中，父亲是暗的、不公开的，暗财又逢暗合，肯定是偷情的产物。（为什么是爷爷，不明确，可能辛金为明父，甲寅是祖上，甲为辛之父，但也不一定，存疑。）

**乾造**：甲癸丁庚／寅酉丑子

断解：这个就不是盲人，因为不用甲木，甲丁之间被癸隔开，生不了；丁不需要甲生，以坐下丑土为用。局中有一个寅丑暗合，月令财为父，入墓又暗合了一下，寅为母，母亲有两次婚姻。从用的角度讲，寅中有劫财，劫财合丑，但制不了劫财，要制了就厉害了，所以自己发不了，只能认识大老板；财库去劫财是最厉害的，可惜制不了。

## 六、存疑标注与本章小结

### 存疑标注

1. **三合局力量变化的“巳酉丑”**：一稿标题作“巳酉丑三合火局”，应为金局，其内容（巳变色龙、丑土弱）按金局归并。
2. **戊壬辛甲／戌戌亥午**：叙述中“丁运丁壬合……（保护而非合去）”与“原局亥午暗合是制，大运丁壬合反而反了”两处，另一稿明确要求“好好理解”，未给出更多解释。又有一问：此盘大运丁壬合为何不制壬水？答：大运合为合绊，不参与原局作用。并存。
3. **壬辛丁癸／寅亥丑卯**：“走壬卯运”，大运表为壬子、癸丑、甲寅、乙卯起，“壬卯运”应为乙卯运，疑笔误，照录。
4. **甲辛乙癸／寅未亥未**：一稿云“亥未拱的是禄”（乙之禄在卯），另一稿云“夫妻宫印星合到年上”；两说并录。又“甲申年应婚未应”的断语被原稿自我否定。
5. **丁癸辛丁／未卯卯酉**：原稿云“禄不怕冲，最怕被穿”，同时“卯酉冲了禄为什么不损寿”答：时上的禄有时可冲，不可穿；对年月禄是否可冲未再展开。
6. **甲丁丁辛／寅丑丑亥**：“为什么是爷爷”，原稿自称看不太懂。
7. 暗合“近似六合”“不论合绊”与六合“合绊”之间，只在流年合旺支是否为合动上写明。
8. 附“合年月之官”两造，原稿未给大运及断解，仅附注一句，不收其他断语。

### 自测

1. 三合局与六合相比，紧密性与用法有何不同？“六合能解三合”怎么理解？
2. 亥卯未三合木局中，若有酉冲卯、巳冲亥、丑冲未，各种情况局还成不成？
3. 中神双现为何不成三合局？按什么论？
4. 暗合有哪三组？与六合在“合绊”的论法上有何区别？
5. 为什么说“相穿不能开墓”？

<details><summary>答案</summary>

1. 三合局紧密性弱于六合，是党局、不为合绊，局中各神仍有自由度，且能合化；若中神与他支有六合，则中神趋于六合，三合受损，按合绊论，先论六合，剩下的支论半三合。
2. 酉冲卯（中神）：三合完全不成；巳冲亥：三合不成但卯未半合仍成；丑冲未：亥卯半合仍成。
3. 三合局以中神为核心，只要中神双现或多现，就不成局，按中神入墓论。
4. 寅丑、午亥、卯申。暗合在原局紧邻或大运暗合命局时不论合绊，只论相制做功；流年合原局或大运旺支为合动，应事。
5. 墓库必须刑或冲才能开；穿只是坏，不能开库（如两午入戌墓，酉戌穿不开墓，反坏食神）。
