# 干支配置（上）：生克、自合与带象

干支配置，讲的是一柱之内、以及柱与柱之间天干与地支的关系，有三大原理：**干支生克**、**干支互通**、**干支虚实**。它们是分析四柱的基础，也是取象的依据：靠干支的组合、互换、虚实、有根无根、禄与原身，把平面的字立体起来。上篇讲生克、自合、之生与带象；下篇讲互通、通根坐库与虚实。

## 一、干支生克：君臣与互生

### 基本规则

1. **干支是君臣关系**：天干为君，地支为臣。**天干可以克地支，地支不能克天干**。
2. 天干克地支时，天干自身必须有力（旺、有根、有气势）。例：甲辰柱，甲坐根而旺，才能克辰。
3. **干支可以互生**：天干生地支，地支也生天干；二者也能相合。
4. **例外：天地自合**。地支只有在与天干合而克（合制）天干时，才算克天干。如丁亥柱，亥中壬水先与丁暗合，然后才能克。
5. 同一柱内，谁强谁制谁：地支旺或有气势，地支合克制去天干；天干旺或有气势，天干制去地支。

> 口诀：天干克地支，地支不克天干；地支要克天干，必先合住它。

### 自合有象：一露就告诉你有官

天地合的柱子一出现，就要特别留意，它自带含义。

**乾造**：辛辛丙癸／丑卯寅巳

只看前三柱，是日主合财、身旺财旺，纯发财的盘。癸水一露、坐巳禄，信息就变了：癸是官，坐丙之禄巳，癸巳天地合，巳火旺而制去癸水，是**用禄制官**，权力落在自己（禄）头上，官帽戴在自己头上。所以此人是有行政职务的企业人。这是表象，不是因为官虚；没有癸水，就没有官。

另有一盘：癸卯 乙卯 辛未 癸巳（原稿性别未注）。巳官制癸水食神，一层意思是当官，一层意思是能说会道；食神主文化而弱，被旺火所制，所以是文化领域的官；辛配癸，是钢笔尖蘸水，主笔杆子。此人曾任某著名报纸的主编。

**乾造**：辛己丙己／未亥辰亥

曾国藩。贵气在哪里：己亥自合，亥水又入辰墓，**都是制官**。辰收官鬼，两头往回收，墓库本身就是控制；两个伤官又把官压住，不让官出头，所以是大官。伤官火土本有造反之象，但伤官弱、虚，不造反，而是靠制官取得：他的官不是皇帝直接任命的，而是自己组织湘军、镇压太平天国取得的。核心是亥水入库，周围被土包围、无处可逃，只能进辰库。若年柱换成辛亥，也是大官，但没有这么大。

**乾造**：丁庚己庚／亥戌巳午

蒋介石。解法从主位入手：先问这么多火要干什么。午是己的禄，年上丁火是午的延伸（原身）；再看丁亥合、巳亥冲，原来是要制亥水财。制完之后，午亥合又把它拉回来：**制去了又拉回来，不是一制了之**。去，是为了管住；拉回来，是为了为我所用，不拉回就像猴子掰玉米。又因亥是官之长生，制去的实际是官与官的原神，官最大，所以大贵。比喻：把敌人赶到死角，再给点吃的，说跟我吧，人就跟着他干了。亥是全盘的精髓；若把亥换成未，则一事无成。

## 二、自合：合而制之

### 九个自合柱

| 自合柱 | 合的内容 | 备注 |
|---|---|---|
| 丁亥 | 亥中壬与丁合 | 前四柱，地支可合克天干 |
| 己亥 | 亥中甲与己合 | 同上 |
| 辛巳 | 巳中丙与辛合 | 同上 |
| 癸巳 | 巳中戊与癸合 | 同上 |
| 壬午 | 午中丁与壬合 | 一般天干制地支 |
| 甲午 | 午中己与甲合 | 同上 |
| 戊子 | 子中癸与戊合 | 同上 |
| 丙戌 | 戌中辛与丙合 | **须未刑开库**才合，罕见 |
| 壬戌 | 戌中丁与壬合 | **须未刑开库**才合 |

（合的内容为按藏干补注；原稿只明写丁亥、丙戌、壬戌。）

规则：
- 同一柱干支自合，**强者制去弱者，强弱看气势**。如丁亥：亥中壬水旺，壬合克去丁；局中火旺得势，丁又可合制去亥水。
- 自合是**合而制之，属做功方式，没有合绊的意思**；合则旺者制弱者，自合双方皆有功，谁制谁不重要。
- 自合柱的地支若被它支冲，则不能自合（如丁亥遇巳冲亥，丁与亥中壬不能合）。
- 戌逢未刑才开库；逢丑刑（金水强时）是坏戌中所藏之物，不算自合。
- 丙戌柱自合做功少见，常见的是另外八柱。

> 口诀：自合是制，不是绊；强者制弱者，看气势。冲破地支，自合不成。

### 命例

**乾造**：壬壬庚辛／子寅辰巳

大运：癸卯 甲辰 乙巳 丙午 丁未 戊申 己酉

时柱辛巳自合；巳是杀，辰是印，巳生辰为**杀生印化用**，杀主权力。巳被辛合制，辛是羊刃，羊刃主武职，杀被制为权，所以此人在执法部门（公检法）工作，但没有当官。原因：寅是巳的原神，寅巳相穿是生中带穿，寅生巳、又穿巳，巳制不干净，穿会坏象。网授班的另一种解释是：辛旺制巳，属羊刃制杀、杀被制有功，但寅巳穿使杀又被穿，故无官。（另一种说法：巳合制辛主要是表象，不算做功，故无官。两种说法并存，见章末存疑。）

**乾造**：辛壬乙丁／亥辰酉亥

大运：癸巳 甲午 乙未 丙申 丁酉 戊戌 己亥

乙木坐酉，辰中与亥中有根，又得亥水生，为活木。年柱辛亥是**印带杀帽**，辛杀被坐下亥印所化，辛与日支酉杀同象，且与主位有关，主文化、学历。辰酉合伤了辰中乙根，但两亥中的根未伤，只是身体较差，不至损寿。时柱丁亥自合，是印制食神，食神在时为门户，主口才聪明；丁壬合也是食神被制之意；壬坐印库辰，辰为思想之库，又被酉合到主位，亥有数学之象，辛象理科。此人是年轻的科学家，在美国读博士。丁火弱而被亥制死，丁主眼目，视力可能有问题。

**乾造**：丙癸丁己／戌巳酉酉

大运：甲午 乙未 丙申 丁酉 戊戌 己亥 庚子

火与燥土成势，意在制金水。月柱癸巳自合，癸杀被坐下劫财巳火合制净；酉财被巳合克，又被年戌穿，日主旺而克坐下酉，财也有制。丁己一家，火土更强。杀与杀的原神（酉）都有制，杀被制净，**官杀制净为当官**。局中酉金两现，财制不净，须待运补。戊戌运：戊是局中巳的原身到，合去癸杀；戌是年上戌到，直接穿酉，火土结党制酉。此人在戊戌运升为某市区区长，副厅级。局中癸杀被原局制净，是能当官的主因。

**乾造**：乙癸辛癸／未未未巳

大运：壬午 辛巳 庚辰 己卯 戊寅 丁丑 己子

火与燥土未成党，时柱癸巳自合，癸水食神被巳官制净，官有功，当权力看；月上癸水无制，有待运补。**时癸是自己的，月癸不是自己的**。庚辰运癸亥年任秘书；己卯运（己克癸，卯合未生巳）丙寅年巳到、丙官合身，升副处级；戊辰年戊合去月癸，卯穿辰、不怕流年辰土，升副处；庚午年乙庚合、午增火势、午未合到主位，升正处；戊寅运火更旺、戊合去癸，乙亥年亥冲巳（原局火土旺，巳亥冲是亥被巳制而巳被冲动，不是冲制）、亥卯未拱木，又升；辛巳年辛是自己、巳是日主坐下官到，升至正厅级，任某省科协主席。

> 提示：相对于原局和大运，流年之力很弱小。

**坤造**：乙丙甲乙／未戌子亥

大运：丁亥 戊子 己丑 庚寅 辛卯 壬辰 癸巳

刘晓庆命造。甲坐亥子水，为活木，年月一片燥土，与日时水党力量相当，不做功。真正的功在天干：甲生丙火食神，丙火又生月支戌财，**食神生财**，命局必用，日后能富；活木见丙为花朵，主漂亮、艺术才能、名气。戌库被年上未刑开，戌中辛官被丙火自合：丙为日主的魅力与感情，辛官太弱，不表示明面的丈夫，只表示凭美色与暗中的男人有暧昧关系，并靠色相取戌财。实际是通过结交权贵而发财。（月令官星主大官，另有此说。）

## 三、干支之生与带象

### 干支之生：统

天干生地支时，这一柱表**一个象**，上面的字代表下面的字，本派术语叫“**统**”，天干把地支统住了。如甲午、庚子、己酉。

**坤造**：甲庚戊戊／午午午午

夫宫午火，年上杀甲木生坐下午火，甲与午是一个意思，午火是夫宫伏吟出来的，代表丈夫；甲说明午的性质，所以丈夫当官，与官坐在同一位置。午火伏吟多现，丈夫工作的地方有好几处。看父母是否当官要看月上：月柱午火上带庚金（食神），不是官，所以父母不当官。

**坤造**：庚戊甲丁／子寅子卯

夫宫子水为丈夫，伏吟到年上，子上坐庚，庚生子，庚与子是一个人，一个意思：带官帽的丈夫，官把丈夫统住，丈夫是大官，为省政法委秘书长。

### 带象的两层意思

**广义带象**：同一柱的干与支当一体看，干为头脑，支为躯体；支带了某个干，支就有了干的象。

**乾造**：乙乙辛戊／卯酉巳戌

大运：甲申 癸未 壬午 辛巳 庚辰 己卯 戊寅

木火成势制酉金；日主坐下七杀巳火与其库制了日主之禄（酉）。酉本是比劫，但乙木财星坐在酉上，酉就带了财的象，酉禄可当财看，制禄即得财。

**乾造**：壬壬己戊／辰寅丑辰

大运：癸卯 甲辰 乙巳 丙午 丁未 戊申 己酉

时支辰为财库，可表大企业，但辰上坐戊（劫财，他人），辰带了他人的象，成了别人的企业；丑为食伤库，也当财看，丑带了日主的象，是自己的企业；丑入辰库，别人的企业大、自己的小，是合伙。此人与人合资办厂，自己有股份并在厂里有职权。

**坤造**：己丙丁癸／酉寅卯卯

大运：丁卯 戊辰 己巳 庚午 辛未 壬申 癸酉

酉财被卯印冲制，酉在年上为宾位，是他人的财，为别人挣钱；但酉财之干坐己，己与日主丁有半通禄关系，酉带了己的象，所以此财也有她一份。她是酒店老板，占四成股份。（此盘亦见下篇半禄。）若酉不带己，就是纯粹给别人打工。

**狭义带象**：天干生地支、干与支象一致的柱子。六十甲子中共十二个：

> 口诀：甲午、乙巳、丙辰、丙戌、丁丑、丁未、戊申、己酉、庚子、辛亥、壬寅、癸卯，十二柱带象。

初级先学**干生支**的带象；广义带象在中级讲。（早期记录中有“丙辰、丙戌不大是带象”的疑问，见存疑。）

## 四、带象的取用原则与命例

### 五条原则

1. **意义最大的只有两种：官（杀）带财帽、印带官（杀）帽**。印带官帽表示当官；官带财帽表示管财的官。其余如食伤带比劫、财带食伤、禄（比劫）带印帽，对日主作用不大，一般不论，但仍算带象。特例：巳、午既是戊、己的禄，又是其印，所以禄带官即是印带官，可定为与日主相关的带象。
2. 带象柱必须**与主位（日柱，日干或日支均可）有关联**才论；无关则无意义。关联方式：相合（五合、六合、三合、半合、暗合、自合）、相生、禄与原身换象、伏吟、拱局、入墓。刑、冲、穿一般不算有关联（表示不和、无缘）；但刑冲在有功的情况下，也可算与日主有关。
3. **财带官帽**（干官杀、支财）是支生干，若与日主有关联也算带象，意思是与财有关的官。这样对日主有意义的带象共三种：财带官帽、印带官帽、官带财帽。
4. 带象在原局被坏，或被大运坏，则失去意义。
5. 大运中的带象，条件同原局：见印带官帽、官带财帽或财带官帽，须与日柱有上述关联才有意义。

补充：命局中干支相同的柱子，干支代表同一个象。看官的正副：与日主有关的官杀在**宾位**，或被合到时支，为副职；官即便在日支，被它支穿（称“穿偏”），也是副职；主神在主位、中神在坐下，则为正职。

> 口诀：印带官帽当官，官带财帽管财；带象不连主位，一概不论。

### 命例

**乾造**：甲癸戊丁／午酉子巳

大运：甲戌 乙亥 丙子 丁丑 戊寅 己卯 庚辰

戊日时见巳禄，丁坐巳，丁与巳当一家；丁在年支见午（丁禄），年柱甲午是**印带杀帽**，由此间接与日主关联，成了日主自己的，是当官之象。戊寅运：戊是日主到，寅是局中甲杀的禄、又合午成印局，权力到，升副市长，且杀有化。本盘火制金水制不住，不看做功，看象。戊合癸财，又自合坐下子财（子与癸同象），求财，实际是贪官。巳合克伤官酉，午也克酉并冲子财，印制财与财的原神，印主权力，此人以权力求财；金水居月令不弱，遇木火旺运财也好。（自述70%的盘看做功，30%的盘看象。）

**乾造**：甲癸辛己／午酉卯亥

大运：甲戌 乙亥 丙子 丁丑 戊寅 己卯 庚辰

年柱甲午杀带财帽；财星甲与时干己印合，坐下午杀与己是禄与原身，时柱己亥自合，亥卯与日支半三合，经此换象，年柱带象与日主关联，成了自己的：甲财合己印为管理，是管财的官，某财政局副局长，副处级。为何是副职：年支午杀居宾位，被时支亥合，没合到日主坐下，所以是副职；合在日主坐下则为正职。这是象的运用。丙戌年四月车祸身亡，主要是酉戌穿，穿了官杀库。

**坤造**：丁丙辛甲／未午未午

大运：丁未 戊申 己酉 庚戌 辛亥 壬子 癸丑

火与燥土成势不做功，地支午合未只是闭财库；女命官杀旺而无制，似差命，实则看象：时柱甲午官带财帽，午未合到主位，是管理财的官象。日支未财库，未伏吟到年上，年丁带杀帽，丁午同象、午合未，印带杀帽与日主关联；印杀皆主权力，丙辛合为管理，所以是管财的官。官在年、时柱，丁与午换象，年为远方、时为门户，所以在海外跨国公司任财务总监。甲财虚透在门户，说明有能力。

**坤造**：壬庚丙辛／寅戌午卯

大运：己酉 戊申 丁未 丙午 乙巳 甲辰 癸卯

年柱壬寅印带杀帽；寅午戌三合羊刃局，中神午落在主位，带象与主位有关，是当官之命；三合局中神在坐下，为正职，是一所学校的正校长。木火成势主文，丙火也主文；戌为食神，主教育学校，又为库，孩子多，所以是教育行业。级别不高，是因庚金无制。庚辛金虚透无制，财虚透主才气口才。做功很小，主要靠象看。

**坤造**：戊甲乙辛／申寅巳巳

大运：癸丑 壬子 辛亥 庚戌 己酉 戊申 丁未

乙坐巳伤官，木火成势；两巳合申、寅冲申，都是制申官，伤官制官做功。年柱戊申官带财帽，经日主坐下伤官巳，把带财的申官合到主位，且巳之原身戊透年干、坐下就是申，申就是日主自己的：管财的官。申主金融银行，此人是某银行的主任。功与象表示同一意思，功象同看。庚戌运庚辰年不吉：原局在制申，不喜申的原身庚透干合身，流年辰土又晦巳火、生申金，把局坏了，破财（家中父亲也生病）。

> 提示：原局中要制的字，不喜大运再透干无制而合身；做功的字不能被流年坏。

**坤造**：癸甲丙庚／卯寅戌子

大运：乙卯 丙辰 丁巳 戊午 己未 庚申 辛酉

丙坐戌有根，年柱癸卯为印带官帽，卯戌合把带官的印合到主位，是当官的；卯戌合还是食神合印，主文化、文类职业，木火之势也主文，所以是文化类的官，县级干部。时柱庚子也是带象（杀带财帽），但与主位无关，不看做它的带象；仅按庚财虚透门户，主才华，又子与癸同字，所以很有才华，夫妻都是当地名人，出版了好几本著作。

> 提示：命局有食神合印，大部分人从事文化、思想等文类职业，如教师。

**乾造**：甲戊戊丁／午辰申巳

大运：己巳 庚午 辛未 壬申 癸酉 甲戌 乙亥

康熙命造。不看做功，主要看象。年柱甲午印带杀帽；午与时干丁同象，丁坐巳一体，巳被申合到主位，巳又是戊的禄，所以年上的印带杀帽是日主自己的；整个八字是自己一个人的象：甲=午=丁=巳=申，都到了主位。大运全是火运。月令财库是大财。是当大官之命。

**乾造**：庚己甲己／子卯辰巳

大运：庚辰 辛巳 壬午 癸未 甲申 乙酉 丙戌

年柱庚子印带杀帽；子水印与日支辰印库半三合，带象与主位关联，当官。可惜半合局中神子在年支、不在主位，所以始终是副职；子是从辰里引出的，卯穿辰是制印，**制印得权**。从27岁任副县长到47岁都是副职。壬午运癸酉年：子午冲去印，癸为子到，坐辰又把酉官合到主位，升副县长；癸未运壬午年：壬癸为局中子到，午冲子制印，升常务副县长，主管工业。日主合两己财，左拥右抱，表示贪财。（子卯破不好。）

**乾造**：乙己庚庚／巳丑午辰

大运：戊子 丁亥 丙戌 乙酉 甲申 癸未 壬午

年柱乙巳杀带财帽，乙财与日主合，带象与主位有关，是管财的官。日坐午火正官，本应是正职，但丑午穿，正职被穿成副职：某学校总务处管后勤的副处长。日主伏吟到时干坐辰，辰为伤官库，主学校；午官生辰、辰又生午官被化，丁丑、辛巳年升官。巳杀居宾位，七杀坐偏不为行政之官，所以是学校里的副职，不是行政部门的官。

> 提示：坐下正官被穿，变成副职。

## 本章（上）小结

| 内容 | 要点 |
|---|---|
| 君臣 | 干克支，支不克干；支要克干须先合 |
| 互生 | 干支可互生，一柱干生支则象同，称“统” |
| 自合九柱 | 丁亥己亥辛巳癸巳（支可合克干）、壬午甲午戊子、丙戌壬戌（须未刑开库） |
| 自合性质 | 合而制，是做功；强者制弱者看气势；支被冲则不成 |
| 带象十二柱 | 甲午乙巳丙辰丙戌丁丑丁未戊申己酉庚子辛亥壬寅癸卯 |
| 带象有用的三种 | 印带官帽、官带财帽、财带官帽，且须与日柱关联 |
| 正副职 | 官在宾位或被合到时支、或被穿偏，为副；在主位坐下为正 |

### 存疑标注（上篇）

1. 壬壬庚辛／子寅辰巳一盘，两处原稿对辛巳自合有两种说法：一说“巳合制辛，主要是表象，不是做功”；一说“辛旺制巳，属羊刃制杀有功，因寅巳穿而无官”。照录并存，不择。
2. 天干克地支时“如果地支很旺，也能制天干”（原稿一处措辞），与“地支旺则地支合克制天干”的说法关系不清，以前者为气势强弱的一般原则理解。
3. 丙戌、壬戌的自合，原稿一处称“冲不起作用，辰太湿，坏了火，整个库就坏了，合不了”，文字疑有误（应指戌，非辰），照录。
4. 带象十二柱中，早期记录称“丙辰和丙戌有说法，不大是带象”，未展开；而丙戌同时列入自合九柱。
5. 乙癸辛癸／未未未巳一盘末位大运原稿作“己子”，顺序应为丙子，疑为笔误，照录。
6. 早期记录对“丁亥”自合有“亥中壬水旺则合克丁”与“局中火旺则丁制亥”两种方向，已按强弱看气势统一。

### 自测题

1. 为什么说“天干克地支，地支不克天干”？地支什么情况下能克天干？
2. 列出九个自合柱，并说明哪几个可以由地支合克天干，哪两柱须未刑开库。
3. 带象的十二柱里，哪三种对日主最有意义？带象柱不与主位有关联时怎么处理？
4. 官在宾位或被合到时支，为正职还是副职？举出另一种变成副职的情形。

<details><summary>答案</summary>

1. 干为君、支为臣，干能克支；支要克干，必须先合住天干（自合），所以只有丁亥、己亥、辛巳、癸巳这类柱子，地支才能合制天干。
2. 丁亥、己亥、辛巳、癸巳、壬午、甲午、戊子、丙戌、壬戌；前四柱地支可合克天干；丙戌、壬戌须未刑戌开库才合。
3. 印带官帽（当官）、官带财帽（管财的官）、财带官帽（与财有关的官）；不与主位关联则一概不论。
4. 为副职；官在日支但被它支穿（穿偏）也是副职。
