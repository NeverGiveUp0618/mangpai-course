# 盲派体系总览

## 一、盲派与传统、新派命理的区别

目前流行的命理大致分两路：

| 流派 | 核心思路 | 本派的评价 |
|---|---|---|
| 传统命理 | 讲用神与格局，以平衡为目标找用神；虽有从旺、从弱之说，但无完整体系。《滴天髓》是其理法的集大成者 | 只能部分解释命理，并非对命理的正确理解 |
| 新派命理 | 同样讲用神，但把日主旺衰放在最重要的位置，据旺衰分忌神、用神，把八字简单分成两个对立面 | 日主旺衰本身难判（从与不从更难判），简单的喜忌分类做不到细断 |
| 盲派 | **不论日主旺衰、不取用神忌神、基本不用格局**，只看结构：做功、宾主、体用、象 | 严格说不是“废弃”，而是体系里根本没有旺衰与用神这些概念 |

三点理由：

1. **命理的本质是表述人生**，八字是人生的缩影。
2. 日主旺衰说明不了能力大小，也解释不了命运轨迹；没见过“日主旺的人身体强”“日主衰的人身体差”。
3. 单找用神使理解僵化：人生没有永远的朋友，也没有永远的敌人，不可能一两个用神陪伴终生。

> 口诀：不看日主衰旺，不找用神，只看结构（做功）与象。

另有两点背景：盲派传承历来口授心传、不立文字，口诀并非万能钥匙，很多断法来自对命局的悟性与分析；因此现代整理需要创造一些新概念（宾主、体用、功神废神、能量效率、贼捕等）来描述这套体系，这些概念属于理法范畴。

## 二、论命三法：理法、象法、技法

三者不是孤立的，针对不同命局有所侧重，要结合使用。

### 理法
- 内容：阴阳五行、干支性质，刑冲克合破害墓等作用规律，以及宾主、体用、做功、效率、干支配置、干支虚实等概念。**看做功是理法中的重中之重**。
- 解决的问题：从哪里入手看八字、如何看出富贵贫贱与职业大类、每步大运与流年的**大致吉凶**。一句话：能读懂八字的吉凶。
- 局限：只能断吉凶，断不到具体事件（病、破财、官司、升官）。
- 初级班的重点：掌握八字如何做功。

### 象法
- 内容：干支象、宫位象、十神象、神煞象；初级涉及换象、带象、十神及虚透的含义，深层象法在中级。
- 作用：把吉凶**具体化、形象化**，同样的“不好”，是生病、破财还是官司，要靠象。象法的形象性和准确率远高于单纯理法。
- 使用原则：象法无处不在，大到一组四柱，小到一个大运或流年干支、局中任何一个字。**先看做功，再看象**；有功有象则功象同看，二者不矛盾。
- 比例：约 80% 的八字用做功来表述，约 20% 的八字用象来表述，所以象也必须深入理解。

### 技法
- 内容：盲人历代相传的口诀，是经验总结，有时说不出道理，但运用准确，是盲派的“绝活”。
- 例：
  - 制去财（或官、杀）与财（或官、杀）的原神，是发大财（当官）的人。
  - 坐下财（官杀）库喜刑冲。
  - 甲生酉月喜水润，乙生酉月宜火攻。
  - 外食内杀是当教师的人。
- 用途：看父母有无克、是否健在，婚姻质量高低、几次婚姻、终身无婚，虽用到理法与象法，**最后靠技法定夺**。

## 三、宾与主

“宾”是别人或属于别人的东西，“主”是自己或属于自己的东西。宾主用来区分命局中哪些是自己的、哪些是别人的，表达命主与外部世界的关系。宾主是**相对的、分层次的**概念，是从**宫位**角度划分的。

### 四个层次

| 层次 | 主 | 宾 | 说明 |
|---|---|---|---|
| 一 | 日干 | 日支及年月时三柱 | 日干代表自己；日支配偶，时柱子女，月柱兄弟或父母，年柱祖上或父母，都是要面对的“别人” |
| 二 | 日柱 | 年、月、时柱 | 日干与坐支配偶组成自己的小家；父母家（年）、兄弟姐妹家（月）、孩子家（时）为别人家 |
| 三 | 日柱、时柱 | 年柱、月柱 | 日主、配偶、子女构成一个家庭，面对年月柱的父母兄弟 |
| 四 | 四柱八字 | 大运、流年 | 四柱是命主的大家庭；大运流年是外来的，从外面作用于八字 |

要点：

- 前三层最重要。“主位”通常指日柱、时柱，**重点在日柱**。分析时以第二层为主：看日干（或禄）及坐下日支与其他干支发生了什么关系。时柱若见禄，或见日主所生的食伤，也可把时柱当主位看。
- **大运流年出现命局中已有的同一个字，不再算宾**，而是命局中的字到了，一般表示原局的**应期**。
- 年月为宾；但年月的财官若通过一定关系被主位所制，或被它制后又被主位所得，就能成为自己的。

### 宾主的用法

看财官，先看它们落在哪个位置：落主位是我的，落宾位是别人的（“财跑出去了”）；定位后还要看主宾之间有无关联、能否为我所用。年月见财官本是外面的，但若与主位发生制、得的关系，也可成为自己的。主位虽有财官，但不被其他支的体所作用（好比钱放在保险柜里不去消费），是“死”的，没有意义；**坐支的财官也一定要用其去做功**。主位财被制去，不等于被劫走。

命例对比：

**乾造**：甲庚丁庚／午午酉戌

酉为丁日坐下之财（主位）。酉被午火与戌燥土制去，表示有财，并非财被劫走。

**乾造**：丙甲丁庚／午午酉戌

与上例相近，但年干透丙（劫财）。劫在宾位，表示别人；丙一透，象就坏了：自己的财被别人劫了。财为妻，所以多婚且都离；此人开出租车，财运亦不佳。

> 结论：命局好坏与日主旺衰无关，只看宾主之间的关系和命局结构。如同一个人只有在与社会上人事物的交往中才体现出能力与贵贱。

## 四、体与用

体用是从**十神**角度划分“自我主体”与“外物客体”。

| 类别 | 内容 | 含义 |
|---|---|---|
| 体 | 日主、禄、比劫、印 | 我自己和我使用、操纵的工具（印生日主、代表母亲；禄即日主自身及身体；比劫帮扶日主、兄弟姐妹） |
| 用 | 财、官（杀） | 我追求的目标：财富、身份、地位、荣誉、权力 |
| 可体可用 | 食神、伤官 | 属精神体验：智力、思想、快乐、享受、财富、头脑、技术、手艺、学历；既是我本身，也是我追求的。**食神偏体，伤官偏用**。追求精神境界也属食伤范畴 |

> 注意：此处的“用”与传统命理的“用神”是两回事。

### 不同的体做功
- **印制财**：凭借单位、学业等手段取财。
- **禄（或比劫）做功**：层次一般不高。禄主身体，多为以体力为主的辛苦职业，成就有限。
- **比劫取财也有得大财者**，要求做功效率很高；比劫做功还有“炒作”之意，大的股票炒家八字多用比劫做功。
- **禄逢印主有福**：如辛丑日主，月支酉为禄，年支卯，酉冲卯为禄做功；因日主坐丑（印），不主辛苦，印禄相随，主有福气。

### 体必须与用发生关系
命局中有财官不一定能得财当官：不当官的人未必命中无官，也可能官杀很旺但无制无化无功，成为局中之害，反而主官灾。财同理，年月见财若与体无关，虽明现也是别人的。**体必须与用发生刑、冲、合、害、破、墓等关系，才可能使财官被日主（体）得到。**

宾主与体用意义相近，都是分析八字的手段，角度不同：宾主论宫位，体用论十神。

## 五、做功、功神、废神

入手先看主位：日干与日支，看日柱是占体还是占用，所占之物与其他干支有何作用。

- **占体的**，如同人手，必须有事做，去作用别的神，闲着不但成差命，甚至无事生非。
- **占用的（财、官杀）**是身外之物，必须与外面的体发生关系：被体制、被体化或被体合，有所作为才是好命；闲而无事，不能发官发富，甚至贫穷或为凶。
- 食伤为中性，可被制，也可去制别人：生财、制官杀、泄秀。

**做功**：体或主与用或宾之间的相互作用。方式：**刑、冲、克、穿、合、墓**（破亦属之）。

| 名称 | 含义 |
|---|---|
| 功神 | 参与做功的字（互制双方都是功神） |
| 辅神 | 帮助功神做功的字 |
| 废神（闲神） | 不参与做功的字；重点看功神与辅神，闲神一般不看 |
| 正向做功 | 主位的体去作用、追求或制去宾位的用 |
| 反向做功 | 主位的用去追求宾位的体；层次一般高于正向，许多大格局属反向做功（后续章节另述） |

> 口诀：体用、宾主之间刑、冲、克、穿、合、墓，都是做功。

## 六、能量与效率

借物理学概念：**消耗能量而产生效率，叫做功**。

- 八字中每个字都有能量，**天干能量低，地支能量高**；十干十二支是不同属性、方向的能量体，彼此刑冲克穿合墓破，发生碰撞、耗散与湮灭。
- 功神：耗散能量后产生了效率。
- 废神：耗散能量后不产生效率；或者既不消耗能量，也不做功。
- 评价：成功者的八字有效率地利用能量，**功神多而废神少，或功神虽少但效率高**；平庸者**废神多功神少，或有功神而效率低**。这就是区分富贵贫贱的依据，做功效率高低直接决定层次。具体评判见后续各章命例。

## 七、贼神与捕神

由宾主、体用演化而来，是做功的一种特例。

- **定义**：在主或为体的字（捕神），去制在宾或属用的字（贼神），且捕较旺、贼较弱，被**制死、制干净**，这种结构称“贼捕”结构。在主或体的字也可被宾或用所制而成贼捕（例如属体的印被制）。若原局捕旺而无贼，大运见贼，也是贼捕。
- 比喻：警察（捕）力量强而小偷少，警察无从体现；希望小偷一出现就被抓住，立功受奖，即做功。
- 含义：某字被制死制净，表示命主得到了它；**大运流年见贼是得到的应期**。

### 应期规则

| 情形 | 吉凶 |
|---|---|
| 局中捕旺 | 喜大运贼神出现 |
| 运中捕旺 | 喜流年贼神出现 |
| 运中贼神临，流年捕到 | 吉 |
| 局中有捕无贼 / 运中见捕不见贼 / 局运流年都见捕不见贼 | 应凶 |

### 辨别要点
- 某字被制但**没有制死**，也做功，但不叫贼捕，大运流年分析方法不同。
- 若表面像贼捕，捕神出现的运或年却应吉，说明该字并没有被制死，不符合条件。要细心辨识何时制净、何时未净。
- 本质：原局一方形成强势（捕）制死力量弱小的另一方（贼）；二者悬殊，做功效率不高，尤其是捕过旺而无贼时，只能等大运或流年出现贼神，被原局强势制去，做高效率的功，才表现为吉，这就是贼捕“喜走贼运”的原因。

### 命例

**乾造**：癸丁甲己／巳巳戌巳

大运：丙辰 乙卯 甲寅 癸丑 壬子 辛亥 庚戌

分析：日主甲木无根，弃之不看。火与燥土（巳、戌）结党成势，年柱癸巳自合，巳旺制去癸水，天干丁又反克癸，印星癸被食伤制净。巳制癸，巳又入主位的戌墓，戌亦在火土势中，这个功归日主。印代表权力，制印得权，当官之命。癸为贼神，局中火土为捕，走癸丑、壬子运贼神到，是制癸的应期，升至地委副书记。癸水太弱，巳合制癸效率本来不大，好在运走贼使贼旺，功才大；又有日主坐下戌土将功神巳火墓之，才做大官。

## 八、正用与反用、正局与反局（入门提示）

- **正用**：主位是体，宾位是用，以主位的体制宾位的用。
- **反用**：主位是用，宾位落了体。
- **正局、反局**较复杂，详见第 11 章与后续各册。

## 九、象与取象的工具

象，就是把干支符号变成实际的东西：把干支与生活中的具体事件、物品、人物对应起来。盲派取象的三种主要工具：

1. **干支本身的象**：如丙火，可类象为太阳之火、媒体、文化、影视传媒。
2. **刑冲化合定象**：把某干支的各种象看成横坐标，其他干支的象为纵坐标，刑冲化合等关系相当于不同象限；通过关系定位，把象“定死”，肯定是这个而不是别的。
3. **干支配置**：天干与地支“一家”（如丙与巳）。天干不好定象，就看地支如何定象，地支的象定下，天干的象随之而出；即干支可以互换、互代、互用。

此外，**六亲要活用**：财为父、印为母，但命中无财怎么看父？无印怎么看母？须按象活用，有自己的原则（见后续章节）。

### 取象命例：看出做律师

**坤造**：辛辛己丙／酉卯丑子

一位母亲拿女儿的八字问将来职业；断为律师，且不是小律师，而此女正在读法律硕士。推理：

1. 辛金为食神。食神可当老师、医生，但**卯酉相冲**，食神目的明确：去制官（卯为官）。
2. 有人会问食神制官为何不是当官？要看食神从哪来：日主坐丑，丑是食神库，食神自丑中来；**身下坐库，表示这类东西很多**，可类象为法律文书、法律文件，用来制官，表示辩护、用条文说服官。
3. 为什么自己不当官？食神太重，食神主自由，喜欢自由，不受约束；再有**子丑合**，食神库合了一个财，表示通过食神的手段取钱，只要给钱就可以为犯罪分子辩护，目的是取财而不是当官，会和公检法对着干；合法与公检法对着干的人只能是律师。
4. 日主坐库，丑库可类象为企业，坐在自己屁股底下，是自己的企业；法律类的私人企业只能是律师事务所。

> 要点：象不是空想，必须由结构（冲、合、库、坐支）一步步“定”出来。

## 本章小结

| 概念 | 要点 |
|---|---|
| 不论旺衰、不取用神 | 只看结构：做功与象 |
| 三法 | 理法断吉凶；象法断具体事；技法为口诀，最后定夺 |
| 宾主 | 宫位角度；日干/日柱/日时柱/四柱为主；其余及运、流年为宾；运岁见局中同字是应期 |
| 体用 | 十神角度；体＝日主禄比劫印；用＝财官；食神偏体，伤官偏用 |
| 做功 | 刑冲克穿合墓；功神、辅神、废神；正向、反向 |
| 能量效率 | 干低支高；功神多废神少或效率高则层次高 |
| 贼捕 | 强捕制死弱贼；喜运岁见贼；有捕无贼应凶；未制死不算 |
| 取象 | 干支本象、刑冲化合定象、干支配置互换 |

### 自测

1. 体、用各包含哪些十神？食神、伤官如何归属？
<details><summary>答案</summary>体：日主、禄、比劫、印；用：财、官杀；食神偏体、伤官偏用，两者可随命局需要为体或为用。</details>

2. 为什么主位上的财官不做功也没有意义？
<details><summary>答案</summary>财官属用，是身外之物；不被体所制、化、合，就像钱放在保险柜里不消费，是死的；坐支的财官也一定要用来做功。</details>

3. 大运流年出现命局中已有的同一字，算宾吗？
<details><summary>答案</summary>不算宾，是命局中的字到了，一般表示原局的应期。</details>

4. 贼捕结构中局中捕旺、运中见哪个字为吉？
<details><summary>答案</summary>局中捕旺喜大运见贼神；运中捕旺喜流年见贼神；局中有捕无贼则需运岁出现贼神，只见捕不见贼应凶。</details>

5. 象法与理法的使用顺序？
<details><summary>答案</summary>先看做功（理法），再看象；有功有象则功象同看，二者不矛盾。</details>
