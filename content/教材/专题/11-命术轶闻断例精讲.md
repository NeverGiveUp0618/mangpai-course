# 命术轶闻断例精讲

本章提炼本派前辈的几则断例。这些断例的共同特点：不论日主旺衰、不找用神、不定格局，由**八字本身的象**直接断出家庭、职业、婚姻、牢狱、子女；大运流年只是**应期**。读法是：先看断语是怎样从命局的某个字推出来的，再看应期怎样被引动。

## 一、盲师一派的基本路数

1. **不排大运、不讲格局喜忌用神**。命局是根本，大运流年只是延伸。人一生发生的任何一件大事，都以类象的形式体现在命局的八个字之中；先从命局看有没有婚姻问题、会不会发财、会不会做官，断完之后求问者追问哪年哪月，才排大运流年检查应期。
2. **八字是根本，行运是应期**。如果八字里没有发财的信息，就算行财运也未必能富，甚至行财运反而潦倒。（这与“命好不如运好”的流行说法相反。）
3. **格局与喜忌只是看命的拐杖**：熟练的人不拘泥于日主旺衰，如同会说话的人不在乎语法。四柱的核心是“象”；一个八字是一本书、一段文字，它向批命者述说命主的一切。
4. **十神意向**：十神在不同组合下意向不同，要先“换象”看清楚。
   - 举例：伤官遥合七杀，庚金就具备了吸引男人（七杀）的能力——这样的命是电影明星。
   - 另一例：以俗论身旺，用庚金泄秀，理应才华出众；但局中见壬水财星，食神意向变为生财，壬水座戌虚透无用，食神生财是做了无用功，这个人很穷。
5. **长生十二宫是象**：长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养，描述一个事物从开始到终结的种种表象，不是旺衰。例如乙木女友嫁给庚金，一入申位（乙在申为“胎”），所以孩子与妻子一块来；断寿数时，除寿元星外，还看行运所处是死、绝或墓；某年流年所处的“病”地，应了生病之象。
6. **盲师不用的东西**：结婚前以财为女朋友，结婚后以妻宫为妻。

> 口诀：命局为根，运为应期；不论旺衰，先看象与功。

## 二、断例一：癸巳 甲寅 甲辰 丁卯（孽情）

**坤造**：癸甲甲丁／巳寅辰卯

大运：4岁起运；卯运在先，己未大运；

### 1. 先断过去

| 断语 | 依据 |
|---|---|
| 四岁随娘改嫁，一个母亲两个父亲 | 童运起运早（4岁），第一步运见变动 |
| 养父疼爱，童年幸福 | 童运的象 |
| 七至九岁入学，读到三五年级就不读 | 学业断得早 |
| 十六七岁婚姻动 | **巳中庚金是七杀，七杀管到十六岁；十六岁是戊申年，走财走官就结婚** |
| 找了远方的对象 | **官在年上**，找远方；官在月上则找同学、同事（近处）。大运走得较早，第一个运见官流年要找的对象就是远处的 |
| 对象年龄大很多（大十四岁） | **女命比劫旺：不是找年龄大的，就是找年龄小的** |
| 一进门就当后娘；五男二女的命 | 第一个大运走卯，第一个孩子属兔，走这个运时还没结婚，子孙宫提前动，所以第一个孩子属兔；第二个属马，正是情人 |
| 二十到三十岁日子苦 | 大运 |

### 2. 近年的隐情：情人是儿子

- “近两年冒出个女人和你争抢这个男人”：流年引动。
- 情人年纪比她小十多岁（小十三岁），是晚辈，很近：**丁火是伤官，伤官就是儿子**。
- 到己未大运仍有那种关系，但不那么密切：**因为未中还有丁火，丁火在此时有余气**。
- 关系到甲戌年（1994）有变化；到54岁彻底结束；54岁以后身体变坏（肾脏或心脏）。

### 3. 克女儿

“她将来会克死一个姑娘”：食神是姑娘，巳中丙与寅中丙都是姑娘，**寅巳相刑所以死闺女**；伤官为儿子，儿子都不错（一个当大官，一个存大钱），姑娘不成器。最晚到2004年。

**坤造**：壬癸癸甲／子卯卯寅

二姑娘八字，1998戊寅年生场大病，是子宫上的病，活不过2004年。实际：1998年子宫癌做手术，次年复发，子宫大出血摘除，转移肺，化疗，不行了。若能过2004年就会好。

### 4. 小结

- 女命断婚：**官的位置（年月日时）定对象的远近；七杀管到十六岁；比劫旺定年龄差**。
- 断子女：看**大运的支**对应属相，**子孙宫（时）提前被引动，则第一个孩子在婚前**。
- 食神为女、伤官为男；刑克在食神者克女。

## 三、断例二：己酉 甲戌 甲申 乙丑（牢狱命定）

**坤造**：己甲甲乙／酉戌申丑

大运：乙亥 丙子 丁丑 戊寅（1岁起运）

1. **断语**：姊妹六个，占末枝；上学不成功；从十六岁开始从男人手中挣钱；最近在南方发大财，是不义之财；钱是从一个人手里转过来的，那人的钱是偷来的，已被逮捕；他供出了你，公安来找；牢狱之灾命中注定；若自首，不会超过四年，到1992年，在本地坐牢。
2. **应验**：自首，四年后出来；又断“还有一次牢狱”，1993癸酉年四月入，七八个月放出；第三次断“再也没有牢狱”，应验。叮嘱：以后如果在男人身上发大财会出事，小财不会。

### 解析

- 甲生戌月，**戌为伤官之库**；年支酉金官星与之相穿；日干甲合己土财星，所以意向取财。
- **十六岁开始赚钱**：大运行戌土偏财运，流年甲子合动时支丑土财星，而年干己土财也被甲合，财星全动。
- **己巳年从南方发大财**：甲己合财之应期，己坐巳火上，所以是南方的财。
- **为何是非法之财**：局中戌土与酉官相穿，意为违反法律；戌中含伤官丁火，在运中透出，是为应期；丁生己，所以是非法之财。**土财主五、十之数，故十万元**。
- **核心看戌土，戌为违法星**。劫财伤官又穿官，是一种犯罪组合。此命伤官隐而不现，所以不是明火执仗式的违法，只是偷偷摸摸；原局金旺火弱，两者形不成明显对抗，一般无牢狱之忧；但**到丁运，甲乙俱生丁，丁有生无制，便要出凶**。这是一种“支转干”应法；一应五年，其间壬申年丁壬合制丁，命主出来，但晦运未过，第二年又入狱。

> 评：若用日主旺衰解，反而陷入“从弱还是身弱”的争论，更无法找出此造做职业“小姐”的依据。官杀为忌，就不能理解为何总从男人取财；官杀为用，又难以解释她如何犯牢狱。把八字简单分为“用神”和“忌神”，如同把人分成朋友或敌人。

## 四、断例三：辛卯 辛丑 丙辰 甲午（老姑娘）

**坤造**：辛辛丙甲／卯丑辰午

大运：寅 卯 辰 巳 午 未（顺排）

1. **断语**：姊妹四个，老大；干服装布匹一类的工作（做刺绣）；当着官（车间主任）；43岁还是未出阁的大姑娘；婚姻要等到六十三岁以后；找一个离退休的干部，一进门就当奶奶。
2. **师父的解释**：她这个人很正派，**正财在天干，所以本分**；有财没官，以财看夫；**财入丑库，因此无法结婚**。
3. **应验**：癸酉年正官星到又合入夫宫，按一般命理应有婚姻，介绍了十个对象，没有一个成。

### 解析

- 女命成为老姑娘的原因：**财官都入了库，只有到六十三岁行未运，冲开库，才能找到对象**。一进丈夫门就当奶奶，是印星伤官大运，伤官为孩子。
- **一个无婚姻的女命，不是八字里没有官杀星，而是有并占据其位置，但不能用，这就是八字本身表达的东西**。同理，一个在人生某方面有缺陷的命，一定有这方面的东西，但被坏了或无用了。
- 辛见丑入墓，失去作用；所谓“透干逢合”的表象，只表示正直，财星生官和产生情欲的能力已经没有了。

## 五、断例四：断“逢克论凶”的简易法

这是民间流传的一种快速判断法，不论强弱、用神、格局，要点是“**逢克论凶**”：

1. **原局克的字越多，命运层次越低**；两个八字可以用克的个数比较好坏。
2. **大运、流年、流月与原局结合，增加了“克”字则增加了凶，克字越多越凶，反之越吉**。
3. 用法：
   - 原局：先看同柱，有无盖头截脚；再天干和天干论，地支和地支论；
   - 大运、流年、流月：先看本柱有无盖头截脚；天干和天干论，地支和地支论；大运和原局每个字论，流年和原局、大运每个字论，流月同样；
   - 当克数大于生数时应凶，越多越凶。
   - 只有一种五行时，0个克是专旺格；有两种五行时，3个克就是从格。
4. 适用范围：大概80%的命局的原局、大运、流年的定性分析，**整体上方便快速，但不是适用所有命局**。
5. 依据：克代表破坏、冲击、粉碎、分散、离开、矛盾，是八字干支结构不稳定和五行突变的重要原因；“有杀只论杀，无杀方论用”（杀的重要性高于用）；“源流”强调干支气势的源远流长，有克气势受阻；不论会合并不是真的不论，贴身克时，会合的机会不大，可略而不计。

> 说明：这只是速判法，与本体系的“作功”论相互补充；遇到“克”时仍须回到做功、宾主、体用来定性。

## 七、断运篇：长生十二宫的论断要点

> 长生遇杀最有灾，沐浴冲宫怕刑伤，冠带临官怕官运，七杀逢财不可当，劫怕见财财怕劫，财官切忌入空亡，官行官地官遭害，一见伤官有一伤，木逢壬癸主漂流，日主无根度春秋，岁运逢着财杀旺，逢凶化吉富悠悠。

## 九、增补四言独步（节要）

原稿有长篇《增补四言独步》，大意可归为下列几组（以可检验的论断为主）：

1. **六亲**：以财为父，以印为母；财印两全，椿萱并茂；财星得禄，父命悠长；印绶被伤，母年早夭；财轻被劫，父命先丧；父星临库，父当先死；妻星失令，半路抛离。
2. **婚姻**：财旺生官，夫唱妇随；财轻逢劫，三妻齐眉；日逢空害，妻多生离；日支同日干，损财伤妻；财官印绶，大忌比肩；女旺食官，子秀夫荣。
3. **伤官**：伤官见官为祸百端，轻者伤躯，重者困监；年月伤官父母不全；月上伤官兄弟不完；日上伤官南配良缘；时上伤官子孙无传；伤官见印，贵不可言；伤官用财，富贵自来。
4. **杀**：七杀有制逢官反怯；羊刃逢冲灾危必至；杀重身轻难逃定数；杀重劫多父亡外土；杀化为印早登金榜；煞不离印，印不离煞。
5. **库**：财官入库，不冲不发；财星要藏，藏财丰厚；辰多好斗，戌多好讼；合多主晦，冲多主凶。
6. **其他**：月令建禄，不住祖屋；日禄归时，青云得路；年冲月令，离乡之客；时柱逢冲羊刃无制，女多产危，男犯刑伤。

### 自测

1. 盲师为什么断命时往往先不排大运？
<details><summary>答案</summary>命局是根本，人一生的大事都以类象体现在命局中；大运流年只是应期，先从命局看有无婚姻、发财、做官的信息，再排运定应期。</details>

2. 女命官在年上与官在月上，对象有何不同？
<details><summary>答案</summary>官在年上，找远方的对象；官在月上，找同学同事，在近处。</details>

3. 为什么说戌是“违法星”？
<details><summary>答案</summary>戌与官星相穿，意为违反法律；劫财伤官穿官是犯罪组合，戌中含伤官丁火，在运中透出即应期；丁运甲乙俱生丁，有生无制则出事。</details>

4. “老姑娘”命的共同特点是什么？
