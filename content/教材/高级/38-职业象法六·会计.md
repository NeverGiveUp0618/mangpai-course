# 职业象法六：会计

> 会计、统计、出纳等财务类工作归为一类，部分银行职员也在其列。这类命局的共性是：**「数字」之象参与做功，并与财（或更大的财——官杀）发生关联**。本章先给取象规律和判断步骤，再用五个命例演示，最后把其余五例的要点汇成一节，供查阅。
> （原稿源自扫描件，个别字词按上下文校订，如「西」作「酉」、「已」作「巳」。）

## 一、会计命局的三条取象规律

1. **亥、子为数字。** 亥、子水都带「数字、运算」之意；这两个字与财星、官杀星挂钩（官杀代表更大的财富），就容易从事会计。壬水同属此类：壬主运算、通达，多与数字相关，再配别的组合，职业容易成为会计师。
2. **子未相穿做功。** 子之象如算盘珠，**穿＝拨动**，是旧时打算盘算账之象。子未穿可以直接读作「运算」；亥未拱财则是「计算财务」。
3. **伤官／食神配印，且有亥子水参与做功。** 食伤是头脑、技能，印是单位、机构，亥子水再加入，就是「用自己的数字技能为单位服务」。

### 配套的细节象

| 象 | 取法 |
|---|---|
| 丁壬合 | 有书写之意；又是食神（伤官）配印，主才华为机构所用、学历文凭较高 |
| 年上的印或官 | 年为远方；印带官合身，可表示外资、大企业 |
| 比劫 | 行动力；伤官为头脑；亥为数字 |
| 寅（中含官杀） | 大机构，也代表大财，机构规模高 |
| 巳 | 眼睛（巳被丑晦、被子克则眼不好） |
| 月令枭神 | 主幼时不吃母乳 |
| 巳火 | 可沟通阴阳，有罗盘之象（见例6-7） |

### 判断步骤

1. **先找数字**：命中有无亥、子、壬？它们与财、官杀有无关系（生、合、拱、墓、冲制）？
2. **再看做功方式**：是子未穿（运算）、亥未拱财（计算财务）、亥子水参与伤食配印，还是亥入财库？
3. **定级别**：财库开不开？财库不开，所管的钱再多也是单位的；财库被冲开、刑开，才轮到自己发财。官杀包局、有印有制，级别才高（总监、行长一类）。
4. **看格局大小**：局不成、制得不干净，只能做普通会计、出纳；包局或杀印相生才有职位。
5. **用大运流年验证**：看大运先看它自身的干支象意，再看与原局每一柱的作用以定吉凶；流年先与大运作用，再与原局作用。

## 二、命例详解

### 例一　会计，婚姻不幸

**坤造**：癸甲乙丁／丑子未亥
大运：乙丑 丙寅 丁卯 戊辰 己巳 庚午 辛未 壬申（1976 起运）

2008年案例：大专，在公司做会计，婚姻未定。

**做功与象**
- 乙未日、丁亥时为活木，生于冬，喜行阳地。食神（丁）高透门户，又自合印星（丁亥），主以技术为单位所用。
- 子、亥是数字，**子为珠算，子未穿＝运算，亥未拱财＝计算财务**，故为会计。
- 原局以子未穿做功，但亥未拱木，未土力量不足，损了格局，所以命平常，没有职权。

**运年应期**
- 丁卯运：丁本是好运，但原局有癸，丁会枭神夺食；卯与亥未三合禄局本吉，却与子卯相破，工作不称心，做过服务业，婚姻不顺。癸未（2003）开始做会计，是原局未财到位。
- 戊辰运：戊癸合，印加财，利于宾位的癸，与己无关；辰使印星入墓，并破坏子未穿，工作得不到提升。戊子（2008）换了几个单位，财运不好：子年引动大运辰，子强未弱，未被穿坏。
- 己巳运：甲己合属平常运；巳冲亥，亥不再损未，未土得大运相生，工作会有起色。

**婚姻**：丑为夫星，日支未墓库本喜丑来冲；不喜月令甲子合住丑，丑成了别人的男人；子未穿又进不了婚姻宫，造成**比肩争夫**。大运不见官杀，戊辰运夫星又入辰墓，婚姻难成，即使结婚也会离，更容易处有家的男人或三角关系。

### 例二　跨国企业财务总监

**乾造**：庚壬乙丁／子午亥丑
大运：癸未 甲申 乙酉 丙戌 丁亥 戊子 己丑 庚寅（1966 起运）

2007年认识的香港人，早年在单位做会计，后任跨国公司财务总监，年薪超百万港币。

**做功与象**
- 乙亥为活木，喜丁火开花泄秀，是才华；**丁壬合与午亥合，为食神配印**，才华为公司所用，学历文凭较高。
- 亥、子、壬皆数字，终日与数字打交道；丁壬合又有书写之意——会计主管。
- 年上庚子为印带官合身，也表示工作单位；年为远方，故是外资大企业。
- 原局印制食神，天干地支制得干净，喜行火运，北方水运也可。

**运年应期**
- 乙酉运：工作不顺，常换单位；酉破午，午是思想才能，才华得不到展示。辛未（1991）成婚，午未合，午为妻。
- 丙戌运：旺丙透干无制，与制食神局相佐；戌运吉，戌代表午到，有丑刑戌制戌为功。辛巳（2001）夫妻分居至今；乙酉（2005）在国外交往女友，仍未正式结婚。
- 丁亥运：丁壬合、午亥合，工作财运大好。丙戌（2006）考取注册会计师资格，应聘为跨国公司财务总监。

**婚姻**：午亥合，午为妻；丑午穿所以婚姻不和，子午冲冲到年，妻在国外两地分居；因女儿不同意而离不了婚，与原局形成**包局**有关。时上丁坐丑为财星，是第二个女人；子丑合了偏印，入不了正室，一直同居没结婚，丁亥运正印得旺与丑无关，更难结婚。

### 例三　专业会计师

**坤造**：辛庚辛庚／亥寅未寅
大运：辛卯 壬辰 癸巳 甲午 乙未 丙申 丁酉 戊戌（1976 起运）

注册会计师，本科会计专业，做事心细，工作水平高，一生专业干会计。

**做功与象**
- 金水食伤生财，又入墓于坐下财库：能管大的财富。
- **为何自己不发财？财库不开，未为印星＝单位，所管的钱再多也是单位的。**若生丑时冲未，则能自己发大财。
- 比劫为行动力，伤官为头脑，亥为数字；寅为大机构，且中含官杀也代表大财——所服务的机构规模级别高，因此能成为注册会计师、大企业会计主管。

**运年应期**
- 癸巳运：巳穿寅冲亥，破坏寅亥合，不受重用，才能不得发挥。丙子（1996）成婚；丁丑（1997）参加工作，丁到未到，丑冲未，未为工作单位。
- 甲申（2004）与领导闹矛盾辞职：巳申合引动巳，巳穿寅，寅是领导；甲代表寅虚透被庚劫，工作丢了。
- 甲午运：杀带财帽合上印，强化印的权力，得领导赏识。丙戌（2006）到更大公司任会计师并任财务总监：丙辛合（官星合身），戌未刑动财库。

**婚姻**：未中藏丁，以未为夫，得正位稳固，婚姻稳定。

### 例四　财会科级干部

**坤造**：壬甲甲庚／子辰申午
大运：癸卯 壬寅 辛丑 庚子 己亥 戊戌 丁酉 丙申（1977 起运，逆排）

城建公司会计，现为科级干部；能力强、个性强，家中说了算。

**做功与象**
- 申子辰合水局，成杀印相生局；**子午冲＝印制伤官，印星做功表示权力**，故有一定职位。但月令比肩坐印库，权力被比肩所分，所以权力不够大。
- 子水为数字，伤官为技能，相冲——会计。
- 申金也为丈夫、主金融，化子水冲午，也与数字相关：丈夫是银行官员。女命伤官伤夫星，幸伤官不旺，只表现为压制丈夫。

**运年应期**
- 壬寅运：寅为学堂，利考学；寅申使杀星发用，毕业后分到大国企。丙子（1996）谈对象，丁丑结婚，丑到＝申金丈夫到位。戊寅（1998）生女儿（伤官落空亡）。
- 辛丑运：辛克月干而不克日主（大限还在月令），以吉论；丑使申入墓、穿午为功。己卯（1999）升副科：甲己合、卯申合，坐支七杀发用，合动杀星。
- 庚子运：庚为桃花，有情人，感情深，预计相处约五年，庚运走完分手；对工作还有帮助，不会因桃花失去家庭。

### 例五　会计转银行（收银）

**坤造**：乙丁丙己／巳亥戌丑
大运：戊子 己丑 庚寅 辛卯 壬辰 癸巳 甲午 乙未（1967 起运）

例选自《段氏理象学》，断她不是办公室文职就是会计，反馈以前做会计，现在做收银，工作稳定。

**做功与象**
- 木火制金水；亥为杀，丙戌柱是连体，坐食神，巳与戌是一家；**巳亥冲＝制杀**。生己丑时，己晦丙，丑坏戌，影响格局，既不能当官，也不能发大财。
- 巳与戌包而制亥，禄与食神做功：食神主技术，禄主辛苦；**亥为数字，巳亥冲表示财务工作，戌制亥表示文职工作**。
- 丁（劫财）落在杀上，比劫争夫，夫宫犯刑，婚缘浅薄。

**运年应期**
- 庚寅运：工作不稳，常换；庚财虚透被人劫；寅合亥，亥为男友而丁亥自合被人争，大运再合必分手；寅穿巳不利工作。庚辰（2000）处对象，辰代表亥到；辛巳（2001）分手，巳冲亥冲走了；壬午又处，癸未（2003）又分——亥卯未三合局泄尽官气，癸丁冲引动丁劫。
- 辛卯运：工作稳定，收入好；辛虚透被劫，关了财门，婚姻不成。卯戌合，食神合印利工作；卯生巳禄，工作轻松。
- 壬辰运：丁壬合有结婚之意，但辰戌冲冲坏夫宫，终会破裂。戊子（2008）问能否成婚：子卯破定不成，不分手2009年也必分；戊代表戌，戊子自合制官杀，利升职，果然升了。

**婚姻与子息**：比劫争夫，一生都要与人争；子息宫落伤官，与坐支食神相刑，夫妻宫和子息宫俱坏，不利子息，生不了孩子。

## 四、本章小结

| 项目 | 要点 |
|---|---|
| 数字象 | 亥、子、壬＝数字运算；子如算盘珠 |
| 运算象 | 子未穿＝拨算盘＝运算；亥未拱财＝计算财务 |
| 格局 | 伤食配印＋亥子水做功；丁壬合兼书写之意 |
| 级别 | 财库不开＝管钱是单位的；包局、杀印相生、虚官虚杀有用＝级别高 |
| 出纳 | 戊坐子，仔细认真；财被合走＝只管不属于自己的钱 |
| 财务总监 | 年上印带官合身（外资大机构）、食神配印、数字多 |
| 易错点 | 巳亥冲不是伤官配印；月令印被坏易丢工作；官多财多不一定贵、富 |
| 看运口径 | 大运先看自身干支象，再与原局诸柱作用；流年先与大运作用，再与原局 |

### 自测

1. 会计命局最常见的三条组合是什么？
<details><summary>答案</summary>①亥子（含壬）为数字，与财星或官杀相关；②子未相穿做功（子如算盘珠，穿为拨动）；③伤官食神配印，且有亥子水参与做功。</details>
2. 命局管大财却自己不发财，原因与改法是什么？（见例三）
<details><summary>答案</summary>财库不开，未为印星即单位，所管的钱是单位的；若生丑时，丑冲未开财库，则能自己发大财。</details>
3. 巳亥冲与伤官配印如何区分？
<details><summary>答案</summary>巳亥冲是伤官冲印，伤官与印不和，不叫伤官配印；月令印被坏容易丢工作。</details>
4. 出纳与会计的象有何差别？
<details><summary>答案</summary>出纳多是戊坐子，认真仔细并带数字，但财被合走（子丑合），表示只帮别人管财；会计主管则印带官、食神配印、数字多，格局更大。</details>
5. 例二中为何午亥合、丁壬合对会计有利？
<details><summary>答案</summary>构成食神配印，才华为公司所用，学历较高；丁壬合又有书写之意，亥、壬皆数字。</details>
