# 职业象法九：地产商与建筑商

> 地产、建筑业的命局，以「高楼」「土木」「钢筋水泥」「房子」四类象为基础，再看财库能否打开、能否制杀取财。本章先讲取象规律与判断步骤，再详解五个命例（官员下海、地产商、地产煤矿酒店富翁、数十亿地产商、基础工程老板），其余四例以表汇要。
> （原稿源自扫描件，个别字词按上下文校订，如「西」作「酉」、「已」作「巳」、「内」作「丙」。）

## 一、地产建筑命局的四类取象

1. **戊土为高岗，取象高大建筑**：干支中出现**戊戌、戊申、戊辰、戊午**，并参与做功及取财之用，可以搞建筑。
2. **木土组合＝土木工程**：卯戌合、卯未合、己未、甲己合、寅未等参与做功。
3. **钢筋水泥**：丑、辰两字——**丑土中藏金，辰土中藏乙**，都是此象，丑辰参与做功。
4. **印主房子**：印或印库参与做功。

### 配套细节象

| 象 | 取法 |
|---|---|
| 辰（印库） | 地产、建筑；辰戌冲为印库做功 |
| 戌 | 高楼、矿山（见例）；戌在门户表地产建筑生意 |
| 未 | 酒店；丑为煤矿 |
| 财库被冲开、刑开 | 发财；只要财在墓库之中，冲开、刑开都可以发财 |
| 制杀取财 | 官杀制而取财；制不干净也能取财 |
| 虚透 | 戊虚透、财虚透＝虚名、虚权；丁印虚透不是权力而是名誉 |
| 木火燥土包局 | 印参与，能发大财 |
| 伤官配印 | 为官象；官不久者，常因申亥相穿等破格而下海 |

### 判断步骤

1. **先找房子与土木**：有无戊戌、戊申等高楼象，木土组合，丑辰，印或印库？
2. **看财库**：财是否在库？库被谁冲、刑、合？冲开则发。
3. **看官杀与制化**：制杀取财（巳申合、丑未冲等）成功，则可发大财。杀无制、劫财夺财、比肩分财则是先富后破。
4. **看出身**：原为官员的下海，多是伤官配印格被破、财库被引动，官位不久；打工起家的多是印库（辰）加伤官配印。
5. **对运**：印库、财库被冲开的大运发财；比肩劫财夺财、坏格的大运必破。

## 二、命例详解

### 例一　公务员下海做建筑商

**乾造**：丁戊甲乙／未申戌亥
大运：丁未 丙午 乙巳 甲辰 癸卯 壬寅 辛丑 庚子（1976 起运）

2008年案例，断以前在国家单位、至少处级干部，现下海经商，实际正是；命局不利六亲，父母已去世。

**做功与象**
- 甲戌日坐下伤官库，喜配印成格；命局申与亥包戌，形成**伤官配印**，所以可当官；唯不喜申亥相穿，申中印与亥中印不和，为官不久。
- 原局未戌刑开火库，而申金七杀被夹制，行巳运成制杀取财，所以后来下海赚钱。不喜时逢乙亥羊刃有劫争之意，易功败垂成。**戊申之象为高楼，所以搞建筑**。

**运年应期**
- 丙午运：前运未运刑坏戌，不利学业，没考上大学；午来合亥，伤官配印成功，利升职。丙寅（1986）参加工作：寅亥合，禄合印星。己巳（1989）、庚午（1990）婚期，引动戌土妻宫妻星；庚午（1990）提升：午亥合伤官配印。丙子（1996）升处级：子代表申，丙子组成食神配印；乙亥年虽午亥合，但劫财透天，别人升职，与己无关。
- 乙巳运：乙劫财羊刃，不利升职；巳合申制杀取财，可以发财。丁丑（1997）父癌去世：财星为父，未戌刑，时见羊刃克父；乙运应乙木克戊土。辛巳（2001）辞职下海做建筑工程：申为杀星主官方，工程有官方背景；巳申合制杀取财，发财数千万。
- 甲辰运：甲比肩夺财，辰运坏格，申辰拱杀星得助，为反局大运，继续做生意必破财。丁亥（2007）投资错误破财上千万：原局制申金杀取财，见亥则坏火、不能制杀，再加大运不好。戊子（2008）买地皮没成功：戊虚透被大运甲劫夺，子代表申被宾位的未穿，与己无关。

**婚姻**：戌为妻宫妻星，有申亥包局，婚姻稳定；三个孩子，头胎女，两个儿子。

### 例二　地产商

**乾造**：丁癸癸壬／未丑卯戌
大运：壬子 辛亥 庚戌 己酉 戊申 丁未 丙午 乙巳（1976 起运）

2001年案例，断发大财、搞地产，亥运起家，庚戌运发财至少几千万；断2007年有大投资，实为2008年投资几千万买地皮。

**做功与象**
- 坐下食神，**卯戌合了财库**，八字木土组合为地产之象。
- 年月丑未冲：**丑为印库，代表房子，未冲丑＝别人拿钱来购房**。命局木火燥土形成包局，又有印星参与做功，所以能发大财。时透壬水劫财，帮日主，放大财富。

**运年应期**
- 辛亥运：小时候行比劫运不爱读书，文化不高；亥运三合食神局，开始投资生意起家。
- 庚戌运：庚戌为印下落财库，财库被丑刑开，印生到自己，发财几千万。
- 己酉运：己代表未透天，己杀克日主，多不顺；酉运丑到，喜卯酉冲、酉戌穿，**房子很好卖**。
- 戊子（2008）投资几千万买地皮，手续至今未办完：子丑合印库＝购地，戊代表戌合癸，戌是财，财动为投资。己丑（2009）处处受阻：己土杀运不利，又见杀年克日主；庚寅（2010）五月预测时仍不顺破耗，需过己运方好。

**婚姻**：卯为妻，年时财包局，夫妻星宫都没有坏。

### 例三　地产、煤矿、酒店富翁

**乾造**：辛壬辛戊／丑辰未戌
大运：辛卯 庚寅 己丑 戊子 丁亥 丙戌 乙酉 甲申（1961 起运）

原在国家单位有官职，下海做地产及成品楼销售，开酒店，投资合股开煤矿，亿万富翁。

**做功与象**
- **辛未坐下财库，戌未刑开财库主发财——只要财在墓库之中，冲开、刑开都可以发财。**
- 原局还有辰戌冲，是伤官库制杀库，杀星制不干净而取财之意。年上丑土入辰墓，强化辰土力量，做功更大。
- 月令辰土印星代表单位，透伤官表示权力部门，墓丑土也表示权力。因时见戊戌克坏原局伤官，所以离职下海。
- 取象：**戊戌在门户表示地产建筑生意；未为酒店（自营店）；丑为煤矿，占比肩，代表合股**。

**运年应期**
- 戊子运：子代表辰被未穿，不想干工作；戊克壬权力受制约。己卯（1999）39岁辞职下海：卯代表未，破大运子，子代表辰，相当坏了辰土印星代表的工作；卯戌合引动戌土杀库，去求财。
- 丁亥运：丁代表戌中丁虚透，丁壬合伤官合杀，制杀取财；亥代表辰中水出，与未拱成财局，利财，但未土变软，不能冲丑，投资的煤矿受损。丁亥（2007）投资煤矿300多万；戊子（2008）发现无法收回，破财：丑为煤矿，落在比肩下受别人控制；丑入辰墓很难冲未，子年合丑穿未，破坏丑未之冲。
- 丙戌运：丙旺透官星，丙壬冲为伤官制官，制服的官星可合日主，吉；戌运刑开未土财库，也能发财。

**婚姻**：坐下财库刑开，婚姻没问题。

### 例四　数十亿的地产商

**乾造**：壬癸戊壬／寅卯午戌
大运：甲辰 乙巳 丙午 丁未 戊申 己酉 庚戌 辛亥（1966 起运）

读书不多，小时候像小混子，很早打拼，1988年起搞房地产开发，资产数十亿；喜虚的名誉，爱面子，身边多是高官。

**做功与象**
- 财星虚透情商高，也主好面子；**壬寅为杀星带财，主公门之人，三合局表示会处理政商关系，或官员给他带来财富**。
- 原局财官多而能生起主位的印星，**以午火印星代表自己的企业与财富**。印为房子，戌为高楼，又有木土组合，所以搞房地产开发。
- 时上戌为比肩，午生戌，戌被卯合，财富被他人劫夺之象，是**先富后破**的命。

**运年应期**
- 丙午运：原局印星到运，开始做房地产发财。戊辰（1988）投资房地产：辰戌冲，财库冲动印库。
- 丁未运：丁代表午火旺透，合壬为印星配财，放大财富；未运午未合刑戌，刑去比肩，独享财富，十年稳健发展。
- 戊申运：戊代表戌虚透合癸，贪合不起坏作用；申冲寅，流转加快，积累数十亿。
- 丁亥（2007）花钱买虚官，进入人大、政协：丁印坐财星，印虚透不是权力而是名誉。戊子（2008）投资不利，受金融危机影响：财星坐到比肩之下，子卯破。己丑（2009）破财不顺，小人破几笔财：劫财高透，丑午穿伤到自己。
- 己酉运预测可能破产：己是午印跑出变成劫财劫财；酉午相破，破了自己的印星，卯酉相冲伤官见官，官灾官司；再加原局戌土比肩归局，必破尽财产。

**婚姻**：不好但不离。壬寅、癸卯为双妻之象，壬寅为大老婆（生子），癸卯为二老婆（生女，包在局中，金屋藏娇；戊癸合为老少配，正官生女儿）。

### 例五　基础工程建设老板

**乾造**：甲庚甲丁／辰午寅卯
大运：辛未 壬申 癸酉 甲戌 乙亥 丙子 丁丑 戊寅（1964 起运）

江苏南通人，学历不高；早年家贫，聪明踏实，在南通二建打工十余年，后自立公司，发展很好。

**做功与象**
- 甲寅日见伤官火旺，木火伤官要配印，惜印星不显，藏于辰库；早年行运官杀与比劫相冲，伤官不能配印，所以读书不多。
- 但伤官聪明，比劫伤官好交朋友；行水运引通辰中水，形成**伤官配印**局，所以能发财。**辰为印库主建筑与房产**，所以是搞工程建筑的命。

**运年应期**
- 癸酉运：癸日主不喜，丁癸冲，伤官不能配印；酉合辰是有单位上班；卯酉冲，官杀不能制服为财，反冲羊刃，干体力活，不怎么赚钱。
- 甲戌运：得提拔，任建设部经理，与政府合作承建学校、镇政府、卫生院、商场等。甲戌自己坐食伤和财而来，寅午戌三合食伤局，才智得发挥；辰戌冲印库做功，印库在宾位，替单位赚钱；卯戌合代表做土木工程，也主自己得财。
- 乙亥运：乙劫财旺透不利，有庚合，为害不深；亥引出辰中水，午亥合形成伤官配印，寅亥合到自己，宾位的辰土财星带印与己相关，能发大财；辰在年为远方，会远方求财。
- 甲申（2004）到沈阳独立，开始艰难：七杀冲禄，卯申合给别人。乙酉（2005）官司：酉破午冲卯，乙庚合劫财与杀星合动官。丙戌（2006）起步：丙戌食伤坐财来三合伤官局，辰戌冲做功，承包几个项目。丁亥（2007）大起步，但工地事故死伤几人赔100多万：亥从辰库出成伤官配印，流年亥引动大运亥生助卯木，劫财发用，强化卯辰穿；卯为手足、工人，穿而有伤亡。戊子（2008）如日中天：财合印。己丑（2009）两年赚数亿，肺部手术：丑从辰出，甲己合到自己，寅丑暗合，明暗财皆合上身；丑午穿月令表身体病，穿有手术意思，丑为肿块，金主肺。庚寅（2010）在几个大城市同时开工，投资数十亿：庚寅杀虚名声远扬，寅亥合印主大工程。

**婚姻**：家贫，父母作主，与不喜欢的女人成家，感情一般，生一女。乙酉（2005）认识比他小十岁的甲寅（1974）年女子，前在大单位做会计，对他帮助大，离异带一女，后同居并生一女。辰为头妻，天干透甲比肩争，加卯辰穿，婚姻名存实亡，幸大运行水运代表辰，保持名义婚姻；午为第二个女人，带杀是离过婚的（带孩子），伤官表示比他小；大运亥合午，与此女同居。

## 三、其余四例要点

| 例 | 盘（干／支） | 要点 |
|---|---|---|
| 小型房产老板 | **乾造**：丁壬壬癸／酉子戌卯 | 原副处级公务员，1990后下海做房地产、开矿山、建筑公司，发财数千万；聪明、争强好胜、行动力强。壬戌坐财库又是杀，戌合是伤官合杀，制杀取财；年上丁酉印带财，戌穿酉是坐下杀星发用有权，但**卯戌贪合而忘穿**，后离职求财；**卯戌合为木土组合，代表地产建筑，戌也代表矿山**；伤官主聪明，时劫财行动力强。己酉运戌穿酉权力发用，在政府任职；戊申运戊虚透合劫财癸，不利财运，申长生宾位子水，无财，下海十年无成；丁未运丁财旺透丁壬合得财，未拱卯制杀、刑开戌财库，合伙发财数千万（丁财合到比肩，帮身合财取财；制杀的卯落劫财癸下＝合伙）。己丑（2009）矿山没搞成：壬怕见己，见官不顺，丑刑戌。丙午运差：丙财与壬冲破丁壬合，午破卯破卯戌合，午代表戌冲子，将己财冲到别人。婚姻两次：卯戌合，戌为头妻因合离开，卯为二妻因合进来，卯木伤官，找年龄很小的 |
| 销售转开发 | **乾造**：甲丁丁辛／寅卯卯丑 | 北大研究生，亿万富翁。丁喜甲木正印为高学历，双丁透学问高；辛丑时见财库＝取财，故离开单位下海；**印为房子，辛丑为财，用房子变财富，从事地产**。庚午运做楼盘销售：午代表寅，表示别人的房子，午穿丑＝替别人卖房，大赚。甲申（2004）承接楼盘销售，销空：甲申印坐财上，房子变现，申代表丑冲寅，房子被抢购。丙戌（2006）购三块地：丙劫财合财＝投资，戌刑开丑财库，丙卯合戌一寅拱戌。辛未运做开发资产数亿：**未是印库冲开财库，用房子换财富**，冲财库级别高。己丑（2009）官方手续麻烦：己合甲，印被合。壬申运比未运更旺财。己亥（2019）官司缠身，因大运好打赢。婚姻：辛丑为老婆，午运穿丑不能结婚，辛未运冲开财库会结婚 |
| 国企地产老总下海 | **乾造**：戊癸辛辛／戌亥卯卯 | 早年当兵，复原分配国家单位，国企房地产公司副总，副厅级。辛卯坐财，月令食伤生财，主位财重，喜卯戌合，**财星配印放大财富**；戊戌在年上为单位，戊癸合为伤官配印，戊戌制得伤官成为权力；**卯戌合为木土组合主房地产**。乙巳（1965）8岁父亡：随母改嫁的组合。壬戌（1982）成婚：卯戌合，财合印。甲子（1984）生子。丙寅运官运亨通，丁卯运升副厅级：寅亥合食伤化财，寅拱戌强化戌权力，透丙合身。癸未（2003）升副总：未刑戌引动权力。乙酉（2005）被架空、犯小人：卯酉冲坏卯戌合，酉戌穿太岁与戌不和，领导有意见。戊辰运离开国企：辰冲坏戌权力；但戊癸合伤官配印成立，辰代表亥到，与卯穿＝财星发用，能赚很多钱。丙戌（2006）辞国企到私企地产公司任工程总监。婚姻稳定：卯财为妻得位，合印 |

### 自测

1. 地产建筑命局的四类取象各是什么？
<details><summary>答案</summary>戊土高岗（戊戌、戊申、戊辰、戊午）；木土组合（卯戌、卯未、己未、甲己合、寅未）；钢筋水泥（丑中藏金、辰中藏乙）；印或印库代表房子。</details>
2. 为什么例三的财库被刑开会发财？
<details><summary>答案</summary>财在墓库之中，冲开、刑开都可以发财；辛未坐财库，戌未刑开，且有辰戌冲伤官库制杀库取财。</details>
3. 例一中官员为何会下海？
<details><summary>答案</summary>申亥相穿，申中印与亥中印不和，伤官配印为官不久；原局未戌刑开火库，行巳运成制杀取财，戊申又为高楼，故下海做建筑。</details>
4. 例二「丑未冲」为何代表房子好卖？
<details><summary>答案</summary>丑为印库代表房子，未冲丑为别人拿钱来购房子；酉运丑到，卯酉冲、酉戌穿，更是好卖。</details>
5. 例四为何是先富后破？
<details><summary>答案</summary>时上戌土比肩，午生戌，戌被卯合，财富被他人劫夺；己酉运午印变劫财、酉破午、卯酉冲伤官见官，破尽财产。</details>
