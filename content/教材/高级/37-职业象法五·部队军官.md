# 职业象法五：部队军官

> 军官的命局组合与公务员相似：都有印星、印库、官杀、杀库，官带财、印带财、印带官等参与做功，或为我所用。区别在于几个**特殊组合**：比劫羊刃（库）做功、寅戌为武库、申为军警与火金相克。本章先讲这些军队特有的象，再讲怎样看军衔与升迁应期，最后用五个命例展开。
> （原稿源自扫描件，个别字词经按上下文校订。）

## 一、军官的特殊组合

| 组合 | 象 |
|---|---|
| **比劫、羊刃、比劫羊刃库参与做功** | 比劫库有兵营、部队的意思；这种组合一般都是军警之类的官 |
| **寅、戌为武库** | 参与做功；戌本意是火药、枪支、炮弹（戌为火库，主军营） |
| **申为军警** | 出现**火金相克**的组合（如丁制辛、午制申） |
| **印星为权力** | 制印得权（财制印）；伤官配印、杀印相生 |

> 口诀：比劫羊刃库，兵营之象；寅戌为武库；申为军警，火金相克成军官。

## 二、军衔与升迁的判断

1. **官位高低**看包局：印包局、官杀包局、食伤包局，军衔较高；单纯伤食混杂，则官职不大。
2. **「制印得权」**：财制印是军官升职的最常见做功。大运流年只要**引动或强化财制印局**，就是升职的时机。
3. **过河拆桥**：过河拆桥之功，是用一个字冲穿掉别人的官或自己已用完的用神，让官位空出来留给自己；丑午穿穿去别人的官、子午冲、丑未冲，都能表示权力发用、提升。
4. **「贼捕结构」**：贼神（被制者）、捕神（制者）。制局中被制的神喜欢到位——辰为贼神，戊为捕神，辰到则制神有对象，升职。
5. 看**见戊土**：做功重要字，戊出现，或印到被制、印库出现、官杀出现被制化，就要升官。
6. **运岁的差别**：同一原局，印被穿、做功被破的大运，升迁停滞甚至变成闲职或转业。

## 三、判断步骤

1. 先找**武象**：比劫羊刃库、寅戌、申、火金相克。
2. 再找**权力**：印、官杀、杀库，谁制谁；制印得权的是军官最常见的做功。
3. 定**军衔级别**：看包局层数（一层功或两层功），有无杂乱。
4. 排**升职应期**：流年引动做功字（冲、穿、合开库）。
5. 看**转业、退休**：官星合入别人（比劫），印被破，做功被破，或运入「官非」。
6. 复核**婚姻与子女**：军官婚姻多不稳，注意夫妻宫、妻星是否被穿冲。

## 四、命例详解

### 例一：部队团长（乾造）

**乾造**：丁壬甲戊／未子寅辰
大运：辛亥 庚戌 己酉 戊申 丁未 丙午 乙巳 甲辰
（原稿时干「戌」按文中「戊辰」校为「戊」。）
部队带兵的军官。1987丁卯年当兵；己酉运1991辛未年提升排长；1992壬申调到机关；1993癸酉升副连；1996丙子升正连；1997丁丑换单位；戊申运1999己卯升副营；2002壬午升正营；2004甲申升副团；2008戊子升正团；预测2008年提升，应验；2010年又提升。预测丁未运提升师级。感情苦恼：1998、1999年结婚，2004甲申年闹离婚，2006丙戌离婚，2007年又找第二个，第二年分手。前妻生一女孩。

- **做功**：壬子印为权力，未来穿子，**财星制印，制印得权**，所以是当官的命。大运流年只要引动或强化财制印局，就是升职的时机。未为比劫羊刃库做功，比劫库有兵营、部队的意思，一般都是军警之类官。壬子与戊辰形成印包局，所以军衔较高。
- **当兵**：戌运刑开比劫羊刃库，丁卯年引动未库进军营，所以当兵。
- **升迁应期**：
  - 己酉运：官星酉带财帽，甲己合表示这个官与自己相关；辰酉合印库合官也是关联。1991辛未未到穿子，提升；1992壬申申子辰三合动印库，调到大地方（子在月令是大地方）；1993癸酉官印都到，升；1996丙子印到，又引动子未穿，升；1997丁丑丑未冲换地方。
  - 1999己卯：转大运流年，卯可以代表未到，甲己合自己合到流年，是提升应期。
  - 戊申运：戊能克制壬水印星为吉；申子辰三合印局强化印的力量，但不破坏未穿子的功，相当于权力更大。2002壬午或2003癸未制印提升；2004甲申自己坐杀得权，虽然岁运逢申冲寅禄，因局中有子化无事；2008戊子年提升再应子未穿，戊子自合。
  - 丁未运：丁未正应子未之穿，继续升职，官至师级。
- **婚姻**：寅入未墓，丁未为妻子，因子未穿所以要离婚；戊辰是第二个妻子，戊申运戊坐申冲禄，也要分手；丁未运如果结婚还要离婚，到丙午运午到与夫妻宫相合才能稳定。

> 学点：**军官升迁的核心节奏就是「制印得权」被流年一次次引动**；婚姻则因为同一个「穿」，成了代价。

### 例二：副军级干部（乾造）

**乾造**：戊癸乙己／戌亥巳卯
大运：甲子 乙丑 丙寅 丁卯 戊辰 己巳 庚午 辛未
军队升至副军级。

- **做功**：木火伤官喜配印；巳火与戌一家，形成对癸亥的包围，通过**财星制印而得权**。时上卯来控制戌土，加码做功的层级——卯控制戌一层功，戊戌控制癸亥又一层功（两层功，级别高）。命局见戌为火库，戌土本意是火药、枪支、炮弹，所以是部队军官。
- **应期**：
  - 乙丑运：自己坐着官杀库来，开始升职。丙辰1976年当兵，辰为马星，辰到代表亥；戊午1978年升排长，戊癸合、亥午合，天地合到印；庚申1980年升连长，乙庚合自己合官，巳申合食伤制官。
  - 丙寅运：丙生戊，寅拱戌，强化原局戊戌的力量，吉运。戊辰1988年升副营（戊合癸印，戊坐印库而来见印就升，制印得权的应期）；庚午1990年升正营（乙庚合官合身，亥午合食伤合印）。
  - 丁卯运：丁到代表戌到，卯戌合应原局的做功。壬申1992年升副团（丁壬合，食神合印星，巳申合食伤合制官杀）；庚辰2000年升正团（官坐印库，乙庚合官合上身）。
  - 戊辰运：大好运，**辰代表亥，形成贼捕结构，戊为捕神，辰为贼神**，制局中被制的神喜欢到位。壬午2002年升副师（壬午自合食伤合印，壬到亥到，亥午合）；甲申2004年升正师（甲申年劫财坐杀是别人的官但有甲己合，又卯申合，说明别人调走，自己升官，无己卯就不行）；戊子2008年升副军（财合制印星；见到戊土出现或印到被制，或印库出现，或官杀出现被制化，就要升官）。
  - 己巳运：差一些。原局依赖戊癸合，见己则无用，升职困难。
- **婚姻**：坐下巳火为老婆，有包局的象，巳透戊坐戌是一个人的象，婚姻稳固。一儿一女皆成材。

### 例三：部队副参谋长（乾造）

**乾造**：丁辛己甲／未亥卯戌
大运：庚戌 己酉 戊申 丁未 丙午 乙巳 甲辰 癸卯
部队某部副参谋长。高中毕业，没考上大学，1985乙丑年当兵；戊申运1992壬申提班长并成婚；1993癸酉提排长；1994甲戌生女孩；丁未运1997丁丑提连长；1999己卯提正营正科；2002壬午破财不顺，妻子出车祸；2005乙酉提副处；2007丁亥自己放弃提正处；丙午运2008戊子外调提正处；2009己丑提副参谋长；2011辛卯预测提副厅，应验。

- **做功**：坐支卯木七杀，需要有功才当权力看。初看亥卯未三合杀局，但细看功在于**包局**：卯未一家包亥，形成阳制阴局，丁来制辛，卯戌合，戌与未来克亥，代表自己的权力控制财星亥水与食神辛金。命局中戌为军队，未戌为比劫星，所以是军官。
- **运岁**：
  - 己酉运：酉冲动杀，酉为马星；乙丑1985年当兵（丑到酉到，卯酉冲，丑未冲到年上远方，丑为马星到）。因酉穿戌，考学不利。
  - 戊申运：卯申合伤官合杀，也表示升职；壬申提班长并成婚（食伤到合杀，丁壬合印动了印星）；癸酉卯酉冲杀星发用，癸酉相当于原局辛亥到位，升排长。
  - 丁未运：原局丁未到位做功，升得快；丁丑（丑代表辛，丁制辛）升连长；己卯1999自己坐杀到，提正营；壬午2002壬到亥到，亥坐午与原局卯破，杀破禄，因妻破财；乙酉2005乙代表未与卯，卯酉冲杀星发用，提副处。
  - 丙午运：旺丙合辛，印制食神为功；因坐支杀星卯强，卯破午发用，权力发威。戊子2008戊子自合，子未穿，未代表权力发用；己丑2009丑未冲权力发用；辛卯2011预测提副厅。
  - 乙巳运：乙木代表卯虚透天干，权力虚而无用；巳亥冲不利亥卯之合，差运，可能变成闲职。
- **六亲**：正官亥水为女儿，水怕卯中伤，又宫位戌土来克，一个女孩八岁早夭，后抱养一女；妻子因生孩子意外切除子宫，不再生育，宫星稳定，婚姻好。

### 例四：师级军官（乾造）

**乾造**：甲壬癸甲／午申卯寅
大运：癸酉 甲戌 乙亥 丙子 丁丑 戊寅 己卯 庚辰
高中毕业，军官至师级。1974甲寅年结婚后当兵；1978戊午升排长；1979己未升副连；1980庚申升正连；1985乙丑升副营；1987丁卯升正营；1991辛未换地方到部队机关，升副团；1993癸酉升正团；1994甲戌两个部队合并，权力范围扩大；1995乙亥、1996丙子工作不顺犯小人；1998戊寅升副师；1999己卯升正师（原是核心部门副师，此年调下属单位当正师，帮助他的领导被调走，后台没了，心情不好）；2004甲申任小单位一把手；2005乙酉、2006丙戌被同事使坏犯小人；2008戊子不会再升职，给一个荣誉。

- **格局**：水木伤官成势，癸以见甲为贵，见壬水为帮；月令印星为单位，卯申合、寅申冲为**伤官配印**成格。申金盖头劫财，再加之申有军队的象，所以是军官。命局见伤官包印局，所以格局较大。
- **运岁节奏**：
  - 甲戌运：甲运得贵，入公门；戌运三合火局，中神在宾位，没有实权，辅佐别人之意。1974甲寅年三合火局见食伤到位当兵，流年三合财星成婚。
  - 乙亥运：乙透混伤官为杂不宜；亥运申亥穿不利升职，喜亥卯合、午亥合得官之意；提升缓慢。乙丑1985丑到申到，丑午穿穿去别人的官，**过河拆桥**。
  - 丙子运：丙壬交辉吉，子运子卯相破，食神破禄不利，食神是心情，主心情不好犯小人；喜子午相冲的功，过河拆桥。辛未1991丙辛合，午未合到年上，换了单位；癸酉1993癸酉自己坐印星，午酉破，过河拆桥，升正团；乙亥1995申亥穿，流年不利；丙子1996子卯破禄，犯小人。
  - 己卯1999：甲己合、卯申合，伤官合杀与食神合印是升职应期，但子运子卯相破，破主位食神，心情不好；卯午相破，午是帮助自己的贵人，被调走，后台没了。
  - 丁丑运：丁代表午火虚透合壬，劫财发用，利别人不利自己；丑代表申到，丑午穿过河拆桥利升职。
  - 2008戊子：子卯破，禄食神互破，不升职无实权，但天干戊癸合，有虚的荣誉。
- **婚姻**：卯为妻，满盘木多现但不会多婚，因为食伤包局把夫妻星包在夫妻宫里。

### 例五：部队正师级干部（乾造）

**乾造**：丁庚丙庚／酉戌辰子
大运：己酉 戊申 丁未 丙午 乙巳 甲辰 癸卯 壬寅
（经校正时辰确定为夜子时。）
高中学历，部队正师级干部；个头不高，白净清秀，文质彬彬，很难看出是部队的官。

- **做功**：丙辰日坐支杀库，**辰戌冲为功，制比劫库**，戌为火库主军营，比劫库也为军营，所以是军官。还有一层功：丁制酉，戌穿酉，被制的比劫库再制酉金财星，提升了命局的级别。辰为杀库为权力中心，故能掌握实权。财旺又早年行财运，不利求学；财星虚透有才华，文笔、讲话水平很高。
- **运岁**：
  - 戊申运：平运，财旺又行财运，家境一般；原局无印，学历不高。申运泄辰土食神转为官星，不利考学，可入公门。乙卯1975年当兵（卯酉冲动年支去远方，卯戌合引动戌土）。
  - 丁未运：利升官，丁代表原局的丁到可做功；未穿子，**过河拆桥**。戊午1978升排长（午到戌到，午合未引动大运）；庚申1980升正排（申子辰合水局加强官杀）；壬戌1982成婚，癸亥1983生女；甲子1984升副连（行未运见子年，子未穿的应期）。
  - 丙午运：自坐羊刃劫财做功，羊刃到位做功本身就是掌握军权的象。戊辰1988升正连，辰到，辰戌冲权力发用；壬申1992升副团（天干羊刃合杀，地支申引动辰）；乙亥1995升正团（乙庚合，亥到代表辰到，官杀发用；如果乙亥不升，丙子年必升，子年表示辰到，子午冲大运发用）。
  - 乙巳运：喜乙不喜巳。乙庚合财星合印利名利官；巳代表戌，原局戌穿酉，伤了妻星，克妻，自己还得心脑方面疾病。庚辰2000升副师；辛巳2001妻得病去世；甲申2004升正师并再婚（申到引动辰，辰既是权力又是第二任妻子）。
  - 甲辰运：印星坐官杀库，利开职大运，预测升到正军级。
- **婚姻**：酉为头妻，被戌穿，又被羊刃丁克伤，中途断弦；辰为第二任妻子，临食神年龄偏小，合官星也会生孩子，第二次婚姻没有问题。

| 退休正师参谋长 | 庚癸己丁／寅未巳卯 | 坐下巳火印星，卯未包局巳火，形成权力中心，贵在巳来穿寅，权力发用；寅见墓于未是比劫，寅代表部队；己酉年寅巳穿腿被枪伤（寅为腿，日主己巳为身体）；己丑运拱日弱化权力，在此运退休 |

## 六、本章小结

| 要点 | 内容 |
|---|---|
| 军官特殊象 | 比劫羊刃库=兵营；寅戌=武库（戌=火药枪炮）；申=军警；火金相克 |
| 核心做功 | 财制印得权；伤官配印；包局层数决定军衔 |
| 过河拆桥 | 冲穿掉别人的官或已用完的神，官位留给自己 |
| 贼捕结构 | 辰为贼神、戊为捕神，被制者到位则升 |
| 应期 | 引动做功字：冲、穿、合开库；戊出现、印到被制是升官的标志 |
| 代价 | 做功用的是「穿」「冲」，多与妻星婚姻宫相关，军官婚姻多波折 |
| 凶运 | 做功被破、官星合给比劫、印被穿 → 闲职或转业；火金无制 → 牢狱 |
