# 职业象法四：公务员

> 公务员的命，核心是**官印的位置与做功**。本章先讲公务员命的几种基本组合、官位大小的判断，再讲执法、财税等部门的象，最后用五个命例演示职务、调动、提升的应期。
> （原稿源自扫描件，个别字词经按上下文校订。）

## 一、公务员命的基本组合

1. **年月的印星、印库、官杀、杀库**，加上**官带财、印带财、印带官**，都代表公家单位。财则表示工资，并且和主位发生了关系，为我日主所用。
2. 这里的官、印俱为日主所喜（指在做功中被用到、被合到主位）；官印为忌、与主位不发生关系，则与公门无缘。
3. 十二地支**寅与甲**代表公门，寅与甲在命局中占重要地位。
4. **伤官配印入格**，也是公务员命的常见结构。

## 二、官位大小怎么看

| 看点 | 判断 |
|---|---|
| 官星是否被制服后合到主位 | 官杀有制，合身为我管理控制；无制而合身，则自己合一个毛病上身，一生灾祸连连 |
| 印在年上远隔 | 用之不得力，没什么权力 |
| 伤食混杂、不见官杀 | 官职不大 |
| 财透生官、官制不好、运又走财生旺官 | 官职升不高 |
| 食伤包局、子辰一家包局 | 权力较大 |
| 忌神（乙为忌）常犯小人 | 受领导压力，职务不高 |
| 官杀库在坐下，被冲动 | 坐下官杀发用，有权力 |
| 合到的是「别人的官」（比劫、劫财） | 官是别人的，只能当副手；若合到自己则升官 |

## 三、不同部门的象

| 部门 | 象与结构 |
|---|---|
| 财政、税务 | 年上财星制印；官杀印库带财；甲辰活木为公家的财；甲戌死木见火多为家具装修；木火伤官而丑为钱财，管理财政税务（例五）；财库在年上=管理国家钱（例三） |
| 执法、纪检、公安检察 | **食伤制杀局**大多在执法部门；**阳制阴局**：辰丑为阴为牢狱，甲丁为阳为光明正义，多为公安、检察院、纪检（例五） |
| 权力部门、市委办、组织部 | 伤官配印，寅（公门）与未包局，财制印得权（例二） |
| 乡党委 | 双寅穿巳，寅发用，杀带财帽合印（见「其余」） |

## 四、判断步骤

1. 找**公门**：年月印星、印库、官杀库、寅、甲；有无官印被合到主位。
2. 找**做功**：谁制谁？伤官配印？财制印？杀印相合？官有无制？
3. 判**职务大小**：有无杂财、伤食混杂、忌神透出、印是否远隔、官杀是否被制。
4. 判**部门**：财税（财制印）、纪检执法（食伤制杀、阳制阴）、权力部门（寅未包局）。
5. 排**应期**：参加工作（合动官印或当兵入公门）、提升（官星/印库被冲穿合开）、调动（冲/穿）、退休或丢官（官印被破、印不生）。
6. 复核**婚姻与六亲**。

## 五、命例详解

### 例一：处级公务员（乾造）

**乾造**：甲乙戊甲／辰亥子寅
大运：丙子 丁丑 戊寅 己卯 庚辰 辛巳 壬午 癸未
1982壬戌年当兵，1984甲子参加工作，1986丙寅年成婚，1994甲戌年父亲去世，1995乙亥年在政府财政部门工作，逐步升到处级；负责政府土地、楼房、厂房出租出售。命犯小人，做事不顺。2008年经济危机单位欠银行上千万贷款。

- **做功**：戊日主喜生甲寅时，财星转化为杀星，杀为更大级别的财富。甲木在年控制辰土为功，亥子又入墓于辰，甲木成了他的权力，落在宾位，**是管理公家的钱**。月令乙亥，戊以乙为忌，常犯小人或领导压力，所以职务不太高。乙木为忌，不利学业。
- **大运**：戊寅运自坐寅，寅为公门，通过当兵入公门；己运劫财不利；卯运卯辰穿，升职掌权；庚辰运食神合官坐财库，官逢合不为害，是好运；辛运后不利，辛不能制乙反有激惹，搞不好丢官罢职。2009己丑年劫财，甲己合资金周转很费劲，2010庚寅有转机。
- **婚姻**：子财正位为老婆，夫妻宫星安静，不会离婚；月令偏财为别的女人，入比劫之墓，墓库不开主桃花多；亥上见乙，乙为孩子，乙为忌，所以那个女人与孩子与他无缘。
- **六亲**：月令财星墓于年上库不开，「财临墓地父当早亡」，1994甲戌年冲辰开墓为应期。

### 例二：科级官员（乾造）

**乾造**：甲丙乙癸／寅子酉未
大运：丁丑 戊寅 己卯 庚辰 辛巳 壬午 癸未 甲申
（原先报申时，很多事对不上，申时不可能是公务员；改为未时，符合公务员命格。）
本科，原在市委，后调组织部副科级；行寅运2000庚辰年提升，2001辛巳年给市长当秘书，2004甲申年提半级到市委办。口才好、文笔好、才华高，但脾气不好、心高气傲。1998戊寅年处对象，己卯年成婚。己卯运时专业搞股票。2006丙戌年身体不好，2007丁亥年破财，2008戊子年犯小人生病，2009己丑年想升官没升成。

- **做功**：月令伤官配印有才华，喜子未相穿，财制印做功。年上寅与未形成包局，**寅主公门，未与寅同象表示权力**，又制印得权，所以是权力部门的官员。不喜伤官透天无制为病，所以官职不大。
- **比劫伤官的投机性**：八字是比劫伤官，喜欢搞投机。己卯运是禄带财虚透，甲己合是表示投机，财星虚浮没有大财。
- **应期**：庚辰年乙庚合官，辰到表示子到，提升；甲申年申到长生子水印星，提升；2006丙戌伤官坐财合动卯、穿酉、刑未，坏局，身体不好；丁亥进卯运，亥卯未合比肩局，破财；2008戊子子卯相破破印星，生病犯小人；2009己丑想升官花钱送礼，但卯运是不好的大运，徒劳无功。

### 例三：税务局官员（乾造）

**乾造**：癸甲辛壬／丑子丑辰
大运：癸亥 壬戌 辛酉 庚申 己未 戊午 丁巳 丙辰
本科，戌运参加工作，县税务局科级干部。2002壬午年工作调整，2006丙戌年变动工作提升。1995乙亥年成婚，2003癸未年生男孩，1992壬申年母亲去世。

- **做功**：公务员的命需要官星或印星做功。此造坐下丑土印星，这个印星有功才能当官。生壬辰时，印星入墓，丑、子俱入辰墓，**入墓本身就是做功，丑变辰还有放大的意思**。辰为伤官库，壬辰伤官配印为权力之意；月上正财表示工资。原局无官星，阴重而无阳、合多安静，往往需要阳的年份冲之，可以提升调动。伤食混杂又不见官杀，官职不大。
- **大运**：
  - 辛酉运：印禄相随，无论男女只要见禄有印生，运气不差，不辛苦劳累，工作稳定；酉禄合到辰土印星，有官职。
  - 2002壬午年：子午冲动，壬午自合，伤官制官，调动。2006丙戌年：丙辛合官来合身，辰戌冲动印星，提升。
  - 庚申运：庚运庚甲冲没问题（本局中甲没有功用）；申运申子辰三合水局，消解辰土，辰不能墓丑土做功，不仅不升职，可能降职。
  - 己未运离开公职求财：甲己合，子未穿，丑未冲破坏丑入辰墓的关系；甲己合坐在未土财库上要投资，丑未冲开财库是求财。
- **婚姻**：甲子是老婆，子丑合到夫妻宫，因两丑合子，需要戌运刑开合才成婚；甲戌年处对象，乙亥年（亥到表示甲到）成婚。
- **母亲**：以子水为母，年日合了两个丑墓，「墓夹」为凶，母亲早逝；壬申年申引动两丑为应期。

### 例四：地税局局长（乾造）

**乾造**：甲丁戊甲／辰卯寅子
大运：戊辰 己巳 庚午 辛未 壬申 癸酉 甲戌 乙亥
大专后补本科，1983癸亥年参加工作；1988戊辰年副所长，1990庚午年正所长，1994甲戌年副科，1999己卯年换地方提升正科，2005乙酉年转壬申运提升副处，预测2010平调（对），2012壬辰年还有一次提升机会，到此为止。

- **做功**：戊日坐七杀，月上见官；戊喜寅木七杀，不喜卯木正官，但卯上有丁透，印化杀生身。更重要的是**卯辰穿，卯木发用为功，表示权力**。年上甲杀坐辰财库，甲是主位寅木所透，所以年支的财库是自己权力控制的财富，在宾位不是自己的钱，代表管理国家钱。寅与甲主公门。子辰一家形成包局，权力较大。
- **运岁**：
  - 庚午运：食伤坐印星，午拱寅，午代表寅冲子，印冲财做功，权力发用。1988戊辰年辰土到位引动子财与印相冲，提升；1990庚午年印到又应子午相冲，再提升；1994甲戌年寅午戌三合印局冲动子水财星，又升。
  - 辛未运：未代表寅卯，将权力集中在未，未穿子为功；1999己卯是卯辰穿的应期，换地方；甲己合劫财合杀也主提升，**甲多不怕合，只有一位就不喜合了**。
  - 壬申运：丁壬合财权力扩大；申子辰三合水局，官的财富更大；寅申冲是权力发用。乙酉年辰酉合引动辰，卯酉冲引动酉，引动卯辰穿发用，提升；庚寅年冲大运申，动工作；壬辰年丁壬合还有一次提升机会。
  - 癸酉运差：戊癸合不利，酉冲卯伤官见官，麻烦不断，容易丢官。

### 例五：执法单位的公务员（乾造）

**乾造**：甲丁壬辛／辰丑午丑
大运：戊寅 己卯 庚辰 辛巳 壬午 癸未 甲申 乙酉
大学毕业，国家执法单位。1988戊辰年走庚辰运在建设银行10年；1997丁丑年调到计生委，当年提升副科；2001辛巳提升正科，当纪检委书记；2003癸未提升副处；行壬午运2006丙戌年换单位仍在纪检；2010庚寅年阴历六月（小暑后）调动，调到政府机关；2014甲午挂职常务副县长；2017年1月调回市里任正处局长。婚姻稳定，一男孩。

- **做功**：壬日坐下正财含正官；地支丑辰群阴包一阳，两丑夹穿午火，夹穿穿不坏午火，反显示独阳之贵。年月甲丁透天，丁壬合，**阳制阴局**：甲控制辰，丁控制丑。食伤制杀主权，丁火控制印库也主权。甲代表公门。时上辛丑不能制服，所以官职不算大。
- **为何是纪检执法**：食伤制杀局大多数都在执法部门；阳制阴局，辰丑为阴为牢狱，甲丁为阳为光明、正义，多数为公安、检察院或纪检部门。
- **运岁**：
  - 庚辰运：以前在银行，丑土金库入辰墓为功；庚甲相冲克，甲木不能发挥作用，没什么权力。
  - 辛巳运：辛代表丑虚透大运，得到丁火制服，丁火发用，有官职。1997丁丑调动并升副科；2001辛巳岁运相并，丁克辛的应期，升正科；2003癸未午未相合加强坐支官星，升副处；癸未透劫财本是别人的官，如别人的官能合到自己，就是自己升官；丁癸相冲一方面表示自己动位置，一方面表示别人被冲走，官位留给自己。
  - 壬午运：吉运，自己坐在官到位的运。2006丙戌丙辛合，辰戌冲动杀库，主调动；庚寅年寅长生支官，庚冲动甲，甲木发用，调动；甲午年午到再调动。
  - 癸未运：癸未是劫财坐在官上，丁癸相冲冲去癸，癸下未合午，自己得权；丙申年末升正处实职，丙辛合为应期。

## 七、本章小结

| 要点 | 内容 |
|---|---|
| 公务员基本组合 | 年月印、印库、官杀、杀库，官带财、印带财；寅、甲为公门；伤官配印入格 |
| 官位大小 | 官有制则合身为我管；杂财、伤食混杂、印远隔、忌神透出则官小；包局则权大 |
| 部门 | 财税：财制印；执法纪检：食伤制杀、阳制阴；权力部门：寅与未包局，财制印 |

### 自测

1. 官杀无制而合身，为什么是凶象？
2. 食伤制杀局为何多在执法部门？
3. 官被「别人的官合来」和「合到自己」，在提升判断上有什么区别？
4. 印在年上远隔，对权力有什么影响？

<details><summary>答案</summary>

1. 官杀未被制服，等于把一个毛病合到身上，一生灾祸不断。
2. 食伤制杀是以我制官杀，对应执法管人的权力；阳制阴更是正义对牢狱之象。
3. 合到别人官（比劫）只能当副手或为人作嫁；若能合到自己（如癸合到自己官位、冲去别人），则是自己得官升职。
4. 远隔则用之不得力，没什么权力。
</details>
