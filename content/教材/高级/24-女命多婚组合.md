# 女命多婚组合

> 女命以官杀为夫星、日支为夫宫。多婚的结构与男命相对，但女命有两个特殊的关键概念：**比劫争夫**与**关财门**（财为官之原神，财被劫克、被冲则官无源）。

## 一、女命多婚的组合

1. **夫宫多现又配夫星**，形成婚姻组合，而夫宫本身不稳——容易多婚。
2. 夫宫虽不多现，但**夫宫被坏**（合坏、刑坏、穿坏）——一婚不到头。
3. 夫宫没坏，但**夫星被坏**，又有新的夫星出现——容易多婚。
4. **夫星多合**，合一次加一个；或因合而离开。
5. **比劫争夫**：夫星被比劫包、被比肩合走，丈夫必有外遇；此时夫星与宫的联系再好，初婚亦离。
6. **关财门**：财是官杀之原神，财星被冲坏、被劫克，称关财门，必多婚。

### 常用诀

> 口诀：一星两宫、双宫双星，两次婚姻（第一次没合到位）。若辰在日时伏吟，则不表示二婚。
> 口诀：星宫之间被穿、被破，则夫星不能相生，离婚；两穿需离两次，破一次，共三婚，第三次婚姻才好（刑的能量耗尽）。

## 二、典型命例

### 1. 夫星被穿、被争

**坤造**：丙辛辛癸／午丑卯巳
大运：庚子 己亥 戊戌 丁酉 丙申 乙未 甲午 癸巳（7岁起运）
夫星为年柱丙午，月干透辛合夫星，为比肩争夫，丈夫必有外遇。夫宫未坏，但宫星关系出了问题：宫卯破午，更不好的是丑午穿，夫星被穿倒，夫宫卯木更不能生午火，必离婚。第二次婚姻看时支巳火，有卯木相生而无伤克，第二次才过得好。实际此女与夫早已分居，乙酉年离异，甲申年认识新男友。应乙酉年，卯木财星被大运流年冲坏，为关财门。

**坤造**：己庚甲戊／酉午戌辰
大运：辛未 壬申 癸酉 甲戌 乙亥 丙子 丁丑 戊寅
很漂亮的女企业家，典型多婚命。夫宫戌土穿夫星酉金。酉为第一个丈夫，已离婚（酉运戊寅或己卯年）；第二个是月干庚金，庚杀虚透为短暂婚姻，甲申年出现，庚与日主甲木相冲，丙戌年离异；第三个是坐支戌土，得位又能做功，是真正的丈夫，白头偕老。

**坤造**：丙丙辛庚／午申酉寅
大运：乙未 甲午 癸巳 壬辰 辛卯 庚寅 己丑 戊子
富女，地委书记的女儿。夫宫见禄，夫星为年上丙午，月令见劫财申，申上又盖丙，说明老公被别人抢了；夫宫见禄又表示现在一个人过。第二个老公寅木出现时间比较晚。乙亥年30岁离婚，是男人跟别的女人跑了，现单身。壬辰运禄合印单身；辛卯运为桃花运才有婚姻。双丙是一个人。寅财被制为关财门，必多婚。

**坤造**：壬癸壬辛／子丑寅亥
大运：壬子 辛亥 庚戌 己酉 戊申 丁未 丙午 乙巳（5岁起运）
以丑土官星为夫，寅丑暗合，本属好婚姻。但年月比劫众多，为比劫争夫；年月子丑合的力量大于寅丑合，故必离。果26岁丁丑年离婚；戌运刑坏丑土也必离。第二夫以寅中丙火看，寅亥合，另嫁远方。

**坤造**：丁壬丙己／巳子午亥
大运：癸丑 甲寅 乙卯 丙辰 丁巳 戊午 己未 庚申
双宫双星。夫宫坐刃，夫星壬子被众比争，命局壬子与亥两个夫星；比劫争夫，初婚必离。第一个男人同居多年，结婚照都拍了没结成，分手；丁亥年与韩国对象结婚，丁到亥到之应。（同类盘丁壬丙己／未子午亥，双宫双星，也是第一次婚姻离异。）

### 2. 宫星双现、夫宫入墓

**坤造**：丙壬甲甲／申辰辰戌
大运：辛卯 庚寅 己丑 戊子 丁亥 丙戌 乙酉 甲申
以辰土为夫宫，申金为夫星，相拱合，本属好婚姻；但命中两辰，夫宫两现，一星两宫会有两次婚姻，等于第一次没合到位，所以二婚。若辰在日时伏吟，则不表示二婚。第一次婚姻离异，第二次很好。

**坤造**：甲乙戊己／寅亥午未
大运：甲戌 癸酉 壬申 辛未 庚午 己巳 戊辰 丁卯
夫宫合入夫星之墓，夫不死则离，把婚姻埋了。甲寅为第一夫，乙亥为第二夫。申运壬午年第一次离婚；辛运乙酉年第二次结婚，官杀多应伤官年结婚；第二次也不长久，亥还有他合之象，夫有外遇。

**坤造**：戊庚辛甲／申申亥午
老师，多婚命。大运：己未 戊午 丁巳 丙辰 乙卯 甲寅 癸丑 壬子
午火是夫，但大运行巳运冲入夫宫，头夫不看午而看巳运。丁巳运辛未年结婚；丙辰运亥入辰墓，男的常年不在家，夫妻关系无法维持。断戊子年，最晚己丑年离。占果：丁亥年末丈夫主动提出，戊子年办完手续。还会有第二次婚姻，当找午为夫，推甲午年结婚。戊申、庚申算一个人；巳申合，男的有女友，成婚后未断。

**坤造**：己乙癸壬／未亥卯戌
大运：丙子 丁丑 戊寅 己卯 庚辰 辛巳 壬午 癸未
己未是第一个丈夫，辛巳或壬午年结婚。断丁亥年夫有外遇，会离：果29岁丁亥年离。戊子年自己因官坐禄又自合，有桃花，连到己丑年。同前夫生一女，卯运合戌第二次婚姻。

**坤造**：戊丙壬丙／申辰子午
记者，多婚命。大运：乙卯 甲寅 癸丑 壬子 辛亥 庚戌 己酉 戊申（2岁起运）
戊申是男友，以辰为夫，戊丙辰连在一起为一个人。辰是官又是比劫库，所以花心。辰拱比劫，争夫之象。财为官之原神，财星弱，财一旦受劫克关财门，必离。丑运必离。断26岁癸酉年结婚，丙子或丁丑年离；如不离，拖到04年必离。实际丁丑年闹得很厉害，04年正月离。又断壬午年遇一个男友追得紧、很有感情（对）；男人从事跟她相似的工作，像做电视媒体（对，摄影的）；人家有婚姻，没有婚缘（对）。午中有己，未来的婚姻当在辛亥运中。

### 3. 星被合、宫被穿的离与再婚

**坤造**：丙庚丁辛／午子卯亥
大运：己亥 戊戌 丁酉 丙申 乙未 甲午 癸巳 壬辰（9岁起运）
段师的同学。庚子为第一夫，与夫宫相破，被比劫争夺，星宫相破，又关财门，必离。辛亥为第二夫，拱合到夫宫，第二次婚姻好。戌运壬申年结婚（丁壬合，卯申合之应），酉运癸未年离婚（杀星虚透被穿）。后去日本，丁亥年找到第二个老公，幸福。

**坤造**：壬癸乙丙／戌丑巳戌
大运：壬子 辛亥 庚戌 己酉 戊申 丁未 丙午 乙巳（4岁起运）
丈夫为赌徒。巳火为夫宫，戌为巳墓为第一个丈夫；巳入戌墓也为丈夫。巳拱丑，丑为第二个丈夫。丙戌年同居，戊子年结婚，发现丈夫赌输几十万，己丑年春离异；庚寅年找第二个丈夫结婚。戌加巳，阳包阴，阳制阴，赌徒之象；丑财为阴暗之财。

**坤造**：癸甲己乙／卯子酉丑
大运：乙丑 丙寅 丁卯 戊辰 己巳 庚午 辛未 壬申
夫宫是酉。卯酉冲是一种关联，故卯为丈夫，原局子卯相破，第一个必离；甲己合，甲子又为丈夫，是一个人。丁卯年25岁第一婚，于壬申年结束（申为子的长生之应）。假如生在辛未时不离婚，卯时也离婚。戊运关财门，没婚姻；乙财虚透不长久。辰为官之退气，找离婚的也不长久。庚辰年同居没领证，己运丙戌年分开，丁亥年甲长生又找一个，也不长久。

**坤造**：戊甲乙乙／申子亥酉
大运：癸亥 壬戌 辛酉 庚申 己未 戊午 丁巳 丙辰
亥子双宫，申酉双星，两婚组合。夫有外遇，因申官生甲子透了劫财。现在还没离，断申运一过必离，应乙未年。

**乾造**：丁壬乙丙／未寅卯戌
大运：辛丑 庚子 己亥 戊戌 丁酉 丙申 乙未 甲午
（上例之夫）也是寅卯两宫，双宫双星。未为第一妻，戌为第二妻。戊戌运，戊代表戌到，有了外遇；戌刑未，新的要取代旧的；到丁酉运坏掉妻宫，丙申年冲破宫位必离。

**坤造**：甲丁丙癸／寅丑子巳
大运：丙子 乙亥 甲戌 癸酉 壬申 辛未 庚午 己巳
主位的正官不喜他合，一合婚姻就坏。23岁丙子年结婚，丁丑年离异（丑上带丁，男人外边有别人）；后再无婚姻。甲申年有男友，因巳禄被申财逢合之故。时上癸巳，禄上坐杀自合有桃花。

**坤造**：乙己己丙／未丑丑寅
三婚命。大运：庚寅 辛卯 壬辰 癸巳 甲午 乙未 丙申 丁酉
双宫双星，两夫宫丑，见乙未官星，丑未冲，未冲两丑，两婚；再见时上寅丑合，三婚命。甲午运婚姻必离，算到己卯年，结果那年丈夫病故（午运合未而穿丑，夫星与宫的关联破坏）。癸未年找了一个，时间不长；癸巳运中己巳与甲戌年也是婚姻不好流年，闹得很厉害。第三次婚姻要换乙未运。

**坤造**：甲戊壬癸／寅辰辰卯
大运：丁卯 丙寅 乙丑 甲子 癸亥 壬戌 辛酉 庚申
以辰土为夫，夫星中墓有比劫，戊癸又合，丈夫的情人会公开化。卯辰穿，伤官穿之，必离婚。乙运庚辰年离婚（乙为阴伤官，克夫之运，庚辰年夫星到位而离）；丑运乙酉年找男友，处三年（丑入于辰墓，酉年为应期）。双宫双星，卯辰为食伤穿了宫星，必离；但没有卯时则不离，只是夫有外遇。甲子运不能接婚。

**坤造**：癸己癸乙／卯未丑卯
大运：庚申 辛酉 壬戌 癸亥 甲子 乙丑 丙寅 丁卯
未丑两夫星，己未为丈夫，二婚为丑土，丑未冲，未为夫宫关联，表示丈夫。行戌运，丑未戌三刑坏了宫星之冲，主离婚；如不行戌运，婚姻没问题，因戌坏了丑未冲，冲不成立。己卯、庚辰年离婚（己虚透，卯戌合引运戌；辰能坏丑未之冲）。癸运癸未年再婚。可以劝不要离。

**坤造**：辛甲丁庚／丑午酉戌
原局无官，以财星当丈夫。穿倒夫宫之财，婚姻不稳定；又见丑午穿，两穿需离两次。戌运穿夫宫，此运离。断戊寅年（三合火局克财星），实际是37岁丁丑年离，丑到之应。第二个也离了（时间很短）；第三个就成了，能稳定，亥运制住比劫可再婚。**穿两次，破一次，三次婚；第三次婚姻就好了，因刑的两次已过去，刑的能量耗尽。**

**坤造**：己丁壬甲／酉丑辰辰
空姐，多婚命。大运：戊寅 己卯 庚辰 辛巳 壬午 癸未 甲申 乙酉（8岁起运）
两辰一丑还有一己，辰酉合，丑入辰墓，都与夫妻宫有关，表示不同男人。第一个同居对象未成婚，是己酉。辰为丈夫，辰中含比肩，带复吟，丈夫是离过婚的。丁丑为情人，在月令是同学；己也是情人。丁丑年老同学找到她，同居。辛巳年离婚，后与老同学生一孩子，送他很多钱。宫带星多现，至少三婚。

**坤造**：己戊壬癸／酉辰申卯
大运：己巳 庚午 辛未 壬申 癸酉 甲戌 乙亥 丙子（3岁起运）
申为夫宫，见酉为副宫；己与戊辰都为丈夫，多婚。第一个男人爱赌，她支付赌债百万，未运己卯年离；庚辰年认识第二个男人，花她的钱，在外养女人，乙酉年分开。第二个是公安，因戊癸合，杀合羊刃，为公安之象。与第一婚生一女。卯食伤财源才是她的财，卯酉冲、卯辰破，两个男人都来破她的财。

**坤造**：癸壬戊乙／丑戌寅卯
大运：癸亥 甲子 乙丑 丙寅 丁卯 戊辰 己巳 庚午（10岁起运）
有杀再见乙卯官，戊土日主喜寅而忌乙。行乙丑大运之乙，定是婚姻问题。婚姻本是寅为正夫，乙卯为偏夫，即婚外情。夫是离过婚的，大她十来岁，有孩子，对她好；情人年岁相当或小一点，不如夫好。实情：先找的是年长的情人，处了好久，后与一个小两岁的癸未年办结婚手续（未到卯到）；现在她准备与那人离婚，跟年长的，而年长的尚未离婚。顺序对了，位错了。断此婚必离，乙酉要离，丙戌年男友的婚姻也离。寅是正夫，却拱劫财，是别人的丈夫；戌为别人。**女命合财在婚姻上没有多大意义。**寅先为情人，后为夫，丑戌刑了，寅变成自己的丈夫。

**坤造**：壬癸癸辛／寅丑丑酉
大运：壬子 辛亥 庚戌 己酉 戊申 丁未 丙午 乙巳
丑为夫宫之夫星，伏吟到月令带比劫，伏吟就是出去了，丈夫跟别人。第二次丑到正位。结婚早、结婚迟，婚前也不顺，经几次反复才结婚；89年结婚，94年发现丈夫有第三者（甲戌刑了，甲到寅到），97年离婚（壬寅当一个人看，壬寅合夫到外面去）。正行己酉运，戌刑丑；97丁丑年夫宫又伏吟，应在这年离。第二次婚姻以夫宫第二个丑土看：庚辰年辰酉合他俩相识，辛巳年夫宫三合局，同居，可保长久。

**坤造**：辛庚丁戊／酉子丑申
中学数学老师，多婚命。大运：辛丑 壬寅 癸卯 甲辰 乙巳 丙午 丁未 戊申（4岁起运）
戊、丑为食伤，庚子为头夫，戊申为二夫。子为老公，又见申入丑墓，申中含壬水。原局并无离婚再嫁信息，要看大运。丙戌年结婚（夫星子合丑，戌刑开其合）。癸卯运夫跑了，子破卯，此夫要离，戊子年婚姻出问题离异。离婚主因是婆婆不喜欢她：卯木枭印为婆婆，卯是七杀的食神。当年谈一个外科大夫，己丑年同居。

做保险的，有银行之象，丈夫也为赌徒。巳为丈夫，巳火伏吟，跑到外面去了，双宫双星。断戊寅年谈对象，己卯年结婚，庚辰年生女；离婚在丁亥年，最晚不会到戊子年。丈夫是赌徒。戊子年找了一个离婚有家的男人，带大檐帽（己为大檐帽之象，交警），对她不好有暴力倾向；庚寅年下半年分了一段，后又回来。第一个丈夫巳，阳包阴，阳制阴，所以是赌徒。壬子运子巳互绝，运中婚姻不好；庚寅年寅酉互绝，辛卯年还要分开段时间。

## 三、本章小结

| 要点 | 规则 |
|---|---|
| 星被穿、宫被破 | 宫星互破，必离；星宫穿后不能相生 |
| 比劫争夫 | 夫星被比肩合、比劫包 → 丈夫有外遇，初婚必离 |
| 关财门 | 财被冲、被劫克则官无源，必多婚；大运戊壬等克财之运婚坏 |
| 双宫双星 | 第一次没到位，两婚；日时伏吟不算 |
| 夫宫入墓 | 夫不死则离，把婚姻埋了 |
| 数夫 | 一人可能占几字（戊申、庚申算一人；丙丙连体一人）；有他合的字，则夫有外遇 |
| 第三次婚好 | 刑穿的能量耗尽后，第三次婚姻方稳 |
| 合财在女命 | 女命合财对婚姻意义不大；情人先、夫后需看刑的变化 |

**自测**

1. 什么叫「关财门」？举一应期。
<details><summary>答案</summary>财为官杀（夫星）之原神，财被冲坏或劫克，夫星无源；如丙壬甲甲／戊丙壬丙案：壬运关财门，癸未年离。</details>
2. 丙壬甲甲／申辰辰戌，申辰相拱为何仍二婚？若辰在日时伏吟又如何？
<details><summary>答案</summary>两辰是夫宫两现，一星两宫，第一次没合到位；若辰在日时伏吟则不表示二婚。</details>
3. 辛甲丁庚／丑午酉戌 为什么第三次婚姻才稳？
<details><summary>答案</summary>丑午穿、戌穿夫宫，两穿离两次，破一次；刑的能量消耗尽后第三次才好。</details>
4. 夫宫合入夫星之墓，如何断？
<details><summary>答案</summary>夫不死则离；官杀多者应伤官运伤官年再婚，但亦不久。</details>
