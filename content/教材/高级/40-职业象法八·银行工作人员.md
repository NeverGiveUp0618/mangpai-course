# 职业象法八：银行工作人员

> 银行从业者是一个很宽的职业群体，这里归纳的规律并不能涵盖所有人，不可求全责备。本章先讲三条取象规律与判断步骤，再详解五个命例（行长、部门经理、后台经理、业务经理、业务管理），其余五例以表汇要。
> （原稿源自扫描件，个别字词按上下文校订，如「两」「内」「西」「已」按上下文取丙、丙、酉、巳；例表中例三盘的「戌」干按上下文取「戊」。）

## 一、银行命局的三条取象规律

1. **数字与财富发生关联**：与会计组合类似（亥子壬为数字，与财星、财库相连），可参见上一章。
2. **收放组合**：银行的业务是吸收存款与发放贷款，用象法就是「收」与「放」——**东方木为放，西方金主收**。出现**卯酉、卯申、寅申、丑未**等组合，容易是银行。
3. **庚与申为金融之意**：银行属金融机构，再配**财星**，就代表银行。

### 配套细节象

| 象 | 取法 |
|---|---|
| 申、酉 | 金融、银行（酉亦为单位、权力；申又为财的原神，表银行） |
| 财库、丑 | 丑是金库又是财库，能装财又是财库的地方＝银行 |
| 丑未冲 | 一收一放，银行之象；丑代表酉，未代表寅 |
| 财星包局 | 单位都是钱，取象为银行 |
| 杀印相生、官带财帽 | 管财的官；官星带财＝管财 |
| 印星 | 单位；月令印被坏易丢工作 |
| 劫财 | 争财、抢财；比肩争妻 |

### 判断步骤

1. **找「收放」与「金融」字**：卯酉、卯申、寅申、丑未、庚、申、酉有无？是否与财星（或财库）绑定？
2. **看做功方式**：伤官配印、食神制杀、印制伤官、财制印；是印做功（职权）还是食伤做功（技术）。
3. **定职位**：包局、杀印相生、印带官才能当官（行长、经理）；官杀无制、印被坏，只是职员。
4. **注意双层职业特点**：戊己印星杂透，金融＋法律两种工作性质（见例表）。
5. **对运**：丑未冲、卯申合被运岁引动是升职／入行；被子穿未、合坏则离岗或不顺。

## 二、命例详解

### 例一　银行行长

**乾造**：戊己甲壬／申未午申
大运：庚申 辛酉 壬戌 癸亥 甲子 乙丑 丙寅 丁卯（1972 起运）

2007年案例，断金融行业高管，实际大学毕业后一直在银行，现任某银行行长。

**做功与象**
- 木火伤官配印成格，时上壬申，**杀印相生主权力**。年上戊中官带财帽，是**管财的官**。
- 一般日主无根、甲己合、月令财星太重主穷，为何此命好？因为**包局**：凡包局形成，所包之神都可以理解成一家，己未与午表示自己的财。
- 申为金融机构，加之杀星带财，故为金融行业高管。

**运年应期**
- 辛酉运：辛克甲不利，酉属平运。丙寅（1986）考入大学：丙辛合，合去辛金之病。己巳（1989）参加工作：甲己合，巳申合，食伤合杀。
- 壬戌运：壬为印，戌为伤官库，伤官配印大运，利升职。壬申（1992）升部门主管：杀印到位。丙子（1996）成婚：子午冲动夫妻宫，合逢冲为应期。丁丑（1997）升部门经理：丁壬合亲合太岁，丑未冲杀星发用。
- 癸亥运：戊癸合去杂留清，亥午合伤官配印。壬午（2002）升副行长：壬午自合，午代表原局午。甲申（2004）升行长（正处级）：甲申自己坐杀到位。
- 丙戌（2006）不顺：丙壬冲印，戌代表午与大运亥水克，影响午亥之合；该年生女。丁亥（2007）换单位到政府企业管信贷：丁壬合、午亥合为升职；行亥运见申亥穿，申代表银行，所以离开银行。戊子（2008）利升职：子午冲、子未穿制印得权，戊子自合也制印。甲子运是一生最好的一步运。

**婚姻**：己未财星为妻，与日主天地相合，婚姻好。

### 例二　银行部门经理

**乾造**：庚丁辛辛／申亥卯卯
大运：戊子 己丑 庚寅 辛卯 壬辰 癸巳 甲午 乙未（1987 起运）

2007年案例，硕士，读金融专业，银行部门经理；内向稳重。

**做功与象**
- 月令伤官生主位的财，财偏旺，得**卯申相合**为吉，唯不喜庚金旺透有争夺。又喜月令杀透，丁亥自合＝**伤官合杀**：杀星代表有工作，伤官是自己的技能，才能为公司服务。
- **亥为运算，生卯木财星，有做会计之象；卯申组合为银行**，所以在银行工作。

**运年应期**
- 己丑运：己运上大学，丁火杀星虚透主学历，伤官配杀，聪明好学；丑运申入墓，卯申不合，上学可以，财运平平。
- 己卯（1999）处对象，壬午（2002）午卯相破分手：原局比肩争妻，容易被争走。癸未（2003）读研究生并又处一个：未代表卯，对象又出现。甲申（2004）参加工作，对象分手：申金劫财把对象劫走。乙酉（2005）又处对象：乙到卯到，卯酉冲把妻宫的财星冲回来。
- 庚寅运：庚劫财虚透不再争财，婚姻搞定；庚绝而虚，被丁制，争夺力弱，利升职；寅运寅申相冲，财星冲到宾位，与己无关。丁亥（2007）提升部门经理并登记结婚：杀虚透被制故升职，亥卯合动夫妻宫之财星成婚。戊子（2008）举行婚礼。辛卯运：比庚寅运好，仍属平淡；辛卯伏吟代表辛苦，职务不会很高。

### 例三　银行后台营业部经理

**乾造**：庚甲癸壬／戌申酉戌
大运：乙酉 丙戌 丁亥 戊子 己丑 庚寅 辛卯 壬辰（1975 起运）

2008年案例，本科，银行后台营业部经理。

**做功与象**
- 癸酉日坐偏印本无用，喜财库包局，**单位都是钱，取象为银行**；戌上见庚金印星，主金融，更表示在银行。
- 月透伤官甲被庚印制服，印星有功主职权；时壬水劫财帮癸水，一同控制戌土，也主权力，所以是银行的官员。

**运年应期**
- 丙戌运：原局酉戌穿，不爱读书，学历低，早参加工作。辛未（1991）参加工作：辛代表酉到，丙辛合，印合财星＝有工作；未刑开戌财库＝赚钱。
- 丁亥运：丁代表戌，壬水合之，与原局壬制戌的象一致；亥运壬到，与申相穿，不与戌发生关系，属平运。丁丑（1997）成婚：丁到戌到＝妻星，丑到酉到＝妻宫。戊寅（1998）生男孩，动一次工作并提升：寅引通戌土官星，冲月令印星，官印俱动。
- 戊子运：戊代表戌虚透合日，相当自己戴上官帽，利升职；子运破酉，子与自己无关，代表别人，申金生之，主别人争权。丙戌（2006）调动：壬丙冲所以不能升职。戊子（2008）动工作并升职，但夫妻感情出问题：戊代表戌，戊子自合为**比肩争妻**。

**婚姻**：以戌为妻，与妻宫酉相穿，感情不好；但**星包宫**不易离婚。迟早要离：①妻宫双现，多主双婚；②将来行丑运坏戌，即便子运不离也难过丑运。

### 例四　银行职员（业务经理）

**坤造**：癸辛丁乙／丑酉丑巳
大运：壬戌 癸亥 甲子 乙丑 丙寅 丁卯 戊辰 己巳（1973 起运）

大学毕业，银行业务经理，丈夫是企业小官。

**做功与象**
- 丁丑日是内食神，适合在企业工作。月令辛酉入丑墓，墓不开，很多钱不是自己的，是公家的。
- 年上癸丑是食神戴杀帽，在单位有点小权，但癸水偏重、不虚透，是受别人领导，所以职权不大。时上己为比劫，**巳酉丑三合局**，从其旺势，别的同行听她的，有点小权。
- **丑是金库又是财库，能装财又是财库的地方肯定是银行**。

**运年应期**
- 甲子运：印化杀，利学业、工作。甲戌（1994）参加工作，先在企业；丙子（1996）招聘进银行：丙辛合又子丑合，流年亲合八字，子丑合引动丑土财库。
- 丁丑（1997）处对象：子运杀合夫妻宫。戊寅（1998）成婚：寅印星合夫妻宫。壬午（2002）动工作：丁壬合太岁亲合，子午冲动大运，工作变好。癸未（2003）又动：未冲丑冲动食神，食神主工作。
- 乙丑运：丁日本不喜乙，但旺辛冲乙＝财星发用，是好运；丑到，工作稳定，有升职机会。甲申（2004）生男孩：巳申合引动子女宫，巳中藏戊。丁亥（2007）升部门经理：亥冲巳，官星发用。

**婚姻**：癸为老公，坐丑伏吟到夫妻宫，婚姻稳定；但癸水远隔、与日主不亲，感情不好，常吵架。

### 例五　银行业务管理

**乾造**：甲癸癸己／寅酉丑未
大运：甲戌 乙亥 丙子 丁丑 戊寅 己卯 庚辰 辛巳（1983 起运）

乙亥运到丙子运身体一直不好（血压、血糖高，失眠头晕）；未婚，处过一个对象分手。

**做功与象**
- 包局八字，**丑酉为工作单位，通过丑未冲做功**：丑代表酉，未代表寅（寅又是财的原神），丑未冲，一收一放＝银行之象。
- 时上己未杀星过重，受人领导；喜甲己合，伤官合杀，可做管理工作。
- 原局酉、丑为阴，喜寅、未之阳；大运亥合寅、子坏丑未冲，故身体不好；甲寅主头，会头晕。

**运年应期**
- 乙亥运：乙运读书不错；亥运寅亥合，去外企。己卯（1999）参加工作，在日本一家银行工作至2008：甲己亲合太岁，卯酉冲应丑未冲。
- 丙子运：丙虚透财星，才能得发挥；子运合丑穿未，破坏丑未冲，不利工作与财运。甲申（2004）动工作：甲己合太岁亲合，申冲寅，离开原银行。戊子（2008）辞职，做第二职业：子运逢子年破坏丑未冲，不利，建议继续回银行；庚寅（2010）回银行工作：寅代表未到，引动丑未冲。

**婚姻**：晚婚命。寅为第一个对象，本寅丑合可合到妻宫，但中隔酉绝寅，亥运合坏寅中丙，丙运代表寅中财落在子水比劫上，难成婚；未中藏木可当妻子，子运穿未，须过子运。

## 四、本章小结

| 项目 | 要点 |
|---|---|
| 三条取象 | 数字＋财；收放（木放金收：卯酉、卯申、寅申、丑未）；庚、申金融＋财星 |
| 银行库象 | 丑＝金库＋财库；财库包局＝单位都是钱 |
| 管财的官 | 杀印相生、官带财帽、财星包局 |
| 双层职业 | 戊己印星杂透：金融＋法律 |
| 破坏 | 子穿未／合丑破丑未冲；卯申合被劫、被冲 |
| 地域 | 官命者在经商气氛浓的地区（如广东）可能弃官下海 |
| 婚姻 | 比肩争妻／争夫，包局不易离；妻宫双现主双婚 |

### 自测

1. 银行命局的「收放」组合有哪些？东西方各代表什么？
<details><summary>答案</summary>东方木为放，西方金为收；卯酉、卯申、寅申、丑未等组合。</details>
2. 为什么丑可以直接取为银行象？

3. 例一中日主无根、甲己合、月令财星太重，为何仍是行长？

4. 例表中金融法律双层职业如何判断时辰？

5. 为何东莞的银行行长会辞职下海？
<details><summary>答案</summary>比劫伤官旺，伤官太旺无印制，喜自由不喜约束；又受地域影响，戌运穿酉制杀取财，寅戌拱旺火，能发财。</details>
