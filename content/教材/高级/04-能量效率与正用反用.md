# 能量效率与正用反用

同样是做功，有的人亿万身家，有的人只混口饭吃，差别在于「制」的方式和效率。本章讲制化泄的能量高低、各种制法的效率排序，以及正用、反用两种格局。

## 一、制、化、泄的总排序

体现方式只有三种：**制、化、泄**。

- **制**：从能量上直接干掉对方，只要制成功，格局都挺高。
- **化**：以印化七杀，格局次之。
- **泄生**：用自己的力量去生去泄，怎么生也生不出几千万上亿，效率最低、层次低；伤官生财一般是十万、百万级。

> 口诀：制高、化次、泄生最低。

**凶神吉神与成就**：杀、伤、劫、枭（凶神）差一点，但**凶神为用档次高，大人物多是凶神有制化的人**——凶神灵活善变、适应能力强，不择手段达到目的，因此能成功。财官印食（吉神）为用，成就反而低，因为太正派，受到外界和自我的种种约束。

**化用不如制用效率高**，所以化用的官级别不大（如火土一气、午火印化杀生身，甲寅七杀被旺火所化当官，级别不大）。

## 二、制的三类：合制、克制、冲制（再加穿制）

### 1. 合制：把原神和用神全部制住

按能量从高到低：

| 次序 | 合 | 说明 |
|---|---|---|
| 1 | 巳申 | 一方旺时制住对方的原神；能量最大、效率最高 |
| 2 | 巳酉 | 同上，亦厉害 |
| 3 | 子丑 | 丑土克子水，能量较大 |
| 4 | 卯戌 | 卯制戌金，能量减 |
| 5 | 卯申（庚克乙）、午亥（壬克丁）、寅亥（水克火）、寅丑（木克土）、午戌（火克金） | 依次递减 |

- **干克支（如戊子、丙戌）效率高；支制干（如辛巳、丁亥）效率低。**
- 干支自合（戊子、癸巳、壬午自合）必须在命局中成势。
- 看富贵贫贱：合制的效率，把原神和本身都制住，制得干净的能量高、层次高。巳申、巳酉只制住本神的，能量中等；子丑、卯戌暗合的、有通关的制，层次中等；难以制尽的（寅亥、午戌）能量低。**在制干净的前提下**：丙戌可到百万，午亥可到副省级，午戌处级、副处级。

### 2. 克制

**围克和干克支效率高，邻克效率低，单纯克制能量最低。**

示意（上干下支）：
- 戌申午：围制，左右上三面围制申金，把申制死，效率很高；午戌、丙与申没有直接关系，但由于组合还是把申制死了。
- 辛丁／酉未：简单的克制，能量小，只能混口饭吃、领工资。
- 辛丁／酉午：效率低。
- 丁丁／酉午：效率高。

### 3. 冲制

冲制是通过冲发生制的关系。最重要的是**冲库**：财官临库，不冲不发，只有逢刑冲才可能有用。

- 丑未、辰戌冲库，冲得干净，制得彻底，能量最高：适当者资产亿元以上、省部级、中央官员、总理总统——这样的人物少，尤其是四库齐全的。但**库不用则纯粹无用**，只有冲得干净、制得彻底才有用。
- 刑库：未刑戌，制去辛金，几百万级；丑戌刑，戌把丑制干净，几千万上亿。
- 子午卯酉、寅申巳亥之冲，一定要形成势力（二冲三冲一，或有生的旺冲衰），才能冲伤冲去对方形成制；一对一力量差不多的冲只是「冲动」，为对抗，没什么意义，只有动和消耗。
- **以木冲能量最高**（把原神、用神全坏了），八字有势的冲制比较好，如寅申、卯酉、巳亥、子午。

### 4. 穿制（子未、酉戌、卯辰、丑午）

主位的体穿了宾位的用，用就坏了，没有缘分，得不到；宾位的用穿主位的体，就好了，得到了，可能都挺好。

> 口诀：体穿用，用坏；用穿体，我得。

### 5. 官命的能量与效率

官命的核心必须有官、杀及印星。官杀佩印、佩财、佩伤官、佩劫刃；印佩财、佩食伤、佩比禄，一般都有官职。官杀及印星不管作忌神还是用神都必须有根：

1. 身旺而从强，官杀作忌神，被旺劫刃反克坏，成「劫刃去官杀格」，大贵。
2. 身旺印重，八字财能制印，再行财星制印大运，也为官。
3. 从财或从弱，有印星为忌，被旺财所克制，行财运去印也为官。
4. 身弱从伤官，印星作忌神，被旺食伤所制，也为官。

看官贵着重看官杀与印：为用要辅要配，为忌要制要去。**官杀主职务，印主权柄。** 制用效率最高。

## 三、正用与反用

### 1. 定义

体用关系产生的两种格局：

- **正用**：主位的体制宾位的用。比较规矩，显示日主正常、大众，但力小。
- **反用**：主位落了用，宾位落了体；用宾位的体不对——是**主位的用反制宾位的体**。阴阳错位，不合常理，显示日主异于常人的思维行为；组合好则有异于常人的才华和智慧，**力大**。

### 2. 命例

**乾造**：戊己癸己／申未巳未

大运：庚申 辛酉 壬戌 癸亥 甲子

用占主位，火土成势制去宾位的体金水，制尽年位的原神：本人必是大富贵之人。日主是股市做庄的大老板，用五年时间积累十几亿。这种人必然有特异才能、非凡手段。（癸亥运反局：见第五章。）

**乾造**：丙辛甲癸／寅卯午酉

大运：壬辰 癸巳 甲午 乙未 丙申 丁酉

格林斯潘。木成势制金水；用午火制酉金效率低，不怎么样；但辛金在月上虚透，被丙火合制尽，大吉。戊戌运酉中辛金到了戌中被午制好；丁酉运天地制很厉害。

**乾造**：戊壬癸壬／辰戌巳戌

大运：癸亥 甲子 乙丑 丙寅 丁卯 戊辰 己巳 庚午

李鹏。火土成势，戌土官星制去劫财库，劫财库到宾位而被制去，反用能量效率极高。戌是财库又是官：制去劫财库，财临库，不管正财偏财，尤其库在年月，父当早死；但戌是最大的用神，虽然父早死，仍占了月令戌（即父）的光。本八字的病是壬有两个制不干净；戊辰运，忌神到位被制吉，当上总理；庚运生起忌神壬水，下台。

**乾造**：丙辛己辛／午丑卯未

大运：壬寅 癸卯 甲辰 乙巳 丙午 丁未 戊申 己酉

天津市委书记，火土去金水。甲辰运甲己一合，辰穿卯，坐牢十年；丙午、丁未运官最大；戊申运文化大革命，财临库不冲不发。

**乾造**：戊甲辛癸／申寅卯巳

大运：乙卯 丙辰 丁巳 戊午 己未 庚申 辛酉 壬戌 癸亥

薄一波。反用非常手段之人：主位用财星制去宾位体，劫财巳申合又把它拉回来。互换劫财被财制为主财，月令为超级财，用巳官拉回来，当官专门管财。卯为配偶宫，寅为副配偶宫，且又为财，所以两个老婆；一次离婚；寅刑巳，子女宫伤，儿子死。食神为口才，弱被制，口才特别好。运气：丙运被捕两次，说自己是做小买卖的，都放了；辰运收水使水无制，同时破用神卯、晦火生金，骗不过去，坐牢五年；丁运抗战开始放政治犯，获得自由；丁巳运成为党内最年轻的领导；庚申运干支一气、天透地藏，制不住，遇文化大革命凶；辛酉运复出；壬戌运权力最大，原局去金水，壬水虚透吉为吉的应期，成为国务院副总理，掌管人事权。

**乾造**：甲丁辛壬／申丑巳辰

大运：戊寅 己卯 庚辰 辛巳 壬午 癸未

吕日周。金水能去掉官星忌神，日主得官；但财星去不掉为病。午运丑午穿，不好；癸运名气大，丑中含的癸和丑是一个字，癸到等于丑到，因此癸运特别不好；未运未冲丑，不吉。

**乾造**：壬戊丙壬／寅申申辰

大运：己酉 庚戌 辛亥 壬子 癸丑

反用命局，主位用财星冲制宾位体印。申制掉寅，寅中有木火印比，且寅在年上，所以富贵层次高，亿万富翁；壬从申中出来，为牛耳。丁丑年丁壬合不好；戊寅、己卯年到位很好；庚辰年财星用神透有源最好；辛巳年同日柱天地合，尤其申巳合不吉；壬午年午冲去子不吉；癸未年穿倒用神不吉；甲申年申到好了。此人是股市庄家，丁丑年才有二百万，戊寅至庚辰年大发到四十八亿；辛巳年后股市下跌，壬午年市值三十亿左右，癸未年剩二十亿左右。癸丑运乙酉年辰酉合绊，辰不生申，不好；丙戌年戌冲开水库，壬为财，壬从申中来，发大财。癸比壬差；壬为财的牛耳精华，壬透到位吉。

**乾造**：壬辛丙丁／寅亥辰酉

大运：壬子 癸丑 甲寅 乙卯

上造的马仔，五千多万富翁。反用命局：亥合寅去寅中之火，亥子入日支辰库，辰库是自己的库；丁壬合去了天干劫财，日主从杀，杀入辰库为自己得杀；辰酉合有点闭库；辛亥月柱财星透，生官去劫，此官生财，财来自时支，说明被收的财有用。用杀制劫而得财，也有老板给我钱发财的意思。乙卯运卯冲酉，辰酉不合，开库，酉为财，辰收酉几十万级别；主要是月令亥水入辰库，几千万级别。

**坤造**：辛甲壬乙／亥午午巳

大运：乙未 丙申 丁酉 戊戌

反用命格，主位财合制宾位比。亥水有源，巳午火去之，去不干净；丁酉运印星辛金干支都被制，发财；制住了印，亥水也就合制干净了。

## 四、宾位的东西被制，且一定要和日主发生关系

两个命造对比：

**乾造**（甲）：庚癸甲丁／子未寅卯

**乾造**（乙）：丙乙甲丁／子未寅卯

（甲）庚金生子水，子水生甲木，是个副处级的官；（乙）子水印星与日主没有关系，所以没有官。结论：**宾位的东西被制，且一定要和日主发生关系。**

## 五、本章小结

| 排序要点 | 内容 |
|---|---|
| 制 > 化 > 泄生 | 制成功格局高；化次；泄生最低（十万百万级） |
| 合制次序 | 巳申 > 巳酉 > 子丑 > 卯戌 > 卯申、午亥、寅亥、寅丑、午戌 |
| 干克支高、支制干低 | 戊子、丙戌高；辛巳、丁亥低 |
| 克制 | 围克、干克支高；邻克低；单克最低 |
| 冲制 | 冲库最高；须成势；一对一只是冲动 |
| 穿制 | 体穿用用坏；用穿体我得 |
| 正用 / 反用 | 主位体制宾位用（力小、规矩）/ 主位用制宾位体（力大、异常） |
| 凶神为用 | 大人物多是凶神有制化 |

### 自测

1. 合制中哪两组效率最高？
<details><summary>答案</summary>巳申、巳酉；其中巳申最高。</details>

2. 为什么「冲库」比单纯克制层次高？冲什么时才有意义？
<details><summary>答案</summary>财官临库不冲不发，冲库制得彻底能量最高；冲必须成势（二冲一、三冲一或旺冲衰）才有意义，一对一只是冲动。</details>

3. 正用与反用各自的特点？
<details><summary>答案</summary>正用：主位体制宾位用，规矩力小；反用：主位的用制宾位的体，阴阳错位，异于常人，力大。</details>

4. 李鹏命中戌土为何既是「父早死」又是「最大的用神」？
<details><summary>答案</summary>戌是财库也是官，制去劫财库而财临库，父当早死；但戌为最大用神，仍占月令（父）的光。</details>

5. 为什么说凶神为用档次高？
<details><summary>答案</summary>凶神灵活善变、适应力强，不择手段，有制化则成大人物；吉神为用太正派，受约束，成就低。</details>
