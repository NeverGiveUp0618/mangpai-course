# 职业象法七：技术人员

> 技术人员的命局，多以食神、伤官为用：食伤是思想、头脑与技能，官印是单位、机构，两者配置得当，就是「自己的技能为机构服务」。本章归纳技术人员的格局特点和行业取象，再详解五个命例，其余五例以表汇要。
> （原稿源自扫描件，个别字词按上下文校订。）

## 一、技术人员命局的总规律

1. **食伤为用**：食神、伤官主头脑、技术；官印为单位、机构。技能为单位所用。
2. **不成包局、制局**：格局不大。格局大者就能当管理者或领导；没有包局、制局，只是靠技术吃饭。
3. **比劫参与做功**：比劫主动手能力。技术人员既要付出脑力，也要付出体力，常是「半体力半技术」。
4. **无食伤也可以是技术命**：某些日柱时柱的象天然偏技术（如壬辰日配己酉时，见例表）。

### 行业取象表

| 象 | 取法 |
|---|---|
| 丙火、寅木 | 传媒、影视、电脑、网络（寅为动手能力；丙寅见电信、网络） |
| 乙未 | 集成电路之象，也表传播、互联网 |
| 戌 | 火库，表电子、电器、电力；寅戌拱为电子、网络技术 |
| 亥、子、壬 | 数字、运算；丁壬合、亥拱，表电脑运算、软件 |
| 金水食伤制火官杀 | 用数理技术做电子、电器、电力工程 |
| 辛 | 财用精细加工；两辛合有「合住」之意（见例一） |
| 丁火 | 灯、电子、网络、文化（见十天干象） |
| 己酉 | 己为线条、酉为面板，设计之象；辰酉合表坐办公室 |
| 辰戌 | 土建工程，戌为高楼 |
| 寅 | 电器、电力设备（印为寅时） |
| 伤食 | 也表学生、老师（阳旺求阴，学生求知），故技术人员常兼职教学 |

### 判断步骤

1. 先看**食伤的位置与来路**：伤官出于何支？是否被印、官杀牵动？食伤透干或在门户，有「手」。
2. 再看**官印是否构成单位**：印、官杀在哪一柱，是否被合、冲、穿坏。
3. 看有无**包局、制局**：有则可升管理，无则普通技术岗。
4. 用**象**定行业：丙、寅→电信、传媒；戌→电子；亥、壬→数字；乙未→集成电路；己酉→设计；辰戌→土建。
5. 对运：官杀得制是好运；官杀旺而制不好只能是普通工薪。

## 二、命例详解

### 例一　电信公司技术人员

**乾造**：丙辛乙戊／辰丑酉寅
大运：壬寅 癸卯 甲辰 乙巳 丙午 丁未 戊申 己酉（1977 起运）

2007年案例，大专；先推断「在执法部门或公职单位」，反馈是电信公司技术岗。

**做功与象**
- 乙日生冬，喜阳，配戊寅时。官杀旺而入墓，墓不开：丑入年上辰库，天干透丙，阳制阴；寅为公门、光明，丑为阴暗、黑社会——很像公安刑警。
- 但**寅与丑隔一酉，酉绝寅，寅合丑就不成立**；如果酉与丑位置互换，才是公安。
- 技术：辛丑为单位，**两辛合，伤官为技术，伤官出于寅，寅为动手能力**——靠技术与动手吃饭。丙与寅有传媒、影视、电脑、网络之象，故在电信公司。
- 两辛合是制杀；官杀太重，只是普通工薪收入。

**运年应期**
- 甲辰运：甲生丙火，但克戊，属平运；辰助官杀，也属平运。丁丑（1997）参加工作一直做技术：丁丑为食伤坐杀库到位，在甲运。
- 戊寅（1998）得乙肝住院破财：甲运见戊，劫财见财破财；戊寅伏吟主难过，寅为肝胆，故肝胆病。
- 庚辰（2000）处对象，辛巳（2001）成婚：辛表夫妻宫到，地支三合局。壬午（2002）破财：午代表寅，丑午穿、酉午破，都坏寅木；丙壬冲又坏丙辛之合。
- 乙酉（2005）工作调动：日主伏吟，不动则难受。丙戌（2006）与领导不和：酉戌穿，戌代表寅与官杀穿，是对抗领导；上合下穿更激烈。

**婚姻**：以丑为妻，宫星稳定，婚姻没问题，生一男孩。

### 例二　广告设计师

**坤造**：戊甲丁丁／午寅巳未
大运：癸丑 壬子 辛亥 庚戌 己酉 戊申 丁未 丙午（1984 起运）

2008年案例，本科，产品广告平面设计，性急但认真，聪明有想象力，很年轻就是公司主要设计师，收入高。

**做功与象**
- 丙与丁是性质不同的两种火：**丙怕旺，太旺焚灭；丁喜旺，如群星灿烂，更喜甲木生**。
- 年上比劫伤官，戊土受甲木制，是**伤官配印**；甲寅主权力，唯不喜寅巳相穿，寅与自己不和，所以不为官职。木火主文化，食伤主技能，甲印代表很不错的单位。

**运年应期**
- 壬子运：原局无夫妻星；壬运丁壬合官为吉，子运子未穿，官星被穿，且子水官杀绝于夫妻宫巳，故没有对象；但工作财运好，子水杀星得制可当财看。
- 辛亥运：官星带财合印星、冲日主，为吉运，利工作财运，可以结婚。甲申（2004）本科毕业参加工作，任设计师和项目经理（甲印是单位，印坐财合上身）。
- 丙戌（2006）换单位：丙辛合动大运，寅午戌三合又刑未（未为印库＝单位），刑去一个、合来另一个＝换单位。丁亥（2007）第一次处对象：丁为自己到年，坐下亥水官星到。戊子（2008）预测结婚，后应：戊代表巳火，夫妻宫到年，自合子水官星。己丑（2009）预测会动工作：甲己合动印星，丑未冲又动印库。

### 例三　电子工程技术人员

**乾造**：壬癸庚辛／子丑戌巳
大运：甲寅 乙卯 丙辰 丁巳 戊午 己未 庚申 辛酉（1978 起运）

2008年案例，断本科、学技术类专业、工程技术、收入较高，结果正确。

**做功与象**
- 金水成势，巳与戌的官杀当财看；丑戌刑与辛巳自合＝制官杀。
- 食伤主头脑技术；**辛金劫财在门户表示手，比劫参与做功＝半体力半技术**；丑土印星为单位；制杀之局收入较高。
- 金水食伤制火官杀，用数理技术做电子、电器、电力工程；**戌是火库，为电器**。

**运年应期**
- 乙卯运：乙运上学；卯合戌，财来合我。乙亥（1995）参加工作，乙庚财合上身，亥长生卯财。戊寅（1998）谈对象并成婚。
- 丙辰运：丙合辛利工作；辰戌冲，制官杀库，收入增加，但原局定位打工做技术，不会发大财。己卯（1999）动工作：卯戌合到坐下印星，内部调整。辛巳（2001）丙辛合，劫财合杀，内部调整。乙酉（2005）换工种：乙庚合，辰酉合动辰，冲制戌土。丙戌（2006）涨工资：杀星被辰冲制，壬冲丙、丑刑戌，制官杀得财。
- 丁亥（2007）离婚。丁巳运：官杀得制就是好运；丁合年上壬，宾位食神合官，论吉；巳代表戌，合丑破坏丑刑戌，容易破财。戊午运：戊癸合伤官合印，利工作升职；午由戌出，被子水冲制，能发财。

**婚姻**：八字无财星，以食伤为妻星，取癸为妻，癸坐丑地，与夫妻宫刑，第一次婚姻要离。夫妻宫犯刑，很难有稳定婚姻。

### 例四　腾讯公司软件开发员

**乾造**：庚己丙乙／申卯午未
大运：庚辰 辛巳 壬午 癸未 甲申 乙酉 丙戌 丁亥（1980 起运）

2008年案例，本科理工，在腾讯负责软件开发，做互联网高科技。

**做功与象**
- **乙未为集成电路之象，也表传播、互联网**；占印星与己卯形成包局，故在互联网公司。
- 乙庚合又卯申合：财合印，财富的放大，公司有钱，工资高。坐支午未合，比劫合到伤官，自己在公司做技术。

**运年应期**
- 辛巳运：巳合申金，申中藏杀，主远方求学，申也主理科。己卯（1999）考入大学。
- 壬午运：壬水虚透主荣誉学位，利深造；午运合未＝搞技术，午卯相破，破月令印星，不利升职、主职业变动；午与申相克，难成婚。癸未（2003）读研；甲申（2004）半工半读，处过对象（甲申印带财与月令己卯天地合，能找到单位）。
- 乙酉（2005）全职工作并换单位：卯酉冲离开原单位，乙到未到，未是新单位，乙庚合到年上财。
- 丁亥（2007）由北京调深圳，对象分手：午亥暗合，丁壬合，太岁亲合大运，午代表自己合杀为吉；亥卯未三合印局＝新工作地方；申亥穿＝离开庚申这个地方、对象分手。
- 己丑（2009）还会有对象且换单位：丑代表申，穿午冲未。癸未运整体好运，卯未相合，午未合，工作稳定，婚姻在此运成；庚寅（2010）处对象并可结婚：庚寅印带财到，合夫妻宫。甲申运是最好的一步大运：甲己合伤官配印，财到卯申合发财。

**婚姻**：庚申年柱为妻；卯申合，午运克申不能结婚（夫妻星无法进入夫妻宫，卯午破印也无法领证）；到癸未运可以结婚，且结婚不错。

### 例五　软件工程师

**乾造**：戊乙己辛／午丑亥未
大运：丙寅 丁卯 戊辰 己巳 庚午 辛未 壬申 癸酉（1978 起运）

大学毕业，高科技企业，收入稳定；欲出国，断2009年可出国；断父母婚姻不好有离婚之象，结果父母1989年已离婚。

**做功与象**
- **食神制杀为功**：辛出于丑为食神，主头脑、技术；通过丑未冲与辛盖头未土制杀。但乙杀透月令制不好，不能当官；比劫偏旺，是搞技术的命。
- **未中藏乙为集成电路，拱亥为数字，电脑运算**，故为软件工程师。

**运年应期**
- 戊辰运：戊运读书，辰运破坏丑未冲，没有功，一直打工收入不多。辛巳（2001）参加工作，在外企做软件开发：食神到位，食神为饭碗。
- 甲申（2004）父得胰腺囊肿去世，处对象并同居：甲代表亥合到自己，申穿动夫妻宫星。丙戌（2006）结婚：辰运亥在墓中，流年戌冲开墓库。丁亥（2007）生女儿。
- 己巳运：己巳为日主坐下印来冲财，旺财大运，自坐马星表示出国。己丑（2009）出国：丑未冲开门户，食神制杀做功。

**六亲**：亥水为财为父，丑为父母宫；走辰运星宫同入墓，甲申年甲代表父星上天，父离世。午亥合，午为母，但丑午穿，父母会离婚。

## 四、本章小结

| 项目 | 要点 |
|---|---|
| 核心 | 食伤为技能，官印为单位；技能为单位服务 |
| 格局 | 不成包局、制局＝技术员；成包局＝可做管理 |
| 动手 | 比劫参与做功，半体力半技术 |
| 行业 | 丙寅→电信传媒；戌→电子电器；亥壬→数字软件；乙未→集成电路；己酉→设计；辰戌→土建 |
| 无食伤 | 壬辰日配己酉时之象，亦可做技术 |
| 兼教学 | 食伤也表学生，阳旺求阴，技术人员可兼职老师 |
| 辨伪 | 寅丑被酉隔绝＝不成公安象，而是电信技术 |

### 自测

1. 技术人员命局有哪两个典型特点？
<details><summary>答案</summary>没有形成包局、制局（格局不大）；多数有比劫参与做功（动手能力，半体力半技术）。</details>
2. 例一为何不是公安而是技术人员？
<details><summary>答案</summary>寅与丑隔一酉，酉绝寅，寅合丑不成立；若酉与丑位置互换则为公安。辛丑单位、两辛合、伤官出于寅、丙寅表电信网络，故是电信技术。</details>
3. 乙未、戌、亥拱分别主什么行业象？
<details><summary>答案</summary>乙未为集成电路、互联网；戌为火库，电子电器；亥为数字，拱亥表电脑运算。</details>
4. 例四中卯申合、乙庚合的含义？
<details><summary>答案</summary>财合印，财富放大，公司有钱、工资高；乙未与己卯包局，在互联网公司。</details>
5. 丙与丁两种火，旺与不旺的取舍有何不同？
<details><summary>答案</summary>丙怕旺，太旺焚灭；丁喜旺，如群星灿烂，更喜甲木来生。</details>
