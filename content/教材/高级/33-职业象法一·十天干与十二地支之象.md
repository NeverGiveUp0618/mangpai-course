# 职业象法一：十天干与十二地支之象

> 象法是命理的核心。看职业、看行业、看病灾、看事件细节，都要靠干支的「象」。本章把十天干、十二地支的取象一次列全（物象、人体、病、动物），再用命例演示怎样把几个象拼成一个完整的职业画面。后面八章按职业展开，均以本章为词典。
> （本章原稿源自扫描件，个别字词经按上下文校订；盘面中疑为 OCR 之误的「戌」按上下文取「戊」，已在盘后注明。）

## 一、阴阳、五行与十干总说

- 十干顺次：木生火，火生土，土生金，金生水，由阳而逐步生阴。十干有尊卑贵贱，**以阳为尊贵，阴为卑贱**。
- 阴阳两种划分：**大阴阳**以木火为阳，金水为阴；**小阴阳**以甲丙戊庚壬为阳，乙丁己辛癸为阴。

|---|---|---|
| 甲乙木 | 春，主生 | 生发、向上 |
| 丙丁火 | 夏，主长 | 火热、美丽 |
| 戊己土 | 季夏，主养育 | 成熟、厚重 |
| 庚辛金 | 秋，主收 | 肃杀、律令 |
| 壬癸水 | 冬，主藏 | 机变、通灵 |

### 十天干命例

**坤造**：癸癸甲丁／丑亥寅卯
大运：甲子（08） 乙丑（18） 丙寅（28） 丁卯（38）
头面被伤。甲木生时上丁，甲主头，丁主面。原局两癸旺透为病，癸水侵害甲木，还克坏丁火。行乙丑运，癸酉年与时柱丁卯天克地冲，路遇抢劫被毁容（癸克丁表示毁容，酉冲卯动羊刃表示抢劫；酉代表丑为劫犯，在年为远方来的，到大运为流窜犯）；丁丑年（1997）整容，从屁股上取皮植皮（丑为阴为屁股）。没有伤性命，因甲寅一体，甲丁组成头面，寅为心胸，地支寅没坏，只伤头面。丁把原局的丁补起来了。

**坤造**：乙丁乙己／未亥丑卯
慈禧。亥卯未三合制丑杀库做功，早克丈夫，咸丰帝早逝，自己独掌权力。丁为孩子，丁亥自合灭丁，中年克子，同治帝梅毒而亡。慈禧并不漂亮，但十分迷人：乙木日主为妖娆、妩媚，年时禄神并现，浑身散发女人魅力，年轻时得皇上专宠。

**乾造**：庚庚丙壬／寅辰子辰
张艺谋。丙日见壬为日照江湖之象，主明暗、光影、色彩；寅木见水为演，故为导演。庚为女演员，壬与子是庚金的伤食，代表她们的才气，全靠丙火来照，寅木来配庚，表示女演员通过他的影视作品展现才华，扬名立万。

**乾造**：甲丁丁壬／午卯卯寅
大律师。丁日喜见甲生，丁多文化高，博士学位；丁壬合，日合虚官主名气，著名律师；为何是律师，与卯午破的象有关。

**乾造**：丁癸庚丁／卯卯辰丑
丁俊晖，少年天才，台球冠军。癸水伤官为技术，丁为点、为目标，卯辰穿为运动，代表球在台桌上被目标瞄准；丁丁伏吟为移动，丁配丑为落袋；命局通过象表达出整个打台球过程。丁为官为荣誉，丁带丑印星代表冠军，丑入辰墓，冠军收入囊中。从2005乙酉年开始得过很多次世界冠军。

**坤造**：壬癸庚戊／辰丑辰寅（原稿「戌」按上下文取戊）
大运：壬子（08） 辛亥（18） 庚戌（28） 己酉（38）
邓丽君。癸伤官为才华，戊印是舞台，戊癸合有落日霞光之象，故成一代歌后。庚生丑月冰寒湿冷，喜戊寅时为阳，阴重阳少；不宜行酉运（寅绝，阳气没有），乙亥年乙克戊土，亥合寅灭丙火，寒湿瘀肺，肺病而亡。

**乾造**：壬己己丁／戌酉酉卯
韩寒，赛车手兼作家。己酉为车象，己象方向盘，酉金食神可代表驾驶技术，酉戌穿为速度（戌为火库象征发动机），组合起来就是赛车之象。为何不是车祸？因酉强戌弱，戌穿不坏酉；如果只有一个己酉，表示的可能是车祸。丁为文字，丁壬合主文章，所以也是作家。

**乾造**：甲癸庚甲／辰酉辰申
庚无火炼。庚日主金太旺为顽铁，最喜火炼，无火则难成才；月见癸水不为秀气，反为生锈之意，所以上学尽考零分。财星虚浮，无钱可赚，勉强糊口。行丙子之子运，子带丙杀，脑子像生锈；水来金沉主牢狱（金子沉到水底不见阳光），五年内进了好几次局子。

**乾造**：癸辛己戊／巳酉巳辰
中医师。辛酉取象病人，巳火能沟通阴阳，扶辛酉之阳气，所以为医生。戊辰劫财代表手，合酉为给病人把脉；辰为水库，又为东方木之余气，戊辰因合酉金食神表示给病人服用的汤药；辛金代表针，所以是针药并用的好中医。

**乾造**：庚丁乙壬／子亥丑午
会计师。食神配印局，丁壬合、壬午自合，表示个人才能被公司单位使用；壬水亥水为数字，所以搞财会，是某大公司财务总监。

**乾造**：庚癸己丙／午未卯寅
本派前辈先师。寅为头，丙为眼，丙配癸就如眼睛与瞳仁。火土太燥，癸水焦干，故双目失明。癸水入墓于未（阴干论墓库），己丑年被炸双目失明，天干己克癸，地支冲开墓为应期。为何是算命师？癸为玄学，又庚伤官技能，伤官生财，一生以此为生。

## 三、十二地支总说

十二地支之象依据四季而来：春温主生，夏热主长，秋凉主收，冬寒主藏，只是更加细化。地支类象与天干类象一样，是看职业或行业的重要依据，也是辨明事情细节和发展脉络的依据。

### 十二地支命例

**坤造**：丁丙丙丁／酉午寅酉
银行资产监管。寅为公门，独寅坐在地支为贵，主有公职。丙丁克住酉财，管财的意思，酉财是阴财，午羊刃有执法之象，实际是银行管理不良资产的。寅酉互绝，没结婚，有婚也不久。

**乾造**：癸甲癸乙／未子丑卯
卯为报纸。报社高级记者、编辑。卯可象为柔软的纸，食神为思想，思想写在纸上为文章；年为卯之库，卯未拱，从年到时连通，所以在报社工作。丑杀为权，表示有身份地位。

**坤造**：壬癸癸壬／子卯卯子
卯为面食。拉面馆女老板。食神为吃饭，卯为面，比劫为手；比劫在两头，用手拉面之象。子破卯，坏食神，到现在没有孩子。

**乾造**：癸丙甲戊／卯辰辰辰（原稿「戌」取戊）
甲辰车象，汽运公司经理。辰含水，水为印为车，又藏子为转动，辰为水库主机器，综合起来代表车；辰多连排，故为汽运公司。原局卯辰穿做功，故掌有权力。

**坤造**：庚乙丙癸／申酉申巳
精神出问题。丙火禄在巳，代表女人的身体，禄合财，财中带官，表示她比较随便，男朋友多，年月日时都跟她的禄有关系。巳表示思想（含食神），巳上落癸水官星，容易胡思乱想，也代表鬼上身。行辛运犯精神病，住院治疗。

**乾造**：壬辛丙庚／申亥午寅
左宗棠。丙午日，性格激烈，直来直去，恃才傲物，杀刃相合，能成将领。亥绝于午，申（庚）绝于寅，又临劫煞亡神，不管多强敌人都可使其灰飞烟灭，成一代名将，晚清重臣。

大运：甲寅（03） 乙卯（13） 丙辰（23） 丁巳（33）
诈骗入狱。食神和伤官同透为说话前后不一，更主要的是丑土合了食伤又墓了辛酉，辛酉见丑为黑社会组合，食伤旺透主思想、语言，所以为诈骗犯。原局未冲丑开墓，取未中财，未为酒店，所以做酒店，少年发家。行辰运破坏了丑未冲，丑再入辰墓主牢狱，故因诈骗罪入狱。

**乾造**：乙戊癸庚／巳子卯申
大运：丁亥（03） 丙戌（13） 乙酉（23） 甲申（33） 癸未（43）
银行行长。庚申主收，卯木主放，一边收一边放为银行与金融之象，加之卯木食神为财原神，银行是钱的源头。卯申合食神合印为功，所以是银行行长。甲申运升迁至分行长。

**乾造**：己辛丙庚／酉未午寅
律师。两辛合，取辛、酉之财，财带伤官，伤官有对抗官之意，站在当事人一边与检控机关对抗，故为律师。这是律师的一类组合：用伤官或食神合法对抗官，很可能是律师。

**乾造**：壬庚乙戊／戌戌丑寅
大运：辛亥（5） 壬子（15） 癸丑（25）
毛岸英。癸丑运庚寅年被炸死。戌有枪弹之意，丙戌加寅形成炸弹的象。乙丑的乙长在湿土上的苔藓，地支一片焦土，故被烧死；丑运自己到位，寅年引动戌为应期。

**乾造**：丁乙丙丁／酉巳戌酉
大运：甲辰（8） 癸卯（18） 壬寅（28） 辛丑（38） 庚子（48）
戴笠。戌穿酉，透丙丁羊刃，丁代表射出去的子弹，酉就代表被射杀的人，所以戴笠以杀人为职业；巳戌一家，强化戌的力量。丑运代表酉得旺，戌穿酉的功量变大，杀人越多官升越大，是最好的大运。庚运丙戌年死于空难，亡神人命；原局丙见酉为太阳落山，本身损寿。

**坤造**：戊癸庚戊／午亥寅寅（原稿「戌」取戊）
会计师。戊为单位，癸亥伤食为技能，戊癸合，自己有技能为单位服务，寅亥合财，所以管理财务。亥与会计职业相关有几种情况：**亥为食伤合财；亥被财墓；亥冲制财星或官杀星；亥为财星。**

**乾造**：乙癸丙戊／卯未子子（原稿「戌」取戊）
李昌镐。子为小珠子，代表黑白棋子，子未穿为运算，也代表战斗，子落空亡代表虚空，棋盘上的厮杀。透癸被戊合为荣誉，夺冠之意。17岁后行辛巳运，戊土行旺地，雄霸棋坛，拿了数不清的世界冠军。

**坤造**：壬丁戊己／子未申未
会计。丁壬相合，财星配印，代表有工作单位。子临财星，未为比劫为手，子未穿的象好比打算盘，珠子拨来拨去，算账之意，故是会计。申金食神形成包局，生到宾位的财，用自己的才能为企业服务，所以是会计主管。

**坤造**：辛己壬辛／酉亥寅丑
大运：庚子（6） 辛丑（16）
煤气中毒亡。辛酉与辛丑为印星，出现年时包局代表房子，丑是阴暗表示房子密不透风；寅是取暖的炉，寅被亥合，炉火烧不起来，形成煤气。丑运乙酉年冬寒假回家煤气中毒而亡，酉年引动丑，阴重坏阳。八字群阴而一阳，全靠这个寅木维持生命，坏则损寿。

**坤造**：癸乙庚庚／丑丑申辰
丑为肿瘤。庚申为肺入墓于丑，丑为寒湿之土，没有生机。戊辰运咳嗽十年，己运代表丑墓到，己丑年查出肺癌，庚寅年庚见绝地病逝。这里的丑也代表肿块、肿瘤。生前为警察，因辰土收双丑入墓，阳库制阴库有功。

## 五、取象的四个层次（总结）

1. **干支本身相配**，干支组合形成一个完整的象（如甲辰=车、己酉=方向盘与驾驶、丁丑=落袋）。
2. **干支与十神综合**，共同判定象义（如癸水伤官=技术、丁官=荣誉、印=舞台/房子）。
3. **干支的作用与变化**判定象义（卯辰穿=运动，酉戌穿=速度，子未穿=算盘，丑午穿=……）。
4. **整体局象**判定（如群阴一阳、亥卯未制丑杀库）。

> 职业取象是一个非常复杂的课题；要通过实际案例反复练习，把干支象、十神意义、作用关系三者连成画面。
