# 男命多婚组合

> 多婚指离婚后再娶（再嫁）。本章讲男命：什么结构必然多婚，每一婚怎么指认、怎么断离、怎么断再娶，以及哪些满盘财星逢刑冲反而一妻的反例。婚外情另见「婚外情与桃花」一章。

## 一、多婚的顺次与总原则

- 婚姻顺次：**年柱为早，时柱为晚，依次排第**。
- **天干虚者为短，或主桃花运；地支实者为长**。
- 除原局外，因大运而成的婚姻，**过运则无**。
- 看婚姻：先看副宫，再看副宫同柱所配之字——这个字就是配偶星，**有多少算多少**；若为印、比劫，则婚姻不好。

### 男命多婚的五种组合

1. **妻宫多现又配妻星**，形成婚姻组合，而妻宫本身不稳——容易多婚。
2. 妻宫虽不多现，但**妻宫被坏**（合坏、刑坏、穿坏）——一婚不到头。
3. 妻宫虽没坏，但**妻星被坏**，加上新的妻星出现——容易多婚。
4. **妻星多合**，合一次加一个；或因合而离开。
5. 妻星落在比劫上、被比肩争，或被羊刃、劫财透干包制——克妻，多结多离。

### 两条断离、断再娶的辅助诀

> 口诀：宫星双合，两次婚姻。一星两宫、一宫两星，第一次合没到位，第二次才合到位。
> 口诀：差一个字，一次婚姻。

- 一个妻星对应两个妻宫（或反之）为「双拱、双宫双星」，命该两次婚姻；第一次未拱到月令、未拱到位，则第一次婚不成立或不牢。
- **凡劫财、羊刃透干对婚不好**；午午戌这类连体都表示丙（日主），也同理。
- **没有透出丙丁劫财羊刃比肩，则两个禄只表示自己，不表示离婚**（见后面对比例）。

## 二、典型多婚命例

### 1. 宫多现、星多用

**乾造**：辛庚甲庚／巳寅申午
大运：己丑 戊子 丁亥 丙戌 乙酉 甲申 癸未 壬午（1岁起运）
经典多婚的才气作家，五次婚姻，老婆带子女全跑，最后孤家寡人。申是妻宫，透出庚辛副宫；副宫下压的是伤食及财星，都是配偶星，表示跟他有婚姻关系的女人多。为何偏偏离婚而不是二奶三奶？因夫宫申被木火旺冲克，又三刑，被刑冲克坏，妻待不住。巳、寅、午三个老婆，其中巳申合、辛巳自合，巳用了两次，为二个；寅配庚一次，寅申冲一次，为二次。寅和巳都多作用一次，故总计五个老婆。官杀为子女，官杀都带着老婆跑，所以一个孩子也没落着；每次成婚都带孩子进来，因妻星上面带有官杀。

**乾造**：甲庚庚丁／辰午戌亥
大运：辛未 壬申 癸酉 甲戌 乙亥 丙子 丁丑 戊寅（2岁起运）
多婚命，贵气文化人。第一任妻子是甲辰的甲木（辰戌冲这个关联）。甲辰连体不能分看，甲被比劫庚劫，是比肩争妻，原局已含离婚信息。甲落根在辰与亥，到甲戌运甲虚了易被人劫；戌又克亥水冲辰土，克了甲的根，必离。流年己卯（甲己合，卯戌合引运）与庚辰（庚克甲，辰被戌冲）两年为应期。第二个老婆是丁亥的亥，伤官落时上主小，要小很多，找的是他的学生。

**乾造**：癸丁丁丙／卯巳巳午
大运：丙辰 乙卯 甲寅 癸丑 壬子 辛亥（3岁起运）
财星过弱受火克，可以巳中戊土伤官当妻。丁巳伏吟，伏吟是走了，入他宫比劫，离婚之象。又见丙午时，午中己为第二妻。戊辰年结婚（辰表示妻到位）；寅运穿巳分居，癸酉年离婚；甲戌年第二妻出现，寅午戌三合局是团聚之象。

**乾造**：癸辛己戊／巳酉巳辰
大运：庚申 己未 戊午 丁巳 丙辰 乙卯 甲寅 癸丑（2岁起运）
妻宫巳火多现，癸坐巳下为第一妻；癸巳自合，合到劫财，妻跟别人跑。乙运丙戌年合去癸的原神离婚；辛酉合妻宫，是第二任妻子。
**乾造**：癸辛己戊／卯酉巳辰
（对照）差一个字，一次婚姻：妻不守妇道，有外遇，因辰酉合；癸财不坐副宫，不是妻子，戊癸合是沾花惹草，自己有外遇；辛酉是老婆。

**乾造**：癸庚癸癸／卯申未亥
大运：己未 戊午 丁巳 丙辰 乙卯 甲寅 癸丑 壬子（1岁起运）
卯木食神拱到妻宫，卯为妻；卯申合，合到劫地，申中壬为劫，妻找别人。辰运庚辰年婚姻变坏（辰生申，加大卯申合及壬劫的力量）；乙运乙酉年离。丁亥年重新组家庭，第二次婚姻幸福：亥中甲是二妻，壬为劫，亥未拱入妻宫，是离过婚的，年龄小。（原稿同盘另有一例同断，不重复。）

**乾造**：己庚甲庚／酉午寅午
大运：己巳 戊辰 丁卯 丙寅 乙丑 甲子 癸亥 壬戌（1岁起运）
结婚早易二婚。丙寅运辛巳年离，壬午年再婚。甲己合，己土为妻，但己不是标准婚姻，己坐酉上下相生，表示一个人；妻宫寅绝酉，第一次婚姻要离。自己在外打工，老婆在家与村里男人在一起，老婆承认；辛巳年穿倒妻宫离婚。壬午年午为老婆，两庚午是同一人，为第二妻，庚午庚午包住自己，不会再离。

**乾造**：戊己己辛／戌未亥未
大运：庚申 辛酉 壬戌 癸亥 甲子 乙丑（6岁起运）
妻宫坐亥水正财，正财得正位，怕逢比劫克夺。命局比劫旺相众多，亥水受克无生，暴力打老婆之象。壬戌运财星虚透，离异，应期丙寅或丁卯年。癸亥运乙亥年找年龄小的结婚；到甲运，甲代表亥透干合了比肩，再次离婚。

**乾造**：庚戊甲丙／戌子子寅
大运：己丑 庚寅 辛卯 壬辰 癸巳 甲午 乙未 丙申（9岁起运）
多婚命官员。子为妻宫，戊为妻，戌也为妻。卯运破子而合戌，妻被他劫财合，离婚之象；癸未年穿倒妻宫必离，老婆出国了。离婚后一直未再婚，需等辰运方可。

**乾造**：乙甲甲壬／巳申辰申
大运：癸未 壬午 辛巳 庚辰 己卯 戊寅 丁丑 丙子（3岁起运）
辰土为妻宫之妻星，巳生辰有关联，巳中戊土为第一个妻，巳上带劫，被宾位申合绊，第一婚要离。庚辰运戊寅、己卯年离；第二个找辰，辛巳年谈，乙酉年结婚。

**乾造**：甲癸乙己／辰酉酉卯
大运：甲戌 乙亥 丙子 丁丑 戊寅 己卯 庚辰 辛巳（2岁起运）
一个妻星辰，两个妻宫酉。**诀曰：宫星双合，两次婚姻**，辰第一次合没到位，第二次合才到位。丑运辛巳年找第二个；第一个老婆不离，直到戊子年法院才判离，应戊子年（戊可代表辰，虚透合癸跑了）。

**乾造**：丙乙庚戊／辰未辰子
大运：丙申 丁酉 戊戌 己亥 庚子 辛丑 壬寅 癸卯（4岁起运）
乙庚合，乙未为第一妻，入墓于辰，在月令，故找的是同学。乙生丙，外生杀，又入于丙杀之墓，丙辰是别的男人的妻宫，妻外遇之意。戌运坏夫妻宫，丙戌年婚姻出问题，丁亥年办手续。第二个找了子水伤官，新潮，时上食伤享受吃喝玩乐型；戊子年同居，辛卯年分手；己亥运续找一个。

**乾造**：癸乙戊庚／丑卯午申
大运：甲寅 癸丑 壬子 辛亥 庚戌 己酉 戊申 丁未（6岁起运）
天干戊癸合，癸为头妻，被妻宫穿了；庚申落时上为第二妻。子运子丑合冲破妻宫，婚姻破裂，壬午年午到位离婚。癸财生乙，妻子还要找别人（癸丑一气，就不能看妻有别的男人）。子运引通申金妻星，冲到妻宫，第二婚；丁亥年（丁是妻宫，亥是妻星）再婚。

**乾造**：乙庚丁壬／巳辰酉寅
大运：己卯 戊寅 丁丑 丙子 乙亥 甲戌 癸酉 壬申（3岁起运）
庚辰为第一妻，乙巳合之，被别人合走，第一婚必离；**如八字无巳劫财出现，庚辰酉的组合视为一人，不会离婚**。23岁丁卯年结婚（原局有合，冲动妻宫之应）；25岁己巳年离婚（巳劫财到年）；28岁壬申年又结婚（大运行到丑，丑与原局第二妻酉相合，申年引动丑）。

**乾造**：庚庚丁庚／戌辰巳戌
大运：辛巳 壬午 癸未 甲申 乙酉 丙戌 丁亥 戊子（10岁起运）
命中两妻：庚辰为妻，上下相生一个人，巳火妻宫生之，同学关系；巳入戌墓又带财星，是另一妻。戊子年子代表辰被大运未穿倒，离婚；戊又代表戌，与女友结婚。土逢冲如何代表两人？财星多现，各有所主。年上庚戌到时上庚戌，妻从远方来。

**乾造**：甲壬戊己／辰申子未
大运：癸酉 甲戌 乙亥 丙子 丁丑 戊寅 己卯 庚辰（6岁起运）
邓。申子辰合水局，妻宫子被未刃穿，克妻之命，有两个羊刃己未克掉两个妻子，第三个就克不动了。1928戊辰年25岁第一次婚姻（财星多逢比劫年成婚）；庚午年合动羊刃，妻难产而亡（子女宫穿克了老婆）；1931辛未年第二次婚姻（行亥运，财多逢比劫流年成婚）；癸酉年离婚（癸为妻坐酉合到辰比劫地，跟别人走）；1939己卯年第三次婚姻，又逢劫财流年成婚，白头到老。

**乾造**：乙己乙丙／巳卯亥戌
大运：戊寅 丁丑 丙子 乙亥 甲戌 癸酉 壬申 辛未（5岁起运）
银保。以亥为妻宫，卯为副宫。多婚是戌克亥：巳为头、二妻，己为三妻，戌为四妻。比肩争妻，妻宫受克，故多婚。25岁己巳结婚；34岁戊寅离婚；再婚找大姑娘；40岁甲申离；乙酉再婚丧偶的，丙戌年离。头妻因钱的事离（妻子有5—6万外债他不知）；二妻是农村姑娘，上班后变得开放风流；三妻因孩子不和。

**乾造**：丁丁丙甲／未未申午
大运：丙午 乙巳 甲辰 癸卯 壬寅 辛丑 庚子 己亥（8岁起运）
以申为妻；劫财羊刃透干包制申金，午代表丁，克妻，命中2丁1午共三个劫财有三个克妻因素，三次婚，申代表三个妻子。甲辰运乙亥年结婚；癸运壬午年（原稿注：此大运与流年不对应）壬水虚透代表申，被丁合，妻跑了，离婚；甲申年再婚。**劫财羊刃透干对婚不好。**

**乾造**：丙甲丁庚／午午酉戌
大运：乙未 丙申 丁酉 戊戌 己亥 庚子 辛丑 壬寅（10岁起运）
克妻多婚命。比劫包财，酉被戌穿倒。93年结婚，94年生男，99年离，2000又结，2004离，2005又找。戌运必离。丙透干对婚不好，午午戌连体都表示丙。

**乾造**：甲庚丁庚／午午酉戌
国家园林处干部，八字好，婚姻稳定。大运：辛未 壬申 癸酉 甲戌 乙亥 丙子 丁丑 戊寅
与上一例只差年月干，命运截然不同：没有透丙丁劫财羊刃比肩，两午之禄可表示自己，所以不表示离婚。但酉财被穿，妻子身体不好，长年有病。

**乾造**：戊丙丙辛／申辰辰卯
四同八字（分别生于澳门和山西运城）。申为妻星，辰为妻宫，辛为桃花。一星两宫，出现双拱，命该两次婚姻；第一次没拱月令没拱到位。澳门的离婚再娶；运城的全家迁北京，男人在外有情人，虽最终没离婚，但甲申年处一个小很多的并怀上他的孩子。

**乾造**：丙辛甲丁／辰卯子卯
大运：壬辰 癸巳 甲午 乙未 丙申 丁酉 戊戌 己亥（7岁起运）
辰为妻，被两卯穿坏，必离。早结婚，甲运癸未年离异，应癸未者穿倒妻宫之故。

## 三、反例：满盘财星逢刑冲，反主一妻

**乾造**：戊壬乙己／辰戌未卯
朱总理。大运：癸亥 甲子 乙丑 丙寅 丁卯 戊辰 己巳 庚午（5岁起运）
**凡土作妻星之命，逢刑冲反主一妻。**此造以土为财为妻，土多犯刑冲，不主妻多，反主一妻。夫妻宫不能刑坏，辰冲戌，戌刑未的力量减弱了。（辰冲戌，戌刑未，三土互相牵制。）

**乾造**：丁庚乙庚／未戌丑辰
满盘财星逢刑冲，只有一妻，也无桃花。丑入辰墓，辰为妻。**不刑冲的土财星，有可能表示桃花。**

## 四、本章小结

| 要点 | 规则 |
|---|---|
| 顺次 | 年早时晚；干虚短、支实长；大运婚过运则无 |
| 配偶星 | 副宫同柱所配之字，有多少算多少；印比则不好 |
| 五种多婚结构 | 宫多现星多现而不稳；宫被坏；星被坏另有新星；星多合；比劫争妻/羊刃透干 |
| 数妻 | 同一字合一次、冲一次各算一次（辛巳案：五妻）；一星两宫宫星双合两婚 |
| 离的应期 | 穿倒妻宫、星入比劫地、官财被合走；流年天干对应其地支 |
| 再娶 | 新妻星到位（如亥、巳、午）或伤官库、年龄小者 |
| 反例 | 土财逢刑冲反一妻；无劫透则禄=自己，不离 |

**自测**

1. 多婚命中「宫星双合，两次婚姻」何解？
<details><summary>答案</summary>一星对两宫（或一宫两星），第一次合没到位，第二次才合到位，故两婚。</details>
2. 为什么甲庚丁庚／午午酉戌 婚姻稳定，而丙甲丁庚／午午酉戌 多婚克妻？
<details><summary>答案</summary>前者没有透出丙丁劫财羊刃比肩，两午之禄表示自己；后者丙透干，午午戌连体都表示丙，劫财包财，酉被戌穿。</details>
3. 土财逢刑冲为何反而一妻？
<details><summary>答案</summary>土多犯刑冲，夫妻宫不能被刑坏，力量互相减弱，不主妻多。</details>
4. 辛巳、庚寅、庚午那例何以算出五个老婆？
<details><summary>答案</summary>巳因巳申合、辛巳自合用两次；寅配庚一次又寅申冲一次；加午，合计五。</details>
