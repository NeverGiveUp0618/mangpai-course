# 天干五合与地支六合的深论

作用方式（合、冲、穿、刑、破）是盲派断命的基本动作。本章讲「合」：天干五合怎样互换信息，地支六合怎样绊住对象、怎样换象，以及大运流年的合在应期里的意义。

## 一、天干五合：双方互为代表

### 1. 互换规则

天干五合如夫妻亲合：合在一起的两个字，**任何一方都能代表对方**，一方的特性可以当另一方的特性来读。合的结果是两个十神的信息互换：

- 合的是哪两个十神，就把两者的象互相借用。**强的一方制弱的一方，强方就代表弱方的信息；弱方则顺从强方的信息。**
- 以丁火日主为例：丙辛合是劫财合财。财是被劫财合过来的，所以这笔财不是劳动所得，而是非常手段获利——炒股、期货、赌博一类。
- 食神合印：印主文化、学校，食神主思考，合起来是「带有思想性的文化」，偏学术研究。
- 伤官合印：偏技术、艺术方面的成就。
- 伤官合杀：伤官也代表杀（权力）。伤官旺、杀弱时，杀可以代表伤官的聪明才智；杀被制而伤官合杀，则伤官变成权力，能当大官；若换成食神合杀被制，则不是当官而是发财。

> 口诀：五合换象，强者代弱；食合印为思，伤合印为技，伤合杀为权。

### 2. 合在宾位还是主位

合发生的位置决定它与日主的关系：

**乾造**：丁壬乙戊／未子丑寅

印旺有制，是当官的命。丁壬合是食神合印，主思考性的学术，但这组合在宾位，与日主本人的事业无关，只是自我精神享受——此人是爱好佛学、周易的官员。

**坤造**：壬己乙丁／子酉丑丑

大运：戊申 丁未 丙午 乙巳

印主权力，合到丑这个主位上；丑又是杀库，杀有制，是官命，有点小职权。丁壬合，做到文化宫电影院的总经理。丙午运癸未年，午穿丑、未穿子，当年腊月失去权力。

**乾造**：壬丁辛甲／午未巳午

大运：戊申 己酉 庚戌 辛亥 壬子

丁壬合，火成势，壬水被制。壬水旺时能当大官：辛亥、壬子运做到副厅长。这是「伤官合杀、杀被制」的当官例。

**乾造**：壬辛庚丁／午亥辰亥

大运：壬子 癸丑 甲寅 乙卯 丙辰 丁巳

伤官去官，本应是官命，但他是科学家。原因：官在宾位、虚透，只能主名气；若壬午与丁亥两柱位置互换，必是当官的。亥水旺，被辰收，辰收亥的信息是归纳总结、聪明才智——所想的是学术而不是当官。

### 3. 合到官星：官合身与谋官

**乾造**：癸戊辛丙／巳午丑申

大运：丁巳 丙辰 乙卯 甲寅 癸丑 壬子

丙申一柱，官被制、劫财被制，意在官。巳申遥合，意在谋官；坐下丑土收申金，申金合来巳官，且入自己的墓，官能为我所用——巳申合我能控制当官的人。毛病在丑午穿，七杀（上级）与他不和。戊土正印利日主，来自巳火（大主管），午火为二主管；申合的是正官，是正官合身，所以当的都是正职，没当过副职。甲寅运虽也当官但最难受，因寅穿巳；己巳年升官；丙子年官星虚透，子午冲、子丑合墓，差点被换掉；癸丑运财权人权集于一身，戊癸合是食神合印，做广播电视局局长；辛巳年又升官，午丑害，沾不到父母的光。

### 4. 合而无制的反例

**乾造**：乙己己庚／巳丑未午

大运：戊子 丁亥 丙戌 乙酉 甲申 癸未 壬午

船王，世界首富。火土成势，未冲丑制去月令的食神和财，大富。但乙庚合是制得不干净的病：年上七杀为儿，时上伤官为儿子的病，乙庚合则儿子要出毛病，二十几岁凶死。

**乾造**：乙庚辛丙／巳辰卯申

大运：己卯 戊寅 丁丑 丙子 乙亥 甲戌

乙庚合，辰卯穿，父亲早死。财生官，官透出来克他，首先无官，并且有官灾。自己的财坐支生官克身，被官克住。读书时偷了图书馆几本书，正赶上严打被重判。

## 二、地支六合：合绊论

### 1. 总规则

地支六合比天干简单：**不管是命局、大运还是流年的合，都以「合绊」论**——合住的双方都失去一定的作用，以丧失原性论。

> 口诀：地支六合，绊住失性。

各合的失性要点：

| 六合 | 失性所指 |
|---|---|
| 寅亥合 | 熄了寅中丙火（印星灭） |
| 卯戌合 | 闭了火库，木和土都失去原性 |
| 辰酉合 | 闭水库，坏乙木 |
| 午未合 | 闭木库，午火被晦 |
| 子丑合 | 闭金库 |
| 巳申合 | 既可去巳火也可去申金：巳火旺时去申中金水，申金旺时去巳中火土 |

### 2. 命例

**乾造**：甲丙己庚／辰寅亥午

大运：丁卯 戊辰 己巳 庚午 辛未

寅亥合，丙火印星灭，丙为工作，没有工作了；亥水妻宫被合走，失去老婆，两次婚姻。13岁犯桃花；第二个老婆看午火，因亥午合。桃花多是因为甲己合，甲坐财库。

**乾造**：壬辛甲己／寅亥戌巳

大运：壬子 癸丑 甲寅 乙卯 丙辰 丁巳

身旺合财，富命。巳火入戌墓，没法生财。卯运第一年，己卯闭了墓才开始发财；丙辰运，辰戌冲开墓，又出名又发财。

**乾造**：甲癸庚甲／辰酉辰申

辰酉合闭水墓，财根被坏。浊金贱命，水木去不掉，不能以从格论。

**乾造**：戊己癸己／申未巳未

大运：庚申 辛酉 壬戌 癸亥 甲子

火土成势，志在去金水，戊癸合是官合，控制的命局。杀紧贴而旺，不是当官的，而是发大财、做大事之人。炒股，坐了两个庄。壬戌运5年从一无所有到发财十几亿，辛巳年最辉煌；癸亥大运不好，最后一庄一路下跌，解不了就要破大财。

**乾造**：庚己乙己／戌卯卯卯

大运：庚辰 辛巳 壬午 癸未

戌卯合，财合身，官也合身，官合身不管旺衰。日主是私人大老板；官星虚浮，不是当官的，是办企业的。三个卯合一个戌，管理着三家企业。壬午运午破卯不好，总体发财（财旺），癸未运更大。

### 3. 寅亥合的婚姻意义

**坤造**：甲辛乙癸／寅未亥未

大运：庚午 己巳 戊辰 丁卯

寅亥合，配偶宫亥水被合走，丈夫难进来，婚姻不顺难成。这组寅亥合有两种读法：一是老公有外遇，二是自己有第三者——实际是自己做第三者。辛巳年因感情问题差点自杀；甲申年冲开寅亥合，问题解决。

**坤造**：甲辛乙己／寅未亥卯

大运：庚午 己巳 戊辰 丁卯

寅亥合：婚前老公不正经乱搞；婚后时柱卯为禄，能把亥水合住，所以这婚姻比前造好，但财运没前造好——木过旺、财弱、杀还有源，不富；前造亥未拱财，身旺财旺，财运好。

## 三、流年合大运：绊与留

大运是静止的，**只有流年去合它才起作用**。流年合大运，大运被「留」得到了；流年与原局合，是「合绊」。合绊有两重性：对原局而言是被绊，对流年而言是被留，即「得到」。**流年合入命局，实际是一种应期。**

**乾造**：壬丁癸乙／子未亥卯

大运：戊申 己酉 庚戌 辛亥

庚戌运，与命局乙卯天合地合，命局的食神被绊。此食神不生财，制一点官，主要表示心性，不以发财看——主悠闲爱自由；食神被绊就不自由不快乐。但得到了庚戌即财官：当年让他管理材料库，也算提升。丧失了原局的食神，得到了大运的官印。

**乾造**：丁壬丁辛／未子巳亥

大运：辛亥 庚戌 己酉 戊申

戊运：巳火中的戊虚透，说明巳火虚了无用，所以戊运不好，只有辛巳年和甲申年好。辛巳年巳到位，带财到位，又合住申财，该年挣了七八万；甲申年申合入巳位，巳火被合绊而不虚透，消耗巳火的力量能发财。

## 四、反局：违背原局意象的合

凡是违背原局组合意象的合冲，叫**反局**，主凶。

**乾造**：己癸丁丁／未酉巳未

大运：壬申 辛未 庚午 己巳 戊辰 丁卯

袁世凯。原局的组合是巳火制酉金，最怕卯木来冲、辰来合。丁卯运卯酉冲，破了巳酉合，不吉。丙辰年：巳用神虚透，说明巳火无用（虚透即「跑出来」，逃走之意，是地支在天干的体现）；辰酉合，把酉忌神合住保护，巳火制不住它，该年死。

**乾造**：辛壬壬癸／亥辰戌卯

大运：辛卯 庚寅 己丑 戊子 丁亥

日主坐下是财库，见财库一定要冲，冲开能发。卯戌合闭库是命局的大毛病，所以己卯年打官司破大财，死了一个女儿。冲开财库最好能制住库中之财和它的原神，这是最大的财之一；此例冲开财库而财有制。但冲也有冲坏的。

**乾造**：戊壬乙己／辰戌未卯

大运：癸亥 甲子 乙丑 丙寅 丁卯 戊辰 己巳 庚午

戌冲辰，辰中壬水被制，财库去了印库：印主权力，财主经济库，最大者又在年月，是掌管经济的官。卯戌合、卯未合都合到主位，卯木为禄为自身，所有的财都归自己控制。丁运最不好：卯戌合库的同时丁壬合，为反局（壬本是被戊制的，丁壬一合，戊制不了壬，壬被保护），没有权力，下乡劳动。辰运彻底制去印，辰到位最好；己巳运戊得禄，制得干净；庚运庚官为忌神，不好。

## 五、六合换象

**换象**：六合中一方变成另一方——合到哪里，被合的东西就带上合方的性质。

**乾造**：壬己癸辛／申酉巳酉

大运：庚戌 辛亥 壬子 癸丑 甲寅 乙卯

大贪官。申巳酉巳合，申制巳，金都成了火财；金水成势，火被灭。亥运一般（冲去但没乱）；丑运会成金局，金成势，全是钱；甲运甲木合住命中唯一的七杀，无人管、权力最大；寅运寅冲申破局，巳火无制，倒霉被抓。

**乾造**：戊己癸己／申未巳未

大运：庚申 辛酉 壬戌 癸亥

火土成势志在去金水，申金弱，要旺才制；命局制不干净，富翁但不是大富翁。巳申合，财制去劫财，申金也当财看，壬戌运发财。

## 六、本章小结

| 作用 | 规则 |
|---|---|
| 天干五合 | 双方互为代表；强者代弱，弱者顺强；合哪两个十神，两者信息互换 |
| 食神合印 / 伤官合印 / 伤官合杀 | 学术思考 / 技术艺术 / 权力（被制则当官；食神则发财） |
| 合在宾位 | 与日主本人事业无关，属精神爱好 |
| 官合身 | 不论旺衰；官在主位且有制是官命，官虚浮则办企业 |
| 地支六合 | 一律以合绊论，双方失其原性 |
| 流年合大运 | 大运静止，流年合才起作用；合入命局即为应期 |
| 反局 | 合冲违背原局组合的意象，主凶 |
| 冲库 | 见财库要冲；冲开且制住库中之财及其原神为大富 |

### 自测

1. 丁火日主，丙辛合是什么十神合什么？得财的性质如何？
<details><summary>答案</summary>劫财合财；财是被劫财合过来的，属非劳动收入、非常手段获利，如炒股、期货、赌博。</details>

2. 同样是合杀被制，伤官合杀与食神合杀结局有何不同？
<details><summary>答案</summary>伤官合杀，伤官变成权力，被制时能当大官；食神合杀被制则不是当官，而是发财。</details>

3. 地支六合如何断？举出寅亥合与辰酉合各自失去了什么。
<details><summary>答案</summary>一律以合绊论，双方失性。寅亥合熄了寅中丙火；辰酉合闭水库、坏乙木。</details>

4. 为什么说「流年合入命局是一种应期」？
<details><summary>答案</summary>大运静止，只有流年去合才起作用；流年与原局合对原局是绊、对流年是留（得到），所以合是应期的表述。</details>

5. 袁世凯丙辰年为什么凶？
<details><summary>答案</summary>原局组合是巳火制酉；丙辰年巳用神虚透（无用），辰酉合把酉忌神保护起来，巳火制不住它，属反局。</details>
