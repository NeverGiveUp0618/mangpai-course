# 职业象法二：生意人

> 生意人分两路：一路是投资经营、开门面的；一路是开公司做贸易的（货物流通、产品代理、销售）。本章先解决两个问题：命局里**什么东西可以当财富看、财富怎么定级**，以及**什么组合是生意组合、对应什么行业**；再用五个命例演示从做功到行业、大运流年应期的完整断法。干支象义查前一章词典。
> （原稿源自扫描件，个别字词经按上下文校订。）

## 一、先定义：什么可以当财富看

求财的命，第一步不是找「财星旺不旺」，而是先弄清命局里**哪个字在代表钱**。财富可以由四类东西承担，级别不同：

| 当财富看的对象 | 级别 | 理由 |
|---|---|---|
| 财星 | 较小 | 财是「养命之源」，指维持基本生活所需的钱，是工资、小生意的格局 |
| 食伤 | 比财大 | 食伤是财的原神（财之源），源头大于水流 |
| 地支食伤本身含财 | 更大 | 食伤库里带着财，源头与结果同在 |
| 官杀 | 最大 | 官杀由财所生，是财富的升级——钱变成权势、规模、产业 |
| 禄 | 个人享用之财 | 指自己能用到、花到的那份，不是做大的资本 |

> 口诀：财是养命钱，食伤是财源，官杀是财升级，禄是自己享用。

**定级的实际用法**：同样是做生意，财星得用的多为小本、稳定经营；食伤旺而得用的多是有技术、有产品的企业；官杀（尤其官杀坐库、官统财）被调动起来的，才是几千万、上亿的规模。例如下文 2-7 的命主「自己坐官星，官能统财」，财富级别便比单纯财旺高一层。

## 二、生意组合的几种基本结构

### （一）印的角色：门店、公司、规模

做生意的命里，**印星常常不是读书、不是工作，而是「门店、公司、厂子、规模」**。

- **印带财、财合印、印冲财、印来合财**：都是做生意的结构。「印来合财与印来冲财都是做生意的」；印带财星合上身，几乎都是开店面做生意。
- **印在年、时（门户）**：印落门户，就是自己的店面、工厂，有几个印星往往就有几个厂子。
- **伤官合印**：是放大财富的方式，生意做成规模（2-2 的甲己合）。
- **财坐印落门户**：印能放大财富，生意有规模，财富级别高（2-7）。
- **印包住财局**：印为车辆、房屋等信息的载体，财是对象，包局就是经营这类东西（2-4）。

### （二）财库、官杀库：开库为发财之机

- 命局有财库，库**不开则财不能释放**；运岁冲开、刑开财库，就是发财的应期（2-2 靠戌刑丑开财库；2-3 预测辰运冲开戌库）。
- 官杀库不开又无制，不能当官，转而求财做生意（2-6）。
- 「财临库地」「财库合闭」同时关系到父亲：财库不开、被合闭，则父寿有碍（2-7）。

### （三）冲与驿马：做贸易跑世界

- **禄冲财、寅申冲**：是典型生意组合。禄冲财求财，再逢驿马，就是满世界跑、辛苦求财（2-6 的进出口贸易）。
- 年、月、日皆驿马逢冲：运输、车辆、出租之象（2-4）。
- 冲有「进出、交易」之象：东西往外卖，亥运穿坏了寅申冲，交易就被破坏（2-4）。

### （四）劫财与财：合财、争财

- **劫财合财**：喜欢投资、喜欢赌博，但被劫之财不赢（2-3：丁壬合，财被劫财合去，所以「十赌九输」，做正经生意却能赚）。
- 劫财高透而又财被引动：投资不顺、一般（2-5）。

### （五）食伤制财库与三合制库

- 三合火局制丑土财库，同时刑动戌土，使功神戌更有力，是「制财库做功」型发财（2-2）。
- 食伤坐财库，是生产有技术含量的东西；食伤合印则是放大成规模（2-2 家具）。

## 三、取行业：象的拼合

行业靠单字象加组合象拼出，不要只靠一个字。以下是本章命例里的拼法，可当模板：

| 行业 | 组合与取象 |
|---|---|
| 装修、彩绘 | 丙火主漂亮、装饰，落门户；火见水有化妆、彩绘之意；亥为墨水，卯为文字文章，卯午相破为用手加工 |
| 高档家具 | 木火成党局，「死木」是木材，见火为漂亮；门户见己土伤官为技艺，得库为一群技术工人；伤官坐财库为生产有技术含量的东西；甲己合为放大，成规模 |
| 建筑、建材、电器 | 戌：装修、建筑、建材，又是火库，为电器；戌冲辰的功为生意组合 |
| 酒店、饭店、餐饮 | 酉金见水，有酒店、饭店、餐饮之象；未也有酒店之意 |
| 车辆出租、五金建材、物业 | 申金：金属、建材、传送、运输、车辆；辛金为小金属；年月日驿马逢冲；印为房屋、物业 |
| 服装、美容、家电 | 印为火有漂亮之意，门户伤官与财包局；适合木火行业，不止服装，家电、美容亦可 |
| 电器进出口贸易 | 戊（戌库透干）：电器、地产、娱乐；寅申冲有进出；年为远方，申为传送 |
| 玻璃、化工、木器厂 | 庚寅为木器厂；辛丑为玻璃厂；子水、亥水为数学和化学，子水有化工之象；一个申字把地支全引动，就是几个厂同时开 |
| 金属器材、化工产品、航运贸易 | 金见亥水为金属、玉器等秀气的东西；年亥与时辰包局，辰为水库，有车船、化工；卯辰穿动辰库 |

> 要点：**拼象要有「做功」的证据**。八字不是单看象，而是有哪一层功、哪个字被制、哪个库被开，象才能落到实处。

## 四、大运流年的应期规律

1. **丁运、劫运、比劫运**：天干比劫透出，多为「帮别人」「别人的钱」，打工、辛苦；或财被劫，破财。
2. **运岁引动财库**：丑到、辰到、戌到使库刑冲，发财。
3. **运岁合住自己**：财来找我、禄带劫财有亥来合午，是财运好。
4. **运岁破坏原局的功**：如亥运穿坏寅申冲，则平运；子运破卯申合，则不好。
5. **原局有「破」的毛病（如卯午破）**，运岁里有字同时合两边（如未既合卯又合午）可解决问题，是最好运。
6. **丑到等于申酉到、辰到等于子到**：流年用本气所藏之字或同类字来代换，要熟练。
7. **官杀被引动而不被制**：不是升官发财，而是官非、伤病、盗贼、小人（2-6 的午运）。

## 五、命例详解

### 例一：装修彩绘企业（坤造）

**坤造**：丁癸丁丙／酉卯亥午
大运：甲辰 乙巳 丙午 丁未 戊申 己酉 庚戌
学历不高，自己独资开公司，做装修彩绘。

- **做功**：丁日主生丙午时，日主连体；月令癸卯是带象，印带杀帽。卯午相破，卯代表工作单位，被破，所以命主没有工作单位的命。亥水官星被卯、午包局（卯午包亥），坐下的亥水官星**当财富看**；午亥相合，合到自己，所以是发财的命。年上丁火控制酉金，酉是亥的原神，源源不断生给自己，财富级别因此偏高。
- **象**：丙火主漂亮，落门户，装修、装潢、美观。火见水有化妆之意，所以做外墙彩绘、画墙、绘图。亥为墨水，卯为文字文章，卯午破为用手加工。
- **大运流年**：
  - 乙巳运开始创业：巳亥冲为动钱，巳酉合财为投资求财。
  - 丙午运财运好，开始发财：禄带劫财，有亥来合午，财来找我；禄运辛苦付出多，但财运比较好。
  - 丁未运最好，发财几千万：丁未自坐食神；亥卯未三合印局，印主放大，生意做大；未既合卯又合午，解决了午破卯的问题。
  - 戊申运：戊癸合伤官合杀为吉；但申穿亥、旺金水而坏卯印，申运不适合做事。2009己丑年预测生意不好（丑到等于申酉到，丑午穿坏午火，对应反馈）；2010庚寅生意能做（庚虚了大运的申，寅长生午火、合亥）；2012壬辰年不行，辰到金受保护、亥入水库坏局，卯辰穿坏卯（单位），应退休养老。
- **婚姻附断**：二婚。头婚癸卯，卯午破，印带杀破禄，吵架过日子；二婚亥，亥午合，官合禄，感情好。庚寅年再婚，对象是离过婚带男孩的人（申运卯申合，所以也是结过婚的；戊为伤官为男孩）。

> 学点：**官杀被包局当财富看，是最高一级的财富**；而「印被破=没有工作单位」是自己创业的信号。

### 例二：高档家具企业（乾造）

**乾造**：甲甲丙己／寅戌午丑
大运：乙亥 丙子 丁丑 戊寅 己卯 庚辰 辛巳 壬午
初中文化，早年打工，后白手起家做家具企业，初见规模。

- **做功**：寅午戌三合火局，制丑土财库做功；丑戌相刑，用戌刑制财库，三合强化了戌土的力量，所以是发财的命。时上伤官坐财库落门户；甲己合合了印星（印在年为门店），自己开门店、工厂；伤官合印是放大财富。
- **象**：木火成党，死木为木材，见火漂亮；己土伤官为技艺，得库表示一群技术工人；伤官坐财库为生产有技术含量的东西；甲己合是放大，形成规模——合起来是家具。
- **大运**：原局戌刑丑，所以喜行制丑运或丑出现的运。
  - 丁丑运：2000庚辰年之前给人打工做家具销售（丁为劫财主别人）；2001辛巳年（辛表示丑到，丙辛合财，自己投资的意思；丑运开了财库）在深圳自己投资开家具厂，一直赚钱。
  - 戊寅运：戊食神坐寅，三合火制财库，丙火喜戊，也发财。
  - 己卯运：己运甲己合，店面还开着；到卯运不开店了，因卯午相破，自己被印破。
- **性格**：满盘皆阳，丑独阴，怕天火旺，脾气急、说一不二、大男人、做事果断胆子大；时落伤官，头脑好，伤官合印会做事，看准就下手。
- **婚姻**：无明财，以食伤为妻，戌为老婆，三合夫妻宫，婚姻无问题；午为夫妻宫透己，己为桃花，己坐财库、丑午穿为花他钱，所以外面有情人。

> 学点：**制库做功的发财命，运岁越能引动被制的库，越发财；伤官合印是由技术到规模的桥梁。**

### 例三：建筑、建材、酒店（乾造）

**乾造**：丁戊癸壬／未申酉戌
大运：丁未 丙午 乙巳 甲辰 癸卯 壬寅 辛丑 庚子
本科学历，丙午运在国家单位工作，不喜欢；乙巳运中1998戊寅年辞公职，自己投资做家电、建材装饰、空调安装；2005乙酉年大投资开火锅酒店，发财几百万。喜欢赌博，十赌九输。

- **做功**：财包局做功，戌财库和未要制申酉印星，但印星制得不好，不能当官。戌变成戊虚透，官星合身，把戊当财富看。戊申为印带官帽子，月令代表国家单位——若不是生在壬戌时，可能是当官的；但戌是财库，戊也是财，表示本人志在求财。
- **赌与投资**：未无法做功制印，透丁财被劫财壬合去（丁壬合，壬在时上为劫财，主手、打牌）。劫财合财，喜欢投资、喜欢赌博，但丁财不做功，还刑戌，戌是功神，最忌未来刑，所以赌博不赢；做生意则可以。
- **多事业**：壬癸都坐在印上，表示多种事业，开公司开店。
- **行业**：两个印星，酉金见水带酒店、饭店、餐饮之象；月令申带戊来自戌财库，戌为装修、建筑建材，又是火库为电器——所以同时开家电、建材公司。
- **大运流年**：
  - 丙午运：丙到等于戊到，戊是月令的财，所以是挣工资。
  - 乙巳运：乙到表示未到，没有功；巳从戌中出，合申酉，财合印，要投资做生意了。1998戊寅年寅申冲破月令的印（食伤冲印要换事业，所以辞职），戊癸合为投资做生意。此运发财几百万。
  - 甲辰运：辰冲开戌库，只有甲辰运发财，其他辰运就不行；甲为食伤，戊喜甲，戊甲相见会搞房地产。
  - 流年：2005乙酉年巳酉合又开酒店；2007丁亥年丁亥自合，丁财虚透被劫合去，赌必输，做生意能赚；2008戊子年戊子自合是破财，投资不成；2009己丑年财库犯三刑，与官方惹是非破财，建材工程质量问题被告赔钱；2010庚寅年寅戌拱财、冲申，财来找我，顺利。
- **婚姻**：财包局婚姻不会有问题，只是老婆看紧自己；男命正官合身生女孩。

> 学点：**同一个财，「合在劫财手里」=赌必输，「合在印上」=投资成事业**；赌与做生意要分开问。

### 例四：门店经营，子承父业（乾造）

**乾造**：甲壬丙辛／寅申申卯
大运：癸酉 甲戌 乙亥 丙子 丁丑 戊寅 己卯 庚辰
高中文化，戌运1994甲戌年出来做事，先给别人打工；乙亥运1998戊寅年辞职，接手父亲的生意——车辆出租、五金建材、物业，管理几个店面，财运稳定，有点资产，不是大发财。

- **做功**：靠卯申合，财合印做功；印门户，印带财合上身，几乎都是开店面做生意。月令财带杀帽是父亲祖上的财，伏吟到主位，所以是继承祖业。年上寅木印星表示以前的工作，寅申冲表示工作干不长，卯申合会转换行业，丙辛合财表示自己做生意。
- **行业**：印包住财局，印在年时门户，本身就是车辆、房屋等信息；申金象金属、建材、传送、运输、车辆，而且年月日均驿马逢冲，所以是出租车辆和五金建材；辛为秀气小金属。
- **大运流年**：
  - 甲戌运：卯戌合，食神合印，自己要参加工作；1994甲戌年为上班应期。
  - 乙亥运：亥运寅亥合而申亥穿，破坏寅申冲；寅申冲也是交易（东西往外卖），亥运破冲，平常运。
  - 1998戊寅年乙运寅申冲印，辞职，冲到月令（父亲），继承父业。
  - 2004甲申、2005乙酉年：财印冲有投资之象，但大运不好，投资破财。
  - 2009己丑年：甲己合，寅丑合，财库合印，丑到为申到，五金和出租车生意扩大投资。
  - 丙子运：子卯相破，破坏卯申合，不算好，不能投资求财。
- **婚姻**：申为老婆，1998年处对象（寅申冲到夫妻宫），1999己卯年甲己合印、卯申合动妻星而结婚；夫妻宫稳定。

> 学点：**印包财局+驿马逢冲=车辆、运输、门店类的家业生意**；大运流年看「破不破原局的合与冲」。

### 例五：木工起家到多厂老板（乾造）

**乾造**：辛庚丙庚／丑子子寅
大运：己亥 戊戌 丁酉 丙申 乙未 甲午 癸巳 壬辰
小学文化，十几岁学木工活；从戌运到丙申运前一直做木工；丙申运自己开工厂发数千万；乙未运与亲人合伙开四个厂（玻璃厂、化工厂、木器厂等）。

- **格局**：金水一党，只有一个寅木印星，独阳。日合财，身弱本为穷命，幸财在年远隔，祖辈不好。**自己坐下官星，官能统财，财富级别较大**。时上庚虚透，庚出于丑，多的地方卖到少的地方，是生意组合。寅为企业、规模；财坐印落门户，印能放大财富。
- **运的节奏**：
  - 戌运：原局丙不见比劫，但有丑土伤官（年上伤官带财，有一技之长），大运又走比劫之墓运，用比劫制财制官杀的多是做体力活，所以做木工。
  - 丁酉运：用劫财克财，辛苦求财。
  - 丙申运：自坐财，财出于丑墓，还可以转化为更高级别的官星；寅木不动，丙申运冲动寅木做功——开厂做老板。庚寅为木器厂，辛丑为玻璃厂，子亥为数学和化学，子水有化工之象。一个申字把地支全引动。
  - 乙未运最辉煌：乙合庚，财合印主投资，几个印星几个厂；未代表寅，丑未冲印库开财库；子未穿，化工效益更好。
  - 甲午运：午引通寅，冲子做功。癸巳运：巳穿寅，不能干了，宜退休。
- **六亲**：「财临库地父当早死」——丑为财库，不开且合子为闭，所以父亲早逝；戌运丑戌刑，宫星俱坏父去世。

> 学点：**一个大运字把多个地支同时引动，就是多个行业、多个厂同时开张**。

## 七、判断步骤

1. 先定**什么代表钱**：财、食伤、食伤带财库、官杀，还是只有禄？依此定财富级别。
2. 看**是否有做功**：谁制谁、谁合谁，库是否被制被开。
3. 看**印的位置**：印在年时门户=门店、公司、工厂；印被破=没有单位，自己干。
4. 看**组合性质**：禄冲财（贸易、跑）、印合财（投资）、劫财合财（赌）、伤官合印（放大）。
5. 拼**行业象**：单字象+组合象，落到具体行业。
6. 看**运岁**：谁引动财库、谁破坏原局的功、谁让劫财夺财，逐步推应期。

## 本章小结

| 要点 | 内容 |
|---|---|
| 财富级别 | 财小，食伤大，食伤带财更大，官杀最大，禄为自用 |
| 生意组合 | 印合财/冲财/带财；禄冲财逢驿马；伤官合印放大；制库开库 |
| 劫财合财 | 喜投资好赌，赌必输 |
| 官杀库不开又无制 | 不当官，求财 |
| 应期 | 库被冲刑合开、财来合我、破原局的功则不利 |
| 父亲 | 财临库地父当早死，库被合闭、被刑冲打开为应 |

### 自测

1. 同是做生意，为什么官杀被引动的人，财富级别通常高于财星得用的人？
2. 印星在命局里，在什么位置、什么组合下代表「门店、厂子」？
3. 「劫财合财」为什么既主喜欢投资又主赌博不赢？
4. 命局里财库不开，通常在哪几类运岁里发财？

<details><summary>答案</summary>

1. 官杀由财所生，是财富升级成权势与规模，所以级别最大；财只是维持生活的养命之源。
2. 印落年、时门户，且与财相合、相冲或带财、包财局，则为门店、公司、工厂；有几个印星往往几个厂。
3. 劫财为手、为朋友，合财即把财引到自己手里，所以喜欢投资；但被劫合去的财不做功，赌博多输，只有做正经生意能赚（例三）。
4. 被冲、刑、合开库的运岁，如丑到刑戌开丑库、辰到冲戌库、丑未冲开财库。
