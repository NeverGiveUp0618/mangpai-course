# 四土辰戌丑未怎么论患（对照命理精讲）

> 我的问题（2026-11-09）：四土辰戌丑未怎么论患的？命理讲解里去找。

## 结论

1. **「患（换）」是命理精讲（大任／小任体系）的说法，盲派资料里没有这个词，也没有这套规则。** 盲派说的「害」就是「穿」的别名，六穿是子未、丑午、寅巳、卯辰、申亥、酉戌，**里面没有土与土之间的组合**。所以盲派那边没有「四土互患」可以对。
2. 命理精讲里，**四土能论患的只有四对：辰丑、辰未、戌丑、戌未**（阴阳不同的两个土）。辰戌、丑未是冲，不论患。这四对同时也论刑，是「既刑又患」。
3. 两边**相近的是「夹刑」**：盲派也说一方两个、一方一个的挤压，但只有两三个命例，没有阴阳划分，也没有「男怕、女怕」的口诀。**两边口径不同，不要互相套用。**

## 讲解

### 一、命理精讲怎么论患（四土部分）

**哪几对**
- 地支能患的：亥子、寅卯、巳午、申酉；**土患：辰丑、辰未、戌丑、戌未**。天干五患：甲乙、丙丁、戊己、庚辛、壬癸。
- ⚠️ 辰戌不患、丑未不患；这四对同时也论刑（丑戌未）。

**怎么论**
- 日干（命主）不参与患，日支可以参与；天干只与天干患，地支只与地支患，天干与地支一般不患。
- **年月相患应得早；年时相患跨度大**：主阶段性更替、长期慢性病，六亲陪伴久但体弱，不主早逝；**日时相患容易流产、伤子女**。
- 患的落点：两个印相患，换工作；两个财相患（男命），换对象。印是母亲，印相患直接换掉母亲的情况少，**大多是患病**；时上相患，小孩爱生病。
- 中间有通关字把两字连成一体，患力大减。例：寅卯害，中间有亥水连着，就不主克母，只主母亲体弱。
- 两个同阴阳的同字（如三个丁）不是患，是伏吟；丑戌既刑又患，不矛盾。

**命例（四土相患）**

**坤造**：辛乙壬庚／亥未寅戌

庚辛患（印，年时跨度大）＋未戌患（官杀，月时）。断：工作阶段性调整；母亲长期慢性病但寿不短；感情有更换。

### 二、和「阴阳夹刑」别混

命理精讲另有一条只用于四土的**阴阳夹刑**（只在原局论，不论运年）：

- 三个土字相邻，**两阳夹一阴或两阴夹一阳**，且中间字与两边有刑或冲（「未辰未」无刑冲不论）。
- 这里土的阴阳是**专用划分：未戌为阳（燥），辰丑为阴（湿）**，与天地阴阳诀（辰戌阳、丑未阴）不是同一套。
- 口诀：**男怕阴刑阳（两阴夹一阳），女怕阳刑阴（两阳夹一阴）**；中间那个字受刑最重。

**命例（1964，乾）**

**乾造**：甲甲辛乙／辰戌丑未

四库齐全。丑被戌、未夹（阳夹阴）⇒ 妻子常年体弱多病，他本人也坏根降格；戌是母，被辰丑夹 ⇒ 母亲身体不好但不严重；丑戌刑（母亲宫与婚姻宫相刑）⇒ 婆媳不和。「辰戌丑未全是帝王命」不成立，要拆开看组合。

### 三、对照盲派

| | 命理精讲 | 盲派八字 |
|---|---|---|
| 「害」是什么 | 「患（换）」是单独一种作用，含土患四对 | 害＝穿的别名，六穿里没有土土 |
| 辰丑、辰未、戌丑、戌未 | 论患，戌丑、戌未还论刑 | 初级只讲丑戌、未戌**刑**（用法同冲），没有「患」；辰丑、辰未的组合原稿没有单独讲 |
| 夹 | 阴阳夹刑，有土的阴阳专用划分和口诀 | **夹冲、夹刑**有说法但很简：一方两个、一方一个，不平衡则被夹者坏；夹刑是挤压，与冲不同论 |
| 刑与库 | 近刑坏库遁藏、远刑开库（十八道法门口径）；另有讲义说不分远近都开库，两说并存 | 近刑坏墓库中的遁藏、远刑开库；刑是开库、是制 |
| 害能不能开库 | 穿库开不了库 | 命例「戌酉相害，**害不能开墓**」，出不了门 |
| 病 | 患落在六亲和阶段性慢病（母亲、小孩、妻子） | 夹刑出现在「父母星临三刑、夹刑」，主克父母 |

**盲派两处原文（夹冲夹刑）**
- 丙壬壬庚／戌辰戌戌：「三戌冲辰」，一方两个、一方一个，不平衡，辰坏；若时上不是戌，相当于**夹冲**；夹刑是挤压，刑的角度不同，不与冲同论。
- 克父母六条里有「父母星临三刑、夹刑」。

⚠️ **待裁定**：
1. 命理精讲里同一份笔记，有一处把四土四对说成「可论合」，与「论害（患）」矛盾；命理精讲已按讲义改为论害，这里照录。
2. 盲派原稿没有「患」的说法，命理精讲这套土患规则、阴阳夹刑的男女口诀，**在盲派资料里没有对应原文，没有迁过来**。盲派遇到辰戌丑未，先按刑、冲、墓库、入墓去断。
