# 生也算做功吗？制得好与制得不好怎么判

> 我的问题（2026-11-12）：关于盲派，还是对制和做功不能理解。一个五行生另一个五行，也是做功？实在没办法判断什么是制得好、什么是制得不好？

## 结论

1. **做功不等于五行生克本身。** 做功是八字里的字「动手去拿一样东西」的过程。教材把做功分成五种基本方式：**制用、化用、生用（泄用）、合用、墓用**，再加复合结构。
2. **「生」算做功，但只在特定形式里算：** 化用（官杀被印化过来，杀生印、印生身）和生用（食伤生财、食伤泄秀）。教材没有写「任何相生都算做功」。
3. **生用、化用的效率比制用低**：制用约占四成，最常见；化用、生用各约一成。中级明说「制用高于生用、化用」，生用一般不发大财。
4. **「制得好不好」有五条判据：** ①谁有势（势均不制）②制得干不干净 ③作用方式的档次 ④该不该制（日主的根不可制等）⑤被制的东西大不大。
5. 教材**没有给分数或公式**，档次都是定性的；本篇只能把散在各处的判据合到一起，并用教材命例对照，**不是原书的一张总表**。

## 讲解

### 一、做功是什么，为什么「生」也可以是做功

**不讲用忌，只看做功**（初级 09 上）：八字是一个过程，看这个过程里谁动手、拿到了什么，不给每个字贴好坏标签。口诀：

> 不讲用忌，只看做功；去它而得它，制用得用。

三个基本词：**做功**＝十神之间相互作用、完成一件事的过程；**功神**＝参与做功的字（手）；**制神**＝被拿住、被处理的那一方（水）。

所以做功的方式按「取得东西的办法」分：

| 方式 | 内容 | 占比 |
|---|---|---|
| 制用（去用） | 比肩去财、伤官去官、食伤制杀、印制食伤、财制印；合冲刑穿克都属制法 | 约 40% |
| 化用 | 以印化官杀，多是当官的 | 约 10% |
| 生用、泄用 | 食伤生财（生着用）；食伤泄秀（用日主泄秀） | 约 10% |
| 合用 | 日干、日支合到财或官 | 约 10% |
| 墓用 | 利用墓库收藏、控制 | |

**「生」出现在这两处：**

**1. 化用（杀印相生）**——官杀太重，有印星把它「化」过来，杀生印、印生身。判断条件（初级 09 上）：
- 印要**紧贴官杀**才化得了，隔位就化不了；
- 印又要**紧贴日主**来生身；
- 有官杀有印不等于化用，化不了、化不净、结构不清纯都不算；
- 同性相生力大，异性相生力小。
- 化不了的那个字就是病，大运制病之运是升官之运（口诀：有病治病运）。

**乾造**：壬丙戊乙／寅午寅卯
大运：丁未 戊申 己酉 庚戌 辛亥 壬子 癸丑
寅杀被午火所化，丙午印又透干生身，年月日三柱是标准化用。但时柱乙卯正官，丙午化不了：卯与丙午隔位，且卯木不生午火反破之。乙木透时贴克日主是病。己酉运酉冲卯，制官去病，开始升官；辛亥运丙辛合绊功神、亥卯又会旺卯官，化用被破，官当不成，终为正处级。

**2. 生用（伤食生财）**——食伤生财，把自己的想法变成财富。

**乾造**：壬癸壬壬／寅卯子寅
大运：甲辰 乙巳 丙午 丁未 戊申 己酉 庚戌
全局水木之势，水生木，水木伤官格；寅中藏丙火财，内食神成格，大企业董事长。伤食喜见财，大运恰走财官，丙午运发财。

**生用的前提**：生财的字不能被穿、被合、入墓。

**乾造**：庚丁己壬／戌亥酉申
己坐酉食，酉生亥财，食伤生财本是好格局。但申穿亥、酉戌穿，把生财的字穿坏了，财与原神被毁，做功不成，无财无业。

> 规则：食伤生财的结构，最怕生财的字被穿、被合、入墓；做功的字坏了，象就坏了。

### 二、为什么说生用、化用效率低

- 中级「官命看法」：**化用不如制用效率高，所以化用的官级别不大**；化用只是印把官杀化走，制用能把对方制干净（如朱镕基造）。
- 高级「能量效率与正用反用」：制用效率最高。
- 生用一般不发大财，靠劳动创造财富（高级「体用宾主与看盘总纲」）。伤官偏性重时，去生财是效率最低的方式（笔记 3 已引）。

### 三、「制得好不好」的五条判据

教材原话：「制得干净与否决定效率」；「被制者制得好，做功效率高，层次高；没有制好，效率低，层次降低。还要看大小：效率高但被制者太弱，功也小。」（初级 09 下）

| 判据 | 内容 | 出处 |
|---|---|---|
| ① 势 | 相制双方都可以互制，**谁得势谁就制弱的一方，势均不制** | 初级 09 下·一 |
| ② 干净 | **制净、制死＝「贼捕」结构**；制不净的官杀**当财看**，不主当官 | 同上 |
| ③ 方式 | 库冲、库刑、巳申合最高，一般克制最低，**围克**是例外（被制者无处可逃，制得干净）；详见笔记 3 | 初级 09 下·四 |
| ④ 该不该制 | 体制用为正局，**制体自己生出来的东西为反局**；**日主的根不可制**（坐支的禄一定不能制）；甲乙**活木根不可伤**；六亲星得正位被制，伤那个六亲；**气势不能与日主意向相悖** | 初级 09 下·三；专题「体用与宾主作用」 |
| ⑤ 大小 | 被制的东西本身太弱，制得再好功也小 | 初级 09 下·三（五） |

**制得好不好，还决定大运怎么看**（初级 09 下·一）：制净、制死的，喜大运见到被制之神（贼）；制不净的，喜大运来补制（捕）。

### 四、教材命例：好与不好对照

**制得好：**

**乾造**：丙辛丁壬／午卯卯子
大运：壬辰 癸巳 甲午 乙未 丙申 丁酉
木火特旺，丙辛合，意在去辛金之财。丙坐午，午是丁的禄，丙去财等于日主自己取财，制得干净，发财。时上壬水是病，隔得远，到甲午运午直接冲去，病去发财。

**同一个盘，只差时柱：**

**乾造**：丙辛丁丙／午卯卯午
大运：壬辰 癸巳 甲午 乙未 丙申 丁酉
原局火已太旺，制得干净，捕神过旺，反而喜大运见**贼神（金水）**。午运缺乏效率，只在个别年份得财。同是制财，**原局有病，喜大运把病冲掉；原局已制干净，喜贼神入运**，两种结构大运喜忌相反，要先分清再断。

**制得不好：**

**坤造**：戊辛丁癸／申酉未卯
大运：庚申 己未 戊午 丁巳 丙辰 乙卯 甲寅
丁坐未得根，用自己的未、卯去制宾位申酉财，意向明确。但局中财旺，辛财又透月干，教材原话：**制得不好，效率低**。好在时柱癸卯「印带杀帽」，杀虚透，戊合癸，杀当财看；戊午运制杀得财，中富。喜火与燥土运，偏行金水大凶。

**制了不该制的（日主之根）：**

**坤造**：壬辛丁辛／子亥巳亥
大运：庚戌 己酉 戊申
丁坐巳，巳是丁的连根之体，金水官杀成党来制巳火，虽未制死，已伤日主之根。丙子年得白血病，丁丑年日主到位，亡。

### 五、拿到盘怎么用（本篇整理，不是原书编号）

1. 先看**谁有势**，势均就不制。
2. 再问**制的是不是该制的**：是宾位的用，还是日主的根、体自己生的东西、六亲星。
3. 再查**作用方式**在哪一档，制得**干不干净**。
4. 再问这是**制用还是化用、生用**，后两者效率本来就低。
5. 最后看**大运**：制净喜贼，制不净喜捕。

⚠️ **待裁定**
1. **没有「制得好」的分值或总表**：教材只有定性的档次和命例，别把本篇第五节当成原书的流程。
2. 「生财效率最低」一句出自中级「十神与宫位」的个别命例，教材没有把「生用一律不如制用」写成通则，只在官命部分明说了「制用高于生用、化用」。
3. 命理精讲那边这部分的口径我没有逐条对过，本篇不做对照。
