# 基础口径，像先对齐钟表与操作规则

## 一、同一张订单，先确认用的是哪套时间

一份订单写“凌晨交货”，有人按午夜换一天，有人按夜班归属记账。如果时间口径未对齐，后面流程算得再细，也可能从起点就分岔。

起运、交运、早夜子时，是本课先要辨清的输入规则。不同讲义有差别时，保留出处，不能把两套规则各取一半。

## 二、起运岁数：先讲这道计算在算什么

原课用生日距相应节令的天数差，除以3，余2进1、余1舍去；最小1岁、最大10岁，4天以内按1岁运，岁数取虚岁。这是该课粗略法，不冒称精确到时分。

例如天数差已知为11天，11除3得3余2，按该条取4岁。这里演示的是余数处理，前提是出生、节令及顺逆方向等输入已经核妥。

起运回答“从几岁开始”，交运回答“交接时间按什么口径定”，不是一个问题。

## 三、交运时间，看年纳音，别错看成日主五行

| 年纳音五行 | 本课所录交运时间 |
|---|---|
| 火 | 清明前三天午时 |
| 土 | 芒种后九天辰时 |
| 金 | 处暑当日申时 |
| 木 | 大寒当日寅时 |
| 水 | 冬至前三天亥时 |

原课“前三天”“后九天”包括节气当天，另载交运避忌，均属该段记录。不能因日主属火，就直接选火这一行。

## 四、早夜子时：日期与时干分别核

```关系图
本课子时口径，分开核两项
早子时0—1点 → 按当日早子时纳干
夜子时23—24点 → 仍先辨当日，时干从早子时数一圈后纳
日期交界 → 本课按24点换日
= 另章若有不同说法，保留并列，不混成一张排盘表。
```

原课乙日早子时为丙子，排完一圈，夜子时为戊子。读例子时把“换日”与“排时干”写两行，就能避免只记一个“子时算哪天”。

## 五、能量与效率：设备很多，业务为何还不通

车间设备齐全，却有两台互相卡住工序，另一台总损坏关键零件。问题不是简单“设备少”，而是哪些起作用、哪些闲置、哪些妨碍流程。

原课据此分功神、废神、起坏作用的字；普通结构常见无效环节多、效率低、功神受损。巳申合、库冲、围克等效率比较，也须在确实成势、有目标时谈。

## 六、正向反向，与正局反局，要分开

```关系图
两组“正反”，问的问题不同
正向、反向做功 → 体用在宾主的什么位置，怎样取得
正局、反局 → 日主意向与全局主要作用是否一致
大运反局 → 运中是否损坏所用、扶起所制，使原功改变
= 位置相反不等于意向相反，不能把“反用”直接叫坏局。
```

一家店原本需要清理库存，店主却继续追加同类货，方向就打架；另一家只是通过外部团队管理自家资源，位置虽不同，目标仍可一致。

回原课练习时，分别写“位置怎样分”和“方向是否合”，就不会用一个“反”字包办结论。

## 常见误区 vs 正确问法

| 常见误区 | 正确问法 |
|---|---|
| 查交运时间时，按日主五行去对应表格里的金木水火土 | 交运时间看“年纳音五行”，不看日主五行；起运与交运要分开核对 |
| 把“早夜子时”混成一套，或只记“子时算第二天” | 先按24点核定当日，再区分0—1点早子时与23—24点夜子时的排时干规则 |
| 见到“反向做功”（体在宾、用在主）就直接叫成“反局、坏局” | 反向做功问的是体用位置怎样分布；反局问的是日主意向或大运是否与原功打架 |
| 一看见大运与原局有合冲，就不问原本在做什么功而直接断反局 | 先查原功靠冲还是靠合：原本靠冲做功，运岁来合绊才可能构成反局 |

## 实战对照

- <a class="qref" data-q="152">命例 152：坤造 辛未日 · 原局是制财库，故此命发大财</a> —— 原局以丑未冲制财库为功，行至己巳运甲申年岁运天地合绊住两党，构成大运流年反局，印证“原本靠冲做功，最怕合绊反局”。
- <a class="qref" data-q="153">命例 153：乾造 丁未日 · 为内外两党，支食神穿杀为功</a> —— 月日与年时分成内外两党、一致对外制杀，印证“分清党势、功神与日主意向一致”的正局读法。
