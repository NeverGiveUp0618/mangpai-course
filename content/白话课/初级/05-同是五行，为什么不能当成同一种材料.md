# 同是五行，为什么不能当成同一种材料

## 一、买来一盆树，与买来一张木桌

店门口的树蔫了，你查根与浇水；木桌缺了一块，你找木工修补。都叫“木”，需要的处理却不同。

本课先练这个分辨：**同属一个五行，还要看具体字、所处环境与作用。** 甲乙、丙丁、戊己、庚辛、壬癸，都不能只凭五行标签混着用。

## 二、活木的关键，是支持能否真正送到根

每天倒水，水却流进排水沟，树仍得不到。附近有水，与根得到水，是两回事。

```关系图
按原课主要口径，先辨活木条件
有根 → 再看水能否真正生到根
有水 → 还要查有没有可生的根
根与水都落实 → 才按活木继续看季节与作用
= 原课另录死活木的不同定义，仍须结合具体段落读。
```

月、日、时贴近的根与远在年的根要分开，虚弱的天干水未必够用。甲辰、乙亥有其配置；甲子不能仅凭坐水就当有根，子卯还有破。活木可讨论甲乙共根，死木不能照搬。

活木喜生养、合适的火秀气，怕金伤根；死木可由金加工，却怕旺火烧尽、旺水腐坏。还须看季节、燥湿与程度，不能把“木喜水火”当无条件喜好。

## 三、十天干：给每一种字留出自己的性情

| 字 | 记忆画面 | 继续辨的条件 |
|---|---|---|
| 甲 | 大树、栋梁 | 死活、根、季节 |
| 乙 | 花草、藤蔓 | 依托与生长条件 |
| 丙 | 太阳、显露 | 过旺、衰弱、湿土晦火 |
| 丁 | 灯光、文字灵光 | 木助、旺水、丁巳连根 |
| 戊 | 大地、堤岸 | 季节燥湿、丙火作用 |
| 己 | 田园 | 丁午之助、金水配合 |
| 庚 | 粗金、工具 | 有根顺用与弱时逆用 |
| 辛 | 精细饰品 | 厚土埋金、夏癸冬丁 |
| 壬 | 江河 | 通源流绝、寅卯差别 |
| 癸 | 雨露 | 力量与去向，弱从木火、旺可制火 |

这些画面帮助记性质。实际取职业、心性等象，还须组合；庚的顺逆用法、辛见壬癸子亥的区别，也要回原课细读。

## 四、四个土，像仓库，但不是四间一模一样的房

干燥储物间与潮湿冷库都能存货，放同一种东西，效果却不同。

```关系图
四土，先分燥湿
戌、未：燥土 → 克水，不按普通土生金来用
辰、丑：湿土 → 晦火、生金，帮土力另论
= 同是土，不能用一句“土生金”全部包办。
```

晦火等细目，原课不同段落有表述差别，仍保留原处。四库的收纳也有规则：先记亥入辰、寅入未、申入丑、巳入戌；子午卯酉一般先辨半合，多而墓之等另有条件。

## 五、地支还要看内部、环境与合作对象

员工换了部门，实际参与的业务可能改变。巳属火，遇金土成势及酉丑等配合，原课有随金党作用的情形；要看环境怎样改变作用，不能一律读成火克金。

子与亥同属水，生木的方式与力度仍有差别；子寅与子卯也不同。支中所藏、合冲穿刑，都要接着看。

## 六、这一课怎样学，才不会只剩十张人物卡

每次选一个字，写三句：它是什么性质；此处怎样作用；什么条件一变，原判断便不能用。

比如“庚喜水”，要补有无根、水是否有用；“木喜水”，要补死活与水能否到根。能把条件补全，就比只背喜忌多懂了一层。
