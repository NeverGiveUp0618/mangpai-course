# 同是五行，为什么不能当成同一种材料

## 一、买来一盆树，与买来一张木桌

假设你开了一家小店。门口的树叶子蔫了，你先检查根、土和浇水；店内的木桌缺了一块，你找木工修补。两者都叫“木”，处理办法却不同。给桌子浇水救不活它，把树根锯掉也不能称为修理。

这个故事只解释“同一类中仍须分类”。教材对甲乙木分死活，还要辨丙丁、戊己、庚辛、壬癸，不能只背五行生克就跳过字的具体条件。

## 二、活木的关键，是支持能否真正送到根

店主每天向门口倒一杯水，可水全流进旁边排水沟，树没有得到。生活上“附近有水”与“根能得到水”已经不同；回到教材，也不能看到水木同盘就宣布活木。

原课先查根，再查水是否能生到。月、日、时贴近的根与远在年的根要区分；一点虚弱的天干水未必够用。甲辰、乙亥有其干支配置，甲子不能仅凭坐水就当成有根，子卯还有破的关系。活木可讨论甲乙共根，死木不能照搬。

活木喜生养、喜合适的火来秀气，怕金伤根；死木另按木材之性理解，可有金来加工，却怕旺火烧尽、旺水腐坏。具体还要分季节、位置和全局作用。“活木都喜火”也不能脱离春夏秋冬、燥湿和是否过头来用。

把盆栽故事反过来检验：我只知道“它是木”，还缺什么？缺根在哪里、水能否到、季节、火金如何作用。缺这些就先停在分类，别急着断结果。

## 三、十天干：给每一种字留出自己的性情

| 字 | 生活画面，帮助记忆 | 回到原课时要补的条件 |
|---|---|---|
| 甲 | 有主干的大树、栋梁 | 死活、根与季节，不是见甲就高大成功 |
| 乙 | 花草、藤蔓 | 依托与生长条件，不能直接套甲木的加工方式 |
| 丙 | 太阳照见众人 | 名气、显露；过旺、衰弱与湿土晦火都要看 |
| 丁 | 灯光、文字中的灵光 | 喜木相助，怕旺水；丁巳连根不能任意坏 |
| 戊 | 大地、堤岸 | 季节燥湿及丙火的作用；夏燥土不宜再机械添火 |
| 己 | 田园、可耕的土 | 丁午之助与金水的配合，不能混作戊土 |
| 庚 | 粗金、工具材料 | 有申酉根时的顺用，与弱时木火逆用要分开 |
| 辛 | 饰品、已加工的精细之物 | 不宜厚土埋没；夏癸冬丁、壬癸子亥不能混同 |
| 壬 | 江河、有来路的水 | 通源与流绝、寅卯的差别，不是木都能同样承接 |
| 癸 | 雨露、细水 | 有力与否及去向，弱从木火、旺可制火须看结构 |

这些是教材取象的记忆入口，不是现实中太阳、灯具、土地的科学模型。人物的性格与职业也不能只凭一个日干从表中挑选。

## 四、四个土，像仓库，但不是四间一模一样的房

小店有干燥储物间，也有潮湿冷库。把怕潮的工具放错地方，虽都叫“存起来”，效果并不相同。

原课分戌未为燥土、辰丑为湿土。燥土克水而不按普通土生金来用；湿土有晦火、生金等特点，帮土的力也另论。这正是不能拿一句“土生金”包办四土的原因。教材不同段落对晦火的表述有差别，仍须回原处核对，白话故事不替异文定案。

四库也不能把同类字不加区别地收进去：入门先记亥入辰、寅入未、申入丑、巳入戌；子午卯酉一般先辨半合，多而墓之等另有条件。详细的收纳规则留到第十三课。

## 五、地支还要看内部、环境与合作对象

一名员工单独工作，与加入另一部门后的实际角色可能不同。巳虽属火，遇金土成势及酉丑等配合，原课有随金党作用的情形；不能固守“火只会克金”，也不能反过来说“巳永远是金”。

子与亥同属水，也不等价。原课对子生木与亥生木、子寅与子卯、四正之间相生的力度另有辨析。辰丑与戌未也须看支中所藏、合冲穿刑，而不是只看标签。

## 六、这一课怎样学，才不会只剩十张人物卡

回原课选一个字，写清三件事：它是什么性质；在当前环境中走哪种作用；哪一个条件一变，原判断就不能用。比如“庚喜水”要追问有无根、水是否有用；“木喜水”要追问死活及水能否到根。

学到的不是把所有人分成十种性格，而是养成遇到同类仍检查条件的习惯。十干细目、十二支与四季配置较多，可以分几次回原课读，本课提供的是逐项辨认的路线。
