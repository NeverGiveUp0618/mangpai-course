# 刑破墓库，像多方牵动和资源收纳

## 一、第三个人加入，未必只是多一份帮助

两位合伙人原来互相约束、分工清楚，第三个人加入，却使原来的安排失效。成员更多，事情反而做不成。

这帮助理解三刑不能只当几组两两关系的简单加总。本体系主要论寅巳申、丑戌未，不取辰午酉亥自刑；子卯在这里归破。

## 二、先拆关系，再看三者齐全的改变

寅巳按穿、巳申按合、寅申按冲；三者齐现，刑的意思才明显。丑未按冲，丑戌、未戌按刑；丑戌谁制谁看金水与木火党势，未戌则有引旺火、制金的特性。

原局丑戌刑或丑未冲若在做功，再来第三字，可能把原来的功破坏。不能说“多来一个刑，所以制得更好”。近刑伤库中物、远刑开库，还要区分位置与所用之物。

## 三、破与害：别把每个动作都当做功

柜子磕破一角，可以说明有破损，却不能因此说它完成了一项业务。原课破偏重不完整、漏洞、破耗等象，通常不作做功。

子卯、卯午要认清；子酉不列破。午酉破是否成立、是否因午制酉而做功，原稿有不同说法，保留原处。运中再来破也不能自动解原破；害则是穿，不必另造一套规则。

## 四、墓库：收进去，是谁在控制谁

货被收入自家仓库，可能是自己取得；自己的机器被别家统一收管，也可能是行动受限。都叫“收进去”，归属与效果并不相同。

```关系图
遇到墓库，沿收纳关系追
收的是什么 → 财官、做功之字，还是代表自身的依托
收到哪里 → 主位还是宾位，哪一方掌握它
能否拿出来使用 → 有无刑冲、合闭及其他限制
= 收藏、得到、控制、受限，要按具体关系分别解释。
```

辰戌丑未为四库，“冲则为库、不冲则为墓”是原课入门提法；不能据字面把所有入墓都直接读成死亡。

## 五、五条入墓原则，像不同的收货规定

| 原则 | 先记的条件 |
|---|---|
| 长生入墓 | 寅入未、申入丑、巳入戌、亥入辰 |
| 多而墓之 | 同类干支相连而多，查是否按入墓处理 |
| 天干坐墓不直接入 | 辛丑、壬辰等坐根，不能见库便说干被收没 |
| 地支土另辨 | 丑未入辰、辰戌冲等须看原局与运岁条件 |
| 夹墓不入 | 两墓夹住中间之字，有特别处理 |

子午卯酉一般先作半合；中神双现或特别弱等，再按原课条件辨入墓。辛酉见丑、申酉相连见丑与两字远隔，处理会不同。戊己随所坐火一起入戌，也不是天干土无条件入墓。

土的收纳尤其不要省步骤：丑未同现相冲，与原局已有辰丑、运中再见未，并非同一种情况；水土共见等段落还有字词存疑，回原处核对。

## 六、把口诀放回整件事

财官临库喜刑冲，仍要看是打开、制取还是损坏依靠；食伤入墓的“不自由”也须联系所代表的人事与原例。禄入墓做功小，讨论的是作用状态。

这一课学会四个区别：**刑是怎样牵动，破表什么象，害就是穿，墓库由谁收管什么。** 名称认清后，仍要追功效。

## 常见误区 vs 正确问法

| 常见误区 | 正确问法 |
|---|---|
| 见到寅巳申或丑戌未三刑，就当“刑得越多越能制” | 原局两组已有功时，再来第三字往往破坏原功；先拆两两关系，再看三者齐全是成势还是搅局 |
| 见到辰午酉亥自刑，按“自己跟自己过不去”照套 | 本体系不取辰午酉亥自刑，子卯归破；先按本课所列关系核对，不混入别家规则 |
| 见到“入墓”就直接断成死亡、完蛋或没用了 | 先问收的是什么、收到主位还是宾位、有无刑冲开库，分清收藏、控制还是受限 |
| 天干坐墓（如辛丑、壬辰）直接按天干入墓算 | 天干坐根不直接入墓，须先看五条入墓原则与隔位、连排条件 |
