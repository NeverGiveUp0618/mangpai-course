# 先把八字当成一张关系图

## 一、先看一家早点店怎样活下来

小林想开早点店。他会包包子，有积蓄，租了铺面，姐姐帮忙配送，附近住户愿意来买。

判断店能不能开成，你会看供货、制作、送货、收款怎样接起来，而不只问小林力气大不大。八字也从这里入门：**看人与资源怎样发生作用，事情怎样做成。** 不以日主旺衰定全部，仍须比较具体作用中的力量。

## 二、理法、象法、技法：分别回答什么

继续看这家店：

- **理法看怎样运转**：有原料，能加工，送得到，收得回钱吗？
- **象法看做的是什么**：同样接单交付，卖包子、写文章、做法律服务，内容不同。
- **技法看具体细节**：进一步细断人物、事项与时间，要用相应经验和条件。

三者配合，先把业务读通，再把事情说具体。

## 三、宾主：先确定现在站在谁的位置

问小林怎样经营，就站在小林这边，看他怎样联系客户与供货商；若改问姐姐的业务，就要重新确定观察中心。

宾主分的是观察位置。八字最常从日柱看自己与外部的关系；也有日干对其余干支、日时对年月、原局对运岁等层次。**先定一层，再谈关系。**

对面超市很赚钱，小林却不能把营业额算成自己的。超市向他订货、付款，或由他实际管理，双方才有联系。宾位有财官，也要追问怎样归到主位。

## 四、体用：我拿什么，去得到什么

```关系图
小林开店，分清三件事
手艺、劳动、店面 → 本钱，帮助理解“体”
订单、收入、管理机会 → 目标，帮助理解“用”
制作、交付、收款 → 连接本钱与目标的作用
= 有本钱、有目标，还要看中间怎样接上。
```

原课中，日主、禄、比劫、印常作体；财、官杀常作用；食伤可体可用，食神偏体、伤官偏用。这是常见分工，具体须看组合。

包子全堆在后厨，没有卖出，便还缺了交付这一步。学体用，也要补上中间的动作。

## 五、做功、功神和废神：忙碌与成果怎样区分

配送员跑了一天，却总送错地址；另一位员工只改了核单流程，错送便明显减少。前者很忙，后者的动作却真正改变了结果。

功神要沿作用关系找：谁参与做事，谁辅助，处理了什么。它常涉及两个以上的字，不能只挑出现最多的一个。废神则指在所论结构中没有形成所需的功，不是评价现实中的人有没有价值。

## 六、能量、效率与贼捕：有能力还要有用武之地

维修队工具齐全，却没有活可干；来了一个能修好的故障，能力才有了落点。如果设备根本修不了，故障越多，负担反而越大。

```关系图
先问：这个目标，处理得了吗
已制净，处理能力有余 → 再来可处理的目标，才有施展余地
原先就处理不了 → 目标增加，可能只是负担增加
= 捕是制的一方，贼是被制的一方；制净后才谈“喜见贼”。
```

能量看有没有力量，效率看力量怎样落到对象上。还须看势、方式、目标大小与是否制完整，人数与忙碌都不能直接代替效率。

## 七、正反、功象，以及读盘的第一句话

正向、反向做功，区分的是体用在宾主的分布；正局、反局，讨论的是意向是否一致。两组概念要分开，也都不能拿来评价做人好坏。

有功先追作用；无明显功再看象；两者都有则合看。把第一句判断说完整：**谁，用什么方式，作用于谁，结果怎样，与主位有什么联系？**
