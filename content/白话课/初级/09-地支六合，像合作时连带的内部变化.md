# 地支六合，像合作时连带的内部变化

## 一、签了合作协议，连带改变什么

两家小店合作，一家送货、一家收款。订单增加了，但收款权限也交给对方；合作既带来帮助，也可能让某项资源暂时不能自由使用。

六合比五合的内部情况更复杂。六组是：子丑、寅亥、卯戌、辰酉、巳申、午未。原课把它看成紧密联系，一般不谈化；紧密，不等于双方所有部分都受益。

## 二、助合、克合、闭气、合伤，要分别看

```关系图
合作之后，分四层观察
得到帮助 → 谁被生助，谁因付出而泄力
受到约束 → 哪一方被克制，是否形成做功
资源封住 → 库中哪一种气因合而闭
内部受损 → 外面合作，里面某个藏干却受伤
= 一组合可以兼有几层效果，不能只读最顺眼的一层。
```

仓库与商店合作后，把一批货锁在专用区。货还在，却不能随时提取，帮助理解“闭气”。原课开库另论刑冲，不能把穿当作同一种开法。

## 三、六组各有侧重

| 合 | 入门先抓的差别 |
|---|---|
| 寅亥 | 生寅，也有亥中壬伤寅中丙的内部变化 |
| 卯戌 | 卯制戌，并闭戌中火 |
| 辰酉 | 生酉，同时伤辰中乙、闭辰中水 |
| 巳申 | 互有制意，谁得势谁制；单独相见不能直接认制净 |
| 午未 | 亲近成党、增火与闭木库，不按制法论 |
| 子丑 | 子被绊、丑库也闭，好坏两面都要查 |

原课午未与燥土晦火等表述仍有差别，保留原处，不用生活故事统一口径。

## 四、同一子丑合，为什么有两种影响

把捣乱的人留在仓库，店面安静了；但仓库门也被锁住，取货受阻。一个安排，可能同时绊住毛病和需要的资源。

子丑合便要分别看子与丑在本局干什么、大运扶哪一方。若要开丑库，原课说须冲丑；冲子使子不再合丑，与直接冲开库不同。

所以“坏字被绊了”只说完一半，还要补“被一并绊住的好东西，是否仍能用”。

## 五、原局、运、年，联系的时间层次不同

长期合作中双方职责被固定，与某一年到场签约、发动一件事，是不同层次。

原课通常以原局紧邻、大运相合论绊，流年合旺支论动或留；天地合又有合绊的专门条件。另稿有“六合统称合绊”的表述，两说仍留在原课。

婚姻合留也须查配偶星宫是否相应，得正位与偏星受制的条件不能省。六合换象同样要沿实际关系读，不能把所有“亲近”都译成感情好。
