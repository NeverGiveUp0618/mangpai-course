# 天干五合，像签约之后的不同结果

## 一、都说“谈好了”，结果可能完全不同

一家小工作室被独家签走，不能再自行接单；两家公司互相卡住进度；准备离职的骨干被续约留下。三件事都有联系，效果却是控制、牵绊、留住。

五合也先认配对，再辨效果：甲己、乙庚、丙辛、丁壬、戊癸。原课天干只论合，不以合化改变原来五行性质。

## 二、合去、合伤、合绊：别把效果混成一个词

```关系图
同一个“合”，先看力量关系
力量悬殊 → 可论合去，弱方被制
有差距但未到悬殊 → 辨合伤，仍查根与原神
双方力量相当 → 可论合绊，彼此行动受限
= 具体归类要看支持与全局，教材没有统一的个数或分值门槛。
```

独家合作中，对方仍保留业务渠道，与彻底受控不同。合伤也可能待运岁条件到来才进一步成事，不能看见合就宣布制尽。

合绊更要问被绊的是谁：唯一能送货的司机被拖住，交付受影响；持续捣乱的环节被约束，整体可能受益。功神与所要去的对象，不能同断。

## 三、合留与合动：联系也能使事情发动

学校续约留住准备离职的老师，帮助理解“留”；项目负责人到场签字、工程开始执行，帮助理解“动”。

原课流年合旺干，可分应人的合留、应事的合动。看婚姻时，星动与星宫同动也有区别：谈对象与正式结婚，不能只凭一个合混成同一件事。

原局、运、年各有语境。先标出是哪一层发生合，再谈牵绊、留住或发动。

## 四、换象：同一项能力，接上不同对象

会表达的人加入研究机构，表达与学问结合；同样的表达用于技术培训，又形成另一种职业内容。关系让能力有了具体去向。

原课食神合印，可取思想、学术；伤官合印，可取技艺、职业；伤官合官杀，可借管理、规则等意思；劫财合财，可读争取资源的过程。

先说明哪个十神怎样作用，再取所合出来的象。不能为了断某种职业，先从两个字各挑一个含义拼起来。

## 五、遇到变化，重新查这条联系

独家合同虽在，关键负责人离开、权限被收回，原先的合作效果也会变。八字中也须检查根、原神、冲克等是否改变合的条件。

完整读法是：**谁与谁合，力量如何，主要是合去、合伤、合绊还是合动，影响了哪个功神或目标？** 原课涉及六亲的重断，还要星宫等条件齐备，不能单拿一个合去推及现实人物。

| 五合结果 | 常见条件 | 读盘抓什么重点 |
|---|---|---|
| 合去 | 双方力量悬殊 | 弱方被制，看被去的是毛病还是用物 |
| 合伤 | 有差距但未到悬殊 | 查根与原神，看运岁能否补足制力 |
| 合绊 | 双方力量相当 | 看被绊住的是功神还是坏字 |
| 合留 / 合动 | 流年合旺干等应期 | 分清是留住人还是发动一件事 |
| 换象 | 不同十神相合 | 先认作用，再读出新的职业或能力象 |

## 常见误区 vs 正确问法

- **常见误区**：看到甲己、乙庚等五合，就按“变成另一种五行”来算，或者看见“日主合财”就一定断发财。
  **正确问法**：天干五合只论合不论变性；先比双方力量与根气，看究竟是谁合制谁、谁被绊住。
- **常见误区**：在流年看到一次五合，就直接断结婚或定某件事已成。
  **正确问法**：分清原局、大运、流年所在层次，查清星与宫是否同动，再判是合留、合动还是合绊。

## 实战对照

- <a class="qref" data-q="20">命例 20：乾造 甲寅日 · 与自己有关系，我自己要做一件事</a>：流年甲己合到日主自己，表示由自己出面动手做成一件事，配合地支卯申合到位，清晰展示五合在应期里的“合动”用法。
- <a class="qref" data-q="77">命例 77：乾造 丙戌日 · 日主丙火合辛财，要看身强弱</a>：日主丙火虽想合辛财，但自身根气受损、财官反重，说明不能只看“合财”两个字就断富，还要看力量对比与根基。
