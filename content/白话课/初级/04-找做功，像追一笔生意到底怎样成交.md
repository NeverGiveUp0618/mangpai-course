# 找做功，像追一笔生意到底怎样成交

## 一、一家店有招牌、有工具，为什么还没有赚到钱

两家修车店都摆着工具，都写着“专业维修”。甲店有人接诊、有人查故障、有人修复，客户确认后付款。乙店三个人不停争论换不换零件，车却一直不能交付。

外观相似，真正做成的事不同。读这一课，先练习沿着一件事追动作，而不是听见一个好名称就下判断。

原课先功后象：有功先找功；无明显功再看象；两者都有则合看。招牌能告诉你店的性质，却不能代替交付结果。

## 二、为什么先从日干、再从日支入手

### 先看本人主动追求什么

店主正在谈收购一间铺面，你先看这笔签约；若他没有签约，却亲自设计维修方案，你就看他的产出接下来被怎样使用。

对应原课的入手顺序：先看日干有无合；没有合，再看贴近的生与食伤；没有合生，再看是否在势中。日干无功，不等于整个人没有作为，要继续看坐下日支，以及其他代表自身的禄、比劫、印等。

### 本人没站在柜台，不等于没有业务

店主外出办事，自己的店仍在运转。日支可代表日干的躯体与实际依托，坐下发生的功也要看。若日干只是谈意向，地支完成了主要业务，就不能只盯日干一句话。

原课对干支同做功而意向不同有处理原则：不是两边的好处随意相加。先把主次与意向说明白，再定从哪一处读。

## 三、势：同向配合，比单纯人多重要

甲店三个人各司其职，乙店六个人各争一个方案。说“乙店人多，所以一定更强”，忽略了能否一起做事。

原课称势为党、团队，分主要功神与辅助功神。有共同作用目标、能在结构中配合，才讨论党势。木火、金水、水木、火燥土、金湿土、水湿土等，是教材列出的成党方向；不是看到两个五行相生就无条件认定合作成功。

| 原课的两党 | 在制局中观察的方向 |
|---|---|
| 木火 | 制金，并兼看金中所含 |
| 火与燥土 | 制水、金、湿土及相关所藏 |
| 金水 | 制火、燥土及相关所藏 |
| 金与湿土 | 制木火 |
| 水与湿土 | 制燥土或火 |
| 水木 | 制土及相关所藏 |

这些方向是规则卡，不是由修车常识推出来的。月令、距离、合会与被制方的支持仍会影响能不能做成；不能数相同五行个数就算完。

## 四、同一班人，换一个目标，结果可能相反

甲店擅长修普通家用车。若接到远超设备能力的重型机械，并非店员突然变笨，而是原来的处理能力不够应付这个目标。

原课强调有势还须做功，有对象还须制得住。只有势没有目标，没有落点；有动作却势不够，可能只是对抗和消耗。不能把成势、制成、制净说成一个词。

反过来，店员为提高效率，把每天必用的唯一检测设备卖掉，眼前收了一笔钱，却坏了后续维修能力。这帮助理解“动到自己所依靠的根”与“处理外部目标”不同，不能见制财或得财意向就一概论好。

## 五、层次：规模、效率与自己怎样参与，都要交代

一家人靠自己每天修几辆车，能维持收入；另一家有团队和稳定渠道，自己负责核心管理，规模更大。原课区分不同体参与做功，禄、比劫、印、食伤所表达的工作方式与忙碌程度不同。

这不是现实职业高低的评价。白话上先观察：成果靠亲力亲为、专业技能，还是组织与资源管理；动作花了多少力气，控制了多大对象，是否归到主位。

“富贵、普通、差”在教材是结构层次分类，不能拿店铺大小直接反推某人命盘。教材中的资产与职位数字是原例断语，不是这门白话课承诺可精确计算的收入表。

## 六、给一个判断补全因果链

拿原课例子练习时，先写：谁是主要做事者，谁辅助，目标是谁，用合、冲、穿还是其他方式，为什么能形成效果，主位怎样取得。

例如只说“有巳申合”还没讲清楚：是哪一方得势、谁制谁、有没有被其他关系破坏、作用怎样归到自己？这些空白要补原课条件，不能用生活故事里的职位和财富替代。

本课的体悟是沿着业务链找真正改变结果的环节。至于原课关于主位是否必须在势中等不同表述，继续保留原处存疑，不以一个店铺故事替它裁定。
