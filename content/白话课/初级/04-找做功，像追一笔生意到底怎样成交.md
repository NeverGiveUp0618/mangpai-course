# 找做功，像追一笔生意到底怎样成交

## 一、一家店有招牌、有工具，为什么还没有赚到钱

两家修车店都有工具。甲店查故障、修好、交车、收款；乙店不停争论换不换零件，车迟迟交不出去。

看做功，像追这条业务链：招牌说明店的性质，交付才说明事情做成没有。原课也是有功先看功，无明显功再看象，两者都有则合看。

## 二、为什么先从日干、再从日支入手

店主亲自签约，先追这笔签约；没有签约，却在设计方案，就追方案接下来怎样被使用。本人不在柜台，也要看店里是否仍在运转。

```关系图
先追日干这条线
有合 → 看追求何物、能否得到
无合而有生 → 看贴近的食伤怎样做功
无合无生而有势 → 看这股势怎样做功
日干无功 → 继续看日支及其他代表自身的体
= 这是入手顺序；地支若另有大功，仍须综合判断主次。
```

日支是日干的实际依托，坐下的功也要追。日柱干支都无功，再查其他柱的禄、比劫、印等。干支同做功却意向不同时，按原课原则处理，不能把两边好处任意相加。

## 三、势：同向配合，比单纯人多重要

三个人分工接得上，可能比六个人各争一个方案更有效。势像团队，要辨谁主做、谁辅助，以及共同处理什么目标。

| 两党 | 原课制局的观察方向 |
|---|---|
| 木火 | 金及相关所藏 |
| 火与燥土 | 水、金、湿土及相关所藏 |
| 金水 | 火、燥土及相关所藏 |
| 金与湿土 | 木火 |
| 水与湿土 | 燥土或火 |
| 水木 | 土及相关所藏 |

这是教材规则对照。月令、距离、合会、目标方的支持，会影响能否做成，不能只数同类字。

## 四、同一班人，换一个目标，结果可能相反

修家用车的队伍，接到超出设备能力的重型机械，原来的能力未必够用。因此要分三步：**能否成势，能否制住，是否制净。**

反过来，若为收一笔钱，把唯一的检测设备卖了，后续业务便受损。这帮助理解：处理外部目标，与破坏自己依靠的根，后果不同。

## 五、层次：规模、效率与自己怎样参与，都要交代

一家店靠店主每天亲手修车；另一家有团队与渠道，店主主要管理。先辨成果靠什么取得，再谈规模与效率。

原课区分禄、比劫、印、食伤等体的参与方式，也看控制多大对象、花多少力量、成果怎样归主位。这是结构分析，不能把现实店铺大小直接反推命盘，也不能把原例中的财富数字当统一计算表。

## 六、给一个判断补全因果链

读原课例子，依次交代主要做事者、辅助者、目标、作用方式、成败原因及主位如何取得。

只说“有巳申合”，还缺谁得势、谁制谁、是否受破坏、怎样归到自己。把这些接起来，才读懂做功。主位是否必须在势中等不同表述，仍保留原课存疑。
