# 婚姻与看寿，先分人物、位置和关键依托

## 一、同一所房子里，谁是谁，要先认清

一所房子由谁居住、登记在谁名下、谁承担日常事务，是不同信息。光看某个人出现过，不能就确定他是伴侣。

本课先分配偶宫与配偶星：日支是配偶宫；具体哪一星作配偶，要看它与日主、夫妻宫有没有相关作用，以及是否入主、得正位。

## 二、先定星宫，再看关系发挥什么作用

```关系图
看婚姻，先补三层信息
位置 → 日支夫妻宫里是什么
人物 → 哪个星与日主、夫妻宫真正相关
作用 → 是支持、制取、受损，还是另有联系
= “某星出现”还没有完成“这个人是配偶”的定位。
```

原课女命坐财官可取夫象，印要看有无官，食伤又须结合制官；男命坐财食伤与坐官杀，也要分有无财等条件。名单提供线索，关系才完成定位。

夫妻宫原来有用而被坏，与原来起坏作用而受到处理，不能同读。配偶星得正位、被他合、混杂多现，也各有条件。

## 三、多处出现，可能是多处家，也可能有别的关系

一对夫妻有老家、工作地住房和临时宿舍，地点多，不代表伴侣一定多。原课也有夫妻宫双现而婚姻好的例子。

所以“遇合一般断二婚”与“多合不一定多婚”，必须保留两说。婚姻次数还涉及伏吟与杂现的区分、起坏作用的字及先后顺序；原课水1与6、火2与7、木3与8、金4与9、土5与10等取数，只能连同其命例读，不能机械数星报次数。

## 四、关系不稳、桃花与关财门，先辨变化链

朋友交往多，与关系越界，是不同问题。原课桃花、混杂财官、食伤、禄被合等条目，须查与配偶宫及主位的联系，不能只凭社交频繁贴标签。

“关财门”一段把财作官的原神，分官财原本轻重，再看劫财如何改变支持；“患夫患妻”又分杂出重患与伏吟轻患。晚婚、婚前波折、分居与离婚，并非每一段都只能落到同一种结果。

## 五、看寿部分，学习它在追哪条依托

一台设备靠电源、控制线路、散热运转。电源就在机内，与外面另有备用电源，依托不同；线路只受影响，与整条供应中断，也不同。

这个画面只帮助理解原课为什么追根、禄、原神与连续作用，不提供现实健康判断。

| 原课线索 | 读时必须补的条件 |
|---|---|
| 食神作寿元星 | 在本局是否承担该角色，是否有效 |
| 禄与连根 | 位于年月、坐下还是时上，有无连体 |
| 水的通源与流绝 | 先有源头，才讨论是否流绝；归库另论 |
| 木的死活与火 | 先辨死活、根与水，再辨火的作用 |
| 空亡 | 查所在、填空与原例，不据单词报寿数 |

## 六、保留反例，才知道自己还缺什么

食神落空亡的寿数提法，原课同时保留反例与不同说法；坐下连根与时上单禄的处理，也不能混在一起。它们都不能压成“见某字就断某年”的图表。

回看原命例时，写清关键依托是什么、怎样受影响、运岁又改变哪一环。身体与寿数相关断语停留在原资料的完整语境，不用生活比喻替它增加确定性。

## 常见误区 vs 正确问法

| 常见误区 | 正确问法 |
|---|---|
| 只要在四柱里看见财星或官杀，就直接当成配偶本人 | 先看它与日主、日支夫妻宫有没有实际作用，是否入主或得正位 |
| 看见“多合”或“夫妻宫双现”，就机械断成一定二婚、多婚 | 原课同时保留“遇合一般断二婚”与“多合不一定多婚”两说，须分伏吟、杂现及起坏作用的字 |
| 套用五行取数（水1、6等）直接数星报婚姻次数 | 取数只能连同原课具体命例读，不能脱离星宫关系单独报数 |
| 把“食神落空亡”或单见禄伤，直接套成固定寿数结论 | 原课对空亡与时上单禄保留反例与不同说法，须先查根、禄、原神与连续依托 |
