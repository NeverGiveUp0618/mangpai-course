# 八字里看病灶与凶危：疾病专题

## 一、比初、中、高级拓展了哪些

初级课程第 12 课只粗略带过“看寿入门”，中级与高级主课**完全没有专门的疾病章节**。本专题是主课未曾展开的**全新实战补充**，把看病的整套思路一次补齐：

1. **立起三条看病总纲**：先看阴阳是否相交、是否失衡（尤其**失阳者容易死亡**），再盯紧原局被穿、刑、破、冲、合坏的字是不是“体”或“连体”。
2. **补齐两条夭寿与死期规则**：明确**凶神夹日**（唯一依靠被运克即死期）与**地支死、墓、绝并现加枭神夹日**（运再见枭即应）的判断法。
3. **给出干支身体、六淫与八大病症组合表**：把十二地支、十天干、六淫（风寒暑湿燥火）以及位置象（年腿脚、月躯干、日腰脊五脏、时头面手与生殖泌尿）落到实处，并集中拆解妇科泌尿、肺与呼吸、心脑血管、精神情志、肝血肾杂症、糖尿病等常见病灶。

## 二、生活类比：一栋讲究水火流通的老房子

看八字里的疾病，不用另学一套新理论，只要把命局想象成人体这栋老房子：

- **阴阳相交、平衡，就像屋里的冷暖水电正常循环**。如果阳气太旺没阴水降火（阳亢），就像暖气片爆表，人就容易血压高、心脑出事；如果阴寒太重把阳气彻底浇灭（灭阳、失阳），就像冬天总闸断电、水管冻裂，代谢停摆，最容易有性命之忧。
- **穿、刑、破，就像装修时把承重墙里的暗管凿坏了**。卯木好比血管和管道，午火和戌土好比心脏与神明，一旦原局出现“卯破午”，就是血管破裂出血；出现“丑午穿”，就是湿寒伤了心脏或妇科。原局只是埋下暗伤，真正出事往往要等大运、流年把那个坏字引动，或者把全盘唯一的救命依靠克掉。

```关系图
盲派看病四步排查法
查阴阳 → 阴阳离决必危；阳亢主高血压心脏病，失阳灭阳最易死亡
查凶夹 → 凶神夹日或死墓绝并现加枭夹日，唯一依靠被运克即死期
找坏字 → 原局被穿刑破冲合坏的字，查它连不连体、在身体代表什么部位
定应期 → 大运流年引动坏字、开墓库、或克绝原神与唯一依靠之时发病
= 先定生死格局与阴阳大势，再落具体脏腑部位，最后由岁运引动应期。
```

## 三、干支身体部位与常见病性组合速查表

### 1. 干支组合与病性速查

| 典型组合 | 病性机理 | 常见对应病症 |
|---|---|---|
| **阳亢（丙见甲/寅，甲见丙旺）** | 阳多阴少，阳气上亢 | 高血压、心脏负荷重、头晕 |
| **寅亥合** | 水湿伤肝，肝失疏泄；水湿生痰 | 风湿、血脂高、心脏病；聚痰成怪病、精神病 |
| **丑辰合（配金水）** | 湿土壅滞金水（肺气） | 肺壅、哮喘、咳嗽、肺癌隐患 |
| **火克金** | 火邪伤金（不主肺则主骨髓造血） | 血病，重则白血病（金水相连则多主肺病） |
| **卯破午** | 卯为血管，午为心 | 血管破裂、出血，重则脑出血、心肌梗死 |
| **丑午穿** | 阴湿伤阳；午为女体、丑为肾与阴 | 心慌惊悸；女命妇科子宫病；男命肾与前列腺寒湿 |
| **酉戌穿** | 酉为肺耳，戌为心包神经 | 伤肺、心脏、神明（精神或心脑问题） |
| **子卯破、卯午破带禄身** | 管道受损连及禄身 | 手术、外伤或刀伤 |
| **土浊水 / 胃火旺 / 肝脾失调** | 水主血尿、土主甜；燥热消渴 | 糖尿病（多数与燥热有关） |

### 2. 身体与位置象简记

- **位置象**：年主腿脚与遗传；月主躯干；日主腰脊与五脏；时主头面、手与生殖泌尿；门户（年、时）对应五官与手。
- **六淫对应**：风（寅卯）、寒（亥子丑）、暑（巳午未）、湿（辰丑及寅亥合）、燥（戌未）、火（戌午未）。

## 四、常见误区 vs 正确问法

- **常见误区**：看到八字里某个字被冲、被穿，就随口乱猜一种病；或者只看五行缺什么，就说缺木得肝病、缺火得心脏病。
- **正确问法**：先问“全盘阴阳有没有离决或失阳？有没有凶神夹日？”如果有，先警惕大凶与寿限；再问“原局到底哪个字被穿、刑、破坏了，它是不是连体之字或唯一依靠？”比如“卯破午”是血管和心脏的关系，不是缺木缺火的问题，找准坏字和部位再等岁运引动。
