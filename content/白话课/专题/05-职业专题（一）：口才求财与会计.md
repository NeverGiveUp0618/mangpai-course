# 靠嘴吃饭与跟数字打交道：口才求财与会计

## 一、比初、中、高级拓展了哪些

初级和中级课程带大家认识了十神、宫位与基本做功，高级课程《职业象法二·生意人》和《职业象法六·会计》也讲过做生意与会计的基本看法。本专题在主课基础上重点拓展了三个实战维度：

1. **先立五条职业总方法**：把“结构定大类、类象落行业、库不开替人管、举一反三、食伤做功忌赌投”拧成一套通用动作，不再见字猜行业。
2. **把“口才与业务求财”独立成类**：在生意人之外，专门拆出靠嘴皮子吃饭的销售、业务与咨询（食伤落门户、财虚透带驿马、合劫财拿货去卖、美容化妆品与酒水饮品取象）。
3. **补齐会计的防错门槛与女命禁忌**：明确“见亥子水不一定是会计”，必须**数字之象 + 穿合做功 + 单位之印**三者俱备才成立；并附带提示了女命会计日时与大运忌走印禄之运的要点（原教材仅记此条提示，未再展开）。

## 二、生活类比：前台推销员与后台算账人

同在一栋写字楼里上班，都是帮老板赚钱，但两种人的工作方式完全不同：

- **业务员和销售**，整天背着包往外跑，靠嘴皮子说服客户，手里拿的货是从仓库或别人（劫财）那里提来的，钱也是替公司赚的，自己拿提成。八字里往往是门户（年、时）坐着食神伤官，或者财星带着驿马跑到外面，财库闭着没开，所以钱是替人周转的。
- **会计和财务**，安安静静坐在办公室里，面前摆着算盘和账本，一天到晚把一笔笔数字（亥、子水）拆开又核对（一穿一合），经手的钱再多，盖的也是公家的章（印星、墓库不开），自己只拿一份技术工资。

但这两类人有一个共同的大忌：**千万别自己拿钱去搞风险投资或赌博**。因为你本来靠的是手艺和嘴皮子（食神伤官），一旦去投机，就会把劫财引过来合走你的财，轻则合伙赔钱，重则把老本赔光。

```关系图
职业判断两步走与共同大忌
结构定大类 → 食伤在门户生财多为口才技术，财入库不开多为替人管财
类象落行业 → 亥子主数字计算，火土与丙丁戊主美容媒体，酉主酒水器材
合劫财拿货 → 从别人处进货去卖，属业务推销而非自己当老板
食伤忌投机 → 用食伤做功之人一搞风险投资，劫财合财必破财
= 先看结构定是不是替人打工，再看类象落到具体哪一行。
```

## 三、口才求财 vs 会计核心特征速查表

| 维度 | 口才与业务求财 | 会计与数字财务 |
|---|---|---|
| **核心结构** | 食伤落门户（年、时）；财星虚透带驿马；天干食伤高透合虚印见财 | 亥子水（印或财）被冲穿做功，且与食神、伤官组合做功 |
| **典型组合象** | 门户伤官包局=口才好；合劫财=从别人处拿货卖；禄做功/比劫制财=辛苦打工 | **子未穿**（子为数字、未为财）；亥巳冲、亥午合；透食神=坐办公室 |
| **常见行业落点** | 火土/丙丁戊=美容、化妆品、媒体广告；巳午=电子；酉金水=酒水饮品；戌=酒店娱乐 | 国家单位/企业会计、审计、统计、大企业或跨国公司财务总监 |
| **钱归谁（库）** | 财入墓库而库不开=替别人打工卖货；开库才可能自己当老板 | 年上财入宾位墓、天干乙庚合、官星被财包局=替公家或老板管钱 |
| **实操注意点** | 禄做功主辛苦；女命比劫争夫易遇有家室之人，财坐劫财易成第三者 | 不能单见子亥就断会计，须**数字+做功+单位**三要素齐全；忌风险投资 |

## 四、常见误区 vs 正确问法

- **常见误区**：只要看到八字里有“子水”或“亥水”，就脱口而出“你是做会计的”；或者看到命主靠口才赚了不少钱，就劝他自己拿钱出来合伙开公司、炒股投资。
- **正确问法**：先问“这颗子亥水有没有跟食神、印星构成穿或合的做功？有没有印星代表单位？”三者都凑齐了，才是坐办公室算账的会计；再问“命局是不是靠食伤做功、财库开没开？”如果库没开又是食伤做功，就老老实实靠嘴皮子或专业技术拿提成、拿高薪，切忌合伙投资或赌博。
