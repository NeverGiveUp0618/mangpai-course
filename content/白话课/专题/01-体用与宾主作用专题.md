# 体用与宾主怎么落到实盘：先分体用正反，再算做功效率

## 一、比初、中、高级拓展了哪些

初级、中级和高级主课已经搭好了宾主、体用、正反局和看盘顺序的骨架。这篇专题不再重复基础定义，而是把“体用与宾主”直接落到实盘答疑里，集中拓展了五块实战边界：

1. **六亲体用的分工规则**：明确“宫为体、星为用”——婚姻宫定星可换（多现原身称“副妻宫”），父母体用同坏才断亡，子女受胎看体（母体）、出生后看用（子星不只看官杀，财也重要）。
2. **正反局与成势的先天差异**：点破**“体制用为正，制体所出之物为反”**，以及**木火局先天有功、金水局先天无功**（金水局伤官极易变成废神）。
3. **合财 vs 合官、日支被制的红线**：明确合财看身强弱（身弱喜财虚透、身旺喜财旺相）、**合官不看强弱而看官下之支**；合禄局中神在月为“替人打工”；日支正星通常不可制，但**“正星一穿即反，相当于偏星”**，制之无碍。
4. **干支同象与天干克制边界**：规定只有**天干生地支**才算干支同象（支生干不算）；天干异性相克除合制外基本无功，同性相克气弱时功也小。
5. **强弱视角与做功视角严格分开**：同一组“寅亥合”，从强弱看是亥生禄，从做功看是合绊不发挥作用，实战绝不能混用。

## 二、先看清“自家的工具”还是“外面的目标”

把八字看盘比作经营一家公司：日柱是你的总控室，**体**是你手里的工具和本钱（比禄印劫），**用**是你想去拿的利润与名分（财官杀）。

新手最容易犯的错，是看见一个字被克就以为是做功。其实同样是制水，如果水是官杀（外面的“用”），你去制它叫**体制用，是正局**；可如果水是日支自己生出来的伤官（体所出的东西），你偏要去制它，就等于自己砍自己的手脚，变成了**反局**。

还有人看见满盘财星就以为大富，其实**财旺不等于有功**。就像仓库里堆满没人管的货物，没有官星来统财，或者没有财去印、财去劫财、财入库，财就只是一堆静物，照样发不了财；而且水大时硬用土去克制反而成害，不如合制、泄制来得顺手。

```关系图
体用、正反局与做功的实战判断链
先定看盘顺序 → 日主 → 日支 → 延伸物（日主与日支意思不一致，以日主为主）
再辨体制与反局 → 体制“用”（财官杀）为正；制“体所出”之物为反
查合财与合官 → 合财看身强弱（弱喜虚、旺喜旺）；合官不看强弱看官下之支
区分强弱与做功 → 如寅亥合：强弱论亥生禄，做功论合绊无功，二者莫混
= 先看日主有没有干活、干的是正活还是反活，再量能量与效率定层次。
```

| 专题维度 | 核心规律 | 实战注意点 / 边界 |
|---|---|---|
| **六亲体用** | 宫为体，星为用 | 父母体用同坏才断亡；受胎看体、生后看用；体为病神受冲克妻 |
| **财多有功** | 财多须官统，或财去印、去劫、入库 | 合制、泄制优于克制；水大硬克反成害 |
| **合禄与日支** | 合禄局中神在月＝为人打工 | 日支偏可制、正不宜制；**正星一穿即反，相当于偏星** |
| **天干与同象** | 天干生地支＝干支同象；支生干不是 | 天干异性相克除合制外无功；日主有合，以合为主看 |
| **能量与效率** | 有势且有对手被制＝大功 | 自己作功但效率极低＝辛苦劳作；日柱无功＝平淡一生 |

在具体盘面上，主位与宾位的体用配合决定了一个人的成事方式。比如 <a class="qref" data-q="133">命例 133：坤造 丙寅日 · 局中日支寅与两亥合</a>，日支寅木是体，与两亥官杀相合做功、官当财看，把宾位的资源拉进主位；再看 <a class="qref" data-q="607">命例 607：乾造 壬子日 · 内食神泄用作功，内食神主企业</a>，则是用主位内食神去泄用做功，能量与效率集中，自然走向办企业、带团队的路子。

> 教材保留口径：专题中提到的“反用结构与弱制”区分、以及学员总结的“癸弱从儿旺去伤”口诀，原稿明确标注“仅供参考”；个别盘面的另一套拆解思路也注明“未被采纳，仅作参考”，读盘时以主线作功逻辑为准。

## 三、常见误区 vs 正确问法

- **常见误区**：「看到八字里财星很旺、或者日主合了财，就以为一定发大财；看到寅亥合，既当成印生禄身旺，又当成印星在做大功。」
- **正确问法**：「财旺有没有官来统、有没有去印去劫或入库？日主合财时身是弱还是旺（弱喜财虚透，旺喜财旺相）？寅亥合在作功层面上是不是反而被合绊住了，强弱视角和作功视角有没有混为一谈？」
