# 道理都懂，一到看盘怎么还是下不去手

很多同学学到专题阶段，常有一个卡点：宾主、体用、作功、反局这些词背得滚瓜烂熟，可真把八个字摆在眼前，还是不知道先盯哪里、谁在干活、谁在偷懒。这一课不堆新概念，而是把实战答疑里最高频的四个卡点——**作功效率、体用分寸、反局反用、合官合财**——重新串成一条清晰的读盘顺序。

## 一、看盘总顺序：先找“干活的人”，别先数谁胖谁瘦

想象一家工厂年底发奖金，老板看的是谁真正谈下了订单、做出了产品（**有功**），而不是谁长得壮、谁嗓门大（**强弱**）。哪怕一个员工力气再大，整天坐在工位上不跟任何人协作，也是白领工资的“废神”；哪怕一个人瘦小，只要和关键岗位的搭档配合默契，一样能把大单子拿下来。

八字看盘也是这个理：**功神不是某一个字，而是“有作用关系并产生效率”的那一组字**；不参与作功的，就是废神。上手读盘，按下面四步走就行：

```关系图
看八字作功的先后顺序与效率
日主参与作功 → 先看日主合了谁、去向哪，意向最直接
日主不作功，看日支 → 日支（夫妻宫/主位）能制能合，照样有成就
日柱全无功 → 看日主延伸物（禄、原身），若仍无功则命相平庸
有势且制住对手 → 格局才大；木火先天有功，金水先天无功
= 先抓功神不问强弱，日主不作看日支，日柱无功命难高。
```

正因为这套体系看重的是**谁在作功、效率多高**，所以平时不必纠结所谓“从格”或传统强弱喜忌。许多看似“从财、从杀”的盘，真正起决定作用的其实是主位日支在干活；如果日支完全不作功，硬套一个从格也没有意义。

同样是“财多”，为什么有人发大财、有人只是守着空账本？关键也在作功：财多本身不管用，必须**见官统财**，或者走**去印、去劫财、财入库**这几条路，把财真正收拢、做实，才算有效率。

| 主题 | 核心规则 | 实战提醒 |
|---|---|---|
| 功神与废神 | 冲、刑、合、化、生、克、墓产生效率才叫功 | 八字功神多时抓核心功神；毫无功神或反局则层次低 |
| 日主与日支 | 日主与日支意思打架时，以日主为主 | 日主不参与作用就放手看日支，不必硬论日主强弱 |
| 同象与虚实 | 只有**干生支**（如癸卯、丁丑）算同象 | **支生干不算同象**；天干异性相克无功（合制除外） |
| 财作功三式 | 去印、去劫、入库（另加见官统财） | 财多无功时，见官把财统起来才能聚财 |

## 二、体用的细账：六亲生死、大小运怎么分主次

体用是看盘的高阶尺子，但在六亲和大运上，很多人容易把体和用搞混：

1. **婚姻看宫体星用**：宫位（家）是固定的“体”，进门的人（星）是可变的“用”，所以宫稳星变可能换人，不一定立刻出大事。
2. **父母必须体用同伤**：生身父母只有一对、不能替换，所以单伤宫或单伤星还不够，**体与用同时出问题**，才容易应父母过世的大凶。
3. **子女分胎前与出生后**：受胎时看母体，**体受损容易小产**；出生之后子女独立了，以用为主，**用受损则出生后子女逢凶**。
4. **财官为用、印禄为体**：永远是“用向体走、为体所用”，不能反过来。比如亥未相拱，是财拱到主位，而不是印拱到宾位。
5. **大运的体用会轮流坐庄**：走**天干运**时，地支不动当“体”、天干在动当“用”，好比自己坐镇后方派天干出去办事，往往顺手；走**地支运**时，天干成“体”、地支成“用”，地支要受天干的象管束，有时忙活半天反而功败垂成。

另外要注意“正星与偏星”的细微反转：日支坐正星一般不能随便制，制了容易伤亲人；但如果这个正星被穿了一下，**正星一穿即反，性质相当于偏星**，反而不按伤亲人论大凶。

## 三、反局、合官与合财：看清意向，别被表象骗了

什么叫“反局”？就像公司已经定好全力向东开拓市场，结果负责执行的部门偏偏掉头往西拆台。原局有明确气势，日主或日柱偏偏与这个势对抗，叫**原局反局**；原局意象很顺，大运偏偏来唱反调、冲破原有的合制，叫**大运反局**。凡是反局，所在之处多半主凶。

在合的用法里，**合官**与**合财**的看盘规矩截然不同：

```关系图
日主合官 vs 日主合财的实战分界
日主合官 → 不先论身强弱，必须看官星坐下的地支是什么、能不能用
日主合财 → 必须看身强身弱：身弱喜财星虚透，身旺喜财星旺相
合制逢冲 → 原局合制干净最怕大运来冲，一冲不是换象而是反局
合冲换象 → 相合可互换象，相冲必须“冲制干净”才能换象（又合又冲不换）
= 合官盯官下支，合财分强弱，合制最怕运来冲破。
```

来看两个真实命例把这几条钉牢：

- 在 <a class="qref" data-q="81">命例 81：乾造 癸酉日 · 金与湿土有势，但日主贪合了时柱的戊官</a> 中，原局金与湿土成势，如果光看气势很容易错判；但日主合了时柱的戊官，这就成了日主明确的意向，**必须用官星坐下的地支（午火）**去以财制印。只可惜午克酉效率太低，所以落到现实里只是开出租车养家糊口。
- 在 <a class="qref" data-q="105">命例 105：坤造 戊寅日 · 女命戊土日主自坐寅木杀星</a> 中，日主去合年干财星，财星坐下又是日主之禄（巳），结果巳去穿了夫宫寅木。大运禄到再遇寅巳穿，直接应验丧夫。这里“禄代表自己去穿正位夫宫”，把原本坐下的偏星性质彻底穿坏，成了典型的凶象反局。

至于“反用”（比如用阳制阳、主位用反制宾位体）与“正用”，原教材也专门留了一句分寸：**反用与正用极少数特殊命局可以并存，但绝大多数八字只有一种主流用法**，千万不要把“弱制”和“反用”混为一谈。

## 四、常见误区 vs 正确问法

- **常见误区**：「看到日主合官就以为一定能当官，或者看到身弱合财就一概断穷；看到原局合制，大运来冲时还以为是在“冲开换象”。」
- **正确问法**：「日主合官时，官星坐下的地支能不能为我所用？合财时日主是强是弱、财是虚是实？原局已经合制干净的关系，大运来冲是不是把局冲反了？」
