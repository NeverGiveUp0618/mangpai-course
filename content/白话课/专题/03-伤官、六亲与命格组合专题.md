# 五类伤官怎么看、过河拆桥怎么发：两套新口诀与六亲汇参

## 一、比初、中、高级拓展了哪些

高级第 31、32 课已经把“父母死亡、离异与弃养（过继）”讲得相当完整，本专题中间的六亲部分主要是对这两课规则与命例的汇拢呼应。真正比初、中、高主课**全新拓展**出来的，是首尾两大实战模块：

1. **五类伤官诀及其原局/大运适用边界（全新）**：按日主与伤官五行分出金水、土金、水木、木火、火土五类伤官，不仅给出喜忌口诀，更点明**金水伤官喜见官只适用于原局、不适用于大运**，而**土金伤官怕见官则是原局忌、大运不忌**，且官伤不相见不坏格。
2. **“过河拆桥”特殊命格（全新）**：首次系统拆解“主位财重生宾位官杀，再把宾位官杀弄住（制、合、穿）”的发财型与升官型组合，并明确**原局主位财轻则不成格**的反例红线。

## 二、先查“五类伤官”的脾气，再认“过河拆桥”的套路

同样叫“伤官”，不同五行的脾气完全不一样。就像做菜放调料，有的菜怕放盐、有的菜非放盐不可。

比如**金水伤官**，原局见官就像冷水烧开水，越烧越旺能成大器；可一旦大运再走官星火地，反倒成了烧伤自己的险境——这就是为什么口诀说“金水伤官喜见官，只适用于原局，不适用于大运”。相反，**土金伤官**原局最怕见官（卯酉相见格局小，寅申相见格可大但易坏格），但到了大运见官却不忌；如果伤官见官只发生在宾位，而主位正急着开财官库，那克的是外面的领导，自己照样稳稳做事。

至于**过河拆桥命格**，生活里就像“先借大老板（宾位官杀）的平台把自家散财聚起来，等能量全聚到平台上了，再一把把平台拿捏住（制住、合住、穿住）”。原局能弄住功最大，大运才弄住功小一点；如果是升官型，则是宾位官杀关联到主位变成了自己的权，大运把宾位官杀制住便能步步高升。

```关系图
五类伤官的判断四步
第一步定类别 → 按日主五行＋伤官五行分出五类
第二步查口诀 → 金水喜官怕印；土金喜印怕官喜杀；水木喜财官怕印；木火喜印；火土看组合
第三步分盘运 → 金水喜官只限原局；土金怕官原局忌、大运不忌
第四步看相见 → 官伤不相见不坏格；主位开库为急时，宾位伤官见官不伤自己
= 别一见“伤官见官”就吓一跳，先看是哪一类伤官、在原局还是大运、相不相见。
```

| 类别 / 命格 | 核心口诀 / 组合条件 | 实战关键细节 |
|---|---|---|
| **金水伤官** | 喜见官，怕见印 | **只适用原局，不适用大运**；原局连体伤官走官运反易遇险 |
| **土金伤官** | 喜见印，怕见官，喜见杀 | 原局忌、大运不忌；**卯酉见格小，寅申见格可大但坏格** |
| **水木伤官** | 喜见财官，怕见印 | 伤官见官为吉；内食神旺者多出企业经营或管理人才 |
| **木火伤官** | 喜见印 | 无官则印当权；口诀：“女命伤官福不真，无财无印守孤贫” |
| **火土伤官** | 看组合 | **丁火见戊土**较好（伤官制水有功）；**丙火见己土**容易坏格 |
| **过河拆桥（发财型）** | 主位财重→生宾位官杀→弄住宾官 | 官杀统财，制/合/穿住即发大财；**原局主位财轻则不成** |
| **过河拆桥（升官型）** | 宾位官杀关联到主位成己权→运制宾官 | 大运将宾位官杀制住则升官 |

在六亲汇参方面，本专题再次用大量命例印证了高级课的断法：父母星相克而不见死亡信息必断离异（双合、伏吟主再婚），年月食神、财星或印星被坏而日时另有生机则主弃养过继。比如 <a class="qref" data-q="543">命例 543：坤造 己卯日 · 父母离异父母戊子运戊寅年闹离婚</a> 中，正是父母星相克、母星伏吟离开且无死亡之象而断离异；再看 <a class="qref" data-q="533">命例 533：坤造 丙申日 · 父母弃养伤官坐母关系不好</a>，母带伤官不养自己、父星他合不管自己，最终合到月令随祖母长大。

## 三、常见误区 vs 正确问法

- **常见误区**：「背了一句“伤官见官为祸百端”，结果见到水木伤官见官、或者土金伤官在大运见官，也一律当成大凶坏格；或者一见主位财生宾位官杀，就不管财重财轻都按过河拆桥断大富。」
- **正确问法**：「这是五类伤官里的哪一类？口诀适用的是原局还是大运，官与伤官在盘面上到底有没有相见？如果是过河拆桥结构，主位财星够不够重，宾位官杀最后有没有被真正弄住？」
