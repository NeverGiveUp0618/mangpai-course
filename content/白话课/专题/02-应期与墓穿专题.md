# 虚透、入墓与穿害的实战细则：把应期锁到那一年

## 一、比初、中、高级拓展了哪些

中级第 05、09 课和高级第 06 课已经讲透了地支作用、大限交脱、流年只管应期，以及静态“体”被流年引动的框架。这篇专题在原有基础上，补上了五组最容易在断流年时踩坑的细则：

1. **天干“虚到”的双轨口诀（全新）**：**禄神虚到大运流年，主虚而弱化；墓神或余气虚到大运流年，不主弱化，而主到位**（比如乙木代表卯禄时是弱化，代表未墓时只表示应期到了）。
2. **补全十干应地支对照表与“破合”**：给出完整“干应支、支应干”互应表，并补充流年冲八字中字时，应的是**“破合”**（破坏原局之合）。
3. **入墓的精准边界与“害不能开墓”**：明确**子午酉卯见各自的墓一般以拱合论、不以墓论**（唯有中神极弱要死时，见墓才作应期）；**午戌、子辰不论位置先后皆为拱，不是入墓**；同时点明**害（穿）不能开墓**。
4. **同合不同命——“合而护” vs “合而去”**：同样是弱酉见辰来合，火燥气势里叫“合而护（反局）”，金水气势里叫“助死去母星”，全由全盘气势定夺；并正式对旧资料里“弱制官星”的误判作了纠偏。
5. **夹冲夹刑、禄神伏吟与官杀库不制也作功**：说明一方二对一的夹冲少数方必坏；禄为功神时伏吟反发迹，禄无功单薄时见禄则凶；官杀库不一定非要制，**入墓或化掉也算作功**。

## 二、同样是“天干出现”，为什么有时变弱、有时只是敲门？

把原局里的地支比作住在房子里的主角，流年天干就像是跑来敲门的“同姓亲戚”。同样是乙木出现在流年：如果家里住的是**卯木（乙的禄神）**，天干乙木出现，就像主角自己从屋里跑到院子里晒太阳，力量散了，叫**虚透弱化**；可如果家里住的是**未土（墓神或余气）**，乙木出现并不代表未土变弱，它只是个报信的，代表**“未土的应期到了”**。

再比如墓库，很多人一看见“酉见丑”“午见戌”就喊入墓，其实规矩很严：第一，**多而墓之**，或者**寅申巳亥**四长生见墓才论入墓；第二，**子午酉卯**四中神见各自的墓，平时按半合/拱合看，只有中神本来就弱得快断气了，见墓才算“死、墓、绝”的凶应；第三，**刑冲能开墓，害（穿）绝对开不了墓**——如果一个字进了墓又遇害，往往像掉进锁死的箱子里，出也出不来。

```关系图
应期、入墓与穿禄的四大判定开关
干应支与虚到 → 禄神虚到＝弱化；墓神/余气虚到＝到位不弱化
流年冲运与冲局 → 不当运冲运为引动，当运冲运为冲去；冲局中字为破合
中神见墓与拱 → 午戌/子辰不论先后皆为拱；子午酉卯极弱见墓才论死墓绝
合酉的两种气势 → 火燥势中辰合酉＝合而护（反局）；金水势中辰合酉＝助死
= 先分清虚到的是“禄”还是“墓余气”，再看全盘气势决定合与墓是护还是去。
```

结合真实命例更能看清这些开关怎么联动：在 <a class="qref" data-q="614">命例 614：乾造 戊辰日 · 戊土长生在寅，因为没有印</a> 里，甲寅杀当财看、辰中水生寅，行子运引出辰水生助寅木便发财，行己运合绊甲木（寅木虚了被合）、再遇甲申年寅申冲破木之根，便对应大笔投资失误破财；而在 <a class="qref" data-q="625">命例 625：乾造 癸丑日 · 七杀旺而无制，财库戌被冲开</a> 中，戌土财库与丑土在原局形成刑制，大运与流年一到刑冲开库、引动到位之时，发财与破耗的年份就一清二楚。

## 三、常见误区 vs 正确问法

- **常见误区**：「看到流年天干出现了原局地支的同五行，就一律当成‘虚透无力’；或者看见子午酉卯见了墓库，就一律断成‘入墓有灾’。」
- **正确问法**：「流年天干代表的是原局的‘禄神’，还是‘墓神或余气’？如果是中神见墓，它是处于拱合状态，还是本身已经极弱要死了？如果遇到合墓，全盘气势是在‘合而护’还是在‘助死’？」
