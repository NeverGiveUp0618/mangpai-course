# 合冲穿、墓库与六亲位置，实战中最容易卡在哪

上一课理清了看盘的总顺序与反局合用，这一课接着把大家在实战中最容易问混的“细枝末节”一次扫清：同样是合和冲，为什么有时越冲越发、有时一冲就散？墓库什么时候算入墓、什么时候不算？禄神到底怕不怕重见？六亲到底在年月找还是满盘都能找？

## 一、合冲穿的边界：别把“促成开库”当成“合能解冲”

打个生活中的比方：保险柜锁得死死的，你拿把钥匙去捅开它，这是“冲开有用”；如果旁边有个人硬把锁眼堵住，那叫“闭库无用”；而如果原本两队人马势均力敌在拔河，突然其中一队多喊来两个人，以二敌一、甚至三打一，原本的平衡瞬间被打破，被围攻的那个就一定会坏。

把这套逻辑放进地支里，几条最容易出错的边界立刻就清楚了：

```关系图
合冲穿实战易错边界速览
冲中有合 → 原教材保留分歧：古书说论冲不论合，答疑认为各有各的用途（合可促冲）
三戌冲辰 / 夹冲 → 一方二、一方一，力量失衡，少数一方必然受损；夹刑角度不同不与冲同论
暗合不成立 → 巳中戊不合子中癸，戌中戊也不合子中癸
穿与被穿 → 相克之穿看“势”在哪一边，得势的一方穿坏对方
= 遇到合冲同见先看方向与气势，别死背“合能解冲”四个字。
```

这里要特别留意原教材保留的一处口径差异：书上常说“冲神在合神中间，则被合，论冲不论合”，但实战答疑认为**两者各有各的用途**——有时合反而是为了促成冲（比如卯戌合之后，卯反过来促成辰戌冲开财库），关键要看气势的方向，不能机械套用“合能解冲”。

同时，干支发生作用也有铁律：**只有在同一柱之内，才论干支直接生克**；大运天干只管命局天干，大运地支只管命局地支，唯有通过禄神与原身，才会出现“支转干”的联动。

## 二、墓库、禄神与六亲位置的实战速查

很多人一见辰戌丑未就喊“入墓”，其实大错特错。墓库的核心只有两句话：**库不开则无用，墓气旺于余气**。像开药房连锁的命例，四柱草木全收进未库，偏偏局里没有丑或戌来冲刑开库，结果货物只进不出、周转失灵，反而破财；而且一旦冲开墓库，**墓库里藏的“墓气”力量最大，往往胜过余气甚至本气**（比如戌中丁火旺于辛金，丑中辛金旺于癸水）。

下面这张速查表，把墓库、禄神和六亲位置最常被问到的坑一次标出来：

| 专题项 | 容易搞错的误区 | 实战准确口径 |
|---|---|---|
| 入墓条件 | 见墓支就一律论入墓 | **多而墓之**、**寅申巳亥见墓入之**；**午戌论拱不论入墓**，中神见墓（如酉见丑）主要以拱合论 |
| 暗合闭库 | 以为寅丑暗合也会闭金库 | **子丑合闭金库；寅丑暗合不闭库**，它表达的是寅与丑相互制克的意思，看各自气势 |
| 禄神与干禄 | 以为禄神伏吟一定凶、干禄到处都是 | **干禄只有丁未时、癸丑时**；禄为功神且局成禄势则不怕伏吟；**禄绊桃花只在日时主位才算** |
| 关财门 | 以为伤官旺财就一定不旺 | 若伤官旺财也旺，不会关财门；**大运把财星坏了，也叫关财门** |
| 六亲位置 | 到处乱找父母，或只死守夫妻宫看配偶 | **父母只在年月找**；**夫妻、子女可在局中任何位置**；**宫位重于星位**；子女在不生育或克子女时才重看宫位 |

再配合两条真实命例来体会“表象 vs 实质”和“反用取财”：

- 在 <a class="qref" data-q="3">命例 3：乾造 丁酉日 · 我认为此造丁是做功的</a> 中，日主两合官星，年官坐辰、月官坐寅。寅丑暗合时，体（寅）在宾位、用（丑库）在主位，属于反用取巨财的象；但全局金水成势偏要坏掉寅木，自己却想用劫财拿财，成了拿不住财而败家的隐患，直到大运冲开或比劫得力、巳酉丑合财引动辰酉合，才应了继承巨额遗产之象。
- 在 <a class="qref" data-q="11">命例 11：乾造 庚申日 · 日主合财是表象，地支作功是主要的</a> 中，天干日主合财只是晃眼的表面动作，真正干活的是地支巳申合（把被制的七杀拉回主位成权柄）与戌酉穿（羊刃穿官杀库），所以命主才成了专门查处官员的纪检干部。这也印证了答疑里的核心提醒：**看工作、看财源，必须看地支作功落在何处，不能只盯天干合财**。

## 三、常见误区 vs 正确问法

- **常见误区**：「看到午戌就断午火入墓，看到寅丑暗合就断闭了金库；或者见到八字禄神伏吟、大运来冲，不看气势直接断凶。」
- **正确问法**：「这两支是拱合还是真入墓？库有没有被刑冲打开？禄神在原局是不是功神、有没有形成禄的气势？找六亲时，父母有没有锁定在年月两柱？」
