# 生意人怎么看：从“什么当财”到“开什么店、何时发财”

## 一、比初级、中级拓展了哪些

中级第 13 课《财命专辑》已经搭好“什么能当财（禄、伤食、官杀）”和“取财五法（经营、风险、智力、体力、工薪）”的基础框架。这一节高级课把视角全部聚焦到**生意人专场**，新拓展了四块可落地的断法：

1. **财富定级更精细**：在“财星、食伤、官杀、禄”之外，专门把**“地支食伤本身含财”**单列成一档（源头与结果同在，级别大于普通食伤）。
2. **印星的“门店／公司／工厂”专象**：把印星从“工作单位、房子”彻底展开为生意场上的**门店、厂房与规模**（印落门户有几个印几个厂、伤官合印放大成规模、印被破则没有单位而自己创业）。
3. **九大具体行业的拼象模板**：给出装修彩绘、高档家具、建筑建材电器、酒店餐饮、车辆出租与五金物业、服装美容家电、进出口贸易、玻璃化工木器厂、金属化工航运贸易的实战拼法。
4. **生意人的大运流年细则**：补出**丑到＝申酉到、辰到＝子到**的地支代换法，点破劫财透干主“帮别人打工”、劫财合财主“喜投资但十赌九输”与财合印主“正经生意赚钱”的关键分界。

## 二、摆摊、开作坊、开工厂还是掌平台：先定财的级别

同是做生意，有人在街角摆小摊赚买菜钱，有人开技术作坊，有人一口气开三四个厂，有人掌控整条行业链条。八字里第一步要看的，不是财星旺不旺，而是**到底哪个字在扮演你的“钱”**。

- **财星**：养命之源，多是工资或小生意格局；
- **食伤**：财的原神，源头大于水流；
- **地支食伤本身含财**：源头与结果同在，级别更大；
- **官杀**：由财所生，是财富升级成权势与规模，级别最大；
- **禄**：自己能用到、花到的享用之财，不是做大的资本。

```关系图
生意人的两步核心判断：先定级，再看“财合去哪里”
定级：财星 → 食伤 → 地支食伤含财 → 官杀（由小到大）
财合在印上（印合财/伤官合印） → 投资开店、开厂、把生意放大成规模
财合在劫财手里（劫财合财） → 喜欢投资与赌博，但赌必输、正经生意可赚
= 先认准谁当财富、级别多高，再看它合到印还是合到劫财手里。
```

比如 <a class="qref" data-q="311">命例 311：坤造 丁亥日 · 自己独资开公司，做装修彩绘生意</a> 中，月令卯印被午禄所破（卯午破），说明命主没有吃公家饭的工作单位，只能自己创业；而坐下亥水官星被卯、午包局，**官杀被包局当财富看**，级别一下子拉高到独资开公司发几千万。再看 <a class="qref" data-q="313">命例 313：乾造 癸酉日 · 丙午运在国家单位工作</a>，丙午运只是挣工资，到乙巳运巳从戌财库出来合申酉印（财合印），才辞公职做建材装饰、家电与火锅酒店发财；而原局丁财虚透被时上劫财壬合去（丁壬合），就应了“喜欢赌博却十赌九输，做正经生意反倒能赚”。

## 三、生意组合、行业拼象与运岁应期速查

| 观察维度 | 典型结构 | 现实结论 |
|---|---|---|
| **印的角色（门店/厂子）** | 印带财、财合印、印冲财；印落年时门户；伤官合印 | 开店面、开工厂；门户有几个印常主几个厂；**伤官合印＝由技术放大成规模**；印被破＝没单位自己干 |
| **财库与官杀库** | 库不开则财不放；运岁冲刑开库；官杀库不开又无制 | 开库即发财应期；官杀库不开无制则不当官、转而求财；**财临库地且合闭，兼主父寿有碍** |
| **冲与驿马** | 禄冲财、寅申冲、年月日驿马逢冲 | 进出交易之象，满世界跑做贸易、运输、车辆出租 |
| **大运流年节奏** | 劫财透干；运岁引动库；原局有破而运岁两头合；代换字 | 比劫透干主帮别人打工；如原局卯午破，**未运既合卯又合午**最发财；**丑到＝申酉到、辰到＝子到** |
| **拼象与做功铁律** | 单字象＋组合象，必须有做功证据 | 如死木见火＋己伤官坐财库＋甲己合＝高档家具企业；酉金见水/未＝餐饮酒店；子亥＋申引动＝化工多厂 |

> 实战提醒：拼行业象一定不能脱离“做功”。只有先看清谁制谁、谁合谁、哪个库被冲刑打开，单字拼出来的行业画面才落得住。

## 四、常见误区 vs 正确问法

| 常见误区 | 正确问法 |
|---|---|
| “看人能不能发大财，只盯着八字里正财、偏财多不多。” | “先看盘里最高级别当财富看的是财星、食伤、地支食伤含财，还是官杀；再看有没有做功、财库开不开。” |
| “只要看到劫财合财，就断他做生意一定赔钱。” | “先分清赌博还是做正经生意：劫财合财常主好赌且十赌九输，但如果同时有财合印、财库开等生意做功，正经做生意依然能赚钱。” |
| “原局财星、印星和行业字都看懂了，大运流年只看天干地支本字就行。” | “生意人的应期要会用同类代换（如丑到等于申酉到、辰到等于子到），还要看运岁是不是破坏了原局的合冲做功。” |
