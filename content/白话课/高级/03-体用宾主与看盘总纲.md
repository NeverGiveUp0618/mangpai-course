# 先分清“谁是自己、谁是目标”，再按顺序拆盘

## 一、比初级、中级拓展了哪些

初级课带你认识了宾主、体用和找做功，中级第一课则从天道、形气与体阴用阳的角度解释了底层原理。到了高级阶段，这一课把看盘动作收拢成一套可直接照搬的总纲，新拓展了四个实战模块：

1. **五类做功结构与八字层次**：按做功方式把八字分为去用（约40%）、化用（约10%）、泄用/生用（约10%）、合用（约10%）、无用（约10%）五类（注：原教材小标题写“八个类型”，正文仅列这五类，此处依原教材保留不硬补），并区分**主要功神**与**辅助功神**，以功神多寡定贫富层次。
2. **体用宾主落位的硬性红线**：明确**体在主位一定要有用**、**杀在主位一定要用才吉（无用则凶）**、财在主位本身有用；点出禄在年受苦、禄或劫在月多为侍候别人。
3. **两类高格局模式与七步看盘顺序**：区分“主位体制宾位用（跟得上形势、被人看好）”与“主位用制宾位用（思维异于常人的特异人才）”，并给出先主位、先日干后日支的固定入手顺序。
4. **解灾绝招与“贼神捕神”四提醒**：提出“找制你命局病神的人”作为解灾思路，并给出制死的叫贼神、天干为弱制、制不干净，以及**“制不了，千万不要再制”**四条提醒。

## 二、盘点自家家底与外部目标：先把位置和角色分清

接手一家公司，第一件事不是急着到处签单，而是先盘点两件事：第一，哪些人是自家人、哪些工具归自己调动（**宾主，按位置分**）；第二，哪些是本钱和手段、哪些是想赚的利润与头衔（**体用，按十神分**）。

用自己的“体”去取得外面的“用”，这就叫**做功**。真正在干活、出效率的字叫**功神**（还分冲在前面的“主要功神”和在旁边搭把手的“辅助功神”）；光耗能量不出活的字，叫**废神**。富贵八字往往成气成势、功神多；普通八字效率低；差八字则是废神扎堆、找不到功神。

```关系图
高级看盘的七步入手顺序
1. 先看主位（日、时柱） → 主位字可用且有力才好，闲着无用则差
2. 再看日干 → 日干合到谁就是追求谁；日干无合无作则跳过
3. 转看日支 → 看日支对其他地支的刑冲克害墓，以及日时禄是否作用
4. 定核心 → 日支做功以日支为主，日干做功以日干为主，以功神为核心
= 先盯紧日柱这间“总控室”，确认谁是主要功神，再向外看全盘成势与否。
```

| 维度 | 核心规则与落位红线 | 实战含义 |
|---|---|---|
| 宾主划分 | 日主、日支（有时含时柱）为主；年月与外来岁运为宾 | 宾主分清“身内工具”与“身外目的”，日时为小家庭、年月为先天祖上父母 |
| 体用归属 | 比、禄、印、劫为体；财、官、杀为用；食伤中性（食偏体、伤偏用） | 财在主位本身有用；**杀在主位必须有用才吉，无用则凶**；体在主位不可闲着 |
| 两类理想模式 | 主位体制宾位用 vs 主位用制宾位用 | 体在主制用者，规矩、跟得上形势；用在主制用者，多为思维异于常人的特异人才 |
| 禄的位置 | 禄在主位多为自身得福；在年上、月上各有不同 | 禄在年多受苦难成大事；禄或劫财在月起作用，多主侍候别人 |
| 五类做功结构 | 去用（约40%）、化用、泄生、合用、无用（各约10%） | 去用结构占比最大，去干净则吉；**禄为自身，去禄要特别慎重** |

在真实命局里，主位与宾位的配合非常讲究。比如 <a class="qref" data-q="130">命例 130：乾造 丁丑日 · 喜财库丑土被戌刑开</a>，日主坐下丑土财库落在主位，正是靠宾位的戌土刑开、大运未土冲开，把主位之用彻底盘活；再看 <a class="qref" data-q="172">命例 172：乾造 庚申日 · 以禄当财富看，时上丑为禄库</a>，局中无财，便把坐下申金禄神当成财富，同时时上丑土禄库在门户护住申禄，体在主位实实在在起了作用。

## 三、制的四个提醒：别硬去惹制不住的字

做功里“去用（制）”占比最高，但不是见着病神就一定要去打。教材专门留下四条关于“贼神与捕神”的提醒：

```关系图
制的四个实战提醒（贼神与捕神）
制死的字 → 叫“贼神”，制干净了才算真正到手
制不干净 → 留有隐患，一遇岁运扶起病神就会反扑
弱制 → 天干上的制力量弱，叫弱制，难成大局
制不了 → 千万不要再去制它，强行去制反而激怒惹祸
= 制得干净才叫功，制不了的字宁可顺着化或避开，也别硬碰硬。
```

此外，如果八字里本身带着难以化解的毛病，盲派还留了一招实用的**解灾思路**：去找八字里正好能制住你命局病神的人来搭档或共事，往往能把原局卡住的局势盘活。

## 四、常见误区 vs 正确问法

- **常见误区**：「一拿到八字就从年柱往后看，或者不管三七二十一，见着七杀和财就想找东西去制它。」
- **正确问法**：「日柱主位里的字有没有在干活、谁是主要功神？主位上的体和杀有没有闲着无用？如果原局的病神根本制不了，是不是已经踩了“制不了别再制”的红线？」
