# 冲穿刑破不只是动作，更要算清远近、成势与换象

## 一、比初级、中级拓展了哪些

初级和中级已经把三合、冲、穿、刑、破的基本定义与开库规则理清了。这一课在高级阶段把所有地支动作的“边界条件”和“实战后果”彻底细化，重点拓展了五个方面：

1. **合的四种用法与五合换象三原理**：把“合”拆成合制、合留（星合谈对象、宫合成夫妻）、合绊、合伤，并归纳出天干五合换象的三条原理（一方定义另一方、一方代替另一方、双方同信息）。
2. **六冲的远近、成势、夹冲与换象**：明确“近冲库坏、隔冲库伤、遥冲库开”；一对一力量相当只是动与消耗，**成势的冲**才冲伤冲去；夹冲一般不坏；运干管前五年、运支管后五年（干运冲为冲动，支运冲为冲去）；以及强方取代弱方信息的**冲的换象**。
3. **相穿的“只能穿倒、制不了”**：强调冲、合、克都能制，唯独**穿制不了对方**，只能“穿倒”（正偏互换）或主凶灾；穿库也开不了库。
4. **三刑的六亲凶象与相破的“旺而不生”**：点明三刑见金多主伤病残疾、见父母星多早逝、墓中六亲被坏主突然死亡；把相破（子卯午）讲透成“双方帝旺、本该相生却不履行职责”。
5. **三合局的“中神双现入墓”**：指出三合局若中神多现或双现，不再按合局论，而是按**入墓**论。

## 二、拆迁与部门推诿：动作背后要看“势”与“职”

街面上拆违建，如果只有一个人对一个人推搡，顶多算互殴扯皮、谁也搬不走谁；只有拆迁队成群结队、气势压倒对方，才叫“拆得掉”。反过来，如果两个职能部门各自手握实权、谁也不买谁的账，本来该上游批文给下游盖章的，结果上游卡着不签、下游干脆躺平，这就叫“旺而不生”。

高级阶段看冲、穿、刑、破，重点就在分清这些动作的“有效度”和“破坏方式”：

```关系图
六冲的远近、成势与换象规律
近冲库 / 隔冲库 / 遥冲库 → 近冲坏库中物，隔冲伤，遥冲才是冲动、冲开
一对一均势 vs 成势之冲 → 力量相当只是动和消耗；二冲一、三冲一或旺冲衰才冲去
夹冲（如两午夹一子） → 一般不为冲坏，除非再见帮手（如巳、未、戌）
冲的换象 → 强方战胜弱方后，强方取代弱方信息（如火土制水，火土全作财看）
= 论冲先量远近、再数人头（成势否），最后看大运管干还是管支。
```

这里要特别留意大运与流年相冲的差别：大运天干管前五年、地支管后五年。如果正走天干运，流年去冲大运地支，叫**冲动**，只是提前引动；如果已经走进地支运，流年去冲大运地支，就叫**冲去**，主暂时离开（但未必一定凶）。

比如 <a class="qref" data-q="9">命例 9：坤造 己巳日 · 壬被丙冲制，子被午冲制印党很大</a>，原局火土成势去冲制子水财星，正是典型的“成势之冲”兼“冲的换象”，火土都成了财，因此能做海外贸易发大财（同时原解也提醒，坐支若为日主“连根筋”则不可被制，一制易伤身寿）。又如 <a class="qref" data-q="30">命例 30：乾造 戊子日 · 一午冲两子，就是两个事情</a>，流年午火同时冲局中子水与大运子水：冲局中之子是“冲动”能挣钱，冲大运之子却是“冲去”，导致合资方撤资跑掉，一个动作两样结果。

## 三、穿、刑、破与合的四种用法速查

很多初学者把“穿”当成最厉害的“制”，这是大误区。穿是一种无法调和的仇恨与暗损，**冲、合、克都能把对方制住，唯独穿制不了对方**。穿的真正后果只有两条：一是**穿倒**（正的穿成偏的、偏的穿成正的，比如正官穿成七杀、正印穿成偏印，拿不到稳定公职或职位偏副）；二是**凶灾**（伤损对应的六亲或自身）。

```关系图
相穿、三刑、相破的实战后果
相穿（克泄穿重、生穿力小） → 制不了对方，只主穿倒（正偏互换）或凶灾，穿库不开
三刑（丑戌未、寅巳申、子卯） → 刑开/坏库；见金主伤病残，墓中六亲被坏主突发死亡
相破（子卯、卯午为主） → 双方帝旺而不相生（如职能部门不办事），主破坏或不生
暗合（午亥、卯申、寅丑） → 强弱悬殊的换象动作，本身也是一种做功方式
= 穿看“倒了谁、伤了谁”，刑看“开没开库、见没见金”，破看“谁旺着不生谁”。
```

| 动作类别 | 核心细分与规则 | 实战关键提醒 |
|---|---|---|
| 合的四种用法 | 合制（一方被合去）、合留（留住）、合绊（均势失性）、合伤（克方大于被克方） | 婚姻应期：只合配偶星是谈对象，干支把配偶宫也合动才结婚 |
| 三合局 | 长生、帝旺、墓库相合，中神为尊 | **中神双现或旺极多现，不成合局而按入墓论**；半合、拱局也成立 |
| 六冲 | 水火、金木、土墓各有胜负；天干四冲主应期 | 辰戌冲难制戌中辛金（多只冲出），唯未土能制；合见冲、冲见合为应期 |
| 相穿 | 克泄穿（子未、丑午、卯辰、酉戌）重；生穿（寅巳、申亥）力小 | 流年穿大运无所谓，最怕命局自己的字被穿；酉戌穿需金极旺才穿倒戌 |
| 三刑与相破 | 寅巳刑以穿为主；子卯以破为主；丑戌/未戌刑开库 | 三刑占全者六亲多不利；相破不是“倒”，而是“不生”兼破坏捣乱 |

## 四、常见误区 vs 正确问法

- **常见误区**：「以为只要是相冲就能把病神冲掉、只要是三合就能合局，或者把“相穿”直接当成“制住对方”来算大格局。」
- **正确问法**：「这一冲是一对一消耗还是成势之冲？距离是近冲坏还是遥冲开？三合局的中神有没有双现变成入墓？遇到相穿时，有没有分清“穿倒正偏互换”和“根本制不住”的区别？」
