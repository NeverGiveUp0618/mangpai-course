# 包局婚姻判断：被盯紧的围城，还是被人包养的局

## 一、比初级、中级拓展了哪些

初级与中级《婚姻专辑》讲过夫妻宫与配偶星的“冲、穿、合、墓”，但还没有专门展开**“包局”**这一结构。本课在宫星关系之上拓展了四个实战维度：

1. **定义包局的三种形态**：星包宫、宫包星，以及星宫一起被他星包住，用来判断婚姻是不是“捆得死、离不了”。
2. **补出包局的“反局”判法**：同样是两头包住，只要两头干支象相反（比如天干相克），就不是同一个人，包局立刻失效，反断必离。
3. **区分“包局难离”与“破包之法”**：明确六合式包局最痛苦，但也给出破包的三条出路（羊刃克妻大运、冲破夫妻宫流年、六合破暗合）。
4. **单列“财包局主被包养”口诀**：女命原局无官杀而财星包局，主被人包养，且能看出包养者多带比劫库、有家室。

## 二、生活类比：合租房里的两把锁

把夫妻宫比作你自己住的房间，把配偶星比作另一半。普通婚姻是两个人各有一把钥匙，合得来就一起住，合不来还能各自推门离开。而**包局**，就像是对方在你的房间前后门都装上了锁，或者你的房间把对方严严实实围在中间——进退都由不得单方面说了算。

这种“被围住”的关系有好有坏：好的时候，外人插不进来，哪怕屋里偶尔吵架磕碰（比如带一点穿、破），门锁依然牢靠，婚姻稳得住；累的时候，对方盯得太紧，连晚归几分钟都要打电话追问，想离却像坐牢一样难脱身，除非遇到能把锁砸开的运和年。

```关系图
包局婚姻的三种核心走向
两头同象包住宫或星 → 看得紧、难离婚，要离代价极大
两头同字但天干相克（反局） → 象反非同一人，包局不成立而必离
女命无官杀、财星包局 → 易被有家室之人包养
= 先看两头是不是“同一个人”，再断婚姻稳不稳。
```

## 三、包局类型、破法与特征速查

| 类型 | 结构特征 | 核心断法与结局 |
|---|---|---|
| **星包宫 / 宫包星** | 配偶星在宫两头，或宫在星两头 | 婚姻看得紧、粘得牢，不易离；六合式包局合得最紧，也最痛苦 |
| **官局 / 食伤包夫星** | 禄印或食伤占年时包住夫宫与夫星 | 婚姻稳、不会离；即便夫宫带穿破，也多只应配偶手术或伤灾 |
| **包局反局** | 两头地支相同但天干相克（如辛亥与乙亥、庚辰与甲辰、丁卯与癸卯） | 象相反、不是同一人，包局不成立，初婚必离 |
| **星入墓 + 包局** | 宫星入墓又形成包局 | 两头同象为一人则稳；若出现不同天干的墓库，则主两夫 |
| **财包局（女命）** | 原局无官杀，财星或伤官带财包局 | 易被人包养；若包局之字带比劫库，多是有家室之人 |
| **破包局的三种出路** | 羊刃克妻大运、冲破夫妻宫流年、六合破暗合（如卯戌合破申卯暗合） | 原局包得再死，逢此三种破法仍可走出围城、正式离婚 |

## 四、常见误区 vs 正确问法

- **常见误区**：只要看到夫妻宫带穿或带破（比如卯辰穿、卯午破、丑午穿），就立刻铁口直断“必定离婚”；或者看到两头地支一模一样，就以为必然是同一个人包局不离。
- **正确问法**：先问“被穿破的宫或星，是不是被两头严密包住了？”若被包局围住，往往只主吵闹、手术或痛苦而不离；再问“包局两头的干支是不是同一象？”如果天干相克相反，反局成立，反而是必离的信号。
