# 五合像签约互换筹码，六合像捆绑丢了单干自由

## 一、比初级、中级拓展了哪些

初级和中级已经讲过“天干五合分得、失、绊”以及“地支六合重在粘接绊住”。进入高级阶段，这一课在原有基础上把“合”的实战用法往深里推进了四个层次：

1. **天干五合的信息互换与强弱代偿**：合在一起的两个十神不再各自独立，而是“双方互为代表、强者代弱、弱者顺强”，直接用来读职业、性格与取财手段。
2. **合在宾位与主位、官星虚实的细断**：同样是合，落在宾位往往只是个人精神爱好；合到主位才关乎本人事业。官合身不论日主强弱，官在主位有制为官命，官星虚浮则主自己办企业。
3. **地支六合“一律合绊”与逐支失性**：明确无论命局、大运还是流年，地支六合都以“合绊失性”论，逐支点明熄火、闭库、坏根的具体所指，并引出**六合换象**（合到哪里就带上合方的性质）。
4. **流年合大运的“绊与留”及反局合**：讲清“大运静止，流年合大运才起作用”；流年合入命局，对原局是绊、对流年是留（得到），本身就是应期。一旦合冲保护了原局正要制去的对象，就成了反局大凶。

## 二、天干五合：两家公司签约，强方接管弱方名号

两家公司签了深度战略合作协议，对外可以互相挂名、共享资源。谁的体量大、实力强，谁的话语权就重——强方不仅能用弱方的牌子去办事，弱方也得顺着强方的路子走。

天干五合就是这套**信息互换**的逻辑：

```关系图
天干五合的互换与位置判断
强方合弱方 → 强方代表弱方的信息，弱方顺从强方
食神合印 / 伤官合印 → 食神合印偏学术思考，伤官合印偏技术艺术
伤官合杀被制 / 食神合杀被制 → 伤官合杀主掌权当大官，食神合杀主发财
合在宾位 vs 合在主位 → 宾位多属精神享受，主位才落实到本人事业
= 先看谁强谁弱决定“谁代表谁”，再看落在宾位还是主位决定“关不关自己的事”。
```

举个最直观的例子：如果劫财去合财，财被劫财合过来，这笔钱往往不是老老实实上班挣的劳动所得，而是靠非常手段、博弈或投机（比如炒股、期货一类）拿到的。同理，如果官星合身，先别急着去算强弱——只要官在主位且有制，多主官命；如果官星虚浮无根，合到身上往往不是当官，而是自己办企业当老板。

比如 <a class="qref" data-q="3">命例 3：乾造 丁酉日 · 我认为此造丁是做功的</a>，日主丁火一连合住年、月两个壬水正官，先看年官坐下的辰（辰收丑财库并辰酉合入主位），让他能继承祖业家产；再看月官坐下的寅，原本全局金水之势是要制寅中劫财的，他却用寅丑暗合去取财，手段恰好踩在了全局要削弱的字上，反而拿不住财。

## 三、地支六合：捆绑在一起，谁也别想单干

如果说天干五合像“签协议互换资源”，地支六合就像把两台机器用铁链锁在一起。不管你是在原局里锁，还是大运流年上来锁，**一律以“合绊”论**——双方都在一定程度上失去了原本的自由与特性。

| 六合组合 | 失性所指（被绊住或关上的东西） | 实战换象与注意点 |
|---|---|---|
| 寅亥合 | 熄了寅中丙火（印星或工作易灭） | 妻宫若为亥被寅合走，主配偶难进门或感情生变 |
| 卯戌合 | 闭了火库，木和土都失去原性 | 若日支坐财库本喜冲，逢卯合闭库反主破财受阻 |
| 辰酉合 | 一闭水库，二坏乙木（断财根） | 原局靠水木生发时，辰酉一合容易把财根铲断 |
| 午未合 | 闭木库，午火被未土晦暗 | 多为纯绊，做功效率偏低 |
| 子丑合 | 闭金库，双方互绊 | 库里东西出不来、外面东西进不去，常拖延婚期或财路 |
| 巳申合 | 巳旺去申中金水，申旺去巳中火土 | 六合里效率最高，可换象成“金都变成火财”或“火去制金” |

六合在时间轴上还有一层非常关键的**“绊与留”**。大运本身是静止的，只有流年去合它才真正发动；流年合大运，大运里的东西就被“留”下来、被你得到了。而流年直接合入原局时，对原局是“绊”（受牵制），对流年来说却是“留”（把这件人事留下来兑现），所以**流年合入命局，本质上就是一种应期**。

```关系图
地支六合的应期、换象与反局
流年合大运 → 大运静止，流年一合才把大运的东西“留”下来
流年合原局 → 对原局是合绊，对流年是“留住”兑现，即应期
六合换象 → 合到哪里，被合的字就带上合方的性质（如劫财合财皆作财看）
反局之合 → 原局本要制某字，岁运却用六合把它保护起来，主大凶
= 看六合先问“绊住了谁、闭了哪个库”，再查这记合是顺着原局制，还是帮了倒忙。
```

有合就有“合不对路”的时候。像 <a class="qref" data-q="77">命例 77：乾造 丙戌日 · 日主丙火合辛财，要看身强弱</a>，日主丙火在天干合辛财，本意明明是想求财，可地支偏偏酉戌相穿，把日主坐下依托的戌根穿坏了，结果求财的心愿落了空，婚姻也受牵连。更凶的则是**反局合**：原局明明摆好阵势要克制某个字，大运或流年突然跑来一个六合，把这个字牢牢护住、制不着了，事情就会立刻翻车。

## 四、常见误区 vs 正确问法

- **常见误区**：「看到天干五合就想着合化成另一种五行，看到地支六合就一概当成贵人相助、好事临门。」
- **正确问法**：「天干五合的两方谁强谁弱，强方把弱方的什么十神象借过来了？地支六合有没有把我要用的火熄掉、把要开的库闭上？这记流年之合，到底是帮我把好事留住，还是反过来护住了原局正要制去的对象？」
