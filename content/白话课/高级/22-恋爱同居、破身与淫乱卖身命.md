# 从早恋同居到“以身取财”：身体符号与关系的深浅

## 一、比初级、中级拓展了哪些

初级和中级只零星提过“桃花绊禄”“只同居不算婚”，几乎没有系统讲过婚前恋爱、破身和“以身取财”怎么看。这一课等于补上了一整块空白，核心拓展有三点：

1. **立出早恋、同居与破身的精准信号**：明确女命**以禄为身体**，破身看“禄被破”的两种方式（食伤泄气式冲破、官杀冲禄）；提出**干支一气**主纯洁没过别人、天干虚透多为婚前对象。
2. **讲清同居对象会不会变成配偶**：对象必须与夫妻宫有关联才容易发展到同居；若对象坐在比劫地支上，最终往往成为别人的配偶。
3. **拆解“以身取财”（卖身命）与才艺命的分野**：把“禄、食伤连体、时上丑（阴中之阴）、官杀入墓不开”的取财做功机制讲透，并用对比案例说明：**同样禄伤相连，夫宫单一稳定并相拱的是才艺名家，夫宫多现又以冲穿取财的才是卖身命。**

## 二、先看清“门户、身体与库”这三样东西

把一个人的感情经历比作一间屋子里的往来：**夫妻宫**是正堂，**禄神**是自己的身体，**墓库（辰、丑、未）**则是外面人群进出的大院。

有的人早早谈恋爱、同居，甚至反复换对象，却迟迟进不了正堂，往往是因为人在“门户”和“院子”里转，没真正落到安稳的夫妻宫里；而有的人之所以走到“以身取财”这一步，本质上也是用身体（禄或食伤）去和院子里的财官发生冲、穿、合，以此换取钱财。

```关系图
早恋、同居与破身的核心判断线
女命见禄无印，或财官在年月（月令常主同学） → 开心早，易早恋、早同居
禄神遇食伤泄破（如子破卯、卯破午）或官杀冲禄 → 多对应破身的时间点
对象虚透天干或坐比劫地支，且与夫妻宫有关联 → 易同居，但对方最终多是别人的配偶
= 干支一气（如丁未）常主纯洁未经历过他人；两禄合一官则婚前多同居对象。
```

## 三、婚前同居与“以身取财”特征速查

| 类别 | 核心命理特征 | 现实表现与关键区别 |
|---|---|---|
| **早恋与同居** | 财官在年月；男命比劫重；女命财旺或见禄无印；对象与夫妻宫有关联 | 年主早、月令多主同学；禄合财官（如巳申合）易失身或因物质同居 |
| **破身时机** | 女命以禄（及巳、午、亥等）为身体，逢冲、破或遇合之时 | 分两种：食伤之间的冲破（子破卯、卯破午），以及官杀直接冲禄 |
| **“以身取财”** | 禄或禄加伤食逢冲穿做功取财；夫宫多现；官杀入墓不开；丑落时上被刑冲穿 | **墓不开**主男人多且都是别人的；官星带财入坐下，主对方带钱而来 |
| **才艺 vs 卖身** | 同样是禄伤相连、长相秀气 | **夫宫单一稳定、星宫相拱**为歌唱/艺术名家；**夫宫多现、冲穿取财**则走向卖身 |

这里需要特别留意两点实操细节：

- **男命同居与花心**：男命若比劫旺、妻宫又是比劫库，再去冲宾位财星，主好色且性关系杂；若时上财带官星合到坐下，则常应奉子成婚。
- **时上“丑”的特殊取象**：原教材指出，阴中之阴（丑）落在时柱门户上，在特定组合里可代表女性身体隐秘部位或私下之事，一旦被刑、冲、穿引动就开始“做功”。但必须配合“夫宫不稳、禄伤取财”的整体结构看，绝不能单凭一个时支见丑就乱下断语。

```关系图
同样是“禄伤相连”，为何人生走向截然不同？
夫宫单一稳定 + 夫星与夫宫相拱 + 食伤吐秀 → 才艺、传媒、演艺成名
夫宫多现（到处是床） + 官杀入墓不开 + 冲穿禄伤取财 → 感情混乱或以身取财
= 分野不在“有没有禄和食伤”，而在“夫宫是否单一稳固”。
```

## 四、常见误区 vs 正确问法

- **常见误区**：一看到女命带桃花、食伤旺或有禄神遇合，就草率给人家贴上“不检点”“卖身”的标签。
- **正确问法**：先问“她的夫妻宫是不是单一稳定，星宫有没有相拱？禄神和食伤是在吐秀做正经事业功，还是在夫妻宫多现、官杀墓不开的前提下用冲穿直接换财？”
