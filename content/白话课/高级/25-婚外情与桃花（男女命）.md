# 婚外情与桃花：为什么“宫稳”反而容易养出婚外情？

## 一、比初级、中级拓展了哪些

初级第 12 课只给过男女婚外情的三四条基础条件（如财官混杂透干、伤食无制、桃花绊禄等），中级也没有专门展开。高级这一课把“婚外情与桃花”拆成了一套完整的判断系统，核心拓展有四点：

1. **先把关系分成三档**：持续最久的叫**妾**，略长的叫**情人**，短的或根本结不了婚的叫**桃花**；明确本体系看桃花按**宫、星、副宫、比劫**，不用“沐浴”那套神煞看法。
2. **点破共同前提——“夫妻宫相对稳定”**：夫妻宫稳不住，一闹就离，那是**多婚**；只有夫妻宫相对稳得住，同时又现出副宫并配出其他配偶星，才会长期维持**婚外情**。
3. **给出男命桃花的“开关与刹车”**：明确**男命一般必须比劫旺，婚外情才有可能；无比劫，财再多也没用**；同时提出两大刹车——**七杀透干制比劫**（自控强、无桃花）与**比劫太弱且财被湿土晦坏**。
4. **补全女命桃花的特有象法**：提出**阴多阳少喜阳（越有桃花婚姻越稳）**、**官星退气库（辰、戌、未）为非正式丈夫**、**见禄再逢财官**、**比劫桃花破财**，以及“流年虚字来去、桃花瞬间散”的应期。

## 二、婚外情和多婚，差在“家里那张床稳不稳”

打个比方：同样是在外面有人，如果家里的房子（夫妻宫）本身地基不稳、天天漏水塌方，外人一来家里就散伙，这叫**多婚**；如果家里的房子地基很稳（夫妻宫没被彻底冲穿坏），但屋主又多开了几扇门（副宫现、或他星拱入），外面的人进得来、家里又散不了，这就成了**婚外情或桃花**。

```关系图
婚外情与多婚的底层分水岭
夫妻宫被穿坏/刑坏 + 他星来争 → 婚姻维持不住，走向离婚、多婚
夫妻宫相对稳定 + 副宫配他星（或他星拱入） → 家里不散，外面不断，形成婚外情
= 看婚外情先查夫妻宫稳不稳，再查有没有“外溢的副宫与星”。
```

## 三、男女命婚外情与桃花速查表

男女命看婚外情的发力点完全不同，下面这张表可以直接对照：

| 对比项 | 男命 | 女命 |
|---|---|---|
| **基本格局** | 妻宫相对稳定 + 副妻宫现 + 配偶星相配 | 夫宫相对稳定 + 副夫宫现 + 配偶星相配；或另有夫星拱入夫宫 |
| **核心开关** | **必须比劫旺**（占有欲强）；无比劫则财多也无用 | **见禄再逢财官**；禄被他合或众财官合禄，固定不住 |
| **常见抑制** | **七杀透干制比劫**（自控强、无桃花）；比劫太弱财被湿土晦坏 | — |
| **不同桃花象** | **伤官桃花**：情薄、不缠身、不专一；**官星化财**：桃花极多；**时上丑库不开**：里边女人多；**戌**：色情场所 | **官星退气库（辰、戌、未）**：不是正式丈夫，入墓不开主多且有家室；**比劫桃花**：易为桃花大破财；**合财**：婚姻意义不大 |
| **特殊心态/走势** | 比劫旺+食伤重，欲望与放任兼有 | **阴多阳少者喜阳**，往往越有桃花婚姻反而越稳定 |

```关系图
男命有没有桃花的“一开一关”
比劫旺（尤其配副宫或伤官） → 欲望强、占有欲重，桃花不断
七杀透干制住比劫，或比劫太弱被湿土晦 → 自我控制强或无力去劫，婚外情不成立
= 不能见了“比劫多”或“财星多”就乱断桃花，必须先查有没有七杀来制。
```

此外，女命还有一条很灵验的应期规律：**流年天干某个虚透的字（如癸）一来，它原局所合的那个字（如戊）就被合走外出，表现为刚看上的桃花瞬间来、瞬间散**；若局中出现“包局”（如酉包合又重现），则往往是藕断丝连、很难彻底断干净。

## 四、常见误区 vs 正确问法

- **常见误区**：一看到男命八字财星多，或者比劫旺，就一口咬定“必定花心、婚外情不断”；或者看到女命有桃花，就断她“马上要离婚”。
- **正确问法**：先问“男命有财时比劫旺不旺？比劫旺时天干有没有七杀透出来制住它？”对女命则先问“她的夫宫本身稳不稳？是不是阴多阳少喜阳的类型，还是禄神与退气库在把外人引进来？”
