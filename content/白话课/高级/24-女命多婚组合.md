# 女命多婚的六条硬杠：比劫争夫、关财门与耗尽才稳

## 一、先把女命多婚的底账理清

如果把女命的婚姻比作维持一条流水线：**财星**是源头（水库），**官杀（夫星）**是产出的正主，**日支（夫宫）**是自己家的门户。只要这条线顺畅、门户不被外人占去，婚姻就能稳；一旦源头被掐断（**关财门**）、门口有人抢人（**比劫争夫**），或者自家的门户反过来把丈夫往外捅（**宫穿星**），婚姻就很容易散。

原教材把女命多婚归纳为六种核心组合，前四条与男命相对，后两条则是女命最关键的关口：

1. **夫宫多现又配夫星**，且夫宫本身不稳。
2. **夫宫虽单现，但被坏**（合坏、刑坏、穿坏），一婚不到头。
3. **夫宫没坏，但夫星被坏**，同时又有新的夫星出现。
4. **夫星多合**，合一次加一个，或因他合而离开。
5. **比劫争夫**：夫星被比劫包住或被比肩合走，丈夫必有外遇；此时哪怕宫星原本联系再好，初婚也会离。
6. **关财门**：财是官杀的原神，财星被冲坏、被劫克，就像断了官星的粮草，必多婚。

```关系图
女命“比劫争夫”与“关财门”的破婚链条
比肩/劫财透干合走夫星，或夫星坐在比劫之上 → 丈夫外心，初婚极难保住
财星（官之原神）被劫财克尽或遭大运冲坏 → 关财门，官星无源而离异
夫宫与夫星之间发生相穿、相破 → 星宫无法相生，矛盾激化必离
= 记住两句实用口诀：日时支“辰”伏吟不主二婚；女命天干合财在婚姻上意义不大。
```

## 二、数清几次婚、哪一次才稳的实操细则

实操里最容易数错的，是“到底算一个人还是两个人”，以及“离到第几次才能稳”。下面这张速查表把高级课里的细化口诀一次收齐：

| 实操问题 | 盲派判断细则 | 常见误判提醒 |
|---|---|---|
| **一个人还是两个人？** | 连体干支或同象可合并为一人（如戊申与庚申、双丙连体） | 不能机械按天干个数硬数，要先查是不是连体或谁坐在劫财上 |
| **一星两宫 / 双宫双星** | 通常主两次婚姻（第一次合没到位，第二次才到位） | 若**辰在日时伏吟**，则不表示二婚 |
| **大运取代原局夫星** | 原局有夫星，但先走冲入夫宫的大运，头婚看大运冲入之字 | 原局无明显离象时，必须结合大运看是否被“破局” |
| **夫宫入夫星之墓** | 夫宫合入夫星之墓，把婚姻“埋”了，不死则离 | 若原局官杀多，往往应**伤官运、伤官年**再婚，但也难长久 |
| **离到第几次才稳？** | 星宫被穿、被破，有两穿需离两次、破一次，共三婚 | **第三次婚姻才好**：因为刑、穿的能量在前两婚里已经耗尽 |

还有一点很值得留意：**情人先、丈夫后**的反转情形。有些女命原局看起来一个像正夫、一个像偏夫，但经过大运流年的刑冲变化（比如把原本拱劫财的阻碍刑开），原本的“先情人”反而会转正成后来的丈夫。

## 三、常见误区 vs 正确问法

- **常见误区**：看到女命天干透出两个丙火正官，就直接数成“两次婚姻”；或者看到女命日主去合财星，就当成“合来好丈夫”。
- **正确问法**：先问“这两个丙火是不是连体，算不算同一个人？其中哪一个坐在劫财上？”再问“她的财星（官的原神）在运岁里有没有被劫克关财门？如果有多次刑穿，前两婚是不是已经把刑穿的能量消耗完了？”
