# 父母离异与从小过继：怎么从八字里分清“聚散”和“谁来养”

## 一、比初级、中级拓展了哪些

初级第 4 课只带过一例弃养，中级第 11 课也只在“十神看六亲”里顺带提了一句“伤官作母主改嫁”，两条线都没有展开成独立方法。这一节高级课把“父母聚散与抚养”正式立成两大专题，补全了四块实战规则：

1. **离异 vs 死亡的明确分界**：父母之星相互克战却看不出死亡信息，断法直接转向“父母离异”。
2. **再婚、随谁与顺序判法**：给出“双合、伏吟主再婚”、“日主坐在谁的字上随谁”、“暗合/冲出之字看继父继母”以及“按伏吟先后定结婚顺序”的全套法则。
3. **弃养与过继的成因**：点破**食神（养我之物）**被合绊、被穿倒、入墓时“没饭吃”而被送走的底层逻辑。
4. **生父母与养父母的分宫**：明确月柱看生父母、时柱看养父母，并归纳出远方食神合入主位（过继给亲属）、乙代表姥姥、未代表祖母等具体找法。

## 二、两口子散伙 vs 家里揭不开锅：生活里的两种离开

同样是“小时候没能一直和亲生父母待在一起”，现实里其实是两码事。一种是父母天天吵架、互相克制，但两个人都平平安安（没有死亡信息），最后只能散伙离婚——孩子站在门中间，看自己脚底下踩着谁的鞋（日主坐在哪一方的字上），就跟着谁过；如果父母又各自找了新伴侣（双合、伏吟、暗合冲出），家里就会出现继父或继母。

另一种则是“没饭吃”：在盲派里，**食神是养我之物**。如果月令的食神掉进墓里，或者被别的字合走、穿倒，就像家里饭锅被人端走了，父母养不了或不想养，只能把孩子送出去（过继给叔叔、姨妈，或由姥姥、奶奶抚养）。

```关系图
父母离异的判断顺序
父母星相克 + 无死亡信息 → 必是父母离异
父（母）星双合或伏吟 → 主父另娶或母改嫁（可按伏吟先后定婚序）
看日主坐字与暗合冲出 → 坐谁字就随谁，暗合或冲出的字看继父母
= 先分清是“克死”还是“克散”，再看孩子跟谁走、谁是后来的家长。
```

在 <a class="qref" data-q="543">命例 543：坤造 己卯日 · 父母离异父母戊子运戊寅年闹离婚</a> 里，就能看到父母星相克、母星伏吟离开、父星另有外遇而离异后各过各的典型画面。

## 三、离异与弃养（过继）核心判据速查

| 类别 | 核心信号 | 具体怎么断 |
|---|---|---|
| **父母离异** | 父母星相克，但无一方死亡信息 | 不以克死论，直接断父母离异 |
| **父另娶 / 母改嫁** | 父星或母星**双合、伏吟** | 双合、伏吟主再婚；先离后与亲妈结婚者，看亲父星伏吟的先后顺序 |
| **随父还是随母** | 看**日主（自己）坐在哪一方字上** | 坐母字随母、坐父字随父；**继父/继母**看暗合、冲引出的另一个字，或父母星被他字合到继位 |
| **弃养 / 过继基础象** | **月令食神入墓**＋时上又见食神 | 父母不养、过继之命；**月柱为生父母，时柱为养父母** |
| **谁养与给出去** | 食神被合、被穿、被绊；远方食神合到主位 | 食神被坏＝没饭吃被送走；**远方食神五合到主位**（如丁壬合）多过继给叔叔；日年相穿倒食神（如寅巳穿）可看时伤官通乙为姥姥养；**乙庚合到门户**＝给出去 |
| **父母态度** | **母带伤官**；**父星他合** | 母带伤官不养自己；父星被他字合走不管自己 |

例如在 <a class="qref" data-q="533">命例 533：坤造 丙申日 · 父母弃养伤官坐母关系不好</a> 中，母亲星带着伤官、与自己关系不好而不养，父星又与别字相合不管自己，合到月令与未土祖母相联，实际就在奶奶家生活长大。

```关系图
父母弃养与过继的识别线
月令食神入墓 / 被合被穿 → 养我之物受损，亲生父母不养
时上再见食神 / 远合入主位 → 时柱出现养父母，或过继给亲属长辈
母带伤官 + 父星他合 → 父母各自顾不上自己，多由祖辈或他人抚养
= 盯紧“食神（饭碗）”有没有被坏，再看“时柱与远合”谁来接手。
```

## 四、常见误区 vs 正确问法

| 常见误区 | 正确问法 |
|---|---|
| “一看到命局里父母星互相克战、相穿，就只敢往‘克死父母’上断。” | “先查有没有死亡信息（如无立足、入墓无救、断原神等）；如果没有死亡信息而父母星相克，就要往父母离异上断。” |
| “父母离婚后孩子肯定跟妈妈，或者跟哪一方纯粹靠猜。” | “看日主自己坐在哪一方的字上：坐母字随母、坐父字随父；再用暗合或冲出的字去看继父、继母。” |
| “食神只看口才和吃喝，和从小送养过继没什么关系。” | “食神是养我之物，一旦月令食神入墓或被合穿绊倒，就主‘没饭吃’而父母不养，再看时柱与远合就能定谁来抚养。” |
