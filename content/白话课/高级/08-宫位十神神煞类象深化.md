# 宫位、十神与神煞深化：谁离家、谁犯小人，墓库唯一性怎么卡

## 一、比初级、中级拓展了哪些

初级和中级已经讲过四柱宫位七维总表、十神正反两面与六亲通变，以及禄、羊刃、墓库、驿马、空亡五大神煞的基本象义。

这节高级课在已有体系上**新拓展了三大实战模块**：

1. **宫位动作的精细生活落点**：明确**月日相合离不开祖籍、月日相冲肯定离开老家**、月日伏吟主搬家移动两处；**日支来穿主犯至亲小人**；买卖房看日支（印财日支）、买车看时柱（印财时柱）、爱打扮看时上食伤；天干表外在评价，地支表家庭内部与内心。
2. **十神与神煞的边界深论**：点破**官杀本身不代表官非桃色（须靠组合与宫位）**；**食神不怕旺、越旺越好**；**禄代表女人的肉体，见禄不可刑冲**；重点补全**墓库“中神与墓神必须唯一”**的严格计数规则，以及**空亡“旺喜空、衰不喜空，伤官空亡无子”**的实操。
3. **兄弟姐妹数量推算与面形诀（全新）**：中级完全未讲——给出**按出生时辰定兄弟姐妹数量**、**超过五人的五行生成数与地支起数**，以及按地支三组分的**面形与睡姿口诀**。

## 二、宫位深挖：谁会离开老家，谁在身边犯小人？

把人生的八字四柱比作一栋四进的院子：年柱是大门外（远方、海外、公婆岳父母），月柱是祖屋客厅（祖籍、家乡、父母、同事领导），日柱是自己的卧室与书房（自己、配偶、内心世界、房子），时柱是临街的门面车库（出门、车子、晚辈、交际形象）。

宫位之间一发生“合、冲、穿、伏吟”，生活里的动静就立刻出来了：
- **离开祖籍与搬家**：**月日相合离不开祖籍**；**月日相冲肯定离开老家**；**月日伏吟**则是搬家、在两处之间来回移动之象。
- **置产与门面**：**日支**见印或财常对应买卖房屋；**时柱**见印或财常对应买车；时上见食伤（门户之上）多主爱打扮、注重外在形象。
- **犯小人**：**日支来穿一下就是犯小人**——因为日支是离自己最近、最贴身的宫位，所以这个小人往往就出在关系最密切的人当中。
- **表里之别**：**天干表外**（外界对你的评价），**地支表内**（家庭内部关系与真实内心）。

```关系图
宫位、十神与神煞的四大深化开关
月日相合 vs 月日相冲 → 合则留恋祖籍，冲则必离老家（伏吟主搬家移动）
官杀与食神特性 → 官杀不单主官非桃色（靠组合）；食神不怕旺、越旺越好
女人见禄与空亡 → 禄表女人肉体，原局大运怕刑冲；空亡旺喜空、衰不喜空
墓库“唯一性”法则 → 中神与墓神必须唯一（丑未全不入辰，一丑两辰不墓）
= 宫位定“事发地点与关系远近”，神煞规则卡死“到底入没入库、算不算空”。
```

## 三、墓库“唯一性”与十神神煞实战铁律

很多同学学到墓库就容易乱装：看到一个辰、一个丑，直接喊“入墓”。高级课专门把**墓库的“唯一性”门槛**卡得非常死：

- **多而墓之，中神墓神都要唯一**：辰是水土库（亥水入辰，未丑土入辰）；但**一个不入墓，两个才入墓**，而且被墓之神（中神）和墓神本身都必须**唯一**。
- **具体卡法**：丑未同见时，两者都不入辰墓；**两丑**或**两未**才入辰墓；反过来，**一丑两辰**或**一亥两辰**也不入墓（原教材举例：`辰丑辰` 中丑不入墓，但若中间隔了字变成 `辰寅丑辰`，则丑入临辰）。另外**戌和辰是相冲，不是入墓**。
- **不同墓库对应的机构**：羊刃墓为军团，伤食墓为学校或庙宇，伤杀墓为权力中心（如组织部），财墓为银行。

十神与空亡也有几条极易用错的纠偏口径：
- **正官合身才算管辖**：正官不合身往往没实际管理意义；所谓“正官为夫、七杀为情人”并不绝对，必须看宫位（若七杀得正位照样以夫看，正官落宾位也可为桃花）。
- **空亡的两面性**：空亡是“有名无实、有象无形、玄学、减半”。**旺喜空，衰不喜空**——六亲临空亡，衰则有病或早缺，旺则没事；日上空亡与自己关系最密切，**伤官空亡往往没有儿子**；但逢流年填实（如未土空亡逢未年）反而容易应凶。

## 五、常见误区 vs 正确问法

- **常见误区**：“命局里有两个辰土和一个丑土，丑土是不是肯定入辰墓了？或者命盘里七杀多，是不是一定有官非、有烂桃花？”
- **正确问法**：“中神和墓神是不是都做到了‘唯一’（一丑两辰通常不入墓）？七杀在盘里有没有正位或制化组合——因为官杀本身只主职务权力，官非与桃色要看具体的穿冲与宫位配合。”
