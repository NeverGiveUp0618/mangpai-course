# 伤克配偶判断：宫星死墓绝与病灾应期

## 一、比初级、中级拓展了哪些

初级只提过配偶星得正位被坏易生病灾，中级仅在“宫穿星”里带过一句“必离或配偶死亡”。本课把“伤克配偶”单列成一套完整的生死与灾厄判断体系，实质拓展有四点：

1. **立出铁打的前提**：明确“伤克配偶”并非本人真的把对方克死，而是**配偶本身命中有问题**，只是通过本人的命局提前体现出来。
2. **补全死墓绝表与“互绝”口诀**：系统给出五行死、墓、绝对照表，以及**寅酉、子巳、卯申、午亥**四组互绝规律，专门用来抓大灾应期。
3. **点明男女命最凶的伤克符号**：女命**阳日主见阴伤官克夫**（阴日主见阳不克），并列出具体干支与伤官库（未、丑、戌）；男命**羊刃、劫财克妻，以申金劫财最重**。
4. **区分“死”与“不死 / 伤而不离”**：给出“墓绝同现主死亡”的硬信号，同时点出**夫星临墓被冲开则伤而不死**、**包局则伤而不离**的救应边界。

## 二、生活类比：不是你撞坏了车，是这辆车本来就有暗伤

很多人一听“克夫、克妻”就害怕，以为是自己把另一半克出事了。盲派看命先破这个心结：就像两辆车并排开在路上，你的行车记录仪刚好拍到了旁边那辆车轮胎漏气、刹车失灵。**真正出毛病的是配偶自己的命**，你的八字只是把这段共处的时间和结果记录了下来。

那记录仪里哪些画面最危险？一是配偶星一进你的夫妻宫，就踩进了自己的**死、墓、绝**之地，好比鱼进了干涸的池塘；二是夫妻宫和夫妻星**同时被坏**，或者凑齐**三刑**、**墓绝同现**；三是女命关了**财门**（把生夫星的原神坏掉），断了配偶的生路。

```关系图
伤克配偶的三类硬信号与救应
宫临星之死墓绝，或宫星三刑、墓绝同现 → 配偶易有大灾或死亡
女命阳日见阴伤官，或关财门坏原神 → 克夫力重，应期看伤官库或原神受克年
男命羊刃、申金劫财克妻，或妻星两头见墓 → 克妻严重，合绝/冲闭墓门为应期
= 墓被冲开多伤而不死，有包局护住则伤而不离。
```

## 三、死墓绝速查与男女克象对比

| 维度 | 核心规则与符号 | 应期与减轻条件 |
|---|---|---|
| **五行死墓绝** | 金绝寅子死丑墓；木绝申午死未墓；水绝巳卯死辰墓；火（土同）绝亥酉死戌墓 | 记忆**四互绝**：寅酉、子巳、卯申、午亥互绝 |
| **女命克夫** | **阳日主见阴伤官**（乙、卯、辛、酉、己、丁、午及伤官库未丑戌）最重；夫星临墓不开；关财门 | 阴日主见阳伤官不克；若夫星临墓被**冲开**，多主车祸伤残而不死 |
| **男命克妻** | 羊刃、劫财克妻（**申金劫财最重**）；妻宫临妻星死绝；妻星两头见墓不开 | 遇合绝之字被冲解、或原神被合去、或刑开墓库之年发凶 |
| **宫星同损与包局** | 宫星同时被坏或逢三刑，主离或死；**墓绝同现**主死亡 | 若原局有**包局**保护，虽见伤官破宫（如卯午破），多只主重伤休养而不离不死 |

> 原教材存疑提示：在“官星丑土墓夫宫申金、财在戌库不开且空亡”一例中，原教材曾留下“丑戌刑不开吗，是否八字阴气重制死了戌阳？”的讨论，此处保留原教材未定论的思考，学习时不必强行下死结论。

## 四、常见误区 vs 正确问法

- **常见误区**：一看到女命带伤官、或者男命带比劫，就吓得断“克夫克妻、必死无疑”；或者真出了事，就把心理负担全揽到命主自己身上。
- **正确问法**：先分清阴阳与位置——“女命是不是**阳日主见阴伤官**？男命的劫财有没有直接合克、冲绝妻星？”再看救应——“墓库是闭死不开，还是有冲开？宫星有没有被包局护住？”把“死别”“伤残”和“只是离婚”分得清清楚楚。
