# 干支象义与干支配置：君臣怎么配合，一个“戌”字能变出多少行业

## 一、比初级、中级拓展了哪些

初级和中级已经讲过十天干、十二地支的基础类象、干支虚实与自合、禄与原身，以及“共象、合象、带象”等七条取象原则。

这节高级课在已有象法基础上**新拓展了四个实战深度**：

1. **干支配置“君臣法则”与带象升华**：明确“干为君、支为臣”，天干可以克地支、地支通常不克天干（唯有**干支相合**如辛巳、癸巳、丁亥、己亥时才论地支克天干）；同时点出**壬戌、丙戌必须用未刑开才能自合**（不能用丑刑），以及“制去官或官的长生之神为大官”的带象应用。
2. **半禄、半通禄与“一个象/半个象”的精细分级（全新）**：不再只讲“禄”和“原身”，而是精确区分**半禄（丁未、癸丑）**、**半通禄/一家（丙戊、丁己）**、**一个字一个象（丙巳、戊巳、丁午、己午）**与**半个象（丙戊、丁未、丁巳）**，以及**藤萝系甲**与乙木借未辰现象。
3. **十神虚透的系统对照表与四库耐受边界**：把财、官、印、食伤虚透后的吉凶与行业指向一张表讲透，并补出“四库都可坏，唯**丙戌不敢坏**（辰冲、丑刑都不可）”。
4. **单字多维拆解示范（以“戌”为例）**：完整演示地支“戌”在配合不同天干与十神后，如何变成枪库/公安、夜总会/网吧、学校/编辑部或凶案应期。

## 二、干支配置：君臣上下怎么联动？

把一柱干支比作一家公司：天干是坐在总经理室拍板的**老板（君）**，地支是跑现场的执行团队**（臣）**。

老板（天干）可以直接管教员工（地支），反过来员工通常不能直接克老板——**除非两人签了内部合伙协议（干支自合）**。就像辛巳、癸巳、丁亥、己亥这几柱，因为上下暗中相合，地支才能反过来制住天干。

而有些“自合”还带着一把锁，必须先开锁才起作用：比如**壬戌、丙戌**两柱，戌里藏着火土，必须见**未**来刑开（燥土相刑开火库），里面的字才能出来跟天干自合；**不能用丑刑**，因为丑是湿土，会把戌里的火闷灭。

```关系图
干支配置的三大核心机制
干克支 / 支克干 → 干能克支；支只有“自合”（辛巳、癸巳、丁亥、己亥）时才克干
干生支（带象） → 支带干象（如丙寅、甲午），上下按一个整体看（如戴官帽/戴财帽）
禄、半禄、半通禄 → 丁未与癸丑为半禄；丙戊、丁己为半通禄（一家）
实透 vs 虚透 → 实为用怕虚，虚为用怕实；虚透之年常作应期
= 看到一柱干支，先问上下是互相生助成“一家”，还是锁在库里等“开锁”。
```

在**干支互通**上，高级课把“一家人”的亲疏关系分得很细：
- **一个字一个象**：丙巳、戊巳、丁午、己午（同出一宫，直接互代）。
- **半个象与半禄**：丙戊、丁未、丁巳算半个象；**丁未、癸丑**是半禄；**丙戊、丁己**是半通禄（一家）。
- **藤萝系甲**：甲木见亥为根，乙木见寅为根；辰戌丑未四库没有原身也没有禄，但土中藏乙木（未、辰）时，天干有乙木、岁运见辰或未，就代表乙木的一个象到了；同理丁火见戌土也是半禄关系。

## 三、十神虚透速查与“地支看它干什么”

高级课有一句点睛口诀：**地支的象要看它干什么——必须配合天干之象和十神透干来用**。同一个地支“戌”，单独看可以是医院、学校、庙宇，也可以是枪弹库、夜总会、网吧、黑道场所；到底取哪一个，全看它头顶坐着什么天干、在原局里配合什么十神做功：
- 头顶七杀或配酉穿、羊刃：多往**枪支、公安、执法、打斗**上走；
- 配食伤、火库文明之象：可落成**编辑部、学校**；
- 落时柱门户配丙火激情或比劫才华：可变成**夜总会、网吧**。

下表总结了**十神虚透天干**时的固定转化规则（记住：**虚财不为财，实财才为财**）：

| 十神 | 虚透天干时的含义 | 实战关键提醒 |
|---|---|---|
| **财星** | 不主钱财，主才华、才气、会来事、能说会道 | 透时上能花钱会办事；合印则擅长沟通、调解与表达 |
| **官杀** | 不主实际官职，主名气、名望、头脑聪明伶俐 | 杀制尽才算当官；官杀虚透常是出名而不掌实权 |
| **印星** | **分用忌**：印为用时虚透＝没文凭；印为忌时虚透＝有文凭 | 印为忌被去掉同样主有文凭，不能一见虚印就断低学历 |
| **食伤** | 虚或弱而受制有用（或泄秀），主口才与才华 | 食神弱不被制反不爱讲话；食伤实了才主要对应实际财运 |

此外，原教材还留下一条极细致的**天干与地支特殊性提示**：丙火最怕晦火（辰、丑湿寒土晦火力大，不克水而能生金）；戊土在时上露出一般鼻子大；戌与亥在学科上主数学（戌亥为乾宫），丙丁火主语文（到年时上可主外语），戌未主化学，酉金（有时含申）主物理。

## 四、常见误区 vs 正确问法

- **常见误区**：“天干没见到日主的禄，那年柱或月柱上的印/伤官就跟我没关系；或者看到命局里有‘戌’，就直接断不是老师就是进牢房。”
- **正确问法**：“盘里有没有**半禄（丁未、癸丑）**或**半通禄（丙戊、丁己）**把宾位的字跟自己连成‘一家’？这个‘戌’头顶坐了什么十神、跟谁合穿刑冲，在干支和十神共象之下到底在干什么？”

## 五、回到题库看真实命例

结合以下三则真实命例，对照体会“半禄一家”“十神虚透”与“干支带象”在原局里的具体判法：

1. <a class="qref" data-q="6">命例 6：乾造 己酉日 · 丁己半禄有自己的一半</a> —— 直观演示了“丁己半禄一家”如何让宾位的财星跟日主产生一半的关联，以及为什么本来不错的食伤生财结构，一旦被“酉戌穿”“亥申穿”穿坏做功之字，依然沦为既不当官也不发财。
2. <a class="qref" data-q="86">命例 86：乾造 辛未日 · 辛金日主坐财库，天干丙丁火官杀虚透</a> —— 清晰印证了“官杀虚透主名气（不主当官）”，同时财库入辰墓再合回主位之禄，把“足球名星”的象义和收入稳稳抓在手里。
3. <a class="qref" data-q="143">命例 143：乾造 丁丑日 · 时柱都为带象，年柱壬寅为印带官帽</a> —— 展示干生支（带象）与“印带官帽”在看盘定象中的直接用法。
