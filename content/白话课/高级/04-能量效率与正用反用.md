# 同是做功，为什么有人赚小钱、有人成大局

## 一、比初级、中级拓展了哪些

初级和中级已经讲过做功的五种基本方式，但还没有给不同做功方式的“赚钱效率”和“格局天花板”排座次。这一课在高级体系里新拓展了四个核心视角：

1. **制、化、泄的总排序与“凶神为用”**：明确**制高 > 化次 > 泄生最低**（泄生多在十万百万级），并解释为什么杀、伤、劫、枭等凶神有制化时档次反而比财官印食（吉神）高。
2. **四种制法的能量细排**：把合制（巳申最高、干克支高于支制干）、克制（围克/干克支高、单克最低）、冲制（冲库最高、成势才有效、木冲能量最高）以及穿制（**体穿用用坏、用穿体我得**）的效率从高到低排得明明白白。
3. **正用与反用**：第一次系统提出“正用（主位体制宾位用，规矩力小）”与“反用（主位用反制宾位体，阴阳错位、思维异于常人、力大）”的格局区分。
4. **宾位被制的必要条件**：点明宾位的东西被制时，**一定要和日主发生关系**，否则制得再干净也不算自己的成就。

## 二、搬砖、做代理与直接收购：能量效率差在哪

同样在商界挣钱，第一种人靠自己双手一点点干活攒钱（**泄生**），哪怕再勤快，天花板也就在十万百万级；第二种人靠当中间商、拿授权资质去疏通关系（**化用**），层次高一截但仍受限于上游；第三种人直接把对手的渠道或核心资产并购过来（**制用**），只要并购干净，格局一下子就能翻到千万上亿。

八字做功的能量效率，就是这三条阶梯：

```关系图
做功方式与凶神吉神的效率排序
制（直接制住对方） → 能量最高，制干净则格局大
化（如以印化杀） → 格局次之，官级通常不如制用大
泄生（食伤泄秀生财） → 效率最低，多在十万、百万级
凶神（杀伤劫枭）为用 → 灵活善变、不拘常理，有制化多成大人物
= 先看八字走的是“制、化、泄”哪一条路，再看制法干不干净、有没有把原神一起制住。
```

同样是“制”，手里拿的工具不同，效率也差很远。比如 <a class="qref" data-q="201">命例 201：乾造 癸未日 · 有金水之势，唯一做功之神为亥水</a>，虽然全盘成金水之势，但唯一干活的功神是亥水拱合未土去克，这种比劫做功的效率偏低，落实到现实就是每天下地干活的体力劳动者。相反，如果能把所制之字连同它的原神一起制干净，或者用冲库、围克、干克支的高效手段，层次就会完全不同。

| 制法类别 | 效率排序（从高到低） | 实战关键细节 |
|---|---|---|
| 合制 | 巳申 > 巳酉 > 子丑 > 卯戌 > 卯申、午亥、寅亥、寅丑、午戌 | **干克支（如戊子、丙戌）效率高，支制干（如辛巳、丁亥）效率低**；制净原神才高 |
| 克制 | 围克（三面围制）、干克支 > 邻克 > 单纯克制 | 单纯邻克能量小，多主混口饭吃、领固定工资 |
| 冲制 | 冲库（丑未、辰戌制净）> 成势之冲 > 一对一之冲 | 库不冲不发，不用则无用；一对一均势只是冲动消耗；**以木冲能量最高** |
| 穿制 | 必须分清体穿谁、谁穿体 | **体穿用，用坏（无缘得不到）；用穿体，我得（反主得到）** |

## 三、正用与反用：守规矩稳步走，还是错位反向操盘

常规公司里，员工用自己的本事去赚客户的钱，合情合理、规规矩矩，但往往爆发力有限；可如果一个人反向操作，把自己位置上摆着的资源和头衔当成杠杆，反过来把外部的资本和人脉统统收编过来，这就叫“不按常理出牌”——一旦成局，能量极其惊人。

```关系图
正用与反用的结构对照
正用（主位体制宾位用） → 合乎常理，日主规矩大众，但爆发力较小
反用（主位用反制宾位体） → 阴阳错位，思维异于常人，组合好则力大非凡
宾位被制的前提 → 宾位被制之物，一定要和日主发生关系，才算自己得到
官命要点 → 官杀主职务、印主权柄；官杀与印不管为用为忌（作病）都必须有根
= 看到“用占主位、体落宾位”先别慌，只要主位之用反制住宾位之体，往往是异于常人的大格局。
```

像 <a class="qref" data-q="133">命例 133：坤造 丙寅日 · 局中日支寅与两亥合</a>，日支印星直接把月、时两个亥官合到坐下，日干又合财牵动官星，高效做功且都与日主发生紧密关联，正是效率与关联度兼具的写法。反过来，如果宾位的官印被制得再热闹，却跟日主半点关系都没搭上，那也是替别人热闹、自己沾不到边。

## 四、常见误区 vs 正确问法

- **常见误区**：「以为只要八字在“做功”就一定能发大财当大官，或者看到主位坐财官、宾位落比劫就急着断成“破格”。」
- **正确问法**：「这个盘走的是“制、化、泄”里的哪一档？制法是高效的冲库、围克、巳申合，还是低效的单克、寅亥合？它是正用还是反用？宾位被制的东西，有没有真正和日主搭上线？」
