# 婚姻怎么定名分、找准人，又在哪年正式成家

## 一、比初级、中级拓展了哪些

初级和中级已经讲过“以夫妻宫为主、配偶星为辅”，以及地支合入、天干五合、合处逢冲与开库这几条基础应期。高级这一课在此基础上，把实操链条又往前推进了三步：

1. **给“结婚”立了硬口径**：明确“以婚姻为目的、共同生活超过半年的同居”就算婚姻；短同居若最终成婚，也算结婚应期的一部分。
2. **把找配偶星拆成“宫 → 副宫 → 配偶星”三步走**：提出**副宫**（日支透出的天干，或日主同柱另一半位置），再看副宫同柱所配之字才是真正的配偶星，并分清“天干虚主短或桃花、地支实主长、大运婚过运则无”。
3. **扩充五条应期与干支互引工具**：在合、冲、开库之外，新增**伤克多者去其一而应**、**宫星联体**、**坏掉阻碍字**（包括女命伤官反主结婚的两种情形），并给出完整的**十天干对应地支表**与**墓库互引口诀**。

## 二、先看“房子”，再找“门牌号”和“住进来的人”

很多人看婚姻，一上来就满盘找财星或官杀，结果找出一堆字却分不清哪个才是正经伴侣。其实可以用租房登记来打个比方：

- **婚姻宫（日支）**好比你名下的**主房**，房子安不安稳，决定了婚姻的底盘。
- **副宫（日支透出的天干）**好比从主房伸出去的**门牌号或门把手**。看婚姻不能只盯着主房本身，往往要先看门牌号透到了哪一柱。
- **配偶星（副宫同柱所配之字）**才是顺着门牌号真正**住进屋里的人**。如果顺藤摸瓜配出来的不是财、官，而是印星或比劫，那段关系就容易别扭。

```关系图
看婚姻“三个件”的顺藤摸瓜顺序
第一步看婚姻宫（日支） → 确定婚姻底盘稳不稳
第二步找副宫（日支透出之干） → 看主房把线索延伸到哪一柱
第三步认配偶星（副宫同柱所配之字） → 有多少算多少，必须与宫有关联才算成婚
= 宫是“位”，星是“人”；宫星没有相合、相生、拱或入库关联的，只是虚的对象。
```

另外，顺次与虚实也有讲究：一般按**年柱为早、时柱为晚**依次排列；**天干虚透的通常时间短或只算桃花，地支落实的才长久**；如果是靠大运凑出来的婚姻，**过了这一步大运就容易散**。

## 三、结婚应期五法与干支互引速查

找结婚年份，核心还是看什么时候把“宫”和“星”接通。除了常见的合动与冲开，原教材把应期归纳为五条规则：

| 应期类型 | 核心触发逻辑 | 常见易错提醒 |
|---|---|---|
| **1. 合动与冲合** | 三合、六合、天干五合将宫星接通；原局已合住的用冲引动 | 同一颗星既有冲法又有合法时，要看引动后是生助还是反伤 |
| **2. 伤克应** | 原局配偶星太多，流年伤克、去掉多余的之一反而成婚 | 仅适用于多星杂现，独星被克反主散 |
| **3. 宫星联体** | 太岁让“宫坐于星上”或“星坐于宫上”，把两件捆在一起 | 干支同时到位（干动星、支动宫）最有力量 |
| **4. 坏掉阻碍字** | 原局有字刑、克、隔住婚姻，运岁把这个阻碍字坏掉即成婚 | **女命伤官运本不利婚，但若能去阻碍、或原局官杀多混杂/官杀入他墓，反主结婚** |
| **5. 综合大运** | 必须结合原局早晚婚底色与大运吉凶 | 刑坏夫妻宫的不利大运，往往要**过运后的第一个合适流年**才完婚 |

在实际推流年时，常会遇到天干引动地支、地支引动墓库的情况，下面两张工具对照表可以直接查用：

| 流年天干 | 对应引动之地支 | 墓库互引口诀（双向通用） |
|---|---|---|
| **甲 / 乙** | 甲引亥、寅 ／ 乙引卯、未、辰 | **寅卯 ↔ 未**（木引未，未代寅卯） |
| **丙 / 丁** | 丙引寅、巳 ／ 丁引午、戌、未 | **巳午 ↔ 戌**（火引戌，戌代巳午） |
| **戊 / 己** | 戊引巳、戌、辰 ／ 己引午、未、丑 | **申酉 ↔ 丑**（金引丑，丑代申酉） |
| **庚 / 辛** | 庚引申 ／ 辛引酉、丑 | **亥子 ↔ 辰**（水引辰，辰代亥子） |
| **壬 / 癸** | 壬引亥、申 ／ 癸引子、辰、丑 | — |

```关系图
女命伤官运反而结婚的两种特殊情形
原局官杀多而混杂 → 伤官出现清理杂气，反而成婚（但婚姻质量一般不高）
原局官杀入墓于他星 → 需要伤官运或流年冲开、去阻碍，方能成婚
= 平时说“伤官克夫不宜结婚”，遇到以上两种原局结构时要反过来用。
```

## 四、常见误区 vs 正确问法

- **常见误区**：看到女命大运走到伤官运，或者流年碰上伤官，就直接断“这步运绝对结不了婚”。
- **正确问法**：先看原局“官杀是不是多而混杂，或者夫星有没有入墓于他星”，再问“这一步伤官运是不是正好坏掉了原局阻碍结婚的那个字”。
