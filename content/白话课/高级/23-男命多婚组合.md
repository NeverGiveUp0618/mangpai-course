# 男命为什么会多婚？看副宫配星、透不透劫，以及土财的反例

## 一、比初级、中级拓展了哪些

中级《婚姻专辑》已经讲过多婚的六条基本规则，以及“一星两宫带合”两婚的道理。高级《男命多婚组合》在此基础上，又把实操门槛和反例边界往前推了三层：

1. **用“副宫配星”精确数婚次**：明确同一颗配偶星，合一次算一次、冲一次也算一次（比如既被合又被冲，可多算一次）；而**差一个字**（比如癸财坐不坐副宫），就能把多婚变成一次婚外情。
2. **讲清“透不透劫财羊刃”的生死线**：同样是地支两禄，只要天干**不透**比肩、劫财、羊刃，两禄只代表自己，不会离婚；一旦透出劫财羊刃包制财星，立刻变成克妻多婚。
3. **补出核心反例——“土作妻星，逢刑冲反主一妻”**：满盘土财星（辰戌丑未）遇到刑冲，反而不主多婚，只主一妻（因为三土互相牵制，夫妻宫未被刑坏）；反倒是**不刑冲的土财星**，才可能表示桃花。

## 二、为什么有的男人一换再换，有的“一字之差”却不离？

把男命的婚姻比作开店合伙：有的人店面（妻宫）稳当，就算外面偶尔有生意往来，家里依然不散；有的人要么店面本身天天被人砸（妻宫被穿、被刑），要么店里刚进的货（妻星）一出门就被同行（比劫羊刃）明抢。

最容易让人看走眼的，是**“差一个字”**。原教材专门对比过两副只差一两字的男命盘：
- 同样坐下两个禄（比如两个午火），如果天干**没有透出**比肩、劫财或羊刃，这两个禄只是命主自己的分身，婚姻照样稳固，顶多配偶身体差一些；
- 可一旦年干透出一个劫财，地支两午再和戌连成一片，劫财就把财星彻底包住、克穿，瞬间就成了克妻、多结多离的命。

```关系图
男命多婚的五种核心触发路数
妻宫多现又配妻星，且妻宫不稳 → 婚姻组合多，易一婚不到头
妻宫虽单现，但被合坏、刑坏、穿坏 → 房子塌了，配偶待不住
妻宫没坏，但妻星被坏，另有新妻星 → 旧人去、新人来
妻星多合（或合一次算一个） → 宫星双合，往往两次以上婚姻
妻星落比劫上，或被羊刃劫财透干包制 → 比肩争妻、克妻，多结多离
= 婚姻顺次按“年早时晚”排，天干虚者短、地支实者长，大运凑成的过运则无。
```

## 三、男命多婚判别与反例速查

| 情形 | 关键特征 | 断法结论 |
|---|---|---|
| **宫星双合** | 一星对两宫，或一宫对两星，形成双拱/双合 | 命该两次婚姻：第一次合没到位，第二次才合到位 |
| **同一字多用** | 同一地支既配副宫、又被妻宫合或冲 | 合一次、冲一次各算一次婚姻（只要与妻宫产生关联） |
| **差一个字** | 财星是否坐在副宫上、有无劫财透干 | 不坐副宫则只算沾花惹草（一次婚）；无劫透则两禄只表自己 |
| **土财反例** | 满盘辰戌丑未土作妻星，且地支互相刑冲 | **反主一妻**（土多刑冲互相牵制，未坏夫妻宫） |
| **不刑冲的土财** | 土财星安静、不逢刑冲 | 反而可能代表婚外桃花 |

还要记住两条原教材的细则：
- **何时算离、何时再娶**：离的应期多在**穿倒妻宫、妻星入比劫地、或财星被合走**的流年；再娶则看**新妻星到位**（如时柱的亥、巳、午，或伤官库、代表年龄小的字）。
- **“有巳无巳”的天壤之别**：若第一妻星（如庚辰）被旁边的劫财（如乙巳）合走，初婚必离；原教材点明，如果原局没有那个劫财出现，前后财星就视同一个人，根本不会离。

## 四、常见误区 vs 正确问法

- **常见误区**：一看见男命地支财星多，尤其是辰戌丑未全了还带刑冲，就直断“财多身弱克妻、至少离三次”。
- **正确问法**：先问“这满盘财星是不是土？土财逢刑冲是不是互相牵制、反主一妻？”再问“天干有没有透出比劫羊刃去包制财星？这些财星是全配了副宫与妻宫，还是有的只算桃花？”
