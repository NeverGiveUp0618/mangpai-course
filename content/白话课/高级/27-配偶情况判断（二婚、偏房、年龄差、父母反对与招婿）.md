# 配偶情况判断：二婚、偏房、年龄差与招婿

## 一、比初级、中级拓展了哪些

初级与中级《婚姻专辑》主要解决“离不离、几婚、何时婚”，中级仅在“比劫争夫”里提过可能找二婚或当小的。本课在原有基础上拓展出六项极细的**配偶画像与关系来源**判法：

1. **精准判“配偶是否二婚”**：点出“比劫在前争夫、夫星从他宫出或入他墓、冲开他库”是对方已有前婚的硬标志。
2. **细拆“偏房、二奶与转正”**：立出“比劫争夫 + 偏印（或夫宫穿正印）”做偏房、“财合灭印”有夫无证、“破枭变印”正式转正的完整链条，并强调**辨别一人二人看天干**。
3. **分清“配偶外情”的轻重与明暗**：用“冲”主短暂偶尔、“暗合”主隐秘不知、“包局/三合稳固”主外情不断却不离。
4. **给出“年龄差”量化口诀**：区分男命伤官比劫旺找小的、不旺找大的，以及年柱拱主大、食神与戊癸合主老少配。
5. **补全“父母反对”的成败条件**：以印、食伤看父母态度，夫宫包夫星则反对也能成，星被穿或宫星自相刑则难成。
6. **新增“嫁后住娘家与招婿入赘”**：以女命月令为娘家，夫星落月令暗合夫宫主住娘家、六合主招女婿；男命月令乙庚合配穿离父母家主入赘。

## 二、生活类比：看清一张结婚证背后的“座位表”

断婚姻不只是问“领没领证”，更像是看一场饭局的座位表：主桌（夫妻宫）坐了谁，旁边（年月宾位）有没有人提前占过座，父母的座位（印与食伤）是帮着递筷子还是直接拍桌子反对。

比如同样是嫁人，如果“正印”这张合法婚书被夫妻宫穿坏了，旁边又站着抢座位的比劫和偏印，就容易变成没有名分的偏房；直到大运流年把偏印“破”掉、让正印透出来，才算正式转正上桌。而女命月令代表娘家，如果丈夫这颗星直接住在娘家院子里，还和夫妻宫暗暗拉手或六合，那多半就是嫁出去还常住娘家，甚至直接招女婿上门。

```关系图
判断配偶来历与名分的四条线索
比劫在前争星，或星从他宫他墓出 → 配偶多有前婚（找二婚）
比劫争夫见偏印，或夫宫穿正印 → 易做偏房无名分（破枭变印可转正）
男伤官比劫旺，或见食神、戊癸合 → 年龄差大（男易找小、女易找大）
夫星落月令暗合/六合夫宫 → 嫁后住娘家，或招婿入赘
= 先看“谁先来、谁占座、有没有正印”，再看年龄与住处。
```

## 三、配偶六项情况速查表

| 判断项目 | 核心判断标志 | 关键区别与结局 |
|---|---|---|
| **找二婚** | 夫（妻）星前有比劫争；星从他宫出、入他墓；寅申冲开库 | 比劫在前多主对方先有婚史；冲解前合后方能到位 |
| **偏房 / 二奶** | 比劫争夫 + 偏印；夫宫穿正印；财合灭印（有夫无证） | **正印**主明媒正娶；**破枭变印**则为偏房转正 |
| **配偶外情** | 比劫合/拱夫星；星入他墓；地支暗合或相冲 | 冲主短暂偶尔；暗合主隐瞒不知；宫稳（如三合/包局）则不离 |
| **年龄差** | 伤官主叛逆；妻星向年上拱主大；食神/戊癸合主老少配 | 男命伤官比劫旺易找小的，不旺易找大的；女命伤官旺易嫁老夫 |
| **父母反对** | 印、食伤代表父母克冲对象；星被穿或比肩争则难成 | 若**夫宫包夫星**，父母反对最终仍能成婚；自身与母各喜一字相刑则反复离 |
| **住娘家 / 招婿** | 女命月令为娘家，夫星落月令合夫宫；男命月令乙庚合且穿离父母 | 女命月令**暗合**夫宫主常住娘家，**六合**多主招女婿 |

## 四、常见误区 vs 正确问法

- **常见误区**：看到两个地支一模一样（比如两个丑、两个申），就默认是同一个人；或者一见比劫争夫，就断定自己一定是“被抛弃的正妻”，想不到二婚或偏房的可能。
- **正确问法**：先按原教材口诀问“天干透的是什么？”**辨别一人还是二人，关键看天干**，天干相克相反就是两个人；再问“命局里正印和偏印都在吗？夫宫有没有穿正印？”把名分、顺序和转正机会一次看清。
