# 差婚姻与好婚姻组合：别把好婚姻误断成多婚

## 一、比初级、中级拓展了哪些

中级《婚姻专辑》已经立过好婚姻与差婚姻的三条基本标准，但实战中只要学了“多婚”“伤克”“穿破”，很容易走偏——把本来能过一辈子的好婚姻看成“必离”，或者把只是吵架的差婚姻断成“几婚”。本课专门解决高阶**甄别与防误判**，拓展了四项关键规则：

1. **拆透“差婚姻为何不离”**：点明宫星虽有穿、破、刑，只要**被包局、合住或宫星本身未坏**，就只是吵闹凑合、分居而不离；大运把印食伤隔断或杀到绝地，才会关系越来越远。
2. **明确“宫星相克却被包住”反而是好婚**：看似宫克星或宫星相穿，但若通过天干延伸形成包局、或天干代表地支合身，反主婚姻稳固。
3. **给出“看似二妻二夫实为一人”的判法**：如**丁乙巳连体**、**寅戌相拱**、**癸卯一人**，外加**妻宫穿桃花星（如卯辰穿）反主排斥桃花**，都是一婚到头的好婚姻。
4. **破除“财多必多婚”的迷思**：点出男命桃花或多婚**一般要比劫旺才行**，比劫弱则没有精力与兴趣找桃花；同时补出**无财无食伤时直接以妻宫为妻**，看宫位之象（如丑为印墓主沾妻光）。

## 二、生活类比：吵了一辈子的老两口，和被误会成“花心”的老实人

街头常见两种夫妻：一种天天拌嘴、意见不合，甚至分房睡十几年，外人天天劝他们“干脆离了吧”，可俩人偏偏白头到老——这就是**差婚姻（不离但差）**，家里虽然天天磕磕碰碰（有穿、有破、有刑），但房门被包局或合局锁着，散不了。

另一种人则最容易被初学看命的人误判：八字里财星一堆、官杀混着出现，或者夫妻宫旁边带个桃花字，看起来像要结两三次婚。可实际上，要么那几个字是同一个人连体出来的，要么夫妻宫一脚把桃花星踹出门外（**宫穿桃花星，反过来排斥桃花**），要么自己比劫弱得根本懒得折腾感情——结果人家一婚到头，夫妻感情好得很。

```关系图
极易误判的好坏婚姻甄别线
宫星有穿破刑，但被包局或合住未坏 → 吵闹、分居、外情，但不离婚（差婚）
宫星看似相克或穿，但延伸包局、代表合身 → 矛盾被包住化解，反成好婚
看似两星或多财，实为连体一人或比劫弱 → 一婚到头，不以多婚论
妻宫穿桃花星（如卯辰穿） → 自己排斥桃花，从无外情且婚姻好
= 先查“是不是同一个人、有没有被包住、有没有比劫折腾”，再下断语。
```

## 三、常见误判现象 vs 实质与结论速查

| 盘面表象 | 容易犯的错 | 实质与正确结论 |
|---|---|---|
| **卯辰穿、卯午破、丑戌刑** | 见穿破刑就断“必离” | 若宫星被**包局、合住**未坏，只主吵架不和、分居或不离；大运若隔断印食伤则关系变淡 |
| **宫星相克（如午克申、子未穿）** | 见克穿就断“婚败” | 若宫延伸形成**包局**，或天干代表地支**合到日主**，反主婚姻稳固、感情好 |
| **同时见两官杀或两财星** | 见两星就断“二婚” | 若属于**连体**（如丁乙巳）、**相拱一人**（如寅戌），或天干地支一体（癸卯），均作一人看 |
| **男命财多、或见桃花星** | 见财多就断“花心多婚” | **男命桃花多婚须比劫旺**，比劫弱且官合身则受妻管束；**妻宫穿桃花星**反主排斥桃花 |
| **无财无食伤（男命）** | 找不到妻星就断“无妻” | **直接以妻宫为妻**，看妻宫所带之象（如丑为印墓带官，主沾妻光入仕途） |

## 四、常见误区 vs 正确问法

- **常见误区**：把“多婚”当成单一公式——见财多就断多婚、见两颗官杀就断两任丈夫、见宫穿桃花就断婚姻被破坏。
- **正确问法**：先问“这几个看似不同的星，能不能通过**连体、相拱、同象**归成一个人？”再问“这个男命的**比劫旺不旺**，他有没有精力和胆量去沾桃花？夫妻宫去穿的那个字，是不是**宾位的桃花**？”这样就不会把稳固的好婚姻看成烂桃花。
