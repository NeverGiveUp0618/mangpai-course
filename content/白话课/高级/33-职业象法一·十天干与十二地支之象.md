# 职业象法总词典：把十天干、十二地支拼成真实行业

## 一、比初级、中级拓展了哪些

中级第 03、06 课已经把十天干的“在天在地在人、逐干喜忌”和十二地支的三层视角讲透了。这一节高级课不再重复基础性情，而是把干支象义升级成一套**专门用来断职业、行业与病灾的实战词典**，拓展集中在三点：

1. **明确提出“大阴阳 vs 小阴阳”与十干尊卑**：大阴阳以木火为阳、金水为阴；小阴阳以甲丙戊庚壬为阳、乙丁己辛癸为阴，且十干以阳为尊贵、阴为卑贱。
2. **补全“职业＋病灾＋动物”四维象义**：集中补出许多中级未细列的职业与细节象——如丁为点/目标/高学历、戊独透易当老师、己为方向盘/道路、壬为运算/会计、癸为提纯西药/玄学；寅为枪弹暴力、卯为报纸/面食、辰为车辆/手机/电脑、酉为酒店/法律/病人、戌为数学/学校/教育部门、亥为会计、子为棋子/算盘、丑为肿瘤/黑社会。
3. **提炼出“取象的四个层次”**：给出从单字到完整职业画面的拼图方法论（干支相配 → 干支与十神综合 → 干支作用与变化 → 整体局象），作为后续八节职业专题课的总词典。

## 二、零件不是行业，把零件拼起来才是行业

中级学十天干、十二地支，像是认识一盒积木里每一块的颜色和材质；到了高级《职业象法》，则是教你把几块积木拼成“一辆赛车”“一张台球桌”“一家报社”或“一间妇产科手术室”。

比如看到**己酉**，己象方向盘、酉金食神可代表驾驶技术，旁边再来一个**酉戌穿**（戌为火库发动机，穿出速度），拼在一起就是**赛车手**；看到**甲辰**，辰含水为车、藏子为转动、水库主机器，连排成片就是**汽运公司**；看到**戊辰合酉**，辛酉是病人、辛是针、辰是水库带木气为汤药、戊辰劫财为手，拼在一起就是**针药并用、给病人把脉的好中医**。

```关系图
职业取象的四个层次：从零件拼出画面
第一层干支本身相配 → 如甲辰＝车、己酉＝方向盘与驾驶、丁丑＝落袋
第二层干支与十神综合 → 如癸伤官＝技术、丁官＝荣誉、印＝舞台或房子
第三层干支作用与变化 → 如卯辰穿＝运动、酉戌穿＝速度、子未穿＝拨算盘
第四层整体局象判定 → 如群阴一阳、三合制库、比劫手艺加包局成规模
= 职业不是靠背一个字猜出来的，而是四个层次拼成一幅动态画面。
```

例如在 <a class="qref" data-q="268">命例 268：坤造 乙未日 · 某地妇产医院的副院长助理</a> 里，之所以能落到医院、妇科主任医生且亲自做手术，就是把干支象、十神职能与做功结构拼在了一起；而在 <a class="qref" data-q="311">命例 311：坤造 丁亥日 · 自己独资开公司，做装修彩绘生意</a> 中，丙火漂亮落门户、火见水有化妆彩绘之意、亥为墨水、卯为文字文章、卯午破为用手加工，几层象叠在一起，就把“装修彩绘”四个字拼活了。

## 三、十天干与十二地支职业高频象速查

| 干支 | 高频职业与事物象 | 常见病灾与人体提示 |
|---|---|---|
| **甲 / 寅** | 首领、公门官府、高楼栋梁；寅含火又主枪弹、发动机、武装 | 头面、肝胆、筋与神经；寅病多中风、头疾 |
| **乙 / 卯** | 书纸、丝线、织物、传播传媒；卯又主报纸、面食、建材 | 颈、四肢、腕、肝胆；卯病多转筋、体痛 |
| **丙 / 午** | 影视传媒、色彩装饰、表演、广告；配壬水主光影色彩 | 眼、心、血液、神经；午病多心脑血管、出血 |
| **丁 / 巳** | 文化文字、电子网络、目标与点、高学历；巳主思想、玄学、中医 | 心、眼、血管、三焦咽喉；巳病多齿痛、目疾 |
| **戊 / 辰 / 戌** | 戊＝建筑、地产、**讲台（独透易当老师）**；辰＝水库、车船、电脑手机、中药；戌＝火库、学校、教育部门、**数学**、化工、装修 | 胃、皮肤、鼻；辰病多隆闭或肿瘤；戌病多胃热消渴 |
| **己 / 未 / 丑** | 己＝书本、建材、道路、方向盘；未＝酒店、休闲、食品、建筑；丑＝银行、军营、黑社会、玄学、矿井 | 脾胃、腹；未易肾亏眼疾；**丑为肿块肿瘤**、肺病 |
| **庚 / 申** | 五金钢材、机械车辆、金融、军警政法、理科、**西医手术**；庚无火炼为顽金 | 肺、大肠、骨齿；申病多肠疾、肺伤 |
| **辛 / 酉** | 珠宝玉器、精加工、法律、医药、针笔；酉又主**酒店、寺院、病人、死人** | 肺、耳、齿、精血；酉病多骨病、血疾 |
| **壬 / 子** | 壬＝运算、数字、**会计师**、航运贸易；子＝流转、车轮、**棋子、算盘**、数学哲学 | 口、肾、膀胱、血液；子病多水液或血液病 |
| **癸 / 亥** | 癸＝水墨、玄学谋略、美容产品、**提纯西药**；亥＝笔墨、酒水、数字运算、**会计**（食伤合财/被财墓/冲制财官/为财） | 肾、眼、脑、津液；亥病多痰湿、肝郁 |

## 四、常见误区 vs 正确问法

| 常见误区 | 正确问法 |
|---|---|
| “看到八字里有戊土就断一定当老师，看到有亥水就断一定做会计。” | “先看这个字在盘里有没有参与做功、和十神怎么配合，再看干支组合与作用关系是否拼出了讲台或算账的完整画面。” |
| “一个地支象表上写了十几个行业，到底该猜哪一个？” | “顺着‘干支相配→十神→作用变化→整体局象’四层往下收窄，能同时满足做功路径和组合关系的行业，才是命主真正在做的事。” |
| “庚金只要见了水就是金水伤官聪明秀气。” | “得看庚金有没有火炼：庚金旺而无火炼是顽铁，见癸水反主生锈、脑子不开窍，走水运金沉还可能应牢狱。” |
