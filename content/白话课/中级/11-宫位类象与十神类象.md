# 宫位加十神，把“谁在哪里”和“什么脾气”叠起来

## 一、比初级拓展了哪些

初级第 02、03 课已经系统讲过四柱宫位（六亲、时间、空间、人物、身体、物件、情商、表里）和十神的基本意向与虚透。

这节中级课在初级框架上**新拓展了三个实战方向**：
1. **宫位的精细实战定位**：补出**丈母娘在年上找**（年表外戚，与妻宫发生关联的印、伤食）、**主位（日）破到年上表肢体残疾且阳左阴右**、以及**时支专看车与门户交往**。
2. **十神“过旺负面 vs 有用职业”与正偏财新解**：明确十神过旺时的负面心性，并点破**正偏财不表示财的来源是正是偏（来源要看比劫做功与否），而表示人对钱财的心性**；同时细分“伤偏食正”（伤官玩乐型、食神付出型）。
3. **「十神看六亲」的通变与排序（核心拓展）**：系统给出看子女的**通变法则**（男杀+财=儿、杀无财=女、穿倒财生女、行伤官运生儿）与**七步排位次序**（日支①→时支②→时干③→月支④→月干⑤→年支⑥→年干⑦），以及父母的多元星位（正偏财与官杀皆可为父，食伤禄皆可为母）。

## 二、通讯录加说明书：宫位定落点，十神定脾气

在公司里，只看一张名片写着“经理”（十神），你不知道他在总部还是在门店（宫位）；反过来，只知道“二楼东侧办公室”（宫位），不知道里面坐的是财务还是法务（十神），照样没法办事。

中级把宫位叠进实战细节时，有三条非常具体：
- **丈母娘在年上找**：年柱本来代表外戚、长辈。只要年上出现和**妻宫**发生关联的印星、伤官或食神，就可以当丈母娘看（食神重感情，伤官无感情）；如果和妻宫毫无瓜葛，年上的伤官就可能是奶奶。
- **主位破到年上，看左右肢体**：年柱离日柱最远，在身体上代表腿、足、四肢。**必须是主位（日）去破到年上的字**，才代表自己控制不住这段肢体而容易残疾；方向上按**阳为左、阴为右**区分左右腿。
- **时支看车与外在门面**：时柱是门户，既管对外打交道，也管出门代步的**车**，买车、车祸或车辆被盗多在时支找。此外天干主外在表象、地支主内心与家庭关系。

结合 <a class="qref" data-q="675">命例 675：乾造 乙酉日 · 戊土财星虚透在时上</a> 可以看到，财星落在时上门户且虚透时，表达出的往往是外在的才华、交际、时尚打扮或来事能力，而不必先等同于手里攥着大笔固定现金；再看 <a class="qref" data-q="660">命例 660：乾造 丙申日 · 乙未运开医药门诊赚钱</a>，时上的门户之象与技能、房屋印星叠在一起，就能把“开临街门诊”这种具体营生定出来。

```关系图
宫位实战定位：先找位置与主宾关系
年上印或伤食 + 关联妻宫 → 丈母娘（无关联则伤官可看奶奶）
主位（日）破到年上 → 自己控不住腿足，按阳左阴右断残疾
时支见财或印 + 门户作用 → 看车辆出入、门面与对外性格
= 同一颗星换了宫位或断了关联，对应的人和物立刻不同。
```

## 三、十神的两面性：正偏财不看财源，伤食分付出与玩乐

十神不是“吉神永远吉、凶神永远凶”。中级课把每个十神拆成了**本义、心性、过旺负面、有用时的职业**四栏，帮你避开“一见正印就好、一见七杀就坏”的死板印象：
- **正印与偏印**：正印稳重仁慈，但**无官杀压力且过旺时容易懒惰、依赖、呆滞**；偏印敏锐、擅非正统学术（技术、五术、咨询、侦察），过旺则孤冷挑剔。
- **正官与七杀**：正官守规矩，过旺则胆小唯诺；七杀是凶神，**有制化才显权威与魄力，无制化则显匪气、懦弱或病灾**。
- **正财与偏财（关键纠偏）**：**正偏财不代表财的来源是正是偏，而是代表人对钱财的心性**（正财专一节俭、偏财慷慨投机）。一个人到底赚正财还是偏财，要看**比劫做功与否**——哪怕原局全是正财，只要比劫参与特殊做功，照样可能满手偏财。此外，年月财旺（尤其女命）多主“财多心乱”而早年辍学。
- **比肩与劫财**：比肩重自主合作，过旺则固执；劫财是凶神，有功用能助我运作、炒作得财，无功用则反致破财招灾。
- **食神与伤官**：**食神正、伤官偏**。食神是吉神，不怕旺只怕受克，属于专注、用情的**付出型**；伤官不受约束、想象力强、对感情不专，属于**玩乐型**，过旺易走极端。

## 四、十神看六亲：通变法则与排位次序

初级只讲了“以宫位为主、星位为辅”，中级专门展开了**子女**和**父母**的精细读法：

```关系图
十神看六亲：先抓原则，再看通变
男命看子女（原则：杀儿官女） → 杀+财=儿，杀无财=女，穿倒财生女
女命看子女（原则：伤儿食女） → 走伤官大运也可能生儿；墓库逢冲子女多
看父母星位（不死守一星） → 正偏财、官杀皆可为父；食、伤、禄皆可为母
= 星位是会随组合“通变”的，不能只背“偏财是父、正印是母”。
```

具体看子女的**先后次序**，原课给出了一条明确的七步路线：
**日支① → 时支② → 时干③ → 月支④ → 月干⑤ → 年支⑥ → 年干⑦**。墓库逢冲则子女多。

至于父母：**印星是父母星，父与母都表示，它是一个整体状态**；具体拆开时，正偏财、官杀都可以当父亲，食神、伤官、禄神都可以当母亲。如果用伤官做母亲（比如水火阴阳相配的组合），往往代表母亲离异改嫁、命主随母生活。

## 五、十神负面倾向与六亲规则速查表

| 类别 | 关键结论 / 过旺倾向 | 实战注意点 |
|---|---|---|
| 正印 / 偏印 | 正印过旺无官杀易懒惰依赖；偏印过旺冷淡挑剔 | 印是父母整体状态；正印正统学术，偏印非正统学术 |
| 正官 / 七杀 | 正官过旺胆小；七杀无制化为匪徒或病人 | 官杀也可当父亲、男性亲人；七杀必须制化 |
| 正财 / 偏财 | 正财过旺吝啬；偏财重交际投机与欲望 | **正偏财只表心性，不表财源；财源看比劫做功与否** |
| 比肩 / 劫财 | 比肩过旺固执；劫财无功用反致破财 | 比劫在年腿足部位，按阳左阴右分左右 |
| 食神 / 伤官 | 食神付出专一、怕受克；伤官玩乐叛逆、过旺走极端 | 男杀+财=儿、杀无财=女、穿倒财生女；伤官作母主改嫁 |
| 看子女次序 | 日支① → 时支② → 时干③ → 月支④ → 月干⑤ → 年支⑥ → 年干⑦ | 墓库逢冲主子女多；女命行伤官大运也可生儿 |

## 六、常见误区 vs 正确问法

| 常见误区 | 正确问法 |
|---|---|
| “我八字里全是正财、没有偏财，是不是一辈子只能拿死工资、不能做投资生意？” | “正偏财只说明我对钱财的心性，财源是正是偏要看原局比劫有没有参与做功、怎么取财。” |
| “男命盘里有七杀，是不是头胎就一定生儿子？” | “男命以杀为儿、官为女只是原则，还要看杀有没有配财（杀+财=儿、杀无财=女），以及有没有穿倒财星或走伤官运。” |

## 七、教材存疑与边界提示

原教材本课有三处保留说明：
1. 「十神类象简表」的“六亲”一栏在原稿整理中发生错位，教材明确要求以第三节“十神看六亲”的规则为准；
2. 某干造原稿记有“生在申时，母亲要改嫁”，但与所列盘中的时支午字不符，教材标注**存疑**；
3. 另有仅记三柱的断例，原稿注明时柱字不合、盘待校，此处只取其断法思路。
