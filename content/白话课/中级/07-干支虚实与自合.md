# 干支虚实与自合，像看清门面、货源流向和内部契约

## 一、比初级拓展了哪些

初级《干支配置（上）（下）》已经讲过自合、带象、通根坐库与单柱虚实；这一课在中级体系里把干支配置收束成实战规则，拓展出三个新重点：

1. **重新分类六十甲子，新增「干支假生」**：把六十甲子划为通禄八、托根十、带象、假生六（丁卯、癸酉、甲子、庚辰、庚戌、辛未）、相克二十，外加余四柱（戊辰、戊戌、己丑、己未）。特别点明“假生六柱”看似相生、实非真生，地支是可以被坏的，有些组合甚至要地支被坏才好。
2. **把「实化虚」拆成三种具体路径与两类生活事件**：明确虚就是“地支跑天上去了”，拆出本气虚、所藏旺气虚、墓气虚（不用冲即可虚而出墓）三种变化；同时把实化虚落到两类现实结果上——人（如妻子）离开，或做生意把货从多的一方运到少的一方卖出去（且明确流年实变虚无大事）。
3. **深化六个自合柱的内部方向、婚姻心理与反局取象**：聚焦丁亥、戊子、己亥、辛巳、壬午、癸巳六柱，点破唯二“地支克天干”的丁亥、辛巳；给出三组直观象义（井盖、水火既济、反晦自毁），并解释自合婚姻为何多不幸（理想完美且支不可坏）。

## 二、五类配置与「实化虚」：货源怎样跑上了门面

开一家店，仓库里堆着实打实的货，这是“实”；把货摆到门口展柜、印成宣传册挂上招牌，让人一眼看见名气与样式，这是“虚”。天干虚透不等于没用——财星虚透主**才气**，官杀虚透主**名气**，印星虚透主**包装、身份与荣誉**。

但要注意：并非所有“虚”都只是静态招牌。当一个地支在别处以天干形式露面，就叫**实化虚**，像人走了、或者货从产地流向市场卖掉了：

```关系图
实化虚的三条路径与大运规律
本气实化虚 → 年上有寅，别处见甲申，等于寅跑天上去了
旺气实化虚 → 地支所藏的旺气跑到别处透干（如寅虚成丙申）
墓气实化虚 → 墓中所藏之气透干（如未见乙酉），不用冲也能出墓
大运与流年 → 大运逢实化虚同原局论变化，流年逢之一般无大事
= 看到“实变虚”，先问是“人离开了”，还是“做生意把货卖出去了”。
```

| 类别 | 核心含义 | 代表柱子与要点 |
|---|---|---|
| 干支通禄（八柱） | 干通于支、连成一体 | 甲寅、乙卯、庚申、辛酉、壬子、癸亥、丁巳、丙午（四土库柱不称通禄） |
| 干支托根（十柱） | 干依支存，支坏则干坏 | 甲辰、乙未、乙亥、丙寅、丁未、戊午、己巳、辛丑、壬辰、壬申 |
| 干支带象 | 干生地支，干为头、支为身 | 如日坐食伤，日主有依托印星时地支可坏（原稿未列具体柱数，与托根有交叠） |
| 干支假生（六柱） | 看似相生，实非真生 | 丁卯、癸酉、甲子、庚辰、庚戌、辛未（地支可坏，如癸酉有时坏酉才好） |
| 干支相克（二十柱） | 天干虚透的主体（加庚戌、辛未共二十二柱） | 含自合六柱在内；子水虚透为癸，壬水不能代表子 |
| 余四柱 | 四土库日柱 | 戊辰、戊戌（阳库不喜刑冲）；己丑、己未（阴库须刑冲反吉） |

## 三、六个自合柱：内部契约为什么既能干事又容易脆弱

天干为君、地支为臣，平常都是天干管地支，地支管不到天干。但在六个自合柱里，**丁亥**（亥中壬合丁）和**辛巳**（巳中丙合辛）是唯二**地支反过来克天干**的组合，就像后宫专权把皇帝架空；而戊子、壬午、己亥、癸巳，虽然地支里也有对应藏干，仍是天干克地支（己亥、癸巳因地支本气受天干所克）。

```关系图
六个自合柱的象义与婚姻心理
戊子、己亥 → 像一口井盖把水盖在里面
壬午、癸巳 → 阴阳气交，水火既济之象
丁亥、辛巳 → 地支反克天干，天地反晦、自毁之象
婚姻与位置 → 心中理想太完美且坐支不可被合冲刑破，故婚姻多脆弱；喜配在时上发挥能力
= 自合代表“正星得正位”，越追求完美，就越经不起一点风吹草动。
```

同样一个盘的象，还要合乎现实生活条件。原教材最后用一则“身首分离”的反局命例提示：**象既要合于命理关系，又要合于生活年代**——在现代主高速车祸（两巳如车轮穿头），放在古代没有高速车，便取房子着火（印为房、火苗引爆）。

回到真实命例里看虚透与象义：<a class="qref" data-q="675">命例 675：乾造 乙酉日 · 戊土财星虚透在时上</a>，戊土财星虚透，便不主钱财而主才华、口才好与花钱大方；<a class="qref" data-q="676">命例 676：乾造 辛酉日 · 局中金水与日主一体成党</a>，则是月时印星己土虚透，在全局金水成党去制财官的结构里，反喜印虚透来代表文凭与文化。

## 四、常见误区与正确问法

- **常见误区**：「看到天干虚透就当“没根没力、一文不值”，或者看到正星自合（如正官自合）就一口咬定夫妻和美。」
- **正确问法**：「这个虚透的十神代表才气、名气还是荣誉？它是不是从原局某个地支“实化虚”跑出来的？若是自合，坐支有没有被合冲刑破，有没有因为标准太理想而反而脆弱？」
