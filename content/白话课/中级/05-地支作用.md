# 地支作用，像看清合作、交易、结党与开关

## 一、比初级拓展了哪些

初级课把六合、三合、暗合、冲、穿、刑、破、墓库拆开当成单个动作来认；到了这一课，中级教材把所有地支作用收成一张完整的实战网，重点拓展了四个层次：

1. **补齐藏干规律与刃的规则**：不再死记藏干表，而是按四长生（俱阳）、四帝旺（俱阴）、四墓库（三气俱阴）的规律推；同时明确只有阳日干有刃、壬子与丙午自坐刃、戊刃在未，天干见比劫也称刃。
2. **用生活交易与组织关系重整作用观**：六冲是“简单交易”、六合是“利益共同体（多数合坏、少数合好）”、三合是“结党（中神为核心，唯寅午戌以戌为中心）”，并把十二支分成木火阳党与金水阴党，强调“有党须有功”。
3. **分清做功强弱与阴阳胜负**：水火相冲看强弱、金木相冲一定金胜木；六穿里阳穿阳力大（寅巳最大、申亥最小），克穿（子未、卯辰、酉戌）可做功；破里卯午最凶、子卯次之、子酉相隔；丑戌刑能做功而未戌刑只开库。
4. **把墓库规则落到实战细节**：区分阳墓（辰戌气墓、凶小、不开也可用）与阴墓（丑未形墓、凶大、一定要开）；讲清开库三法（直开、旁开、开天库）与天引法（虚透引出）的效率排序，以及丑未亥子同见辰时的收墓优先级。

## 二、合作、交易、结党：先分清关系的性质

街角两家店做生意，有的只是你供货、我付款的简单买卖，一手交钱一手交货，各自还是独立老板；有的则是签了长约捆绑在一起，利润共享、风险同担，谁也不能随便单干；还有的是几家联合成立商会，平时各做各的，遇到大项目才按共同目标聚到一起。

地支之间的作用，也是这三种关系：

```关系图
地支作用的四条底层判断
六合（捆绑合作） → 粘合最强，多数合坏少合好，克合才易做功
六冲（往来交易） → 不失独立，水火既济、金木金胜、土墓开库
六穿（背后排斥） → 阳穿力大、克穿能做功，绝不可穿体与六亲
三合（团队结党） → 党多必须有功，光有团队不做事反成累赘
= 先认清“是合作、交易、排斥还是结党”，再问做没做成事、伤没伤到自己。
```

这里还要特别分清**暗合**与**六合**的差别。暗合（午亥、寅丑、卯申）粘接没六合那么死，彼此不丧失独立性，反而更容易在互补中做成生意——午亥、寅丑往往比六合更有价值；只有卯申是“合绝”，做功可以，落到婚姻人事上容易先合后伤。

| 作用 | 关系本质 | 能否做功 | 体与六亲禁忌 |
|---|---|---|---|
| 六合 | 粘接缠绊、得与失 | 克合（卯戌、巳申等）可做功；午未多为绊 | 贴近合易失自主；体被合坏不利 |
| 暗合 | 互补互通、不失自我 | 午亥、寅丑多吉；卯申可做功 | 卯申主“合绝”，婚姻人事易带克 |
| 六冲 | 往来互换、冲主动 | 土墓冲开库功大；体不喜动、用喜动 | 体不可被克冲（金冲木时木体易伤） |
| 六穿 | 排斥敌视、主速度 | 子未、卯辰、酉戌可做功；丑午有可能 | 不可穿体、不可穿六亲；墓不怕穿 |
| 三刑 | 寅巳申、丑戌未（只论这两组） | 丑戌刑能做功；未戌刑只开库 | 体与六亲不可被刑；流年第三字只引动 |
| 地支破 | 相生不生反破（子卯、卯午、子酉） | 一般不作做功，主损伤或特定职业象 | 不可破体；卯午破最凶，子酉为相隔 |

教材里对**三合与党**还留有两处要照原处保留的细节：一是三合中唯独“巳”能沟通阴阳，遇木火为火、遇酉丑则化为金；二是“木火阳党、金水阴党、阳土归阳党、阴土归阴党”的总原则下，原稿举例曾把阴土“未”列入阳党，这处口径前后不一致，学习时按原稿记录存疑，不自行硬改。

## 三、墓库开关：收进去容易，拿出来讲究方法

仓库门锁着，你知道里面堆满货物却取不出来，这叫“墓”；有钥匙能随时打开取用，这才叫“库”。同样是土，辰戌是阳墓（气墓），像阳宅或临时安置点，不开有时也能用，入阳墓凶也小；丑未是阴墓（形墓），像封闭的地下金库或坟墓，不开就彻底封死，入阴墓凶就大。

```关系图
墓库的入、出与开库路径
年月见神、日时见墓（或运来墓） → 入墓；反过来墓在前神在后 → 出墓
多而墓之 → 地支多现或天干相连通墓才入，本坐库（如辛丑）不直接入
开库三法 → 直开（冲刑）最全，旁开其次，开天库（干透神冲）再次
天引法 → 靠天干虚透把库中之神引出来，效率不如冲但主慢售之象
= 墓怕穿（逢穿不开），入墓先看清是“被收管”还是“我收别人”。
```

遇到**丑、未、亥、子同见辰**的复杂局面时，不能简单套用“丑未冲”，要先看辰这位“大管家”先收谁：丑未同见辰，辰与丑一党，辰只收丑不收未，丑未冲反而不成立；未子同见辰，辰不收未却拱子，子未穿反而更激烈；亥未同见辰则亥未合着一起入墓；亥子丑见辰则一起被辰收进墓里。

在实战里，冲与合、穿与体的配合往往一环扣一环。比如 <a class="qref" data-q="20">命例 20：乾造 甲寅日 · 与自己有关系，我自己要做一件事</a>，正是在大运卯申合与流年寅申冲的交替中，体现出“合来权力”与“冲破原有生扶路线”的起落；而 <a class="qref" data-q="77">命例 77：乾造 丙戌日 · 日主丙火合辛财，要看身强弱</a>，则是原局酉戌相穿，直接把日主依托的坐支根穿坏，使求财意向落空。

## 四、常见误区与正确问法

- **常见误区**：「六合就是关系好、贵人帮，冲和穿就是倒霉坏事；见丑未同现又有辰，还是直接按丑未冲开库来断。」
- **正确问法**：「这组合或冲落在谁身上？是“体”还是“用”？合有没有把好东西绊住、冲有没有把库打开或克伤体？遇到辰、丑、未同场时，有没有先核对辰先收丑的先后规则？」
