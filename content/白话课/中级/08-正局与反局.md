# 正局与反局，像看个人打算和公司大势是否同向

## 一、比初级拓展了哪些

初级教材**没有单设《正局与反局》这一课**，只在做功、冲穿章节里零散提过“体不可坏”“岁运别来拆台”。这一课在中级阶段系统立起了一套“日柱意向 vs 原局大势”的总校验规则：

1. **建立原局正反判定四步顺序**：先看日主，日主不做功看日支；日支看的是“追求意向”是否与大势对抗；日主与日支同做功时以日主为主；同时把**日合年月官**（我管人）与**日合时官**（我被管，时支是兵卒不可坏，尤其己日甲戌时、辛日丙申时）区分开来。
2. **明确「连体不可坏」的红线**：教你怎么分辨一个“用”是不是和日主通过生、通根连成一体——连体被坏就是反局、重则伤寿；不连体反而可以制。
3. **给出原局冲合反局的排列公式**：明确必须是地支冲合（干合支冲不算），按两党排列区分**交叉（ABAB）为反局**、**内外（ABBA）与左右（AABB）不反**。
4. **理清岁运冲合反局、大运体用与应期顺序**：原局有明确之制时，冲怕运合、合怕运冲；大运走干运干为用支为体、走支运支为用干为体；点出“七杀夹克主牢狱”以及流年代表字顺序（先地支后天干，地支先本气、再墓气、最后余气）。

## 二、个人意向与大势：先查日主，再看日支

一家公司正在全力压缩成本、回笼资金，如果某个部门经理私下拿着公章往外大笔放款，这就是“个人动作和公司大势相反”。放到八字里，整个盘成势要做的事是“大势”，日主和日支要做的事是“个人意向”——意向顺着大势走叫**正局**，逆着大势拆台就叫**反局**。

判定原局正反，按固定顺序一步步查：

```关系图
原局正反局的四步排查顺序
先看日主 → 日主合、生做功，就以日主意向为主（如日主与日支同做功，仍以日主为主）
转看日支 → 日主不做功，看日支追求的方向是否与全盘大势对抗
分日合官位置 → 合年月官是我管人，一般不反；合时官是我被管，时支为兵卒不可坏
查是否连体 → 被制之“用”若与日主连成一体，坏了它就是反局（重则伤寿）
= 记住口诀：日柱之意随大势为正，逆大势为反；反在哪一类，凶就应在哪一类。
```

这里有两个最容易踩坑的细节。第一是**日合时官**：时柱是主位、管头脑，日主合到时上的官，等于头脑受制于官，官坐下的时支就是兵卒，打仗必须用它、绝不能坏它（尤其是**己日配甲戌时、辛日配丙申时**，时支还是劫财“体”，体更不可坏）；可如果这柱官落在**月上**，变成日主主动去管理别人，就不要求非用它的坐支不可。

第二是**连体与不连体**：同样是金被火制，如果地支的金通过土生、通根和日主连成一体，这就是连体之“用”，一合坏就反局伤寿；如果日主和这个地支并不连体，那去制它反而是正局。

## 三、原局冲合反局与岁运反局

“冲”和“合”是两种相反的手段，好比一边猛踩油门、一边死踩刹车。但并非盘里一见冲和合就叫反局，核心要看**两党怎么站队**：

```关系图
地支冲合的两党排列判定
ABAB（两党交叉间隔） → 年月与日时手脚打架，构成冲合反局
ABBA（一党在内、一党在外） → 里制外或主制宾，手段不同但方向一致，不反
AABB（一党在左、一党在右） → 主位制宾位，阵营分明，不反
干合支冲 → 不算冲合反局，必须是地支与地支的冲合才算
= 先给两党分阵营，再看站队是“交叉打架”还是“阵营分明”。
```

| 反局类型 | 触发条件 | 后果与关键规则 |
|---|---|---|
| 原局反局 | 日主/日支意向逆大势、连体被坏、或地支两党交叉冲合 | 原局自带的凶（哪方面反局哪方面凶，如财反局则穷） |
| 岁运冲合反局 | 原局有**明确的制**（冲或合），大运流年用相反方式破它 | 原局冲做功怕运来合，原局合做功怕运来冲；无明确制则不怕 |
| 大运反局 | 大运意思与原局相反，或对抗原局且制不住 | 只凶这一步大运，过运则吉（走干运干为用支为体，走支运支为用干为体） |
| 流年反局 | 某一年引动破坏原局功神或连体 | 应在该年；应期顺序先地支后天干，地支先本气、再墓气、最后余气 |

岁运冲合反局在真实命局里非常经典。比如 <a class="qref" data-q="151">命例 151：乾造 丙申日 · 两申入了丑墓与未冲为去印库</a>，原局两申入丑墓冲未，本来是“靠冲做功”，但一走到卯运，卯与申合，把原本“冲”的路线扭成了“合”，构成冲合反局，结果应在父亲破财；又如 <a class="qref" data-q="152">命例 152：坤造 辛未日 · 原局是制财库，故此命发大财</a>，原局丑未冲制财库本是大吉，行至己巳大运甲申流年，岁运天地合绊把原本相冲的两党合住，冲被反掉，这一年应了严重车祸。

## 四、常见误区与正确问法

- **常见误区**：「只要八字里既有冲又有合就断成冲合反局，或者看到某一步大运反局就以为这辈子彻底完了。」
- **正确问法**：「盘里的冲和合是天干还是地支？两党是交叉排列（ABAB）还是内外/左右排列？原局有没有明确的制？如果是大运反局，过了这一步运之后，原局的功还在不在？」
