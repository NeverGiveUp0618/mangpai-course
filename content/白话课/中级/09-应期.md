# 应期进阶，看清大运怎么动、流年怎么点

## 一、比初级拓展了哪些

初级《应期入门》已经讲过四柱大限（1–18 岁、18–35 岁、35–55 岁、55 岁后）与交脱诀、通禄与现原身的“出现”、虚实与贼捕结构，以及基本的刑冲合穿墓口诀。

这节中级课在初级基础上**新拓展了三个实战核心**：
1. **冲与合的精细辨析**：不再笼统把“冲”当成动或破，而是细分为“冲而破 vs 冲而动”“弱神冲旺神之冲而应合”“合而应冲”“财动促合”，并补出“活木两根不敢坏、一根可坏”。
2. **大运体用的动态切换（全新）**：同一柱大运（如丁未运），前五年走天干运时“干为用、支为体”，后五年走地支运时“支为用、干为体”，主客与控局角色互换，结局截然不同。
3. **遁藏透干的次序与连环应期**：明确乙木反推地支的先后次序（先卯、再未、最后辰），以及开库闭库联动、跨越多年的连环应期（起因→到位→临旺→制服）。

## 二、大限是时间门框，大运与流年是门锁

把人生比作一栋四进的院子：年、月、日、时四个柱子就像四道时间门框，先划出这件事大概率落在哪个年龄段（1–18、18–35、35–55、55 岁后）。但门框只是范围，**真正开门的钥匙在大运和流年**。

原课把大限与大运的关系总结成“与”门逻辑：**大限和大运都吉才应吉，都凶才应凶**；一吉一凶就像门框没问题但钥匙卡住了，事情往往往后推到“过运”才应。反过来，如果大限本身应凶，只是后面有一步好运，那么在还没走到好运之前，凶事照样先发生。

同时，禄与原身、遁藏透干依然是找“谁到场了”的优先捷径：
- **禄与原身优先**：原局有某天干，流年或大运见到它的禄（或原局有某地支，岁运天干见它的原身），就等于它亲自到场，按它在原局里的作用论吉凶。注意辰戌丑未四库没有原身。
- **遁藏透干有次序**：地支藏干透到岁运天干，代表该地支的信息要变动（如寅可透丙甲戊，辰可透乙癸）；反过来天干“乙”出现时，对应地支有先后次序：**先卯、再未、最后辰**。

## 三、同样是“冲”，为什么有时是发财、有时是破局？

生活中，同样是“推一把”：推一把稳稳停在坡上的货车，可能只是让它启动开跑；推一把本就摇摇欲坠的违章棚子，一推就散架了。

盲派看岁运相冲，就是先分“被冲的一方在原局是旺还是弱、当运还是不当运”：

```关系图
岁运出现“冲”，先看原局根基与当运否
局中本弱，旺神来冲 → 冲而破（不是动，是直接坏掉）
局中本旺，逢流年冲 → 冲而动（动起来发挥作用）
弱神去冲旺神 → 冲而应合（冲动旺神，反去克伤它所克之物）
原局有合，逢冲 → 合而应冲（或“财动促合”，把合局里的事催出来）
= 冲字本身没有固定吉凶，必须先看谁旺谁弱、原本有合还是有冲。
```

另外两条实战铁律也常决定生死与成败：
- **流年冲大运**：当运的字被冲叫“冲去”，不当运的字被冲叫“冲起”（对应“旺冲衰为冲去，旺冲旺为冲起”）。
- **活木怕埋根之铁**：活木只要还有**两个根**，一般不敢轻易坏根；只有**一个根**时，一旦岁运坏了这个根，就变成死木而应凶。

结合 <a class="qref" data-q="615">命例 615：乾造 甲戌日 · 原局成火与燥土之势</a> 可以看到，原局的合与病一旦确立，大运走到对应组合时，应期往往不是单年完成，而是沿着“起因年（合起）→ 到位年 → 临旺年 → 制住年”走出一串连环节点；而 <a class="qref" data-q="626">命例 626：乾造 乙巳日 · 泄秀兼制杀为功，丑穿午必有应丁为食神</a> 则直观展示了禄通原身（丁通禄于午）在穿害应期中如何连带出人际与成果的变动。

## 四、大运的“体用切换”：前五年和后五年不是同一个人管事

初级只讲了整步大运的吉凶方向，中级进一步点破：一柱大运干支管十年，**前五年和后五年，“干”和“支”谁当动态主事者（用），谁当静态被控者（体），会直接对调**。

就像一家门店，前五年由外联经理（天干）出面签合同、后台主管（地支）配合；后五年换成后台主管（地支）亲自拍板、外联经理（天干）退居静态。字还是那两个字，谁动谁静一换，结果可能从“破财”变成“合作赚钱”。

```关系图
大运分前后五年，干支体用会互换
走天干运（前五年） → 天干为用（动态主事），地支为体（静态被控）
走地支运（后五年） → 地支为用（动态主事），天干为体（静态被控）
= 同一柱大运的干与支，不能混成一团算；体被穿是状态差，用被控或制局才定实际进退。
```

这点在两则真实命例里体现得最清楚：
- 看 <a class="qref" data-q="614">命例 614：乾造 戊辰日 · 戊土长生在寅，因为没有印</a>：走到同一个天干与地支组合的大运时，天干主事的五年里，劫财主动去合财，主破财；等换到地支主事的后五年，原先那个劫财天干不再主动运动、退成了静态的“体”，同样的相合关系反而变成合作取财。
- 再看 <a class="qref" data-q="607">命例 607：乾造 壬子日 · 内食神泄用作功，内食神主企业</a>：走天干运时，天干合身而地支的“体”被主位穿了，结果只是心情极度郁闷、官位不动；一旦进入地支运，地支变成主动的“用”，把天干之“体”收归自己控制，反而进管理部门升职（只是依然带穿，所以是副职）。

## 五、中级应期规则速查表

| 维度 | 核心规则 | 实战注意点 |
|---|---|---|
| 大限与交脱 | 年 1–18、月 18–35、日 35–55、时 55 后 | 大限与大运“同吉才吉、同凶才凶”；一吉一凶多推到过运 |
| 禄与原身 | 见禄代表原身，见原身代表禄（四库无原身） | 具有优先性；到场后按原局中的作用论吉凶 |
| 遁藏透干 | 地支藏干透出岁运天干，即该地支变动之应 | 乙木反推地支有先后次序：先卯、再未、最后辰 |
| 冲的细分 | 冲去/冲起、冲而破/冲而动、冲而应合、财动促合 | 先辨原局旺弱与是否当运；原局有合以冲应，有冲以合应 |
| 根的耐受 | 活木有两根不敢坏，一根可坏 | 坏根后活木转死木，多应在寿元或重疾 |
| 大运体用 | 干运干用支体，支运支用干体 | 同一柱大运前后五年作用方式可能反转，须分开断 |

## 六、常见误区 vs 正确问法

| 常见误区 | 正确问法 |
|---|---|
| “流年冲了财星/夫妻宫，今年是不是肯定要动、要发财或要离婚？” | “被冲的字在原局是旺还是弱、当运还是不当运？这次冲是‘冲而动’‘冲而破’，还是‘弱冲旺而应合’？” |
| “这步大运是干支一柱，前五年和后五年吉凶应该差不多吧？” | “走天干运时干为用、支为体，走地支运时支为用、干为体；角色互换后，谁在主动发生作用、谁被控制住了？” |

## 七、教材存疑与边界提示

原教材在讲解大限克父与岁运应期时，同一命造在“大限应期”一节记为走寅运应期（寅穿巳），而在“岁运作用应期”一节又记为丁丑运甲戌年应期（弱冲旺而应合）。两处应期记载并不一致，教材本身明确标注**存疑**。学习时应保留这种谨慎口径，重点吸收各自对应的断法逻辑，不必替原稿强行统一答案。
