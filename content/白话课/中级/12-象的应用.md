# 七条取象原则，从百种含义里锁定唯一答案

## 一、比初级拓展了哪些

初级课程只分散讲过宫位、十神的基础象和简单的“换象”，还没解决一个最让人头疼的实战问题：**同一个字同时带着几十种干支、宫位、十神含义，落到具体命局里到底取哪一个？**

这节中级课是整套象法体系的**总收口与方法论升级（全新内容）**：
1. **七条取象原则（全新体系）**：提炼出**共象、合象、化象、墓象、制象、带象、借象**七把筛子，把静态象（干支、宫位、十神、神煞）与动态作用（生合、刑冲、穿墓）合起来精准定象。
2. **带象“吃西瓜理论”与官财帽子口诀**：讲透“财带官帽、官带财帽、印带官帽、印带财帽”，并用年干“西瓜皮”与年支“西瓜肉”分出真富与假富。
3. **夫妻宫的副宫与时空八字**：明确夫妻宫副宫的两种判定条件（引出字 / 同五行字），并展示如何用起盘时间的“时空八字”套用同套原则问事。

## 二、商场找人：先用“共象”和“合象”缩小包围圈

在大型商场里找人，只说“找个穿黑色外套的”（单个干支象），你能找到几百人；但如果加上“在三楼财务室”（宫位象）+“手里拿着公章”（十神象）+“正和法务签合同”（合象），人立刻就锁定了。

**1. 共象原则：两类以上指向同一件事，就能拍板**
把干支、宫位、十神、神煞四类静态象叠在一起，只要有**两类以上**说出差不多的意思，这个象就确立了。比如乙木日主时上见丁火：丁干象是眼睛，时柱宫位也是眼睛，食神主窍、眼睛也是窍——三类象交叉于一点，这个丁火就铁定当眼睛看（若被克合坏，就应眼疾）。此外，用起盘时间起的“时空八字”，也是靠这套交叉定位来断当下事。

**2. 合象原则：要么复合描述，要么互用对方的象**
合象有两层用法：
- **复合描述**：一个字身上多种象互相定义，比如“建筑物（戌）+ 作品（食神）”＝建筑设计。
- **相合双方互用对方的象（仅限原局中有的合）**：天干五合与地支六合就像夫妻成家，“你中有我、我中有你”。比如**劫财合财＝劫取而得的财（投机或赌博）**；**食神合印＝思想性学问（学术）**；**伤官合印＝技能技艺**。再比如“阳制阴”的组合（如阳木制阴湿丑辰），在警政执法与司法行业里非常典型。

```关系图
拿到一个字，先用前四条原则做交叉定象
共象（静态交叉） → 干支、宫位、十神两类以上指向同一物，直接确立
合象（互定性质） → 原局相合双方互借含义（如劫财合财、食神合印）
化象（生化转化） → 阴木生火为纺织服装，阳木生火为家具，辰配子为化工提纯
墓象（收藏机构） → 按所墓之神定机构（如七杀入羊刃库＝军队）
= 先找静态交集，再看合、生、墓把象“加工”成了什么具体行业。
```

## 三、制象、带象与借象：把关系和头衔读透

定出基础行业后，接下来要看**制法（谁用什么手段制谁）**、**带象（头和脚怎么搭配）**和**借象（谁能替谁出面）**。

**3. 制象原则**：合制、克制、冲制、刑制、穿制，都能把双方的象揉在一起推出行业或事情。比如财库（丑）去刑冲印库与劫财库（未），劫财主资本运作、印库主实体企业，合起来就是靠资本运作搞实业地产；比如羊刃库穿印，多主军权或政法实权，若再合伤官火象（文），则是军队里的文职官员。可结合 <a class="qref" data-q="9">命例 9：坤造 己巳日 · 壬被丙冲制，子被午冲制印党很大</a> 与 <a class="qref" data-q="30">命例 30：乾造 戊子日 · 一午冲两子，就是两个事情</a> 体会冲制关系如何直接决定事情数量与成败。

**4. 带象原则（以干统支）与“吃西瓜理论”**：
一柱干支，干像头、支像身体，认识一个人先看头再看身，所以**以干统支之象**，干决定支的特点：
- **财带官帽**＝公家之财；
- **官带财帽**＝管理财的官（官当财看）；
- **印带官帽**＝权力；
- **印带财帽**（或财带印帽）＝薪水、上班领工资（财来自单位印中）。
此外还有一句经验口诀：**辛金、酉金配丙丁火时，辛酉多代表“人”**（如病人、死人或手术、执法对象）。

说到财富真假，原课给出了极形象的**吃西瓜理论**：把**年干当成西瓜皮，年支当成西瓜肉**（年柱本身是带象或见禄的同象）。日主如果能合到或制到代表“西瓜肉”的地支实质，叫**吃了西瓜肉、丢了西瓜皮——富命**（皮肉一起吃也是富命）；如果只合到虚浮在天干的“西瓜皮”，没拿到地支的实质，叫**吃了西瓜皮、丢了西瓜肉——穷命**。可参看 <a class="qref" data-q="20">命例 20：乾造 甲寅日 · 与自己有关系，我自己要做一件事</a> 理解“必须与自己发生实质关联”才算真正拿到手。

```关系图
带象与借象：分清“头衔归属”与“谁能替谁”
干统支（带象） → 财带官帽是公家财，官带财帽是管财的官
吃西瓜（辨真富） → 得年支实质（瓜肉）为富，只得年干（瓜皮）为穷
借象（通禄与同五行） → 天干通禄、同五行不同阴阳，可互借其象
夫妻宫副宫 → 从夫妻宫引出的字，或与夫妻宫同五行的字（多则多婚）
= 别只看表面合到了什么字，要追问它底下坐着什么实质、和主位连没连上。
```

**5. 借象原则与夫妻宫副宫**：
有两种关系可以互借其象：一是**天干通禄神**（如丙象不明，就看巳怎么定象）；二是**同五行但阴阳不同**（如寅与卯互借）。
落到婚姻上，除了日支正位外，还有两种**夫妻宫的副宫**：①从夫妻宫引出来的字（或夫妻宫是从某字引出来的）；②与夫妻宫**同五行**的字。只要命局里出现多个妻宫（含副宫）与妻星，往往就主好几次婚姻。

## 四、七条取象原则速查表

| 原则 | 一句话核心 | 典型断法示例 |
|---|---|---|
| 共象 | 两类以上象指向同一事物，即可确立 | 丁在时上+食神＝眼睛；甲申＝颈椎 |
| 合象 | 复合描述，或原局相合双方互用其象 | 劫财合财＝赌徒/劫财；食神合印＝学术；伤官合印＝技艺 |
| 化象 | 生、三合、半合转化成新的行业象 | 阴木生火＝纺织服装；阳木生火＝家具；辰配子＝化工制药 |
| 墓象 | 墓为收藏控制，按所墓之神定机构 | 七杀入羊刃库＝军队；丑（隐蔽）控申＝公安部门 |
| 制象 | 合克冲刑穿制，取复合象推行业与事情 | 丑戌刑＝财库被制发财；丑未冲＝资本运作+实业 |
| 带象 | 干统支；“吃西瓜”辨得实还是得虚 | 财带官帽＝公财；官带财帽＝管财官；得瓜肉为富 |
| 借象 | 天干通禄、同五行不同阴阳互借其象 | 寅借卯作副宫；癸透自辰则辰与癸可互借取象 |

## 五、常见误区 vs 正确问法

| 常见误区 | 正确问法 |
|---|---|
| “日主合到了年干的财星，是不是说明命主一定会发大财？” | “先看合到的是‘西瓜皮’（虚透天干）还是‘西瓜肉’（地支实质根基与财库），再看有没有破或穿。” |
| “一个字在类象表里有二十多种意思，到底该猜哪一个？” | “不要硬猜：先用共象看两类以上交叉点，再用合、化、墓、制、带、借去过滤，交叉出来的才是唯一答案。” |

## 六、教材存疑与边界提示

原教材本课有几处保持了谨慎口径：
1. 某乾造“连体不怕制，戌土不通，制戌库”，原稿注明“是当官还是黑道，尚未讲清”，明确标注**存疑**；
2. 教材中部分因“盘不合历法”而从略的例子，仅保留其取象推理方式（如酉表人、吃西瓜取财等），读者应以题库校对后的真实命例为准。
