# 官命怎么看：区分“管人掌权”和“借台赚钱”

## 一、比初级拓展了哪些

初级课讲过官杀与印的基本类象，以及制局里“我制官”和“官制我”都能出官象的思路。中级《官命看法》把官命直接拉成一套可对照的实战清单：

1. **给出了官命的六种标准组合与效率高低**：明确区分“制用”与“生用、化用”的级别差距。
2. **细化了部门特征与“帽子”规则**：通过做功地支判断检法、公安、纪检或文职；并提出**官戴财帽（偏企业）**与**财戴官帽（偏管财行政官）**的区别。
3. **补上了“根与虚实”的硬门槛**：官杀虚透只主名气，实与虚在被合时结果完全相反。

## 二、成官的底座：有官有印、有根、连主位

把当官比作在一家大机构里拿任命书。**官杀**好比职务头衔，**印**好比公章实权；光有头衔没有公章，或者公章放在别人抽屉里跟自己无关，都算不上真当官。

```关系图
判断官命的三道门槛
官杀与印 → 必须至少有核心做功组合，且大多须有根
主位参与 → 功必须落在主位或与主位相连，否则易转向发财
制要干净 → 对抗不分胜负不算，制不净多为官小或改去求财
= 官杀虚透只算名气；大运把它落实时，才容易应到实际职务。
```

原教材总结了可成官命的**六种组合**：官杀配印、官杀配伤官、官杀配劫刃、印配财星、印配食伤、印配比禄（官禄格）。整体规律是：**制用做功的效率高于生用、化用**；纯靠印去化官杀，往往级别有限。

| 分类维度 | 关键组合 | 典型走向 / 部门倾向 |
|---|---|---|
| **制用与化用** | 伤食制官杀、刃杀相制、财制印 | 制得干净则权大；化用做功效率偏低，级别相对小 |
| **执法与文职** | 申酉做功 / 申酉丑寅 / 刃＋杀 | 申酉偏检法法律；申酉丑寅偏公安；刃杀偏执法实权；伤官泄刃反主文笔文官（刃空不带枪） |
| **企业与行政** | 官戴财帽 vs 财戴官帽 | **戴什么帽子以什么为主**：官戴财帽以财为主（多为国企经营者）；财戴官帽以官为主（多为管财行政官） |

## 三、两个最容易看走眼的细节：虚实与摘帽

在原教材的对照案例里，有两个极关键的分界线：

1. **天干的虚与实，决定“被合”是好事还是坏事**：同样是命局要制水，如果天干透出的水在原局**有根（实）**，大运来合它，等于把它固定拴住，反而是制住了；如果天干的水**无根（虚）**，原局本来靠克去制它，大运一来合，反而是把功神合走、救了它，立刻变成反局丢官。
2. **印戴官帽，最怕大运摘帽或坏印**：印在主位带官帽当权，大运流年如果把天干那顶“官帽”合走，或者直接冲穿坏掉那颗印，就容易应验免职、丢官。哪怕只是**差一个时辰**，官星虚实一变、能不能合回主位一变，格局就会从“当官”变成“做企业”。

## 四、常见误区 vs 正确问法

- **常见误区**：见到命盘里官杀多、或者官印相生，就直接断“官运亨通”；见到伤官克官，就一律当成“克官没官命”。
- **正确问法**：先问“官杀和印有没有根？做功有没有主位的字参与？”再问“如果是伤官或比劫去制官杀，到底有没有制干净？如果戴着财帽或官帽，重心到底落在管企业还是管行政？”
