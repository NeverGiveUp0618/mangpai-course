# 干支像百科，神煞只取最管用的五个

## 一、比初级拓展了哪些

初级第 05 课主要讲了十天干与四墓库的五行生克特性（如死活木、燥湿土、金的刚柔特性、水动静），第 07 课只讲了禄与原身的基本对应。

这节中级课在初级基础上**新拓展了三大板块**：
1. **干支四维类象与形体口诀**：把十天干、十二地支全面对应到自然事物、人体器官、人性心性与几何形状，并补出地支**三种阴阳分法**（特别是**丑、酉纯阴**的特殊性）以及文理科、行业的快速定位。
2. **六十干支自身象与组合象（全新）**：如丁丑（盲派）、乙未（建筑）、甲申（脊椎颈椎）、己卯（幼苗豆芽）等单柱象，以及**阳木遇火为家具、阴木遇火为纺织**、**丙配癸才算眼睛**等组合象。
3. **盲派五大神煞类象（全新）**：明确舍弃传统命书繁杂低效的神煞，只保留**禄神、羊刃、墓库、驿马、空亡**五个，讲清各自的心性、行业与查询口径。

## 二、给符号建实体清单：先看形状与阴阳，再看组合

学类象好比做刑侦或设计：只知道“木生火”太抽象，落到生活里，它可能是做家具，也可能是卖衣服。干支象就是把抽象符号和现实事物一一挂钩。

记十天干先抓**“形”**的对比：
- **甲直、乙曲**：甲是大树、高楼、直路、经脉；乙是藤条、花草、织物、丝线、颈与脊柱。
- **丙大、丁小**：丙是太阳、广场、演说、大眼睛、大场面；丁是星火、文字、玄学、电子、内心的细光。
- **戊方、己平**：戊是山丘、建筑、仓库、古董；己是田园、房屋、皮肤、曲线与粉尘。
- **庚棱角、辛致密**：庚是顽铁、机器、大路、军队警察；辛是珠宝、针剪、法律、精细加工。
- **壬无规则、癸圆润**：壬是江河、航运、贸易、血液；癸是雨露、墨水、谋略、眼泪与精血。

到了十二地支，中级特别强调**三种阴阳分法**各有用途：
1. **按五行分**：木火为阳（寅卯辰巳午未），金水为阴（申酉戌亥子丑）；其中辰为阳中阴，戌为阴中阳。
2. **按本身位置分**：子寅辰午申戌为阳，丑卯巳未酉亥为阴。
3. **按遁藏分**：**丑、酉是纯阴之物（阴中之阴）**。亥虽在阴位但中含阳，子虽为阴但位在阳，都不算阴中阴。

因为丑酉纯阴，多与隐蔽、犯罪、黑道、玄学、牢狱或阴暗面有关；但不能一见就乱贴标签——原课专门对比：**辛酉日主见丑时**，阴见阴又入墓，容易走黑道；而**辛丑日主**则是浊中见清，人性是好的，不能当成黑社会。

```关系图
拿到干支组合，快速锁定行业与学科
木火组合 vs 金水组合 → 木火多主文科，金水多主理科
戌亥 / 丑 / 申酉 → 戌亥主数学运算，丑主玄学，申酉主法律（申兼金融）
辰见走动或见子 → 辰本身表车与机器，辰见子为化学、提纯
阳木遇火 vs 阴木遇火 → 阳木遇火做家具装潢，阴木遇火做纺织服装
= 同一五行换了阴阳或搭配，落到现实里的行业立刻分家。
```

另外，**丙配癸才算眼睛**（丙为眼眶、癸为瞳孔眼珠），癸被火烤干则眼盲；而“甲遇丁火头发稀”，原稿也顺带存疑“寅木遇午火是否同样头发稀”。结合 <a class="qref" data-q="660">命例 660：乾造 丙申日 · 乙未运开医药门诊赚钱</a> 可以体会地支“未”（药品、技术）与“酉”（门面）如何叠出具体职业；而 <a class="qref" data-q="680">命例 680：乾造 辛丑日 · 从事建筑与地产业</a> 则体现了土建干支组合在行业上的落点。

## 三、工具箱做减法：为什么盲派只讲这五个神煞？

传统命书里神煞动辄几十上百个，在实际断命里应验率很低。盲派就像老木匠出门，不背花哨工具，只带五个最管用的：**禄神、羊刃、墓库、驿马、空亡**（严格说前三个是十干本气与墓气，因象极丰富而单列）。

1. **禄神（日主的延伸）**：
   代表日主亲临地支行使权力，核心看“配不配印”与“有没有绊桃花”：
   - **禄印相随**主有福气、享受、略懒惰；**禄不配印**（尤其禄去冲财）主亲自操劳辛苦。
   - 女命禄合伤官、官杀、财星，或禄逢三合，为“禄绊桃花”；但合到夫妻宫或合到印星，**不算桃花**。
   可参看 <a class="qref" data-q="676">命例 676：乾造 辛酉日 · 局中金水与日主一体成党</a> 中禄神与食神的配合。

2. **羊刃（阳干独有）**：
   只有甲（卯/乙）、丙（午/丁）、戊（未/巳，原稿如此）、庚（酉/辛）、壬（子/癸）五阳干有羊刃，阴干没有。它比劫财更凶悍，代表刀枪、手术、执法与炒作，**核心看“喜制服”**：制之得用正，可做军警、执法、外科医生、运动员；无制服而用偏，则易成赌徒、打斗或非法谋营。

3. **墓库（按所收十神定机构）**：
   凡是聚集众多的地方都是库。羊刃库＝军团营地；伤官食神库＝寺庙学校；财库＝银行；官杀库＝权力中心、组织部门。

4. **驿马（与传统查法不同）**：
   盲派驿马以**年柱和日柱**为主（日柱最明显），口诀按三合局整组算：申子辰见寅午戌都是驿马，寅午戌见申子辰，巳酉丑见亥卯未，亥卯未见巳酉丑。驿马主走动、车船、远行，**逢合则停留不动**。

5. **空亡（有其气而无其形）**：
   以日主或年柱查六甲空亡。空亡主“有名无实、减半、挂名、影子、务虚”。如果所用之神旺相而空亡，反而适合佛道、玄学、五术、艺术等务虚领域。大运可以论空亡（只是一种象），**流年不讲空亡**。

## 四、干支关键象与五大神煞速查表

| 类别 | 核心口诀与对应 | 实战提醒 |
|---|---|---|
| 典型单柱象 | 丁丑（盲派）、乙未（建筑）、甲申（脊椎颈椎）、辛未（蒜辣）、己卯（幼苗豆芽）、戊戌（水泥墩子） | 单柱先定底色，再看生克穿合出的新象 |
| 禄神 | 甲寅、乙卯、丙戊巳、丁己午、庚申、辛酉、壬亥、癸子 | 禄印相随享受，禄冲财辛苦；禄合印、合夫妻宫不算桃花 |
| 羊刃 | 仅阳干有：甲卯、丙午、戊未（或巳）、庚酉、壬子（亦可看天干） | 喜制服；有制用正（军警医），无制用偏（赌斗非法） |
| 墓库 | 刃库（军团）、伤食库（学校寺庙）、财库（银行）、官杀库（权力中心） | 必须与干支十神象匹配，才能定出具体机构 |
| 驿马 | 申子辰↔寅午戌；巳酉丑↔亥卯未（互为驿马） | 以年、日柱为主查；逢合则停留不动 |
| 空亡 | 甲子空戌亥、甲戌空申酉、甲申空午未、甲午空辰巳、甲辰空寅卯、甲寅空子丑 | 金空鸣、火空发、水空流、木空朽、土空陷；流年不讲 |

## 五、常见误区 vs 正确问法

| 常见误区 | 正确问法 |
|---|---|
| “命里带了天乙贵人、华盖、亡神，是不是一定有贵人或孤独？” | “盲派不堆砌传统神煞，先看禄、刃、库、马、空亡这五个里面，原局究竟出现了哪几个、怎么参与做功？” |
| “这个盘里既有丑又有酉，是不是一定和黑社会或犯罪有关？” | “丑酉纯阴确实偏阴暗面，但它是浊中见清，还是阴见阴又入墓？在原局里是被制还是无制？” |

## 六、教材存疑与边界提示

原教材本课有几处明确保留了存疑或从略说明：
1. 戊干的羊刃，原稿记为“未（或巳，原稿如此）”；
2. “甲遇丁火头发稀”的口诀旁，原稿自注存疑：“寅木遇午火头发稀吗？”；
3. “官杀空亡反断生儿”的命例，原稿注明尚有部分断法未讲清；
4. 导游命例因原稿盘与注记年份不符，教材只保留其“辰为车、酉在门户合车”的断法逻辑。学习时照此保留边界即可，不必强行圆说。
