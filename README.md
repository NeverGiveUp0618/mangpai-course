# 盲派八字 · mangpai-course

仿「命理精讲」的盲派八字学习站：**学**（初/中/高级课程）、**查**（专题与答疑）、**练**（命例库，三层展开＋吸顶四柱盘）、搜索、我的笔记、阅读进度。
本地项目，**尚未发布**（资料版权来自段建业系，发布前先确认）。

## 流程
```
_src/txt/*.txt（原始资料提取文本，不进 git）
   └ python3 convert.py   → content/{初级,中级,高级,专题}/*.md + _src/cases.json + _src/books.json
        └ python3 build_mp.py → data/data-{meta,course,notes,quiz}.js
             └ NODE_PATH=../bazi-course/node_modules node smoke_mp.js
```
`_patch_app.py`：从 bazi-course 复制 app.js/index.html 并改成本站（存储键 `mp_course_*`，去掉入站自检、断命台、v课、复习卡）。

## 教材（改写稿）
课程分两层：`content/教材/{初,中,高}级/` 是**改写后的教材**（归纳消化、知识点不丢、带小结与自测，规范见 `content/教材/STYLE.md`，覆盖清单在 `_coverage/`，体检 `python3 check_textbook.py`）；`content/{初,中,高}级/` 是**逐字整理的原稿**，在站内各级下的「原稿讲义」折叠组里，供查对。build_mp.py 两层都读。

## 体检脚本
- `check_textbook.py`：教材盘面历法校验、禁用词。
- `verify_textbook.py`：教材 vs 原稿抽查（盘面在原稿是否出现、作用方式条目与术语有无丢失），报告 `_src/verify_report.md`。2026-11-08：1397 个盘，52 个在原稿无逐字同款，其中 44 个历法校验全过（原稿的大运行夹在干支行之间所致，非编造），丢失术语 0。
- `_gap.py`：生成专题「我没学过」对照页（只读 ../bazi-course）。
- 已知做不到：面授笔记里「此造」命例的盘在 .doc 里没有图片也没有文本，无法补录，需用户另提供原件。
